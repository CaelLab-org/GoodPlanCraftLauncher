GoodPlanCraftLauncher

سبک · کارآمد · متن‌باز

لانچری برای Minecraft نوشته‌شده برای Windows: ورود Microsoft و آفلاین، مدیریت نسخه‌ها و نصب یک‌کلیکی Forge / Fabric / OptiFine. وقتی بازی کرش می‌کند، دلیلش را می‌گوید، نه فقط یک کادر خالی.

پنجره بالا قابل کلیک است — این خود رابط لانچر است که داخل صفحه وب اجرا می‌شود.

ویژگی‌ها

ویژگی‌های اصلی

ابزارهای کاربردی برای بازیکنان، هر کدام برای اینکه سریع‌تر وارد بازی شوید

دو حالت ورود

ورود Microsoft و آفلاین، قابل تغییر در هر زمان؛ حالت آفلاین نیازی به تأیید آنلاین ندارد.

دانلود مود یکپارچه

در Modrinth وCurseForge جستجو کنید و مودها، شیدرها یا بسته‌های منابع را در پوشه‌ای که نسخه انتخاب‌شده واقعاً استفاده می‌کند نصب کنید.

چهار لودر مود

Forge، NeoForge، Fabric و OptiFine از منابع رسمی نصب می‌شوند و نسخه Java ابتدا بررسی می‌شود.

۲۵ زبان رابط

در اولین اجرا از زبان سیستم پیروی می‌کند و هر زمان از تنظیمات قابل تغییر است.

مدیریت خودکار نسخه‌ها

دانلود، نصب و تغییر نسخه‌های Minecraft با یک کلیک، با مدیریت خودکار کتابخانه‌ها و فایل‌های بازی.

شروع سریع

مسیر اجرای سبک و کش، تا کلیک کنید و بازی کنید، نه اینکه منتظر بمانید.

مدیریت محیط اجرای Java

محیط اجرای Java را خودکار تشخیص و نصب می‌کند؛ منبع دانلود را می‌توان روی Tsinghua، دانشگاه نانجینگ، Huawei Cloud یا منبع رسمی گذاشت و در صورت خطا به منبع بعدی می‌رود.

پشتیبانی از پوسته

پشتیبانی کامل از حالت روشن و تاریک، با مقیاس رابط قابل تنظیم برای ظاهری یکدست.

به‌روزرسانی و نگهداری خودکار

بررسی به‌روزرسانی داخلی و پاکسازی خودکار قابل تنظیم لاگ‌ها، تا لانچر در طول زمان سبک بماند.

اعلان کرش و گزارش خطا

وقتی بازی غیرعادی بسته می‌شود دلیل را توضیح می‌دهد و می‌تواند با یک کلیک گزارش خطا صادر کند (گزارش کرش + لاگ‌ها + اطلاعات سیستم).

پنل اجرا

پس از اجرا، پنلی در سمت راست نسخه، PID، زمان اجرا و مصرف حافظه را نشان می‌دهد و می‌تواند بازی را در هر لحظه ببندد.

عنوان دلخواه پنجره

عنوان پنجره بازی را خودتان بنویسید، با واژه‌های جادویی مثل {mc_version} و {time}.

تصاویر

تصاویر واقعی

پنجره بالای صفحه بازسازی وب رابط لانچر است و بدون نصب چیزی قابل کلیک است. چهار تصویر زیر لانچر در حال اجرا روی Windows است، بدون ویرایش.

v1.9.3 دانلودهای Java از صف مشترک دانلود استفاده می‌کنند آخرین 2026-10-29
  • دانلودهای Java اکنون از همان صف نسخه‌های بازی و مادها استفاده می‌کنند: پیشرفت، سرعت، نوبت و لغو در نوار پایین.
  • مشکل آینهٔ پیش‌فرض Tsinghua که همیشه شکست می‌خورد رفع شد: لانچر User-Agent مرورگر می‌فرستاد و آینه آن را رد می‌کرد.
  • آینهٔ Huawei Cloud حذف شد (دیگر فایل ارائه نمی‌دهد)؛ اگر قبلاً آن را انتخاب کرده بودید، لانچر به‌طور خودکار به Tsinghua برمی‌گردد.
  • تنظیم آینهٔ Java اکنون واقعاً اعمال می‌شود: قبلاً فقط ذخیره می‌شد و هنگام دانلود خوانده نمی‌شد.
  • رانتایم‌های Java اکنون داخل پوشهٔ بازی نصب می‌شوند، بنابراین پوشه‌های بازی سفارشی (رایانه‌های مدرسه، پروفایل‌های رومینگ) کار می‌کنند.
  • اگر شبکه نیاز به ورود داشته باشد (احراز هویت پروکسی)، به‌جای پیام سادهٔ «دانلود ناموفق» پیام روشن و ثبت در لاگ نشان داده می‌شود.
  • خطاهای نصب Java دقیق‌تر شده‌اند (فایل بسیار کوچک / آرشیو خراب / منبعی موجود نیست) و Java سیستمی دیگر از لانچر حذف نمی‌شود.
  • دانلود مجدد ناموفق دیگر پوشهٔ نسخهٔ موجود را پاک نمی‌کند.
  • نصب Java در پنل دانلود نمایش داده می‌شود، قابل لغو است و در پس‌زمینه ادامه نمی‌یابد.
v1.9.2 اولین نسخه لینوکس (آزمایشی) و اتصال CaelLabMinecraft 2026-10-24

  • اتصال جدید CaelLabMinecraft: از تنظیمات فعالش کنید و حساب مایکروسافت را با کد اتصال وصل کنید
  • Java های نصب‌شده روی سیستم (Program Files، JAVA_HOME و…) به‌طور خودکار پیدا می‌شوند و برای هر نسخه می‌توانید جداگانه انتخابشان کنید؛ دیگر دانلود تکراری انجام نمی‌شود
  • دانلود Java پایدارتر شد: اگر جدیدترین بیلد هنوز روی mirror همگام‌سازی نشده باشد، از بیلد قدیمی‌تر موجود در همان mirror استفاده می‌شود و اگر API در دسترس نباشد، فهرست فایل‌های mirror به کار می‌آید
  • مشکل خالی بودن آیکون پنجره اصلی برطرف شد؛ اکنون آیکون لانچر درست نمایش داده می‌شود
  • مشکل خرابی بررسی به‌روزرسانی برای شماره نسخه‌های با پسوند حرفی برطرف شد
  • در ویندوز، دانلود بازی کتابخانه‌های غیرضروریِ این پلتفرم را نادیده می‌گیرد و فایل کمتری دانلود می‌شود
v1.9.1 حساب‌های Microsoft، چند پوشه بازی و Java برای هر نسخه 2026-10-23

  • توکن‌های ورود پیش از اجرا به‌طور خودکار تمدید می‌شوند؛ اگر منقضی شوند، لانچر به‌جای خطا هنگام ورود به سرور از شما می‌خواهد دوباره وارد شوید
  • حساب‌های ذخیره‌شده سر واقعی اسکین ماینکرفت را نشان می‌دهند
  • چند پوشه بازی اضافه کنید و نسخه‌ها را بر اساس پوشه فیلتر کنید؛ با انتخاب یک پوشه والد مانند ریشه PCL2، پوشه .minecraft داخل آن خودکار پیدا می‌شود

  • تحلیل خرابی در هر ۲۵ زبان در دسترس است و گزارش خطا اکنون منطقه زمانی و زمان محلی شما را شامل می‌شود
  • پنل دانلود نمودار زنده سرعت، سرعت فعلی و اوج و کارهای در صف را نشان می‌دهد؛ سرعت را می‌توان بر حسب MB/s یا Mbps نمایش داد
  • دانلود Java به زبانه جداگانه‌ای در صفحه دانلود منتقل شد
  • مصرف حافظه در صفحه تنظیمات اکنون به‌صورت زنده به‌روزرسانی می‌شود و عدد قدیمی زمان باز شدن صفحه را نشان نمی‌دهد
  • با حذف نسخه انتخاب‌شده فوراً به فهرست نسخه‌ها برمی‌گردید و نسخه حذف‌شده دیگر نمایش داده نمی‌شود
v1.9.0 صفحهٔ دانلود تازه، با پشتیبانی از مادپک و شیدر 2026-10-23
  • پیشرفت دانلود حالا پایین پنجره است: در همان صفحه‌ای که هستید بمانید؛ نوار، فایل، پیشرفت و سرعت را نشان می‌دهد و با باز کردنش فهرست کامل دانلودها را می‌بینید و هر وقت بخواهید لغو می‌کنید
  • صفحهٔ دانلود حالا بخش‌های شیدر، بستهٔ منابع و مادپک دارد: مادپک‌های Modrinth و CurseForge با یک کلیک نصب می‌شوند، آرشیوهای محلی وارد می‌شوند و NeoForge پشتیبانی می‌شود
  • جداسازی نسخه‌ها حالا یک تنظیم مشخص است: هر نسخه به‌طور پیش‌فرض مادها، سیوها و تنظیمات خودش را دارد، با پنج سطح و کلید جدا برای هر نسخه
  • هنگام دانلود می‌توانید برای نسخه نام بگذارید و یک نمونهٔ جدا بسازید تا تنظیمات ماد مختلف با هم تداخل نکنند
  • جست‌وجوی ماد بسیار سریع‌تر شده: «همهٔ منابع» موازی و با فشرده‌سازی اجرا می‌شود، جست‌وجوهای تکراری از حافظهٔ موقت می‌آیند و جست‌وجوی چینی ابتدا نام انگلیسی را در ویکی پیدا می‌کند
  • جست‌وجوی ماد بر اساس ارتباط مرتب می‌شود و منابع یکی‌درمیان می‌آیند؛ صفحهٔ جزئیات منبع نام چینی را نشان می‌دهد و در تنظیمات می‌توانید منبع ماد و واژه‌نامهٔ دلخواه اضافه کنید
  • لودرهای ماد حالا ناسازگار با هم هستند: با انتخاب Forge بقیه «ناسازگار» علامت می‌خورند، فهرست مقصد فقط نسخه‌های سازگار را نشان می‌دهد و دکمه مقصد را می‌نویسد
  • دانلودهای ناقص، لغو کند و به‌روز نشدن پنجرهٔ اصلی پس از حذف نسخه رفع شد؛ نصب اول دیگر انیمیشن شروع را پخش نمی‌کند
