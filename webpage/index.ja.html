GoodPlanCraftLauncher

軽量 · 高効率 · オープンソース

Windows 向けに作られた Minecraft ランチャーです。Microsoft ログインとオフラインログイン、バージョン管理、Forge / Fabric / OptiFine のワンクリック導入に対応。ゲームがクラッシュしたときも、空のダイアログではなく原因を表示します。

バージョン v1.9.1 / 更新日 2026-10-23 / 対応環境 Windows 10 以降

上のウィンドウはクリックできます — ページの中で動いているランチャーの画面そのものです。

機能

主な機能

プレイヤー向けの実用的な機能を、どれもゲームを早く始められるように設計しています

2 種類のログイン

Microsoft ログインとオフラインログインをいつでも切り替えられます。オフラインモードはオンライン認証が不要です。

MOD のダウンロードを内蔵

Modrinth と CurseForge を検索し、MOD・シェーダー・リソースパックを選択中のバージョンが実際に使うフォルダーへインストールします。

4 つの MOD ローダー

Forge、NeoForge、Fabric、OptiFine を公式ソースからインストールし、Java のバージョンも事前に確認します。

25 言語のインターフェース

初回起動時はシステム言語に従い、その後は設定でいつでも切り替えられます。

バージョンの自動管理

Minecraft の各バージョンをワンクリックでダウンロード・インストール・切り替え。ライブラリとアセットも自動で処理します。

高速な起動

起動経路を簡素化し、キャッシュを活用。待たされず、クリックすればすぐ遊べます。

Java ランタイムの管理

Java ランタイムを自動で検出・導入します。ダウンロード元は清華大学、南京大学、Huawei Cloud、公式から選べ、失敗すると次のソースに切り替わります。

テーマ対応

ライトモードとダークモードに完全対応。画面スケーリングも調整でき、見た目が崩れません。

自動更新とメンテナンス

更新チェックを内蔵し、ログの自動削除も設定可能。長く使っても軽いままです。

クラッシュ通知とエラーレポート

ゲームが異常終了すると原因を説明し、エラーレポートをワンクリックで出力できます（クラッシュレポート + ログ + システム情報）。

実行中パネル

起動後、右側のパネルにバージョン、PID、稼働時間、メモリ使用量を表示し、いつでもゲームを終了できます。

ウィンドウタイトルのカスタム

ゲームウィンドウのタイトルを自由に設定できます。{mc_version} や {time} などのマジックワードに対応。

スクリーンショット

実際の画面

動作環境

システム要件

高くはありませんが、確認しておくと安心です

オペレーティングシステム

Windows 10 64 ビット（1709 以降）。Windows 11 でも動作します

Java ランタイム

ランチャーが自動で導入します。システム上に重複した Java や競合する Java がある場合は整理をおすすめします

ストレージ

ランチャー本体に 90 MB 以上の空き容量（ゲームデータは含みません）

メモリ

2 GB 以上の空きメモリを推奨

v1.6.1 クラッシュの原因を、はっきりと 2026-10-21
  • クラッシュを自動診断します（メモリ不足、Java のバージョン違い、前提 MOD の不足、GPU ドライバー、OptiFine / Forge の非互換など）。ダイアログには結論を 1〜2 件表示します
  • 「詳細を表示」で手がかりと根拠の行をすべて確認できます。「ログを表示」はクラッシュしたバージョンのゲームディレクトリを開きます
  • エラーレポートは完全な zip として出力します: 診断結果、エラー概要、システムと GPU、Java バージョン、バージョンと MOD ローダー、MOD / リソースパック / シェーダーの一覧、起動引数、ゲーム出力、クラッシュレポート
  • レポートでは --accessToken とシステムのユーザー名を伏せ字にするため、そのまま他の人に送って調査を頼めます
  • 複数のゲームを同時に起動していても、各セッションが自分の出力を保持するため、クラッシュの情報が別のバージョンに混ざりません
  • MOD 詳細ページを作り直しました: 中国語・英語名、ダウンロード数、カテゴリタグ、MC バージョン別のファイル一覧、前提 MOD カード、Modrinth / CurseForge / MCMod へのリンク、名前のワンクリックコピー
  • 1.20.1 向けの前提 MOD が 1.20 として解決され、Fabric API / GeckoLib のバージョンが重複して Fabric が Incompatible mods found を出し起動しない不具合を修正
  • MOD を導入すると同じプロジェクトの古い jar を削除するため、複数バージョンが溜まらなくなりました
