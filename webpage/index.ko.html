GoodPlanCraftLauncher

가볍게 · 빠르게 · 오픈소스

Windows용으로 만든 Minecraft 런처입니다. Microsoft 로그인과 오프라인 로그인, 버전 관리, Forge / Fabric / OptiFine 원클릭 설치를 지원합니다. 게임이 중단되면 빈 창만 띄우지 않고 이유를 알려 줍니다.

지금 다운로드
버전 v1.9.1 / 업데이트 2026-10-23 / 플랫폼 Windows 10 이상

위 창은 클릭할 수 있습니다 — 웹 페이지 안에서 실행되는 런처 인터페이스 자체입니다.

기능

핵심 기능

플레이어를 위한 실용적인 기능으로, 모두 게임에 더 빨리 들어가도록 설계했습니다

두 가지 로그인 방식

Microsoft 로그인과 오프라인 로그인을 언제든 전환할 수 있습니다. 오프라인 모드는 온라인 인증이 필요 없습니다.

모드 다운로드 내장

Modrinth와 CurseForge를 검색해 모드, 셰이더, 리소스 팩을 선택한 버전이 실제로 쓰는 폴더에 설치합니다.

네 가지 모드 로더

Forge, NeoForge, Fabric, OptiFine을 공식 소스에서 설치하며 Java 버전도 먼저 확인합니다.

25개 인터페이스 언어

첫 실행 시 시스템 언어를 따르고, 이후 설정에서 언제든 바꿀 수 있습니다.

자동 버전 관리

Minecraft 버전을 원클릭으로 다운로드, 설치, 전환하며 라이브러리와 에셋도 자동으로 처리합니다.

빠른 시작

시작 경로를 간소화하고 캐시를 활용해 기다리지 않고 클릭하면 바로 플레이할 수 있습니다.

Java 런타임 관리

Java 런타임을 자동으로 감지하고 설치합니다. 다운로드 소스는 칭화대, 난징대, Huawei Cloud, 공식 소스 중에서 선택할 수 있으며 실패하면 다음 소스로 넘어갑니다.

테마 지원

라이트 모드와 다크 모드를 완전히 지원하며 화면 배율도 조절할 수 있어 일관된 화면을 유지합니다.

자동 업데이트와 유지 관리

업데이트 확인을 내장하고 로그 자동 정리를 설정할 수 있어 오래 사용해도 가볍습니다.

중단 알림과 오류 보고서

게임이 비정상 종료되면 이유를 알려 주고 오류 보고서를 원클릭으로 내보낼 수 있습니다(중단 보고서 + 로그 + 시스템 정보).

실행 중 패널

게임을 시작하면 오른쪽 패널에 버전, PID, 실행 시간, 메모리 사용량이 표시되고 언제든 게임을 종료할 수 있습니다.

창 제목 사용자 지정

게임 창 제목을 직접 작성할 수 있으며 {mc_version}, {time} 같은 매직 워드를 지원합니다.

스크린샷

실제 화면

위쪽 창은 런처 인터페이스를 웹으로 재현한 것으로 설치 없이 조작할 수 있습니다. 아래 네 장은 Windows에서 실제로 실행한 런처 화면이며 보정하지 않았습니다.

버전 기록

이전 버전과 변경 사항

v1.9.1 Microsoft 계정, 여러 게임 폴더, 버전별 Java 최신 2026-10-23
  • Microsoft 로그인을 새로 만들었습니다. 여러 계정을 저장하고 언제든 전환하거나 삭제할 수 있으며, 런처를 다시 시작해도 로그인이 유지됩니다
  • 실행 전에 로그인 토큰을 자동으로 갱신합니다. 토큰이 만료되면 다시 로그인하도록 안내하고, 서버 접속 시 실패하지 않습니다
  • 저장된 계정에 실제 Minecraft 스킨 머리가 표시됩니다
  • 게임 폴더를 여러 개 추가하고 폴더별로 버전을 필터링할 수 있습니다. PCL2 루트 같은 상위 폴더를 고르면 안의 .minecraft를 자동으로 찾습니다
  • 버전마다 Java를 따로 선택할 수 있습니다(자동 / 8 / 16 / 17 / 21 / 25 / 사용자 지정 경로)
  • 크래시 분석이 25개 언어를 모두 지원하고, 오류 보고서에 시간대와 현지 시간이 추가되었습니다
  • 다운로드 패널에 실시간 속도 그래프, 현재 및 최고 속도, 대기 중인 작업이 표시됩니다. 속도 단위는 MB/s 또는 Mbps로 선택할 수 있습니다
  • Java 런타임 다운로드를 다운로드 페이지의 별도 탭으로 옮겼습니다
  • 설정 페이지의 메모리 사용량이 실시간으로 갱신되어, 페이지를 열었을 때의 오래된 숫자가 아니게 되었습니다
  • 선택한 버전을 삭제하면 즉시 버전 목록으로 돌아가고, 삭제된 버전이 계속 표시되지 않습니다
v1.9.0 다운로드 화면 개편, 모드팩과 셰이더 지원 2026-10-23
  • 다운로드 진행 상황이 창 아래로 이동했습니다. 현재 페이지에 그대로 있으면서 막대에서 파일, 진행률, 속도를 볼 수 있고, 펼치면 전체 다운로드 목록에서 언제든 취소할 수 있습니다
  • 다운로드 화면에 셰이더, 리소스 팩, 모드팩 탭이 추가되었습니다. Modrinth와 CurseForge 모드팩을 한 번에 설치하고 로컬 압축 파일도 가져올 수 있으며 NeoForge도 지원합니다
  • 버전 격리가 명확한 설정이 되었습니다. 기본적으로 각 버전이 자체 모드, 저장, 설정을 가지며 다섯 단계 중에서 고를 수 있고 버전별로 따로 켜고 끌 수 있습니다
  • 다운로드할 때 버전 이름을 지정해 별도 인스턴스를 만들 수 있어, 서로 다른 모드 구성이 충돌하지 않습니다
  • 모드 검색이 훨씬 빨라졌습니다. «모든 소스»가 병렬 및 압축으로 동작하고, 반복 검색은 캐시에서 나오며, 중국어 검색은 먼저 위키에서 영어 이름을 찾습니다
  • 모드 검색은 관련도순으로 정렬되고 소스가 번갈아 표시됩니다. 상세 화면에는 중국어 이름의 출처가 표시되며, 설정에서 사용자 지정 모드 소스와 용어 사전을 추가할 수 있습니다
  • 모드 로더가 상호 배타적으로 바뀌었습니다. Forge를 고르면 나머지는 «호환되지 않음»으로 표시되고, 설치 대상 목록에는 호환되는 버전만 나오며 버튼에 대상이 표시됩니다
  • 잘린 다운로드, 느린 취소, 버전 삭제 후 메인 화면이 갱신되지 않는 문제를 수정했습니다. 첫 설치 시 오프닝 애니메이션도 제거했습니다
v1.8.0 런처부터 공식 사이트까지, 25개 언어 2026-10-22
  • 런처가 이제 25개 언어를 지원합니다. 설정 → 모양 → 인터페이스 언어에서 바꿀 수 있고, 목록을 검색할 수도 있습니다
  • 첫 실행 시 시스템 언어를 따르며, 시작 안내에서 먼저 고를 수도 있습니다
  • 처음 사용자를 위한 시작 안내를 추가했습니다. 언어, 화면 스타일, 간단한 소개로 이루어진 4단계이며 건너뛸 수 있습니다
  • 화면 스타일이 세 가지로 늘었습니다: Minecraft, 고급(기존 모습), 미니멀
  • 설치 프로그램도 같은 25개 언어로 번역되었고, 시스템 언어를 자동으로 선택합니다
  • 도움말 센터가 25개 언어를 지원하며, 런처의 도움말 링크는 인터페이스 언어에 맞는 페이지를 엽니다
  • 공식 사이트와 사이트 안의 체험 화면도 25개 언어를 지원합니다
  • 아랍어, 페르시아어, 히브리어에서는 인터페이스 전체가 오른쪽에서 왼쪽으로 배치됩니다
  • 시작할 때 깜빡임이 사라졌습니다. 시작 화면과 메인 화면을 한 페이지로 합치고 창 배경색이 테마를 따릅니다. 언어를 바꿔 다시 불러올 때도 검게 변하지 않습니다
v1.7.2 사용자 지정 아바타와 검색할 수 있는 버전 목록 2026-10-22
  • 시작 화면 아바타를 바꿀 수 있습니다. 아바타를 클릭하거나 설정 → 화면 → 아바타에서 이미지를 고르면 되고, PNG / JPG / GIF / WebP를 지원합니다
  • 1 MB가 넘는 이미지는 압축할지 묻습니다. 상한은 4 MB이며 기본 아바타를 원클릭으로 되돌릴 수 있습니다
  • 화면 설정에 '아바타 크기' 슬라이더가 추가되었습니다. 범위는 32~160픽셀입니다
  • 버전 목록에 검색 상자가 생겼습니다. 각 버전에 게임 버전과 모드 로더가 표시되고 선택한 항목이 강조됩니다
  • 버전 목록을 새로고침해도 목록을 다시 만들지 않아 스크롤 위치가 유지됩니다. '로컬 버전 가져오기'는 목록 오른쪽 위로 옮겼습니다
  • 1.20 이상에서 '서버 접속'을 고르면 바로 연결됩니다. 주소가 없으면 조용히 싱글플레이를 시작하지 않고 안내를 표시합니다
  • 버전 설정을 자동 저장할 때마다 '저장됨' 팝업이 뜨지 않습니다
  • 설치 파일이 약 103 MB에서 93 MB로 줄었습니다. 중국어와 영어 언어 팩만 유지하며 다른 언어는 영어로 대체됩니다
  • 1.7.1은 공개하지 않은 내부 테스트 빌드로 철회되었습니다. 1.7.2에 그 변경 사항이 모두 들어 있습니다
v1.7.0 셰이더, 리소스 팩, 모드팩을 원클릭으로 설치 2026-10-22
  • 다운로드 페이지에 셰이더와 리소스 팩 탭이 추가되었습니다. Modrinth / CurseForge에서 검색해 선택한 버전의 해당 폴더에 바로 설치합니다
  • 새 모드팩 탭은 Modrinth(.mrpack)와 CurseForge 모드팩을 지원하며, 맞는 게임 버전과 모드 로더, 모든 모드를 자동으로 설치합니다
  • 모드팩마다 별도 버전이 만들어져 모드, 설정, 저장 파일이 각자의 폴더에 들어가므로 모드팩끼리 섞이지 않습니다
  • 로컬 모드팩도 가져올 수 있습니다. 버전 관리에서 zip / .mrpack을 고르고 이름을 입력하면 설치가 시작됩니다
  • 모드팩 파일은 매니페스트의 크기와 SHA1로 검증하므로 덜 받은 jar를 다시 받아오고, 실행되지 않는 게임이 생기지 않습니다
  • NeoForge를 Forge / Fabric처럼 버전별로 설치할 수 있습니다(1.20.1 이상)
  • '더 보기' 메뉴가 기본으로 접혀 있습니다. 필요할 때 설정 → 화면에서 켤 수 있으며, 다시 시작하면 다시 나타나던 문제도 수정했습니다
v1.6.1 중단 원인을 그대로 알려 줍니다 2026-10-21
  • 중단 원인을 자동으로 진단합니다(메모리 부족, Java 버전 불일치, 누락된 의존성, 그래픽 드라이버, OptiFine / Forge 호환성 문제 등). 대화 상자에는 결론 1~2개를 표시합니다
  • '자세히 보기'에서 모든 단서와 근거 줄을 확인할 수 있고, '로그 보기'는 중단된 버전의 게임 폴더를 엽니다
  • 오류 보고서는 완전한 zip으로 내보냅니다. 분석 결과, 오류 요약, 시스템과 GPU, Java 버전, 버전과 모드 로더, 모드 / 리소스 팩 / 셰이더 목록, 시작 인수, 게임 출력, 중단 보고서가 들어 있습니다
  • 보고서는 --accessToken과 시스템 사용자 이름을 가리므로 다른 사람에게 보내 문제를 함께 확인할 수 있습니다
  • 게임을 여러 개 동시에 실행해도 세션마다 출력을 따로 보관하므로 중단 상황이 다른 버전에 섞이지 않습니다
  • 모드 상세 페이지를 새로 만들었습니다. 중국어와 영어 이름, 다운로드 수, 분류 태그, MC 버전별로 묶인 파일 목록, 의존성 카드, Modrinth / CurseForge / MCMod 링크, 이름 원클릭 복사가 있습니다
  • 1.20.1 설치의 의존성이 1.20으로 해석되어 Fabric API / GeckoLib 버전이 중복되고 Fabric이 Incompatible mods found를 보고 시작을 거부하던 문제를 수정했습니다
  • 모드를 설치하면 같은 프로젝트의 이전 jar를 지우므로 여러 버전이 쌓이지 않습니다
v1.6.0 파일을 찾아 헤매지 않고 모드 설치 2026-10-20
  • 다운로드 페이지에 모드 탭이 추가되었습니다. Modrinth / CurseForge에서 검색하고 현재 게임 버전에 맞는 파일을 골라 설치할 버전을 선택합니다

  • 다운로드가 작업 대기열이 되었습니다. 여러 버전을 클릭하면 차례로 대기하고, 대기 중인 작업은 제거할 수 있으며, 현재 작업을 취소하면 대기열이 이어집니다
  • 자동 업데이트가 조용히 설치됩니다. 백그라운드에서 내려받고 런처를 종료할 때 설치하며, 오른쪽 위 원형 배지에 진행률을 표시합니다
  • 새 기능: 게임 언어 자동 설정(기본값은 중국어 간체), 사용자 지정 게임 폴더, 사용자 지정 파일 미러
  • 새 기능: 버전 폴더나 zip / jar에서 로컬 버전 가져오기
  • Fabric이 이제 실제로 설치됩니다. 기본으로 Fabric API를 포함하며, 버전 격리를 켜면 모드와 저장 파일이 버전을 따라갑니다
  • Forge 설치는 --installClient만 실행하고 진행 상황을 보여 주며, Java 버전이 낮으면 명확하게 알려 줍니다
