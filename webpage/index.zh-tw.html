GoodPlanCraftLauncher

輕量 · 高效 · 開源

一個為 Windows 寫的 Minecraft 啟動器：Microsoft 正版與離線雙模式登入、版本管理、Forge / Fabric / OptiFine 一鍵安裝，Java 環境自動補齊。崩潰時會告訴你原因，而不是只彈出一個空白視窗。

立即下載 GitHub
版本 v1.9.0 / 更新 2026-10-23 / 平台 Windows 10+

上面這個視窗是可以點的——它就是啟動器的介面，在網頁裡跑了一遍。

Features

核心功能

為玩家打造的實用工具，每一項都為了「更快進入遊戲」而設計

雙模式登入

支援 Microsoft 正版登入與離線登入，隨時切換；離線模式不需要連網驗證。

內建模組下載

在啟動器裡搜尋 Modrinth 和 CurseForge，模組、光影、資源包直接裝進所選版本實際使用的資料夾。

四種模組載入器

Forge、NeoForge、Fabric、OptiFine 都從官方來源安裝，安裝前先確認 Java 版本。

25 種介面語言

首次啟動跟隨系統語言，之後隨時可以在設定裡切換。

版本自動管理

一鍵下載、安裝、切換 Minecraft 各版本，自動處理依賴函式庫與資源檔案。

極速啟動

最佳化的啟動流程與快取機制，點擊即玩，告別漫長等待。

Java 執行環境管理

自動偵測並補齊 Java 執行環境，下載來源可在清華、南大、華為雲、官方之間切換，失敗自動換下一個。

視覺主題支援

完整支援淺色模式與深色模式，介面縮放可調，提供一致的視覺體驗。

自動更新與維護

內建更新檢查機制，支援可設定的日誌自動清理策略，讓啟動器長期保持簡潔高效。

崩潰提示與錯誤報告

遊戲異常結束時說明原因，可一鍵匯出錯誤報告（崩潰報告 + 日誌 + 系統資訊）。

執行中面板

遊戲啟動後右側顯示版本、PID、執行時間、記憶體用量，隨時能結束遊戲。

自訂視窗標題

遊戲視窗標題可以自己寫，支援 {mc_version}、{time} 等魔術字。

System

系統需求

不高，但值得知道

作業系統

Windows 10 64 位元（1709+），Windows 11 同樣相容

Java 環境

由啟動器自動補齊；建議手動清理系統中多餘或衝突的 Java 安裝

儲存空間

啟動器本體至少需要 90 MB 可用空間（不含遊戲本體）

記憶體

建議 2 GB 以上可用記憶體

v1.9.0 下載頁重做，整合包和光影也能裝 最新 2026-10-23
  • 下載進度移到視窗底部：下載時不用離開目前頁面，底部列顯示檔案、進度、速度，點開能看到完整下載進程，隨時可以取消
  • 下載頁新增「光影」「資源包」「整合包」三個分類：支援 Modrinth 和 CurseForge 整合包，本機壓縮檔也能匯入，還支援 NeoForge 載入器
  • 版本隔離成為明確設定：預設每個版本獨立存放模組、存檔和設定，可在設定裡選五檔，單個版本也能單獨開關
  • 下載時可以給版本取名稱，產生獨立執行個體，不同的整合設定不會互相干擾
  • 模組搜尋更快：「全部來源」並行請求並啟用壓縮，重複搜尋直接命中快取；中文搜尋會先查百科拿英文名再搜
  • 模組搜尋按相關度排序，來源交替出現；詳情頁標註中文名來自 MC 百科還是輕之舟百科；設定裡能加自訂模組來源和中文詞表
  • 模組載入器改為互斥：選中 Forge 後其他載入器標「不相容」；安裝目標只列相容版本，按鈕寫明裝到哪個版本
  • 修正下載被截斷、取消下載不及時、刪除版本後主介面沒更新；首次安裝不再播放開場動畫
v1.8.0 25 種語言，從啟動器到官網 2026-10-22
  • 啟動器現在支援 25 種語言：在設定 → 外觀 → 介面語言裡切換，清單可以直接搜尋
  • 首次啟動跟隨系統語言，歡迎引導裡也能先選好再開始
  • 新增首次使用的歡迎引導：語言、介面風格、簡短介紹共 4 步，可以跳過
  • 新增三種介面風格：Minecraft、進階（原本的樣子）、簡約
  • 安裝程式也翻成同樣的 25 種語言，依系統語言自動選擇
  • 說明中心支援 25 種語言，啟動器裡的說明連結會開啟與介面語言對應的頁面
  • 官網和官網裡的互動示範也支援 25 種語言
  • 阿拉伯語、波斯語、希伯來語會把整個介面切換成從右到左的排版
  • 啟動不再閃一下：啟動頁和主介面合成一個頁面，視窗底色跟隨主題；切換語言重新載入時也不會黑一下
v1.7.2 自訂頭像，以及可以搜尋的版本列表 2026-10-22
  • 現在可以更換啟動頁頭像：點擊頭像，或在「設定 → 外觀 → 頭像」選擇圖片；支援 PNG / JPG / GIF / WebP
  • 超過 1 MB 的圖片會詢問是否壓縮；上限為 4 MB，也能一鍵還原預設頭像
  • 外觀設定新增「頭像大小」滑桿，範圍 32–160 像素
  • 版本列表新增搜尋框；每個版本會顯示對應的遊戲版本與模組載入器，選取中的版本會醒目標示
  • 重新整理版本列表不再整個重建，捲動位置會保留；「匯入本機版本」移到列表右上角
  • 1.20 以上選擇「加入伺服器」會直接連線；沒填位址時會提示，而不是默默開單人遊戲
  • 版本設定自動儲存不再每次都彈出「已儲存」
  • 安裝包從約 103 MB 縮小到 93 MB：只保留中文與英文語言包，其他語言回退為英文
  • 1.7.1 是未發布的內部測試版，已撤下；1.7.2 已包含它的全部變更
v1.7.0 光影、資源包與整合包，一鍵安裝 2026-10-22
  • 下載頁新增「光影」與「資源包」分頁：可搜尋 Modrinth / CurseForge，並直接安裝到所選版本對應的資料夾
  • 新增「整合包」分頁，支援 Modrinth（.mrpack）與 CurseForge 整合包，會自動安裝對應的遊戲版本、模組載入器與所有模組
  • 每個整合包都是獨立版本，模組、設定與存檔都放在自己的資料夾，整合包之間不會互相混在一起
  • 也支援匯入本機整合包：在版本管理裡選擇 zip / .mrpack，輸入名稱後就開始安裝
  • 整合包檔案會依清單核對大小與 SHA1，下載不完整的 jar 會重新抓取，而不是裝出一個開不起來的遊戲
  • NeoForge 現在也能像 Forge / Fabric 一樣依版本安裝（1.20.1 以上）
  • 「更多」選單預設收合；需要時在「設定 → 外觀」開啟，重新啟動後又冒出來的問題也已修正
v1.6.1 崩潰原因，直接說清楚 2026-10-21
  • 崩潰會自動診斷（記憶體不足、Java 版本錯誤、缺少前置、顯示卡驅動、OptiFine / Forge 不相容等），彈窗直接給出 1–2 條結論
  • 「查看詳情」可看到全部線索與證據行；「查看日誌」會開啟發生崩潰那個版本所屬的遊戲資料夾
  • 錯誤報告會匯出完整 zip：分析結果、錯誤摘要、系統與顯示卡、Java 版本、版本與模組載入器、模組 / 資源包 / 光影清單、啟動參數、遊戲輸出與崩潰報告
  • 報告會遮蔽 --accessToken 與系統使用者名稱，可以直接傳給別人協助排查
  • 同時開多個遊戲時，每個工作階段各自保留輸出，崩潰現場不會混到別的版本
  • 模組詳情頁重做：中英文名稱、下載量、分類標籤、依 MC 版本分組的檔案清單、前置卡片、前往 Modrinth / CurseForge / MCMOD 的連結，以及一鍵複製名稱
  • 修正在 1.20.1 安裝時把前置當成 1.20 解析，導致 Fabric API / GeckoLib 出現重複版本、Fabric 回報 Incompatible mods found 而拒絕啟動
  • 安裝模組時會清掉同專案的舊 jar，不會再堆積多個版本
v1.6.0 裝模組不用自己找檔案 2026-10-20
  • 下載頁新增「模組」分頁：搜尋 Modrinth / CurseForge，挑選符合目前遊戲版本的檔案，並選擇要裝進哪個版本
  • Modrinth 會自動帶上必要前置；支援中文搜尋（查詢會先經由 MCMOD 取得英文名稱）
  • 沒有 CurseForge API Key 也能用：貼上專案連結或 cf:slug，即可透過鏡像安裝單一檔案
  • 下載改為任務佇列：連點多個版本會排隊，等待中的任務可以移除，取消目前任務後佇列會繼續
  • 自動更新改為靜默安裝：背景下載，離開啟動器時安裝，右上角圓形徽章會顯示進度
  • 新增：自動設定遊戲語言（預設簡體中文）、自訂遊戲資料夾與自訂檔案鏡像
  • 新增：從版本資料夾或 zip / jar 匯入本機版本
  • Fabric 現在真的能安裝，預設一併安裝 Fabric API；開啟版本隔離後，模組與存檔會跟著版本走
  • Forge 安裝只執行 --installClient，會顯示進度，Java 版本太舊時也會直接說明
  • OptiFine 改為靜默安裝，不再彈出圖形化安裝程式
  • 修正 0 位元組下載被當成成功、相對位址轉址，以及第二次下載沒有進度的問題
v1.5.2 設定頁重做 2026-10-18
  • 設定頁重做：記憶體、視窗、啟動行為、下載來源與 Java 參數重新分組，可用滑桿、開關與分段按鈕調整
  • 記憶體預設改為「自動」：實體記憶體的 30%，最少 1 GB、最多 8 GB，並保留 2 GB 給系統；也可以手動設定
  • 記憶體管理現在真的會釋放：只清理啟動器自己的行程，絕不碰正在跑的遊戲，還能設定啟動前自動最佳化
  • 下載來源有四種模式（自動 / 鏡像優先 / 官方優先 / 僅官方），檔案與版本清單可分開設定；新增 0–20 MB/s 全域限速
  • 新增：G1GC 調校、自訂 JVM 參數、行程優先順序、視窗大小預設值與啟動器顯示模式
  • 關於頁現在包含專案資訊、執行環境與完整授權條款；官網與說明頁也一併重寫
  • 修正：執行緒數設定沒有生效、404 頁面被存成檔案，以及下載失敗後殘留部分檔案
