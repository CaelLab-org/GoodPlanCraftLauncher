GoodPlanCraftLauncher / 帮助 / 模组加载器

Forge / Fabric / OptiFine

在下载页选版本时可以直接选加载器。GPCL 会先装原版，再把加载器装到单独的版本目录里。

怎么装

  1. 打开下载页，选一个 Minecraft 版本。
  2. 在加载器选项里选 Forge、Fabric 或 OptiFine，再选对应的加载器版本。
  3. 点下载，等 GPCL 把原版和加载器都装完。
  4. 回到启动页，选带加载器名字的版本启动。

原版和加载器版本是分开的，不会覆盖原来的原版。想玩原版就选原版那一项。

三种加载器怎么选

加载器适合注意
Forge大型整合包、老牌模组启动比 Fabric 慢，版本选择多
Fabric轻量模组、新版本需要按游戏版本选对 Fabric Loader
OptiFine光影、性能优化只保证对应版本可用，和其他加载器混装可能冲突

模组放哪

放在游戏目录的 mods 文件夹里。GPCL 默认游戏目录是 %APPDATA%\gpcl\.minecraft，也可以在启动页打开对应的版本文件夹。

  • 模组要同时匹配 Minecraft 版本和加载器版本。
  • Forge 模组不能直接丢进 Fabric，反过来也一样。
  • 很多模组需要前置，缺前置会在启动时崩。

装完崩了

先把 mods 里的模组全部移走，裸启动一次。能进就每次放回一半，找出问题模组。

OptiFine 和 Forge / Fabric 混装时，可能需要额外的兼容模组。没有对应兼容模组就不要硬装。
