下载与镜像源

下载慢通常不是启动器的问题，先换下载源，再考虑调线程和限速。

两个下载源

设置 → 下载里有「文件下载源」和「版本列表源」，都可以选四种顺序：

选项什么时候用
优先官方，缓慢时换镜像默认。官方能连就官方，几秒没响应就换 BMCLAPI。
尽量使用镜像源国内网络访问官方很慢，直接用镜像。
优先使用官方源想要官方文件，官方失败后再回镜像。
尽量使用官方源只用官方，不走镜像。官方连不上就会失败。

文件下载源管客户端、资源文件和依赖库；版本列表源管版本清单、版本 JSON 和资源索引。

最大线程数

默认 64，范围 1–128。小文件多的时候提高并发会快一些，但太高也可能被网络设备或镜像限流。网络不稳定就往下调。

速度限制

0 表示不限速。填了数值后，所有下载任务共享这个总上限，单位是 MB/s。多人共用网络时可以调低。

这个限制只作用于游戏资源下载。Java 运行时使用单独的镜像下载，不受这里影响。

Java 镜像源

「设置 → 下载 → Java 下载」里选清华、南大、华为云或自定义。失败会自动换下一个源。自定义地址支持 {v} 和 {version} 变量。

下载失败先做什么

  1. 换一个下载源。
  2. 把线程数降到 32 或 16 再试。
  3. 确认系统时间正确，时间偏差太大会导致 HTTPS 证书校验失败。
  4. 还不行就发邮件，附上启动器日志。
