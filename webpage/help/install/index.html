安装与更新

GPCL 只支持 Windows 10 / 11 64 位。安装包不需要额外装 Java，启动器会按游戏版本自己补。

下载

从 官网下载区 或 GitHub Releases 下载 GPCL-<版本>-Setup.exe。不要从别的网盘或群文件拿安装包。

安装

  1. 双击安装包，选择安装目录。
  2. 安装完成后从桌面或开始菜单启动 GPCL。
  3. 第一次启动会创建配置文件、日志目录和默认游戏目录。

游戏和设置存在哪

都在 %APPDATA%\gpcl，不在安装目录里。升级和卸载都不会删这个文件夹。

  • .minecraft：游戏版本、资源、模组和存档。
  • gpcl\config\setting.ini：启动器设置。
  • gpcl\log：启动器日志。

更新

默认会在启动时检查更新。也可以在「设置 → 关于」里手动检查。

发现新版本后，GPCL 会下载安装包并校验 SHA1，然后启动安装程序。直接覆盖安装即可，不需要先卸载旧版。

如果更新后打不开，先去 %APPDATA%\gpcl\gpcl\log 看最新日志，再发邮件。

卸载

从 Windows 的「应用和功能」里卸载 GPCL。卸载程序不会删除 %APPDATA%\gpcl，这样重装后游戏和设置还在。

确定不再使用，可以手动删除 %APPDATA%\gpcl。删之前把存档备份出来。
