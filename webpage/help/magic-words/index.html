窗口标题魔术字

游戏窗口标题里可以写 {time} 这样的占位符，启动时 GPCL 会把它换成真实的值。

位置在 设置 → 游戏 → 游戏窗口标题。标题留空表示不修改游戏窗口标题。

举个例子

标题写成：

现在是 {time} · {mc_version} · {gpcl_version}

启动后可能显示为：

现在是 20:09:58 · Minecraft 1.21.3 · 1.5.1

能用的占位符

占位符会变成什么
{mc_version}版本显示名，例如 Minecraft 1.21.3，或带加载器的名字
{mc_id}版本文件夹名，例如 1.21.3-Fabric
{username}这次启动使用的玩家名
{gpcl_version}GPCL 版本号，例如 1.5.1
{date}启动日期，格式 2026/10/18
{time}当前时间，格式 20:09:58
{datetime}日期和时间，中间用空格分开
{java}当前 Java 运行时目录名
{memory}这次分配的最大内存，例如 4096MB

大小写要一致。写错的占位符会原样显示，方便你看出是哪一个写错了。

标题会一直保持吗

下面有一个「尽量保持该名称」开关，默认关闭。

  • 关闭：游戏窗口出现后，GPCL 会持续校正 20 秒。之后如果游戏或模组改了标题，就不再管了。含 {time} 的标题也会停在那时候。
  • 开启：整局游戏期间一直保持你设置的标题，进入世界也不会被「 - Singleplayer」盖掉。

有些整合包或模组也会改窗口标题，两边会互相覆盖，这属于正常现象。

目前只有游戏窗口标题支持魔术字，其他设置里不生效。
