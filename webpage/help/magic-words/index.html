魔术字（替换标记）

在游戏窗口标题里，你可以写一些像 {time} 这样的占位符。启动游戏时 GPCL 会把它们换成真实的值，所以每次看到的标题都不一样。

现在能写魔术字的地方是 设置 → 游戏 → 游戏窗口标题。 默认值是 Minecraft {mc_version} (GPCL)，把它清空就表示不修改游戏窗口标题。

用起来是什么样

假设你把窗口标题写成这样：

现在是 {time} · {mc_version} · {gpcl_version}

启动游戏后，窗口标题就会显示成：

现在是 20:09:58 · Minecraft 1.21.3 · 1.5.1

全部魔术字

大小写要一致，写错的占位符会原样显示出来（方便你看出是哪个写错了）。

魔术字会变成什么
{mc_version}游戏版本的显示名，例如 Minecraft 1.21.3 或带模组加载器的名字
{mc_id}版本文件夹的名字，例如 1.21.3-Fabric
{username}这次启动使用的玩家名
{gpcl_version}GPCL 的版本号，例如 1.5.1
{date}启动当天日期，格式 2026/10/16
{time}当前时间，格式 20:09:58，会随游戏运行更新
{datetime}日期和时间，中间用空格隔开
{java}当前使用的 Java 运行时目录名
{memory}这次分配的最大内存，例如 4096MB

几点说明

● 窗口标题是 GPCL 启动后持续校正的，所以进入世界时标题
不会被游戏自己的「 - Singleplayer」之类的内容盖掉。
● 含 {time} 时标题每几秒刷新一次，这是预期行为。
● 有些整合包或模组也会改窗口标题，两边会互相覆盖，属于正常现象。
● 除了窗口标题，GPCL 暂时没有别的地方支持魔术字。
