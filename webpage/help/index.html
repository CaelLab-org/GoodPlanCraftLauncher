帮助

遇到问题先从这里找。没写到的，发邮件到 gamets@caellab.com。

安装与更新 安装包怎么用、游戏和设置存在哪、怎么升级和卸载。 登录：正版与离线 微软正版登录流程，离线登录能做什么、不能做什么。 Java 与内存 Java 版本怎么选，内存自动/自定义怎么调，内存不够时怎么办。 Forge / Fabric / OptiFine 装模组加载器、版本对应关系、模组放哪。 下载与镜像源 官方源和镜像源怎么选，线程数和限速怎么设。 游戏崩溃 导出错误报告、看日志、常见崩溃原因。 窗口标题魔术字 {time}、{mc_version} 这些占位符怎么用。
发邮件时附上 GPCL 导出的错误报告，再写清楚游戏版本、装了什么模组、崩溃前做了什么。只发一张截图很难定位问题。

虚舟实验室旗下独立游戏开发与工具团队。探未来之境，载无界新生。
