登录：正版与离线

GPCL 支持两种登录方式，随时可以切换。离线登录不需要联网，但不能进入要求正版验证的服务器。

离线登录

在启动页输入一个玩家名就能启动，不需要密码。名字会记住最近用过的几个，可以随时换。

  • 适合单人游戏、局域网联机，以及没有正版验证的离线服务器。
  • 不需要联网验证，断网也能启动。
  • 不能进入开启正版验证的服务器，进去会被踢。
  • 不要用别人的正版 ID，服务器和玩家都可能认错人。

Microsoft 正版登录

  1. 在启动页点「正版登录」。
  2. GPCL 会打开默认浏览器，跳到 Microsoft 登录页。
  3. 登录并同意授权，浏览器会提示可以回到启动器。
  4. GPCL 会自动获取登录结果，成功后玩家名由账号决定。

登录最多等 2 分钟。如果一直没反应，先确认浏览器里已经完成登录和授权，再检查网络。

两种模式怎么选

场景用哪种
单人游戏、自己玩离线或正版都行
正版验证服务器必须正版
没有正版验证的服务器离线或正版都行
没有网络离线

切换账号

正版登录状态下，再点一次正版按钮可以登出，然后就能改用离线名字。离线状态下点正版登录会直接进入微软登录流程。
