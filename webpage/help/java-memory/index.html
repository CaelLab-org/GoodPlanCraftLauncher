Java 与内存

GPCL 会按游戏版本自动选 Java，也会根据电脑内存自动分配。一般不需要手动改。

Java 版本对应关系

Minecraft 版本需要的 Java
1.16.5 及更早Java 8
1.17 – 1.20.4Java 17
1.20.5 及之后Java 21

启动时发现缺少对应的 Java，GPCL 会自动下载并安装。下载失败时，去「设置 → 下载 → Java 镜像源」换一个镜像再试。

Java 装在 GPCL 自己的目录里，不会影响系统里其他 Java。

内存：自动

默认是「由 GPCL 自动控制」。它会先按物理内存的 30% 估算，再受当前可用内存限制：至少给系统留 2 GB，可用内存不够时会自动下调。

  • 16 GB 内存、可用 8 GB：分配 4 GB。
  • 16 GB 内存、可用 3 GB：分配 1 GB。
  • 8 GB 内存、可用 4 GB：分配 2 GB。
  • 最多分配 8 GB，最少 1 GB。

设置页会显示已用 / 总计和当前可用内存；可用内存低于 4 GB 时会提示你先关掉一些程序。

内存：自定义

整合包或大型模组包不够用时，切到「自定义」拖滑块。注意给系统和其他程序留空间，不要把物理内存全部分给游戏。

出现 OutOfMemoryError 就是内存不够：先把分配调大一档，再试。还不行就减少模组，或者关掉其他占内存的程序。

G1GC 调优

「设置 → 高级 → 内存管理」里有 G1GC 调优。默认不用开；只有在帧数波动、GC 卡顿明显时才试。开启后会追加一组常用的 G1GC 参数。

自定义 JVM 参数也在这里。参数写错会导致游戏直接起不来，不确定就不要改。

启动前优化内存

开启后，GPCL 会在启动游戏前回收自己占用的一部分内存。不会动正在运行的 Minecraft，也不会清登录状态。
