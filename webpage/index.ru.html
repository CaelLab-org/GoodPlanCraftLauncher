GoodPlanCraftLauncher

Лёгкий · Быстрый · Открытый

Лаунчер Minecraft для Windows: вход через Microsoft и офлайн-вход, управление версиями, установка Forge / Fabric / OptiFine в один клик. Если игра падает, он объясняет причину, а не показывает пустое окно.

Версия v1.9.3 / Обновлено 2026-10-29 / Платформа Windows / Linux

Окно выше — интерактивное: это сам интерфейс лаунчера, работающий прямо на странице.

Возможности

Основные возможности

Практичные инструменты для игроков — каждый помогает быстрее попасть в игру

Два способа входа

Вход через Microsoft и офлайн-вход, переключаться можно в любой момент; офлайн-режим не требует проверки по сети.

Скачивание модов встроено

Ищите на Modrinth и CurseForge и устанавливайте моды, шейдеры и наборы ресурсов в папку, которую действительно использует выбранная версия.

Четыре загрузчика модов

Forge, NeoForge, Fabric и OptiFine ставятся из официальных источников, версия Java проверяется заранее.

25 языков интерфейса

При первом запуске следует языку системы; переключается в настройках в любой момент.

Автоматическое управление версиями

Скачивание, установка и переключение версий Minecraft в один клик; библиотеки и ресурсы подтягиваются сами.

Быстрый запуск

Упрощённый путь запуска и кэширование: вы нажимаете — и играете, без ожидания.

Управление Java

Находит и устанавливает Java автоматически; источник загрузки можно выбрать — Университет Цинхуа, Нанкинский университет, Huawei Cloud или официальный, при ошибке используется следующий.

Поддержка тем

Полная поддержка светлой и тёмной темы, масштаб интерфейса настраивается.

Автообновление и обслуживание

Встроенная проверка обновлений и настраиваемая автоочистка логов не дают лаунчеру разрастаться.

Сообщения о падениях и отчёты об ошибках

При аварийном завершении игры лаунчер объясняет причину и позволяет в один клик выгрузить отчёт об ошибке (отчёт о падении + логи + сведения о системе).

Панель запущенной игры

После запуска справа появляется панель с версией, PID, временем работы и памятью; игру можно завершить в любой момент.

Свой заголовок окна

Задайте собственный заголовок окна игры, с магическими словами вроде {mc_version} и {time}.

История версий

Прошлые версии и их списки изменений

v1.9.3 Загрузка Java теперь через общую очередь загрузок Последняя 2026-10-29
  • Загрузка Java теперь идёт через ту же очередь, что версии игры и моды: прогресс, скорость, очередь и отмена — в нижней панели загрузок.
  • Исправлена ошибка с зеркалом Tsinghua по умолчанию: лаунчер отправлял браузерный User-Agent, а зеркало такие запросы отклоняет.
  • Зеркало Huawei Cloud удалено (оно больше не отдаёт файлы); если оно было выбрано, лаунчер вернётся к Tsinghua.
  • Настройка зеркала Java теперь действительно работает: раньше она только сохранялась и не читалась при загрузке.
  • Среда Java теперь устанавливается в папку игры, поэтому собственные игровые папки (школьные компьютеры, перемещаемые профили) работают.
  • Если сеть требует входа (авторизация прокси), появляется понятное сообщение и запись в журнале вместо простого «ошибка загрузки».
  • Ошибки установки Java стали конкретнее (файл слишком мал / архив повреждён / нет доступного источника), а системную Java больше нельзя удалить из лаунчера.
  • Неудачная повторная загрузка больше не удаляет уже существующую папку версии.
  • Установка Java отображается в панели загрузок, её можно отменить, и она не продолжается в фоне.
v1.9.2 Первая версия для Linux (экспериментальная), привязка CaelLabMinecraft 2026-10-24
  • Первая версия для Linux (экспериментальная): пакет tar.gz x64 для скачивания игры и установки Forge / Fabric / модов; обновления внутри приложения пока недоступны — при новой версии откроется страница загрузки
  • Новая привязка CaelLabMinecraft: включите её в настройках и подключите учётную запись Microsoft по коду привязки
  • Java, уже установленные в системе (Program Files, JAVA_HOME и т.д.), находятся автоматически, и их можно выбирать для каждой версии — без повторных скачиваний
  • Скачивание Java стало надёжнее: если на зеркале ещё нет последней сборки, берётся более старая с того же зеркала; если API недоступен, выручает список файлов зеркала
  • Исправлена пустая иконка главного окна — теперь корректно показывается иконка лаунчера
  • Исправлена проверка обновлений, ломавшаяся на номерах версий с буквенным суффиксом
  • При скачивании игры на Windows пропускаются библиотеки, не нужные на этой платформе
v1.9.1 Аккаунты Microsoft, несколько игровых папок и Java для каждой версии 2026-10-23
  • Вход в Microsoft переделан: можно сохранить несколько аккаунтов, переключаться между ними или удалять их в любой момент, и после перезапуска лаунчера вы остаётесь в системе
  • Токены входа автоматически продлеваются перед запуском; если срок истёк, лаунчер предложит войти заново, а не выдаст ошибку при подключении к серверу
  • Сохранённые аккаунты показывают настоящую голову скина Minecraft
  • Добавляйте несколько игровых папок и фильтруйте версии по папке; при выборе родительской папки, например корня PCL2, .minecraft внутри находится автоматически
  • Каждая версия может использовать свою Java: автоматически, 8, 16, 17, 21, 25 или свой путь
  • Анализ сбоев доступен на всех 25 языках, а отчёты об ошибках теперь содержат часовой пояс и местное время
  • Панель загрузки показывает график скорости в реальном времени, текущую и пиковую скорость и очередь задач; скорость можно отображать в MB/s или Mbps
  • Загрузка Java перенесена на отдельную вкладку страницы загрузок
  • Использование памяти в настройках теперь обновляется в реальном времени, а не показывает значение на момент открытия страницы
  • После удаления выбранной версии вы сразу возвращаетесь к списку версий, а не видите удалённую версию
v1.9.0 Новая страница загрузок с модпаками и шейдерами 2026-10-23
  • Прогресс загрузки теперь внизу окна: вы остаётесь на текущей странице, панель показывает файл, прогресс и скорость, а при раскрытии — полный список загрузок, где можно отменить в любой момент
  • На странице загрузок появились вкладки «Шейдеры», «Наборы ресурсов» и «Модпаки»: модпаки Modrinth и CurseForge ставятся одним щелчком, локальные архивы можно импортировать, а NeoForge поддерживается
  • Изоляция версий стала отдельной настройкой: у каждой версии по умолчанию свои моды, сохранения и настройки, доступно пять уровней и переключатель для отдельной версии
  • При загрузке можно задать версии имя и создать отдельный экземпляр, чтобы разные наборы модов не мешали друг другу
  • Поиск модов стал заметно быстрее: «Все источники» работают параллельно и со сжатием, повторные запросы берутся из кэша, а китайские запросы сначала ищут английское название в вики
  • Поиск сортируется по релевантности и чередует источники; на странице сведений видно, откуда взялось китайское название, а в настройках можно добавить свои источники модов и словари
  • Загрузчики модов теперь взаимоисключающие: после выбора Forge остальные помечаются «несовместимо», список целей показывает только совместимые версии, а на кнопке указано назначение
  • Исправлены обрывы загрузок, медленная отмена и главное окно, не обновлявшееся после удаления версии; при первой установке больше не проигрывается вступительная анимация
v1.8.0 25 языков — от лаунчера до сайта 2026-10-22
  • Лаунчер теперь говорит на 25 языках: переключите в Настройки → Оформление → Язык интерфейса, список можно искать
  • При первом запуске выбирается язык системы, а в приветственном окне его можно указать заранее
  • Добавлено приветственное окно для новых пользователей: язык, стиль интерфейса и краткое знакомство за 4 шага, можно пропустить
  • Три стиля интерфейса: Minecraft, Расширенный (привычный вид) и Минимальный
  • Установщик переведён на те же 25 языков и выбирает язык системы автоматически
  • Центр помощи доступен на 25 языках, а ссылки в лаунчере открывают страницу на языке интерфейса
  • Сайт и интерактивная демонстрация на нём тоже доступны на 25 языках
  • Для арабского, персидского и иврита весь интерфейс переключается на письмо справа налево
  • Запуск больше не мерцает: экран запуска и главное окно объединены в одну страницу, фон окна следует теме; при смене языка перезагрузка проходит без чёрного кадра
v1.7.2 Свои аватары и список версий с поиском 2026-10-22
  • Теперь можно сменить аватар на экране запуска: нажмите на него или выберите картинку в «Настройки → Оформление → Аватар»; поддерживаются PNG / JPG / GIF / WebP
  • Для изображений больше 1 МБ предлагается сжатие; ограничение — 4 МБ, а стандартный аватар возвращается в один клик
  • В настройках оформления появился ползунок «Размер аватара» — от 32 до 160 пикселей
  • В списке версий появился поиск; у каждой версии видны версия игры и загрузчик модов, выбранная подсвечена
  • Обновление списка версий больше не перестраивает его — позиция прокрутки сохраняется; «Импорт локальной версии» переехал в правый верхний угол списка
  • На 1.20 и новее пункт «Подключиться к серверу» подключается напрямую; если адрес не указан, появляется подсказка, а не тихий запуск одиночной игры
  • Автосохранение настроек версии больше не показывает «Сохранено» каждый раз
  • Установщик уменьшился с ~103 МБ до 93 МБ: оставлены только китайский и английский языковые пакеты, остальные языки используют английский
  • 1.7.1 была внутренней тестовой сборкой и отозвана; 1.7.2 включает все её изменения
v1.7.0 Шейдеры, ресурспаки и сборки модов — в один клик 2026-10-22
  • На странице загрузки появились вкладки «Шейдеры» и «Ресурспаки»: ищите на Modrinth / CurseForge и устанавливайте сразу в нужную папку выбранной версии
  • Новая вкладка «Сборки модов» поддерживает сборки Modrinth (.mrpack) и CurseForge: нужная версия игры, загрузчик модов и все моды ставятся автоматически
  • Каждая сборка становится отдельной версией со своими модами, конфигами и сохранениями, поэтому сборки не смешиваются между собой
  • Локальные сборки тоже можно импортировать: выберите zip / .mrpack в управлении версиями, введите имя — и установка начнётся
  • Файлы сборки проверяются по манифесту (размер и SHA1), поэтому недокачанные jar скачиваются заново, а не дают игру, которая не запускается
  • NeoForge теперь можно установить по версии, как Forge / Fabric (1.20.1 и новее)
  • Меню «Больше» по умолчанию свёрнуто; при необходимости включите его в «Настройки → Оформление» — ошибка, из-за которой оно возвращалось после перезапуска, исправлена
v1.6.1 Причина падения — прямо и по делу 2026-10-21
  • Падения диагностируются автоматически (нехватка памяти, неподходящая версия Java, отсутствующие зависимости, драйверы видеокарты, несовместимость OptiFine / Forge и другое), в диалоге 1–2 вывода
  • «Подробнее» показывает все улики и строки-доказательства; «Посмотреть логи» открывает папку игры той версии, которая упала
  • Отчёт об ошибке выгружается полным zip: результаты анализа, сводка ошибки, система и видеокарта, версия Java, версия и загрузчик модов, списки модов / ресурспаков / шейдеров, аргументы запуска, вывод игры и отчёты о падениях
  • В отчёте скрыты --accessToken и имя пользователя системы, поэтому его можно передать другим для разбора
  • При нескольких запущенных играх каждая сессия хранит свой вывод, поэтому контекст падения не смешивается с другой версией
  • Страница мода переделана: китайское и английское названия, число загрузок, теги категорий, списки файлов по версиям MC, карточки зависимостей, ссылки на Modrinth / CurseForge / MCMod и копирование названия в один клик
  • Исправлено: зависимости для установки на 1.20.1 определялись как 1.20, из-за чего появлялись дубли Fabric API / GeckoLib и Fabric писал Incompatible mods found и отказывался запускаться
  • При установке мода удаляются старые jar того же проекта, поэтому несколько версий больше не копятся

v1.6.0 Установка модов без поиска файлов 2026-10-20
  • На странице загрузки появилась вкладка «Моды»: ищите на Modrinth / CurseForge, выбирайте файлы под текущую версию игры и указывайте, в какую версию ставить
  • Modrinth автоматически подтягивает обязательные зависимости; поддерживается поиск по-китайски (запрос сначала идёт через MCMod за английским названием)
  • Работает и без API-ключа CurseForge: вставьте ссылку на проект или cf:slug и установите один файл через зеркало
  • Загрузки теперь очередь задач: несколько версий ставятся в очередь, ожидающие задачи можно убрать, а отмена текущей продолжает очередь
  • Автообновление ставится молча: качается в фоне и устанавливается при выходе из лаунчера, прогресс показывает круглый значок справа сверху
  • Новое: автоязык игры (по умолчанию упрощённый китайский), своя папка игры и своё зеркало файлов
  • Новое: импорт локальной версии из папки версии или zip / jar
  • Fabric наконец устанавливается, по умолчанию вместе с Fabric API; при изоляции версий моды и сохранения следуют за версией
  • Установка Forge запускает только --installClient, показывает прогресс и прямо говорит, если версия Java слишком старая
  • OptiFine ставится молча, без графического установщика
  • Исправлено: загрузка нулевого размера считалась успешной, редиректы на относительные адреса и отсутствие прогресса при второй загрузке
