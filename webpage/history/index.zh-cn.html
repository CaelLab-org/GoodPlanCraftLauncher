v1.9.3 Java 下载接入统一下载队列 最新 2026-10-29
  • Java 下载现在和游戏版本、模组共用同一条队列：进度、速度、排队位置和取消都在底部下载条里。
  • 修好了默认清华镜像每次都下不动的问题：启动器以前给镜像站发浏览器标识，被镜像直接拒绝。
  • 华为云镜像已移除（那边已经不给文件了）；之前选过它的会自动回落到清华。
  • Java 镜像设置现在真的生效了。以前只是存下来、下载时根本没读，所以怎么选都还是清华。
  • Java 运行时改为装到游戏目录里，自定义游戏目录（学校电脑、漫游配置）也能正常用。
  • 网络需要登录（代理认证）时会明确提示并写进日志，不再只报一句「下载失败」。
  • Java 安装失败的提示更具体（文件太小 / 压缩包损坏 / 没有可用下载源），系统自带的 Java 也不能再从启动器卸载。
  • 重新下载失败时，不再把之前就装好的版本文件夹删掉。
  • 安装 Java 会进「下载进程」面板，也能取消，不会留下一个还在后台跑的下载。
