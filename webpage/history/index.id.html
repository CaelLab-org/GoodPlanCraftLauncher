Catatan perubahan

Dari 1.0.0 hingga rilis terbaru, setiap versi — apa yang berubah dan apakah dapat diunduh — ada di halaman ini.

Pemasang untuk 1.3.2 dan versi sebelumnya tidak disimpan; pembaruan otomatis bawaan di versi lama mungkin sudah tidak berfungsi, jadi sebaiknya pasang rilis terbaru untuk penggunaan sehari-hari.

v1.9.3 Unduhan Java memakai antrean unduhan bersama Terbaru 2026-10-29
  • Unduhan Java sekarang memakai antrean yang sama dengan versi game dan mod: progres, kecepatan, urutan, dan pembatalan ada di bilah bawah.
  • Memperbaiki mirror Tsinghua bawaan yang selalu gagal: launcher mengirim User-Agent browser, yang ditolak mirror tersebut.
  • Mirror Huawei Cloud dihapus (tidak lagi menyediakan file); jika sebelumnya dipilih, launcher kembali ke Tsinghua.
  • Pengaturan mirror Java sekarang benar-benar berlaku: sebelumnya hanya disimpan dan tidak dibaca saat mengunduh.
  • Runtime Java kini dipasang di folder game, jadi folder game kustom (komputer sekolah, profil roaming) tetap berfungsi.
  • Jika jaringan memerlukan login (autentikasi proxy), muncul pesan jelas dan catatan log, bukan hanya "unduhan gagal".
  • Kesalahan pemasangan Java lebih spesifik (file terlalu kecil / arsip rusak / tidak ada sumber) dan Java sistem tidak bisa lagi dihapus dari launcher.
  • Unduhan ulang yang gagal tidak lagi menghapus folder versi yang sudah ada.
  • Pemasangan Java muncul di panel unduhan, bisa dibatalkan, dan tidak berjalan terus di latar belakang.

  • Unduhan gim di Windows melewati pustaka yang tidak diperlukan di platform ini
