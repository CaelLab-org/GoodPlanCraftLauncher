更新紀錄

從 1.0.0 到最新版，每個版本改了什麼、能不能下載，全都在這一頁。

1.3.2 及更早的版本沒有保留安裝包；舊版啟動器的內建更新可能已無法使用，日常使用建議安裝最新版。

v1.9.2 Linux 實驗版首發，支援 CaelLabMinecraft 正版綁定 最新 2026-10-24
  • 新增 Linux 版（實驗性）：提供 x64 的 tar.gz 包，可以下載遊戲、安裝 Forge / Fabric / 模組；應用程式內更新暫不可用，有新版本時會引導到官網下載
  • 新增 CaelLabMinecraft 正版綁定：在設定裡開啟後，用綁定碼即可接入 CaelLabMinecraft 伺服器
  • 會自動掃描系統裡已安裝的 Java（Program Files、JAVA_HOME 等），版本設定裡可以直接選用，不再重複下載
  • Java 執行環境下載更穩定：鏡像還沒同步最新版時自動改用鏡像裡已有的版本，API 不可用時從鏡像目錄列表兜底
  • 修正主視窗圖示一直空白的問題，現在正確顯示啟動器圖示
  • 修正帶字母後綴的版本號導致更新檢查異常的問題
  • Windows 下載遊戲時會略過目前平台用不到的相依程式庫，少下一些檔案

v1.9.1 微軟帳號登入重做，支援多個遊戲目錄 2026-10-23
  • 微軟帳號登入重新做了：可以儲存多個帳號，隨時切換或移除；登入資訊加密保存，重新啟動啟動器不用再登入
  • 啟動前會自動續期登入憑證；憑證過期時會提示重新登入，不會再出現「登入了卻進不了伺服器」
  • 帳號列表會顯示真實的 Minecraft 外觀頭像
  • 可以新增多個遊戲目錄，並依目錄篩選版本；選到 PCL2 根目錄這類上層資料夾時會自動辨識裡面的 .minecraft
  • 每個版本可以單獨選擇 Java 版本（自動 / 8 / 16 / 17 / 21 / 25 / 自訂路徑）
  • 崩潰分析支援全部 25 種語言，錯誤報告裡補上了時區和本地時間
  • 下載面板現在有即時速度曲線、目前與峰值速度、排隊任務；速度單位可選 MB/s 或 Mbps
  • Java 執行環境下載移到下載頁的獨立標籤頁
  • 設定頁的記憶體佔用改為即時重新整理，不再是開啟頁面那一刻的舊數字
  • 刪除目前版本後會立刻回到版本選擇，不再繼續顯示已經刪掉的版本

v1.9.0 下載頁重做，整合包和光影也能裝 2026-10-23
  • 下載進度移到視窗底部：下載時不用離開目前頁面，底部列顯示檔案、進度、速度，點開能看到完整下載進程，隨時可以取消
  • 下載頁新增「光影」「資源包」「整合包」三個分類：支援 Modrinth 和 CurseForge 整合包，本機壓縮檔也能匯入，還支援 NeoForge 載入器
  • 版本隔離成為明確設定：預設每個版本獨立存放模組、存檔和設定，可在設定裡選五檔，單個版本也能單獨開關
  • 下載時可以給版本取名稱，產生獨立執行個體，不同的整合設定不會互相干擾
  • 模組搜尋更快：「全部來源」並行請求並啟用壓縮，重複搜尋直接命中快取；中文搜尋會先查百科拿英文名再搜
  • 模組搜尋按相關度排序，來源交替出現；詳情頁標註中文名來自 MC 百科還是輕之舟百科；設定裡能加自訂模組來源和中文詞表
  • 模組載入器改為互斥：選中 Forge 後其他載入器標「不相容」；安裝目標只列相容版本，按鈕寫明裝到哪個版本
  • 修正下載被截斷、取消下載不及時、刪除版本後主介面沒更新；首次安裝不再播放開場動畫

v1.7.0 光影、資源包與整合包，一鍵安裝 2026-10-22
  • 下載頁新增「光影」與「資源包」分頁：可搜尋 Modrinth / CurseForge，並直接安裝到所選版本對應的資料夾
