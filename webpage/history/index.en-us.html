Changelog

From 1.0.0 to the latest release, every version — what changed, and whether it can be downloaded — is on this page.

Installers were not kept for 1.3.2 and earlier; the built-in updater in old versions may no longer work, so installing the latest release is recommended for daily use.

v1.9.2 First Linux build (experimental), CaelLabMinecraft linking Latest 2026-10-24
  • First Linux build (experimental): an x64 tar.gz package that can download the game and install Forge / Fabric / mods; in-app updates are not available yet, so the launcher opens the download page instead
  • New CaelLabMinecraft linking: turn it on in settings and connect your Microsoft account with a link code
  • Java runtimes already installed on your system (Program Files, JAVA_HOME, etc.) are detected automatically and can be picked per version, so no more duplicate downloads
  • Java downloads are more resilient: if a mirror has not synced the latest build yet, an older build from that mirror is used, and the mirror's file listing serves as a fallback when the API is unreachable
  • Fixed the main window icon, which used to be blank
  • Fixed update checks breaking on version numbers with letter suffixes
  • Game downloads on Windows skip libraries that are not needed on this platform

v1.9.1 Microsoft accounts, multiple game folders, per-version Java 2026-10-23
  • Microsoft sign-in has been rebuilt: save several accounts, switch or remove them at any time, and stay signed in after restarting the launcher
  • Sign-in tokens refresh automatically before launch; if a token expires, the launcher now asks you to sign in again instead of failing when joining a server
  • Saved accounts show their real Minecraft skin head
  • Add several game folders and filter versions by folder; choosing a parent folder such as a PCL2 root automatically finds the .minecraft inside it
  • Each version can use its own Java runtime: automatic, 8, 16, 17, 21, 25 or a custom path
  • Crash analysis now speaks all 25 languages, and error reports include your time zone and local time
  • The download panel shows a live speed graph, current and peak speed and queued tasks; speed can be displayed in MB/s or Mbps
  • Java runtime downloads moved to their own tab on the download page
  • Memory usage on the settings page now refreshes live instead of showing the value from when the page was opened
  • Deleting the selected version returns to the version list immediately instead of still showing the deleted version
Download v1.9.1 GPCL-1.9.1-Setup.exe · 94.0 MB · Windows 64-bit
v1.9.0 A rebuilt download page, with modpacks and shaders 2026-10-23
  • Download progress now lives at the bottom of the window: stay on whatever page you are on, the bar shows the current file, progress and speed, and it opens into the full download queue where you can cancel at any time
  • The download page now has Shaders, Resource packs and Modpacks tabs: Modrinth and CurseForge modpacks install in one click, local archives can be imported, and NeoForge is supported
  • Version isolation is now an explicit setting: each version gets its own mods, saves and settings by default, with five levels to choose from and a per-version switch
  • You can name a version while downloading it, creating a separate instance so different mod setups do not interfere with each other
  • Mod search is much faster: All sources now runs in parallel with compression, repeated searches hit the cache, and Chinese searches look up the English name in a wiki first
  • Mod search sorts by relevance with sources interleaved; the detail page shows where the Chinese name came from, and you can add custom mod sources and name dictionaries in Settings
  • Mod loaders are now mutually exclusive: picking Forge marks the others as incompatible, and the install target list only shows compatible versions with the destination written on the button
  • Fixed truncated downloads, slow cancellation and the main window not updating after deleting a version; first-time installs no longer play the intro animation

v1.8.0 Twenty-five languages, from the launcher to the website 2026-10-22
  • GoodPlanCraftLauncher now speaks 25 languages: pick one under Settings → Appearance → Interface language, and search the list to find it quickly
  • On first launch it follows your system language, and the welcome guide lets you choose one before doing anything else

Download v1.8.0 GPCL-1.8.0-Setup.exe · 94 MB · Windows 64-bit
v1.7.2 Custom avatars, and a version list you can search 2026-10-22
  • You can now change the launch screen avatar: click it, or pick an image under Settings → Appearance → Avatar; PNG / JPG / GIF / WebP are supported
  • Images over 1 MB ask whether to compress; the limit is 4 MB, and the default avatar can be restored in one click

  • Version settings autosave no longer pops up 'Saved' every time

Download v1.7.2 GPCL-1.7.2-Setup.exe · 93 MB · Windows 64-bit
v1.7.0 Shaders, resource packs, and modpacks, installed in one click 2026-10-22
  • The download page adds Shaders and Resource packs tabs: search Modrinth / CurseForge and install straight into the matching folder for the chosen version
  • A new Modpacks tab supports Modrinth (.mrpack) and CurseForge modpacks, installing the matching game version, mod loader, and all mods automatically
  • Each modpack becomes its own version, with mods, configs, and saves in its own folder, so modpacks do not mix into each other
  • Local modpacks can be imported too: pick a zip / .mrpack in version management, enter a name, and installation starts
  • Modpack files are checked against the manifest for size and SHA1, so half-downloaded jars are fetched again instead of producing a game that will not start
  • NeoForge can now be installed by version like Forge / Fabric (1.20.1 and later)
  • The 'More' menu is collapsed by default; enable it under Settings → Appearance when needed, and the bug where it reappeared after a restart has been fixed
Download v1.7.0 GPCL-1.7.0-Setup.exe · 103 MB · Windows 64-bit
v1.6.1 Crash reasons, told straight 2026-10-21
  • Crashes are diagnosed automatically (out of memory, wrong Java version, missing dependencies, GPU drivers, OptiFine / Forge incompatibility, and more), and the dialog gives 1–2 conclusions
  • 'View details' shows every clue and evidence line; 'View logs' opens the game directory of the version that crashed
  • Error reports export a complete zip: analysis results, error summary, system and GPU, Java version, version and mod loader, mods / resource packs / shaders lists, launch arguments, game output, and crash reports
  • The report redacts --accessToken and the system username, so it can be sent to others for troubleshooting
  • With several games running at once, each session keeps its own output, so a crash context never bleeds into another version
  • The mod details page was rebuilt: Chinese and English names, download counts, category tags, file lists grouped by MC version, dependency cards, links to Modrinth / CurseForge / MCMod, and one-click name copying
  • Fixed dependencies for a 1.20.1 install being resolved as 1.20, which duplicated Fabric API / GeckoLib versions and made Fabric report Incompatible mods found and refuse to start
  • Installing a mod removes old jars of the same project, so multiple versions no longer pile up
Download v1.6.1 GPCL-1.6.1-Setup.exe · 103 MB · Windows 64-bit
v1.6.0 Install mods without hunting for files 2026-10-20
  • The download page adds a Mods tab: search Modrinth / CurseForge, pick files for the current game version, and choose which version to install into
  • Modrinth pulls in required dependencies automatically; Chinese search is supported (the query goes through MCMod to get the English name first)
  • It also works without a CurseForge API key: paste a project link or cf:slug and install a single file through the mirror
  • Downloads are now a task queue: clicking several versions queues them, queued tasks can be removed, and cancelling the current one lets the queue continue
  • Auto-update now installs silently: it downloads in the background and installs when you exit the launcher, with a round badge in the top right showing progress
  • New: automatic game language (Simplified Chinese by default), a custom game directory, and a custom file mirror
  • New: import a local version from a version folder or zip / jar
  • Fabric actually installs now, with Fabric API by default; with version isolation, mods and saves follow the version
  • Forge installation only runs --installClient, shows progress, and says plainly when the Java version is too old
  • OptiFine installs silently instead of opening the graphical installer
  • Fixed zero-byte downloads counting as success, relative-address redirects, and the second download showing no progress
Download v1.6.0 GPCL-1.6.0-Setup.exe · 103 MB · Windows 64-bit
v1.5.2 Settings, rebuilt 2026-10-18
  • The settings page was rebuilt: memory, window, launch behavior, download sources, and Java arguments are regrouped, adjustable with sliders, switches, and segmented buttons
  • Memory now defaults to 'Auto': 30% of physical memory, at least 1 GB and at most 8 GB, leaving 2 GB for the system; it can also be set manually
  • Memory management actually reclaims now: it only cleans the launcher's own processes, never a running game, and can be set to optimize automatically before launch
  • Download sources have four modes (auto / mirror first / official first / official only), chosen separately for files and version lists; a 0–20 MB/s global speed limit was added
  • New: G1GC tuning, custom JVM arguments, process priority, window size presets, and launcher visibility
  • The About page now covers project information, the runtime environment, and the full license; the website and help pages were rewritten too
  • Fixed: the thread count setting being ignored, 404 pages being saved as files, and partial files left behind after failed downloads
