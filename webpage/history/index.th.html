  • เวอร์ชันแรกสำหรับ Linux (ทดลอง): แพ็กเกจ tar.gz แบบ x64 สำหรับดาวน์โหลดเกมและติดตั้ง Forge / Fabric / มอด; การอัปเดตในแอปยังไม่รองรับ เมื่อมีเวอร์ชันใหม่จะพาไปที่หน้าดาวน์โหลด

  • ตรวจหา Java ที่ติดตั้งอยู่ในเครื่องอัตโนมัติ (Program Files, JAVA_HOME ฯลฯ) และเลือกใช้แยกตามเวอร์ชันได้ ไม่ต้องดาวน์โหลดซ้ำ
  • ดาวน์โหลด Java เสถียรขึ้น: ถ้ามิเรอร์ยังไม่มีบิลด์ล่าสุดจะใช้บิลด์เก่ากว่าจากมิเรอร์ตัวเดิม ถ้า API ใช้ไม่ได้จะใช้รายการไฟล์ของมิเรอร์แทน
  • แก้ไขไอคอนหน้าต่างหลักที่ว่างเปล่า ตอนนี้แสดงไอคอนของตัวเกมเมอร์อย่างถูกต้อง
  • แก้ไขปัญหาการตรวจสอบอัปเดตล้มเหลวเมื่อหมายเลขเวอร์ชันมีตัวอักษรต่อท้าย
  • บน Windows การดาวน์โหลดเกมจะข้ามไลบรารีที่ไม่จำเป็นบนแพลตฟอร์มนี้
