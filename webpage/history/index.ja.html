v1.9.1 Microsoft アカウント、複数のゲームフォルダー、バージョンごとの Java 最新 2026-10-23
  • Microsoft ログインを作り直しました。複数のアカウントを保存して、いつでも切り替え・削除でき、ランチャーを再起動してもログインしたままです
  • 起動前にログイン情報を自動で更新します。期限が切れたときは再ログインを促し、サーバー接続時に失敗しなくなりました
  • 保存したアカウントに実際の Minecraft スキンの頭が表示されます
  • ゲームフォルダーを複数追加でき、フォルダーでバージョンを絞り込めます。PCL2 のルートのような親フォルダーを選ぶと、中の .minecraft を自動で見つけます
  • バージョンごとに Java を選べます（自動 / 8 / 16 / 17 / 21 / 25 / カスタムパス）
  • クラッシュ解析が 25 言語すべてに対応し、エラーレポートにタイムゾーンとローカル時刻が入りました
  • ダウンロードパネルにリアルタイムの速度グラフ、現在・最高速度、待機中のタスクが表示されます。速度単位は MB/s と Mbps から選べます
  • Java ランタイムのダウンロードをダウンロードページの専用タブに移しました
  • 設定ページのメモリ使用量がリアルタイムで更新され、ページを開いた時点の古い数字ではなくなりました
  • 選択中のバージョンを削除すると、すぐにバージョン一覧へ戻り、削除済みのバージョンが表示されたままになりません

v1.9.0 ダウンロード画面を刷新、Modパックとシェーダーに対応 2026-10-23
  • ダウンロードの進捗がウィンドウ下部に移動しました。今のページにいたまま、バーでファイル・進捗・速度を確認でき、開くと完全なダウンロード一覧からいつでもキャンセルできます
  • ダウンロード画面に「シェーダー」「リソースパック」「Modパック」タブを追加しました。Modrinth と CurseForge の Modパックをワンクリックで導入でき、ローカルのアーカイブも取り込めます。NeoForge にも対応しました
  • バージョン分離が明確な設定になりました。各バージョンは既定で専用の Mod・ワールド・設定を持ち、5 段階から選べ、バージョンごとに個別に切り替えられます
  • ダウンロード時にバージョンへ名前を付け、独立したインスタンスを作れます。Mod 構成が違っても互いに干渉しません
  • Mod 検索が大幅に速くなりました。「すべてのソース」は並列かつ圧縮で動作し、再検索はキャッシュから返します。中国語の検索は先に Wiki で英語名を調べます
  • Mod 検索は関連度順で並び、ソースが交互に表示されます。詳細画面には中国語名の出典が表示され、設定では独自の Mod ソースと用語辞書を追加できます
  • Mod ローダーは排他的になりました。Forge を選ぶと他は「非対応」と表示され、インストール先には対応バージョンだけが並び、ボタンにインストール先が書かれます
  • ダウンロードの途中切れ、キャンセルの遅さ、バージョン削除後にメイン画面が更新されない問題を修正しました。初回インストール時のオープニングアニメーションも廃止しました

v1.7.0 シェーダー、リソースパック、MOD パックをワンクリックで導入 2026-10-22
  • ダウンロードページに「シェーダー」「リソースパック」タブを追加。Modrinth / CurseForge で検索し、選択したバージョンの対応フォルダーへ直接インストールできます
  • 新しい「MOD パック」タブは Modrinth（.mrpack）と CurseForge の MOD パックに対応し、対応するゲームバージョン、MOD ローダー、すべての MOD を自動で導入します
  • MOD パックはそれぞれ独立したバージョンになり、MOD・設定・セーブデータが専用フォルダーに入るため、MOD パック同士が混ざりません
  • ローカルの MOD パックもインポートできます。バージョン管理で zip / .mrpack を選び、名前を入力すると導入が始まります
  • MOD パックのファイルはマニフェストとサイズ・SHA1 を照合するため、途中までしか落ちていない jar は取り直され、起動しないゲームにはなりません
  • NeoForge を Forge / Fabric と同じようにバージョン指定で導入できるようになりました（1.20.1 以降）
  • 「その他」メニューは既定で折りたたまれます。必要なときは設定 → 外観で有効化でき、再起動後に復活してしまう不具合も修正しました

v1.6.1 クラッシュの原因を、はっきりと 2026-10-21
  • クラッシュを自動診断します（メモリ不足、Java のバージョン違い、前提 MOD の不足、GPU ドライバー、OptiFine / Forge の非互換など）。ダイアログには結論を 1〜2 件表示します
  • 「詳細を表示」で手がかりと根拠の行をすべて確認できます。「ログを表示」はクラッシュしたバージョンのゲームディレクトリを開きます
  • エラーレポートは完全な zip として出力します: 診断結果、エラー概要、システムと GPU、Java バージョン、バージョンと MOD ローダー、MOD / リソースパック / シェーダーの一覧、起動引数、ゲーム出力、クラッシュレポート
  • レポートでは --accessToken とシステムのユーザー名を伏せ字にするため、そのまま他の人に送って調査を頼めます
  • 複数のゲームを同時に起動していても、各セッションが自分の出力を保持するため、クラッシュの情報が別のバージョンに混ざりません
  • MOD 詳細ページを作り直しました: 中国語・英語名、ダウンロード数、カテゴリタグ、MC バージョン別のファイル一覧、前提 MOD カード、Modrinth / CurseForge / MCMod へのリンク、名前のワンクリックコピー
  • 1.20.1 向けの前提 MOD が 1.20 として解決され、Fabric API / GeckoLib のバージョンが重複して Fabric が Incompatible mods found を出し起動しない不具合を修正
  • MOD を導入すると同じプロジェクトの古い jar を削除するため、複数バージョンが溜まらなくなりました
