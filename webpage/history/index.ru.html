v1.9.2 Первая версия для Linux (экспериментальная), привязка CaelLabMinecraft Последняя 2026-10-24
  • Первая версия для Linux (экспериментальная): пакет tar.gz x64 для скачивания игры и установки Forge / Fabric / модов; обновления внутри приложения пока недоступны — при новой версии откроется страница загрузки
  • Новая привязка CaelLabMinecraft: включите её в настройках и подключите учётную запись Microsoft по коду привязки
  • Java, уже установленные в системе (Program Files, JAVA_HOME и т.д.), находятся автоматически, и их можно выбирать для каждой версии — без повторных скачиваний
  • Скачивание Java стало надёжнее: если на зеркале ещё нет последней сборки, берётся более старая с того же зеркала; если API недоступен, выручает список файлов зеркала
  • Исправлена пустая иконка главного окна — теперь корректно показывается иконка лаунчера
  • Исправлена проверка обновлений, ломавшаяся на номерах версий с буквенным суффиксом
  • При скачивании игры на Windows пропускаются библиотеки, не нужные на этой платформе

v1.9.1 Аккаунты Microsoft, несколько игровых папок и Java для каждой версии 2026-10-23
  • Вход в Microsoft переделан: можно сохранить несколько аккаунтов, переключаться между ними или удалять их в любой момент, и после перезапуска лаунчера вы остаётесь в системе
  • Токены входа автоматически продлеваются перед запуском; если срок истёк, лаунчер предложит войти заново, а не выдаст ошибку при подключении к серверу
  • Сохранённые аккаунты показывают настоящую голову скина Minecraft
  • Добавляйте несколько игровых папок и фильтруйте версии по папке; при выборе родительской папки, например корня PCL2, .minecraft внутри находится автоматически
  • Каждая версия может использовать свою Java: автоматически, 8, 16, 17, 21, 25 или свой путь
  • Анализ сбоев доступен на всех 25 языках, а отчёты об ошибках теперь содержат часовой пояс и местное время
  • Панель загрузки показывает график скорости в реальном времени, текущую и пиковую скорость и очередь задач; скорость можно отображать в MB/s или Mbps
  • Загрузка Java перенесена на отдельную вкладку страницы загрузок
  • Использование памяти в настройках теперь обновляется в реальном времени, а не показывает значение на момент открытия страницы
  • После удаления выбранной версии вы сразу возвращаетесь к списку версий, а не видите удалённую версию

v1.9.0 Новая страница загрузок с модпаками и шейдерами 2026-10-23
  • Прогресс загрузки теперь внизу окна: вы остаётесь на текущей странице, панель показывает файл, прогресс и скорость, а при раскрытии — полный список загрузок, где можно отменить в любой момент
  • На странице загрузок появились вкладки «Шейдеры», «Наборы ресурсов» и «Модпаки»: модпаки Modrinth и CurseForge ставятся одним щелчком, локальные архивы можно импортировать, а NeoForge поддерживается
  • Изоляция версий стала отдельной настройкой: у каждой версии по умолчанию свои моды, сохранения и настройки, доступно пять уровней и переключатель для отдельной версии

  • Поиск модов стал заметно быстрее: «Все источники» работают параллельно и со сжатием, повторные запросы берутся из кэша, а китайские запросы сначала ищут английское название в вики

  • Загрузчики модов теперь взаимоисключающие: после выбора Forge остальные помечаются «несовместимо», список целей показывает только совместимые версии, а на кнопке указано назначение
  • Исправлены обрывы загрузок, медленная отмена и главное окно, не обновлявшееся после удаления версии; при первой установке больше не проигрывается вступительная анимация
