  • Перша версія для Linux (експериментальна): пакунок tar.gz x64 для завантаження гри та встановлення Forge / Fabric / модів; оновлення всередині застосунку поки недоступні — з новою версією відкриється сторінка завантаження

  • Завантаження Java стало надійнішим: якщо на дзеркалі ще немає останньої збірки, береться старіша з того самого дзеркала; якщо API недоступний, виручає список файлів дзеркала
  • Виправлено порожню піктограму головного вікна — тепер коректно показується піктограма лаунчера

v1.9.1 Акаунти Microsoft, кілька ігрових тек та Java для кожної версії 2026-10-23
  • Вхід у Microsoft перероблено: можна зберегти кілька акаунтів, перемикатися між ними чи видаляти їх будь-коли, і після перезапуску лаунчера ви залишаєтеся в системі
  • Токени входу автоматично продовжуються перед запуском; якщо термін минув, лаунчер запропонує увійти знову, а не видасть помилку під час підключення до сервера
  • Збережені акаунти показують справжню голову скіна Minecraft
  • Додавайте кілька ігрових тек і фільтруйте версії за текою; вибравши батьківську теку, наприклад корінь PCL2, .minecraft усередині знаходиться автоматично
  • Кожна версія може використовувати свою Java: автоматично, 8, 16, 17, 21, 25 або власний шлях
  • Аналіз збоїв доступний усіма 25 мовами, а звіти про помилки тепер містять часовий пояс і місцевий час
  • Панель завантаження показує графік швидкості в реальному часі, поточну й пікову швидкість та чергу завдань; швидкість можна показувати в MB/s або Mbps
  • Завантаження Java перенесено на окрему вкладку сторінки завантажень
  • Використання пам'яті в налаштуваннях тепер оновлюється в реальному часі, а не показує значення на момент відкриття сторінки
  • Після видалення вибраної версії ви одразу повертаєтеся до списку версій, а не бачите видалену версію

  • Виправлено обірвані завантаження, повільне скасування та головне вікно, що не оновлювалося після видалення версії; під час першого встановлення більше не відтворюється вступна анімація
