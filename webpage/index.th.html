GoodPlanCraftLauncher

เบา · มีประสิทธิภาพ · โอเพนซอร์ส

ตัวเรียกเกม Minecraft ที่เขียนขึ้นสำหรับ Windows: เข้าสู่ระบบด้วย Microsoft หรือแบบออฟไลน์ จัดการเวอร์ชัน และติดตั้ง Forge / Fabric / OptiFine ในคลิกเดียว เมื่อเกมพังจะบอกสาเหตุให้ ไม่ใช่แค่แสดงกล่องเปล่า

ดาวน์โหลดเลย GitHub
เวอร์ชัน v1.9.0 / อัปเดตเมื่อ 2026-10-23 / แพลตฟอร์ม Windows 10 ขึ้นไป

หน้าต่างด้านบนคลิกได้ — นี่คือหน้าจอตัวเรียกเกมจริงที่ทำงานอยู่ในหน้าเว็บ

ฟีเจอร์

ฟีเจอร์หลัก

เครื่องมือที่ใช้งานได้จริงสำหรับผู้เล่น ทุกอย่างออกแบบให้เข้าสู่เกมได้เร็วขึ้น

การเข้าสู่ระบบสองแบบ

เข้าสู่ระบบด้วย Microsoft หรือแบบออฟไลน์ สลับได้ทุกเมื่อ โหมดออฟไลน์ไม่ต้องยืนยันออนไลน์

ดาวน์โหลดมอดในตัว

ค้นหาใน Modrinth และ CurseForge แล้วติดตั้งมอด เชเดอร์ หรือรีซอร์สแพ็กลงโฟลเดอร์ที่เวอร์ชันที่เลือกใช้งานจริง

ตัวโหลดมอดสี่ตัว

Forge, NeoForge, Fabric และ OptiFine ติดตั้งจากแหล่งทางการ โดยตรวจสอบเวอร์ชัน Java ก่อน

25 ภาษาของอินเทอร์เฟซ

ครั้งแรกจะตามภาษาระบบ เปลี่ยนได้ทุกเมื่อในการตั้งค่า

จัดการเวอร์ชันอัตโนมัติ

ดาวน์โหลด ติดตั้ง และสลับเวอร์ชัน Minecraft ในคลิกเดียว ไลบรารีและแอสเซ็ตจัดการให้เอง

เริ่มเกมเร็ว

เส้นทางเริ่มเกมที่กระชับพร้อมแคช คลิกแล้วเล่นได้เลย ไม่ต้องรอ

จัดการ Java runtime

ตรวจหาและติดตั้ง Java runtime อัตโนมัติ แหล่งดาวน์โหลดเลือกได้ระหว่าง Tsinghua, Nanjing University, Huawei Cloud หรือแหล่งทางการ และจะลองแหล่งถัดไปเมื่อล้มเหลว

รองรับธีม

รองรับโหมดสว่างและมืดเต็มรูปแบบ ปรับขนาดอินเทอร์เฟซได้ หน้าตาสม่ำเสมอ

อัปเดตและบำรุงรักษาอัตโนมัติ

ตรวจหาการอัปเดตในตัว และตั้งเวลาล้างบันทึกอัตโนมัติได้ ใช้ไปนานก็ยังเบา

แจ้งเตือนเกมพังและรายงานข้อผิดพลาด

เมื่อเกมออกผิดปกติจะบอกสาเหตุ และส่งออกรายงานข้อผิดพลาดได้ในคลิกเดียว (รายงานการพัง + บันทึก + ข้อมูลระบบ)

แผงขณะเกมทำงาน

หลังเริ่มเกม แผงด้านขวาจะแสดงเวอร์ชัน PID เวลาที่ทำงาน และการใช้หน่วยความจำ และสั่งปิดเกมได้ทุกเมื่อ

ชื่อหน้าต่างกำหนดเอง

ตั้งชื่อหน้าต่างเกมเองได้ รองรับคำพิเศษอย่าง {mc_version} และ {time}

ภาพหน้าจอ

ภาพหน้าจอจริง

หน้าต่างด้านบนเป็นตัวเรียกเกมที่จำลองขึ้นมาบนเว็บ คลิกได้โดยไม่ต้องติดตั้ง ส่วนสี่ภาพด้านล่างคือตัวเรียกเกมที่รันอยู่บน Windows จริง ไม่ผ่านการแต่ง

ประวัติเวอร์ชัน

เวอร์ชันที่ผ่านมาและบันทึกการเปลี่ยนแปลง

v1.9.0 หน้าดาวน์โหลดใหม่ พร้อมมอดแพ็กและเชดเดอร์ ล่าสุด 2026-10-23
  • ความคืบหน้าการดาวน์โหลดย้ายไปอยู่ด้านล่างของหน้าต่างแล้ว คุณอยู่ในหน้าที่ใช้งานได้ แถบจะแสดงไฟล์ ความคืบหน้า และความเร็ว และเมื่อเปิดจะเห็นรายการดาวน์โหลดทั้งหมดที่ยกเลิกได้ทุกเมื่อ
  • หน้าดาวน์โหลดมีแท็บเชดเดอร์ ชุดทรัพยากร และมอดแพ็กใหม่: ติดตั้งมอดแพ็กของ Modrinth และ CurseForge ได้ในคลิกเดียว นำเข้าไฟล์บีบอัดในเครื่องได้ และรองรับ NeoForge
  • การแยกเวอร์ชันกลายเป็นการตั้งค่าที่ชัดเจน: แต่ละเวอร์ชันมีมอด เซฟ และการตั้งค่าของตัวเองโดยค่าเริ่มต้น เลือกได้ห้าระดับ และเปิดปิดแยกแต่ละเวอร์ชันได้
  • ตั้งชื่อเวอร์ชันตอนดาวน์โหลดและสร้างอินสแตนซ์แยกได้ เพื่อให้ชุดมอดต่างกันไม่รบกวนกัน
  • ค้นหามอดเร็วขึ้นมาก: «ทุกแหล่ง» ทำงานพร้อมกันและบีบอัดข้อมูล การค้นซ้ำใช้แคช และการค้นหาภาษาจีนจะหาชื่อภาษาอังกฤษในวิกิก่อน
  • การค้นหามอดเรียงตามความเกี่ยวข้องและสลับแหล่งที่มา หน้ารายละเอียดแสดงที่มาของชื่อภาษาจีน และในการตั้งค่าสามารถเพิ่มแหล่งมอดและพจนานุกรมชื่อของคุณเองได้
  • มอดโหลดเดอร์แยกจากกันแล้ว: เลือก Forge แล้วตัวอื่นจะขึ้น «ไม่เข้ากัน» รายการเป้าหมายติดตั้งแสดงเฉพาะเวอร์ชันที่เข้ากัน และปุ่มระบุปลายทาง
  • แก้ไขการดาวน์โหลดที่ถูกตัดขาด การยกเลิกที่ช้า และหน้าต่างหลักไม่อัปเดตหลังลบเวอร์ชัน; การติดตั้งครั้งแรกไม่เล่นแอนิเมชันเปิดอีกต่อไป
v1.8.0 25 ภาษา ตั้งแต่ตัวเรียกใช้จนถึงเว็บไซต์ 2026-10-22
  • ตัวเรียกใช้รองรับ 25 ภาษาแล้ว: เลือกได้ที่ การตั้งค่า → รูปลักษณ์ → ภาษาของอินเทอร์เฟซ และค้นหาในรายการได้
  • ในการเปิดครั้งแรกจะตามภาษาของระบบ และตัวช่วยต้อนรับก็ให้เลือกก่อนได้
  • ตัวช่วยต้อนรับใหม่: ภาษา รูปแบบอินเทอร์เฟซ และแนะนำสั้น ๆ ใน 4 ขั้น ข้ามได้
  • รูปแบบอินเทอร์เฟซสามแบบ: Minecraft, ขั้นสูง (หน้าตาเดิม) และมินิมอล
  • ตัวติดตั้งแปลเป็น 25 ภาษาเดียวกันและเลือกภาษาของระบบอัตโนมัติ
  • ศูนย์ช่วยเหลือมี 25 ภาษา และลิงก์ช่วยเหลือในตัวเรียกใช้จะเปิดหน้าที่ตรงกับภาษาอินเทอร์เฟซ
  • เว็บไซต์และเดโมแบบโต้ตอบในเว็บก็มี 25 ภาษาเช่นกัน
  • ภาษาอาหรับ เปอร์เซีย และฮีบรูจะทำให้อินเทอร์เฟซทั้งหมดเขียนจากขวาไปซ้าย
  • การเปิดโปรแกรมไม่กระพริบแล้ว: หน้าจอเริ่มต้นและหน้าต่างหลักเป็นหน้าเดียวกัน พื้นหลังหน้าต่างตามธีม และการเปลี่ยนภาษาไม่เหลือเฟรมดำ
v1.7.2 อวาตาร์กำหนดเอง และรายการเวอร์ชันที่ค้นหาได้ 2026-10-22
  • ตอนนี้เปลี่ยนอวาตาร์บนหน้าจอเริ่มเกมได้แล้ว: คลิกที่รูป หรือเลือกภาพที่ การตั้งค่า → รูปลักษณ์ → อวาตาร์ รองรับ PNG / JPG / GIF / WebP
  • ภาพที่ใหญ่กว่า 1 MB จะถามก่อนว่าจะบีบอัดหรือไม่ ขีดจำกัดคือ 4 MB และกู้คืนอวาตาร์เริ่มต้นได้ในคลิกเดียว
  • การตั้งค่ารูปลักษณ์เพิ่มแถบเลื่อน 'ขนาดอวาตาร์' 32–160 พิกเซล
  • รายการเวอร์ชันมีช่องค้นหา แต่ละเวอร์ชันแสดงเวอร์ชันเกมและมอดโหลดเดอร์ และไฮไลต์อันที่เลือกอยู่
  • รีเฟรชรายการเวอร์ชันแล้วไม่สร้างรายการใหม่ ตำแหน่งเลื่อนจึงอยู่ที่เดิม และย้าย 'นำเข้าเวอร์ชันในเครื่อง' ไปมุมขวาบนของรายการ
  • บน 1.20 ขึ้นไป การเลือก 'เข้าร่วมเซิร์ฟเวอร์' จะเชื่อมต่อโดยตรง หากไม่มีที่อยู่จะแสดงข้อความเตือนแทนการเปิดโหมดผู้เล่นคนเดียวเงียบ ๆ
  • บันทึกอัตโนมัติในการตั้งค่าเวอร์ชันไม่เด้ง 'บันทึกแล้ว' ทุกครั้งอีกต่อไป
  • ตัวติดตั้งลดจากประมาณ 103 MB เหลือ 93 MB: เก็บเฉพาะแพ็กภาษาจีนและอังกฤษ ภาษาอื่นจะใช้ภาษาอังกฤษแทน
  • 1.7.1 เป็นบิลด์ทดสอบภายในที่ไม่ได้เผยแพร่และถูกถอนแล้ว 1.7.2 รวมการเปลี่ยนแปลงทั้งหมดของมันไว้
v1.7.0 เชดเดอร์ แพ็กทรัพยากร และมอดแพ็ก ติดตั้งได้ในคลิกเดียว 2026-10-22
  • หน้าดาวน์โหลดเพิ่มแท็บเชดเดอร์และแพ็กทรัพยากร: ค้นหาใน Modrinth / CurseForge แล้วติดตั้งลงโฟลเดอร์ที่ตรงกับเวอร์ชันที่เลือกได้ทันที
  • แท็บใหม่สำหรับมอดแพ็ก รองรับ Modrinth (.mrpack) และ CurseForge ติดตั้งเวอร์ชันเกม มอดโหลดเดอร์ และมอดทั้งหมดให้อัตโนมัติ
  • มอดแพ็กแต่ละอันกลายเป็นเวอร์ชันของตัวเอง มอด การตั้งค่า และเซฟอยู่ในโฟลเดอร์ของตัวเอง มอดแพ็กจึงไม่ปนกัน
  • นำเข้ามอดแพ็กในเครื่องได้ด้วย: เลือก zip / .mrpack ในการจัดการเวอร์ชัน ใส่ชื่อ แล้วเริ่มติดตั้ง
  • ไฟล์มอดแพ็กถูกตรวจขนาดและ SHA1 เทียบกับไฟล์ manifest jar ที่ดาวน์โหลดมาไม่ครบจะถูกโหลดใหม่ แทนที่จะได้เกมที่เปิดไม่ขึ้น
  • ติดตั้ง NeoForge ตามเวอร์ชันได้แล้วเหมือน Forge / Fabric (1.20.1 ขึ้นไป)
  • เมนู 'เพิ่มเติม' ถูกย่อไว้เป็นค่าเริ่มต้น เปิดได้ที่ การตั้งค่า → รูปลักษณ์ เมื่อต้องใช้ และแก้บั๊กที่มันโผล่กลับมาหลังรีสตาร์ตแล้ว
v1.6.1 บอกสาเหตุที่เกมพัง ตรง ๆ 2026-10-21
  • วินิจฉัยเกมพังอัตโนมัติ (หน่วยความจำไม่พอ, Java เวอร์ชันผิด, ขาดมอดที่ต้องพึ่ง, ไดรเวอร์การ์ดจอ, OptiFine / Forge เข้ากันไม่ได้ และอื่น ๆ) และกล่องข้อความสรุปให้ 1–2 ข้อ
  • 'ดูรายละเอียด' แสดงเบาะแสและหลักฐานทุกบรรทัด ส่วน 'ดูบันทึก' เปิดโฟลเดอร์เกมของเวอร์ชันที่พัง
  • รายงานข้อผิดพลาดส่งออกเป็น zip ครบชุด: ผลการวิเคราะห์ สรุปข้อผิดพลาด ระบบและการ์ดจอ เวอร์ชัน Java เวอร์ชันและมอดโหลดเดอร์ รายการมอด / แพ็กทรัพยากร / เชดเดอร์ อาร์กิวเมนต์เริ่มเกม เอาต์พุตเกม และรายงานการพัง
  • รายงานปิดบัง --accessToken และชื่อผู้ใช้ระบบ จึงส่งให้คนอื่นช่วยตรวจได้
  • เมื่อเปิดเกมหลายตัวพร้อมกัน แต่ละเซสชันเก็บเอาต์พุตของตัวเอง บริบทการพังจึงไม่ปนไปยังเวอร์ชันอื่น
  • หน้าข้อมูลมอดสร้างใหม่: ชื่อจีนและอังกฤษ ยอดดาวน์โหลด แท็กหมวดหมู่ รายการไฟล์แบ่งตามเวอร์ชัน MC การ์ดมอดที่ต้องพึ่ง ลิงก์ไป Modrinth / CurseForge / MCMod และคัดลอกชื่อได้ในคลิกเดียว
  • แก้กรณีติดตั้งบน 1.20.1 แล้วมอดที่ต้องพึ่งถูกแก้เป็น 1.20 ทำให้ Fabric API / GeckoLib ซ้ำเวอร์ชัน และ Fabric ขึ้น Incompatible mods found แล้วไม่ยอมเริ่ม
  • ติดตั้งมอดแล้วจะลบ jar เก่าของโปรเจกต์เดียวกัน เวอร์ชันจึงไม่ทับถมกัน
v1.6.0 ติดตั้งมอดได้โดยไม่ต้องไล่หาไฟล์เอง 2026-10-20
  • หน้าดาวน์โหลดเพิ่มแท็บมอด: ค้นหา Modrinth / CurseForge เลือกไฟล์ให้ตรงกับเวอร์ชันเกมปัจจุบัน และเลือกว่าจะติดตั้งลงเวอร์ชันไหน
  • Modrinth ดึงมอดที่ต้องพึ่งให้อัตโนมัติ รองรับการค้นหาภาษาจีน (คำค้นจะผ่าน MCMod เพื่อหาชื่ออังกฤษก่อน)
  • ใช้ได้แม้ไม่มี API key ของ CurseForge: วางลิงก์โปรเจกต์หรือ cf:slug แล้วติดตั้งไฟล์เดียวผ่านมิเรอร์
  • การดาวน์โหลดกลายเป็นคิวงาน: คลิกหลายเวอร์ชันจะเข้าคิว ลบงานที่รออยู่ได้ และยกเลิกงานปัจจุบันแล้วคิวจะทำงานต่อ
  • อัปเดตอัตโนมัติติดตั้งแบบเงียบแล้ว: ดาวน์โหลดเบื้องหลังและติดตั้งเมื่อออกจากตัวเรียกเกม มีป้ายวงกลมมุมขวาบนแสดงความคืบหน้า
  • ใหม่: ตั้งภาษาภายในเกมอัตโนมัติ (ค่าเริ่มต้นจีนตัวย่อ) โฟลเดอร์เกมกำหนดเอง และมิเรอร์ไฟล์กำหนดเอง
  • ใหม่: นำเข้าเวอร์ชันในเครื่องจากโฟลเดอร์เวอร์ชันหรือ zip / jar
  • Fabric ติดตั้งได้จริงแล้ว พร้อม Fabric API เป็นค่าเริ่มต้น เมื่อแยกเวอร์ชัน มอดและเซฟจะตามเวอร์ชัน
  • การติดตั้ง Forge รันเฉพาะ --installClient แสดงความคืบหน้า และบอกตรง ๆ เมื่อเวอร์ชัน Java เก่าเกินไป
  • OptiFine ติดตั้งแบบเงียบ ไม่เปิดตัวติดตั้งแบบกราฟิก
  • แก้การดาวน์โหลด 0 ไบต์ที่นับว่าสำเร็จ การเปลี่ยนเส้นทางด้วยที่อยู่สัมพัทธ์ และการดาวน์โหลดครั้งที่สองที่ไม่แสดงความคืบหน้า
v1.5.2 หน้าตั้งค่า สร้างใหม่ 2026-10-18
  • หน้าตั้งค่าถูกสร้างใหม่: หน่วยความจำ หน้าต่าง พฤติกรรมตอนเริ่ม แหล่งดาวน์โหลด และอาร์กิวเมนต์ Java ถูกจัดกลุ่มใหม่ ปรับได้ด้วยแถบเลื่อน สวิตช์ และปุ่มแบบแบ่งส่วน
  • หน่วยความจำเริ่มต้นเป็น 'อัตโนมัติ': 30% ของหน่วยความจำจริง อย่างน้อย 1 GB และไม่เกิน 8 GB เผื่อให้ระบบ 2 GB และตั้งเองได้
  • การจัดการหน่วยความจำคืนหน่วยความจำได้จริงแล้ว: ล้างเฉพาะโปรเซสของตัวเรียกเกมเอง ไม่แตะเกมที่กำลังรัน และตั้งให้เพิ่มประสิทธิภาพอัตโนมัติก่อนเริ่มเกมได้
  • แหล่งดาวน์โหลดมีสี่โหมด (อัตโนมัติ / มิเรอร์ก่อน / ทางการก่อน / ทางการเท่านั้น) เลือกแยกสำหรับไฟล์และรายการเวอร์ชัน และเพิ่มการจำกัดความเร็วรวม 0–20 MB/s
  • ใหม่: ปรับแต่ง G1GC อาร์กิวเมนต์ JVM กำหนดเอง ลำดับความสำคัญของโปรเซส ขนาดหน้าต่างสำเร็จรูป และการแสดงตัวเรียกเกม
  • หน้าเกี่ยวกับตอนนี้มีข้อมูลโปรเจกต์ สภาพแวดล้อมการทำงาน และสัญญาอนุญาตฉบับเต็ม เว็บไซต์และหน้าช่วยเหลือก็เขียนใหม่ด้วย
  • แก้: การตั้งค่าจำนวนเธรดที่ถูกเพิกเฉย หน้า 404 ที่ถูกบันทึกเป็นไฟล์ และไฟล์บางส่วนที่ค้างหลังดาวน์โหลดล้มเหลว
v1.5.1 พังเหรอ? เดี๋ยวดูให้ 2026-10-16
