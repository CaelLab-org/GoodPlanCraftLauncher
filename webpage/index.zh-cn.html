GoodPlanCraftLauncher

轻量 · 高效 · 开源

一个为 Windows 写的 Minecraft 启动器：微软正版与离线双模式登录、版本管理、Forge / Fabric / OptiFine 一键安装，Java 环境自动补全。崩溃了会告诉你为什么，而不是只弹一个白框。

Features

核心功能

为玩家打造的实用工具，每一项都为「更快进入游戏」服务

双模式登录

支持 Microsoft 正版登录与离线登录，随时切换；离线模式不需要联网验证。

内置模组下载

在启动器里搜 Modrinth 和 CurseForge，模组、光影、资源包直接装进所选版本实际使用的文件夹。

四种模组加载器

Forge、NeoForge、Fabric、OptiFine 都从官方源安装，装之前先核对 Java 版本。

25 种界面语言

首次启动跟随系统语言，之后随时可以在设置里切换。

版本自动管理

一键下载、安装、切换 Minecraft 各版本，自动处理依赖库与资源文件。

极速启动

优化的启动流程与缓存机制，点击即玩，告别漫长等待。

Java 运行时管理

自动检测并补全 Java 运行环境，下载源可在清华、南大、华为云、官方之间切换，失败自动换下一个。

视觉主题适配

完整支持浅色模式与深色模式，界面缩放可调，提供一致的视觉体验。

自动更新与维护

内置更新检测机制，支持可配置的日志自动清理策略，保持启动器长期整洁高效。

崩溃提示与错误报告

游戏异常退出时说明原因，可一键导出错误报告（崩溃报告 + 日志 + 系统信息）。

运行中面板

游戏启动后右侧显示版本、PID、运行时长、内存占用，随时能结束游戏。

自定义窗口标题

游戏窗口标题可以自己写，支持 {mc_version}、{time} 等魔术字。

v1.8.0 25 种语言，从启动器到官网 最新 2026-10-22
  • 启动器现在支持 25 种语言：在设置 → 外观 → 界面语言里切换，列表可以直接搜索
  • 首次启动跟随系统语言，欢迎引导里也能先选好再开始
  • 新增首次使用的欢迎引导：语言、界面风格、简短介绍共 4 步，可以跳过
  • 新增三种界面风格：Minecraft、高级（原来的样子）、简约
  • 安装包也翻成了同样的 25 种语言，按系统语言自动选择
  • 帮助中心支持 25 种语言，启动器里的帮助链接会打开与界面语言对应的页面
  • 官网和官网里的交互演示也支持 25 种语言
  • 阿拉伯语、波斯语、希伯来语会把整个界面切换成从右到左的排版
  • 启动不再闪一下：启动页和主界面合成一个页面，窗口底色跟随主题；切换语言重载时也不会黑一下
v1.7.2 头像能换了，版本列表也好找了 2026-10-22
  • 启动页头像可以换了：点一下头像，或在设置 → 外观 → 头像里选图片，支持 PNG / JPG / GIF / WebP
  • 图片超过 1 MB 会询问是否压缩，最大 4 MB；也能一键恢复默认头像
  • 外观设置新增「头像大小」，32–160 像素拖动调整
  • 版本列表新增搜索框，每个版本标出游戏版本和加载器，当前选中的会高亮
  • 版本列表刷新时不再重建整个列表，滚动位置不会被顶回顶部；「导入本地版本」挪到列表右上角
  • 1.20 及以后选择「加入服务器」能直接进服，没填地址时会提示，不再悄悄启动单人游戏
  • 版本设置自动保存不再每次弹「保存成功」
  • 安装包从约 103 MB 降到 93 MB：只保留中英语言包，其他语言回退英文
  • 1.7.1 是未发布的内部测试版本，已作废；1.7.2 包含它的全部改动
v1.7.0 光影、资源包、整合包，一键装好 2026-10-22
  • 下载页新增「光影」「资源包」分类：Modrinth / CurseForge 搜索，选好目标版本后直接装进对应文件夹
  • 新增「整合包」分类：支持 Modrinth（.mrpack）和 CurseForge 整合包，自动安装对应的游戏版本、加载器和全部模组
  • 每个整合包会建成独立版本，模组、配置和存档都在自己的文件夹里，不同整合包不会互相串
  • 本地整合包也能导入：在版本管理里选 zip / .mrpack，填个名字就开始装
  • 整合包文件按清单校验大小与 SHA1，下了一半的 jar 会被重下，不会装出一个进不去的游戏
  • NeoForge 现在能像 Forge / Fabric 一样选版本安装（1.20.1 及以后）
  • 「更多」菜单默认收起，需要时在设置 → 外观里打开；修了关掉后重启又冒出来的问题
v1.6.1 崩溃原因，直接告诉你 2026-10-21
  • 崩溃后自动分析原因：内存不足、Java 版本不对、缺前置、显卡驱动、OptiFine / Forge 不兼容等，弹窗直接给 1–2 条结论
  • 点「查看详情」能看到全部线索和证据行；「查看日志」打开崩溃那个版本自己的游戏目录
  • 错误报告导出一个完整的 zip：分析结果、错误摘要、系统与显卡、Java 版本、版本与加载器、Mod / 资源包 / 光影列表、启动参数、游戏输出与崩溃报告
  • 报告里的 --accessToken 和系统用户名已打码，可以直接发给别人排查
  • 同时开多个游戏时，每个会话单独保留输出，崩溃现场不会串到别的版本
  • 模组详情页重做：中文名 + 英文名、下载量、分类标签、按 MC 版本分组的文件列表、前置资源卡片，可跳 Modrinth / CurseForge / MC 百科、一键复制名称
  • 修复给 1.20.1 装前置却按 1.20 解析，导致 Fabric API / GeckoLib 版本重复、Fabric 报 Incompatible mods found 不启动
  • 装完模组会清掉同一项目的旧 jar，不再出现多个版本并存
v1.6.0 装 Mod，不用手动找文件了 2026-10-20
  • 下载页新增「模组」分区：Modrinth / CurseForge 搜索，按当前游戏版本挑文件，安装时选择装到哪个版本
  • Modrinth 自动带必需前置；支持中文搜索（先查 MCMOD 转成英文名）
  • 没有 CurseForge API Key 也能用：粘贴项目链接或 cf:短名，走镜像装单个文件
  • 下载改成任务队列：连续点多个版本会排队，可以移除排队任务、取消当前任务后继续
  • 自动更新改为静默安装：后台自动下载，退出启动器时装好；右上角圆形徽标显示进度
  • 新增自动设置游戏语言（默认简体中文）、自定义游戏目录、自定义文件镜像
  • 新增导入本地版本（版本文件夹或 zip / jar）
  • Fabric 真能装了，默认同时安装 Fabric API；版本隔离后 Mod / 存档跟着版本走
  • Forge 安装只跑 --installClient，会显示安装进度，Java 版本不够会直接说明
  • OptiFine 改为静默安装，不再弹图形安装器
  • 修复下载 0 字节算成功、相对地址重定向、第二次下载没进度
v1.5.2 设置，重做了一遍 2026-10-18
  • 设置页重做：内存、窗口、启动行为、下载源、Java 参数重新分组，滑块、开关、分段按钮直接调
  • 内存默认改为「自动」：按物理内存 30% 分配，至少 1 GB、最多 8 GB，并给系统留 2 GB；也可手动指定
  • 内存管理真能回收了：只清理启动器自己的进程，不碰正在运行的游戏，可设启动前自动优化
  • 下载源分四档（自动 / 镜像优先 / 官方优先 / 仅官方），文件和版本列表分开选；新增 0–20 MB/s 全局限速
  • 新增 G1GC 调优、自定义 JVM 参数、进程优先级、窗口尺寸预设、启动器可见性
  • 关于页补齐项目信息、运行环境与许可证全文；官网与帮助页一并重写
  • 修复：线程数设置不生效、下载 404 页面被当成文件保存、下载失败残留半截文件
