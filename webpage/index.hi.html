GoodPlanCraftLauncher

हल्का · कुशल · ओपन सोर्स

Windows के लिए बनाया गया Minecraft लॉन्चर: Microsoft और ऑफ़लाइन लॉगिन, संस्करण प्रबंधन, और Forge / Fabric / OptiFine की एक-क्लिक इंस्टॉलेशन। गेम क्रैश होने पर यह खाली डायलॉग की जगह कारण बताता है।

अभी डाउनलोड करें
संस्करण v1.9.3 / अपडेट 2026-10-29 / प्लेटफ़ॉर्म Windows / Linux

ऊपर वाली विंडो क्लिक करने योग्य है — यह खुद लॉन्चर का इंटरफ़ेस है, जो वेब पेज के अंदर चल रहा है।

विशेषताएँ

मुख्य विशेषताएँ

खिलाड़ियों के लिए काम की सुविधाएँ, हर एक तेज़ी से गेम में पहुँचाने के लिए

दो लॉगिन तरीके

Microsoft और ऑफ़लाइन लॉगिन, कभी भी बदल सकते हैं; ऑफ़लाइन मोड में ऑनलाइन सत्यापन की ज़रूरत नहीं।

मॉड डाउनलोड अंतर्निहित

Modrinth और CurseForge पर खोजें और मॉड, शेडर या रिसोर्स पैक को उस फ़ोल्डर में इंस्टॉल करें जिसे चुना गया संस्करण वास्तव में उपयोग करता है।

चार मॉड लोडर

Forge, NeoForge, Fabric और OptiFine आधिकारिक स्रोतों से इंस्टॉल होते हैं, पहले Java संस्करण जाँचा जाता है।

25 इंटरफ़ेस भाषाएँ

पहली बार शुरू होने पर सिस्टम भाषा का पालन करता है; सेटिंग्स में कभी भी बदलें।

स्वचालित संस्करण प्रबंधन

Minecraft संस्करण एक क्लिक में डाउनलोड, इंस्टॉल और बदलें, लाइब्रेरी और एसेट्स अपने आप संभल जाते हैं।

तेज़ स्टार्टअप

सरल लॉन्च प्रक्रिया और कैशिंग, ताकि आप क्लिक करें और खेलें, इंतज़ार न करें।

Java रनटाइम प्रबंधन

Java रनटाइम अपने आप पहचानता और इंस्टॉल करता है; डाउनलोड स्रोत Tsinghua, Nanjing University, Huawei Cloud या आधिकारिक स्रोत चुन सकते हैं, और विफल होने पर अगले स्रोत पर चला जाता है।

थीम समर्थन

हल्के और गहरे रंग मोड का पूरा समर्थन, साथ में समायोज्य इंटरफ़ेस स्केलिंग ताकि लुक एक जैसा रहे।

स्वचालित अपडेट और रखरखाव

अंतर्निहित अपडेट जाँच और समायोज्य स्वचालित लॉग सफ़ाई समय के साथ लॉन्चर को हल्का रखते हैं।

क्रैश सूचना और त्रुटि रिपोर्ट

गेम असामान्य रूप से बंद होने पर यह कारण बताता है, और एक क्लिक में त्रुटि रिपोर्ट निर्यात कर सकता है (क्रैश रिपोर्ट + लॉग + सिस्टम जानकारी)।

रनिंग पैनल

लॉन्च के बाद दाईं ओर एक पैनल संस्करण, PID, चलने का समय और मेमोरी उपयोग दिखाता है, और कभी भी गेम बंद कर सकता है।

कस्टम विंडो शीर्षक

अपना गेम विंडो शीर्षक लिखें, {mc_version} और {time} जैसे मैजिक शब्दों के साथ।

स्क्रीनशॉट

असली स्क्रीनशॉट

ऊपर की विंडो लॉन्चर इंटरफ़ेस का वेब रूप है, बिना कुछ इंस्टॉल किए क्लिक किया जा सकता है। नीचे की चार तस्वीरें Windows पर असल में चल रहे लॉन्चर की हैं, बिना एडिट।

v1.9.3 Java डाउनलोड अब साझा डाउनलोड कतार में नवीनतम 2026-10-29
  • Java डाउनलोड अब गेम वर्ज़न और मॉड के साथ उसी कतार में चलते हैं: प्रगति, गति, कतार और रद्द करना नीचे की पट्टी में।
  • डिफ़ॉल्ट Tsinghua मिरर हर बार विफल होने की समस्या ठीक हुई: लॉन्चर ब्राउज़र User-Agent भेज रहा था, जिसे मिरर अस्वीकार करता है।
  • Huawei Cloud मिरर हटा दिया गया (अब फ़ाइलें नहीं देता); पहले चुना हो तो लॉन्चर अपने-आप Tsinghua पर लौट आता है।
  • Java मिरर सेटिंग अब सचमुच लागू होती है: पहले सिर्फ़ सहेजी जाती थी, डाउनलोड के समय पढ़ी नहीं जाती थी।
  • Java रनटाइम अब गेम फ़ोल्डर के अंदर इंस्टॉल होता है, इसलिए कस्टम गेम फ़ोल्डर (स्कूल के कंप्यूटर, रोमिंग प्रोफ़ाइल) काम करते हैं।
  • अगर नेटवर्क में साइन-इन चाहिए (प्रॉक्सी प्रमाणीकरण), तो सिर्फ़ "डाउनलोड विफल" के बजाय साफ़ संदेश और लॉग प्रविष्टि दिखती है।
  • Java इंस्टॉल की त्रुटियाँ ज़्यादा स्पष्ट हैं (फ़ाइल बहुत छोटी / आर्काइव खराब / कोई स्रोत नहीं) और सिस्टम का Java अब लॉन्चर से अनइंस्टॉल नहीं हो सकता।
  • दोबारा डाउनलोड विफल होने पर पहले से मौजूद वर्ज़न फ़ोल्डर अब नहीं हटता।
  • Java इंस्टॉल डाउनलोड पैनल में दिखता है, रद्द किया जा सकता है और पृष्ठभूमि में नहीं चलता रहता।

  • मुख्य विंडो के खाली आइकन की समस्या ठीक हो गई — अब लॉन्चर का आइकन सही दिखता है
  • अक्षर-प्रत्यय वाले संस्करण नंबर पर अपडेट जाँच टूटने की समस्या ठीक की गई
  • Windows पर गेम डाउनलोड उन लाइब्रेरी को छोड़ देता है जो इस प्लेटफ़ॉर्म पर ज़रूरी नहीं हैं
v1.9.1 Microsoft खाते, कई गेम फ़ोल्डर और हर वर्ज़न के लिए Java 2026-10-23
  • Microsoft साइन-इन फिर से बनाया गया है: कई खाते सहेजें, कभी भी बदलें या हटाएँ, और लॉन्चर दोबारा शुरू करने पर भी साइन-इन रहें
  • लॉन्च से पहले साइन-इन टोकन अपने आप रिन्यू हो जाते हैं; समय खत्म होने पर अब सर्वर से जुड़ते समय विफल होने के बजाय दोबारा साइन-इन करने को कहा जाता है
  • सहेजे गए खाते असली Minecraft स्किन हेड दिखाते हैं
  • कई गेम फ़ोल्डर जोड़ें और वर्ज़न को फ़ोल्डर के अनुसार फ़िल्टर करें; PCL2 रूट जैसा ऊपरी फ़ोल्डर चुनने पर उसके अंदर का .minecraft अपने आप मिल जाता है
  • हर वर्ज़न अपना Java इस्तेमाल कर सकता है: अपने आप, 8, 16, 17, 21, 25 या कस्टम पथ
  • क्रैश विश्लेषण अब सभी 25 भाषाओं में उपलब्ध है, और त्रुटि रिपोर्ट में आपका टाइम ज़ोन और स्थानीय समय भी शामिल है
  • डाउनलोड पैनल अब लाइव स्पीड ग्राफ़, मौजूदा और अधिकतम स्पीड तथा कतार में लगे कार्य दिखाता है; स्पीड MB/s या Mbps में दिखाई जा सकती है
  • Java डाउनलोड अब डाउनलोड पेज के अलग टैब में है
  • सेटिंग्स पेज पर मेमोरी उपयोग अब लाइव अपडेट होता है, न कि पेज खोलने के समय की पुरानी संख्या
  • चुना हुआ वर्ज़न हटाने पर अब तुरंत वर्ज़न सूची पर लौटते हैं, हटाया गया वर्ज़न दिखता नहीं रहता
v1.9.0 नया डाउनलोड पेज, मॉडपैक और शेडर के साथ 2026-10-23
  • डाउनलोड प्रगति अब विंडो के नीचे है: आप अपने पेज पर रहते हैं, बार फ़ाइल, प्रगति और गति दिखाता है, और खोलने पर पूरी डाउनलोड सूची दिखती है जहाँ कभी भी रद्द कर सकते हैं
  • डाउनलोड पेज में अब शेडर, रिसोर्स पैक और मॉडपैक टैब हैं: Modrinth और CurseForge मॉडपैक एक क्लिक में इंस्टॉल होते हैं, स्थानीय आर्काइव आयात होते हैं, और NeoForge समर्थित है
  • वर्शन आइसोलेशन अब एक स्पष्ट सेटिंग है: हर वर्शन के अपने मॉड, सेव और सेटिंग्स डिफ़ॉल्ट रूप से होते हैं, पाँच स्तरों में चुन सकते हैं और हर वर्शन के लिए अलग स्विच है
  • डाउनलोड करते समय वर्शन को नाम दे सकते हैं और अलग इंस्टेंस बना सकते हैं, ताकि अलग मॉड सेटअप एक-दूसरे को प्रभावित न करें
  • मॉड खोज काफी तेज़ है: «सभी स्रोत» समानांतर और कम्प्रेशन के साथ चलते हैं, दोहराई गई खोज कैश से आती है, और चीनी खोज पहले विकी में अंग्रेज़ी नाम ढूँढती है
  • मॉड खोज प्रासंगिकता से क्रमबद्ध होती है और स्रोत बारी-बारी आते हैं; विवरण पेज बताता है कि चीनी नाम कहाँ से आया, और सेटिंग्स में अपने मॉड स्रोत और नाम शब्दकोश जोड़ सकते हैं
