קוד פתוח חינמי משגר Minecraft

GoodPlanCraftLauncher

קל · מהיר · קוד פתוח

משגר Minecraft שנכתב ל-Windows: התחברות Microsoft ומצב לא מקוון, ניהול גרסאות והתקנה בלחיצה אחת של Forge / Fabric / OptiFine. כשהמשחק קורס, הוא אומר לך למה במקום פשוט להציג חלון ריק.

הורדה עכשיו
גרסה v1.9.2 / עודכן 2026-10-24 / פלטפורמה Windows 10+

החלון שלמעלה הוא לחיץ — זהו ממשק המשגר עצמו, שרץ בתוך דף האינטרנט.

יכולות

יכולות עיקריות

כלים שימושיים לשחקנים, כל אחד מהם מכוון להכניס אותך למשחק מהר יותר

שני מצבי התחברות

התחברות Microsoft ומצב לא מקוון, עם אפשרות החלפה בכל רגע; מצב לא מקוון לא דורש אימות מקוון.

הורדת מודים מובנית

חפשו ב-Modrinth וב-CurseForge והתקינו מודים, שיידרים או חבילות משאבים בתיקייה שבה הגרסה הנבחרת באמת משתמשת.

ארבעה טועני מודים

Forge, NeoForge, Fabric ו-OptiFine מותקנים מהמקורות הרשמיים, עם בדיקת גרסת Java מראש.

25 שפות ממשק

עוקב אחר שפת המערכת בהפעלה הראשונה; ניתן לשנות בהגדרות בכל עת.

ניהול גרסאות אוטומטי

הורדה, התקנה והחלפה של גרסאות Minecraft בלחיצה אחת, כשהספריות והנכסים מטופלים אוטומטית.

הפעלה מהירה

מסלול הפעלה מצומצם ומטמון, כך שלוחצים ומשחקים במקום לחכות.

ניהול סביבת Java

מזהה ומתקין סביבת Java אוטומטית; אפשר לבחור מקור הורדה — Tsinghua, אוניברסיטת נאנג'ינג, Huawei Cloud או המקור הרשמי, עם מעבר לבא בתור אם נכשל.

תמיכה בערכות נושא

תמיכה מלאה במצב בהיר וכהה, עם קנה מידה מתכוונן של הממשק למראה אחיד.

עדכונים ותחזוקה אוטומטיים

בדיקות עדכון מובנות וניקוי יומנים אוטומטי הניתן להגדרה שומרים על המשגר רזה לאורך זמן.

התראות קריסה ודוחות שגיאה

כשהמשחק יוצא באופן חריג הוא מסביר למה, ויכול לייצא דוח שגיאה בלחיצה אחת (דוח קריסה + יומנים + מידע מערכת).

פאנל ריצה

לאחר ההפעלה, פאנל בצד ימין מציג את הגרסה, ה-PID, משך הריצה והשימוש בזיכרון, ומאפשר לסיים את המשחק בכל רגע.

כותרת חלון מותאמת

כתבו כותרת משלכם לחלון המשחק, עם מילות קסם כמו {mc_version} ו-{time}.

צילומי מסך

צילומי מסך אמיתיים

החלון למעלה הוא שחזור וובי של ממשק המשגר, לחיץ בלי להתקין דבר. ארבעת אלה שלמטה הם המשגר שרץ בפועל על Windows, ללא עריכה.
