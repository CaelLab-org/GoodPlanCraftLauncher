title: 安装与更新
description: 下载、安装、升级和卸载 GPCL；游戏与设置存在 %APPDATA%\gpcl。
---

GPCL 只支持 **Windows 10 / 11 64 位**。安装包里不带 Java，启动器会按游戏版本自己补。

## 下载

从[官网下载区](https://gamets.caellab.com/gpcl/#download)或 [GitHub Releases](https://github.com/CaelLab-org/GoodPlanCraftLauncher/releases) 拿安装包，文件名是 `GPCL-<版本>-Setup.exe`。

别从网盘、群文件或第三方下载站拿安装包：那类文件可能被替换过，启动器也无法校验来源。

## 安装

1. 双击安装包，选择安装目录。
2. 装完从桌面或开始菜单启动 GPCL。
3. 第一次启动会创建配置、日志和默认游戏目录。

从旧版升级不用先卸载。安装程序会就地接管原来的安装（包括更早的 NSIS 安装包），桌面快捷方式和数据都保留。

## 游戏和设置存在哪

都在 `%APPDATA%\gpcl`，不在安装目录里：

| 路径 | 内容 |
| --- | --- |
| `%APPDATA%\gpcl\.minecraft` | 游戏版本、库、资源、模组和存档 |
| `%APPDATA%\gpcl\gpcl\config\setting.ini` | 启动器设置 |
| `%APPDATA%\gpcl\gpcl\log` | 启动器日志 |
| `%APPDATA%\gpcl\gpcl\updata` | 自动更新下载的安装包和进度记录 |

如果改过游戏目录，版本和资源会放到新位置，但配置和日志仍然留在 `%APPDATA%\gpcl`。

### 自动设置游戏语言

**设置 → 游戏 → 自动设置游戏语言** 默认开启，选中的语言默认是简体中文。每次启动前，GPCL 会把当前版本实际使用的 `options.txt` 里的 `lang:` 改成选定的值，其余行原样保留。

隔离版本写进 `versions/<版本名>/options.txt`，未隔离的写进游戏根目录的 `options.txt`。关掉这个开关就完全不碰游戏里的设置。

## 更新

默认开启两项：

- **自动检查更新**：启动时检查，有新版本会在右上角显示提示。
- **自动安装更新**：后台静默下载，不占用下载页，也不改状态栏。校验通过后，等你**退出启动器**时再静默安装。

右上角的圆形徽标会显示下载进度；点开能看到版本号和这一版的更新内容。也可以在里面点「立即下载」，装完会自动重新打开启动器。

在 **设置 → 关于** 里可以关掉自动检查或自动安装，也可以手动点「检查更新」。

更新包会先校验 SHA1 再安装，校验失败不会装。如果装到一半中断，下次启动会提示「上次更新未完成」，可以重试；连续失败三次会引导你去官网重新下载安装包。

:::warning 从 1.5.2 或更早升级
旧版本还不认识静默安装的参数，所以这一次升级仍会弹出一次旧的安装向导。从 1.6.0 往后才是全程静默。
:::

更新后启动器打不开，先看 `%APPDATA%\gpcl\gpcl\log` 里最新的日志，再带着日志发邮件。

## 导入本地版本

在启动页的「版本选择」面板里点「导入本地版本」，可以导入：

- 一个版本文件夹（里面要有 `<版本名>.json`）；
- 一个 zip 或 jar 压缩包，启动器会解开并递归找 `<版本名>.json` 所在的目录；

整合包（`manifest.json` 里带 `minecraft` 段的那种）目前不能导入，启动器会直接拒绝，不会装一半。

## 卸载

在 Windows 的「应用和功能」里卸载 GPCL。卸载程序**不会**删除 `%APPDATA%\gpcl`，重装之后游戏和设置还在。

确定不再使用，可以手动删掉整个 `%APPDATA%\gpcl`。删之前先把存档备份出来。
