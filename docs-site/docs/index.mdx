:::tip 先确认版本
这些页面按 1.9.0 写。当前版本在 **设置 → 关于** 里能看到；版本差得多时，个别选项的位置可能不一样。
:::

## 出了问题怎么问

发邮件到 [gamets@caellab.com](mailto:gamets@caellab.com)。写清楚这几样，基本就能定位：

- 启动器版本、Minecraft 版本、装了哪些模组；
- 崩溃前做了什么（刚装完模组？换过 Java？改过内存？）；
- **GPCL 导出的错误报告**（崩溃弹窗上的「导出错误报告」）。

只发一张崩溃窗口的截图，信息量通常不够。
