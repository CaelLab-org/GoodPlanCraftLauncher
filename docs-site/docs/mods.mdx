---
title: 模组下载
description: 在 GPCL 里搜索、安装 Modrinth 和 CurseForge 模组，前置依赖与中文搜索。
---

下载页的「模组」分区可以直接搜模组、选文件、装到指定版本，不用自己去网页下载再拖进文件夹。

## 搜索

来源有两个：**Modrinth** 和 **CurseForge**。默认会同时搜，结果列表里会标出来源。

搜索框可以先打中文。查询里含中文时，GPCL 会先查 MCMOD 的公开搜索结果，从标题括号里取英文名（比如「雾中人 (The Man From The Fog)」取出 `The Man From The Fog`），再用英文名去搜 Modrinth。取不到英文名就按原查询搜。

## 筛选

默认**不带**版本和加载器筛选，和 PCL 一样先搜全部，免得新模组因为筛选条件被藏起来。需要收窄时再手动选：

- Minecraft 版本；
- 加载器（Forge / Fabric / NeoForge / Quilt）；
- 排序方式。

文件列表会优先把当前启动版本的 MC 版本排在前面，减少装错版本的概率。

## 安装

点文件行的「安装」才会弹出目标选择：

- 已安装的 Mod 版本列表，选一个直接装；
- 「选择文件夹」，装到任意目录的 `mods`。

文件会落在目标版本实际使用的 `mods`：隔离版本是 `versions/<版本名>/mods`，否则是游戏根目录的 `mods`。

未隔离的版本第一次装模组时会启用版本隔离，目标框里会写明这一点，不再额外弹确认。

### 前置依赖

Modrinth 的文件行会显示「N 个前置」。安装时会递归装上下载必需的依赖，成功提示里也会说明带了几个前置。

CurseForge 的链接模式只装选中的单个文件，**不自动装前置**，界面上也会写明。

## CurseForge 没有 API Key

正常搜索 CurseForge 需要 API Key（**设置 → 下载 → CurseForge API Key**，可选），或者等公共镜像可用。没有 Key、镜像又不可用时，还有一条兜底：

在搜索框里粘贴项目地址，或者写 `cf:<短名>`：

```text
https://www.curseforge.com/minecraft/mc-mods/sodium
cf:sodium
```

GPCL 会通过 `api.cfwidget.com` 查项目和文件，再用 ForgeCDN 直链下载。这条路径**只装选中的单个文件，不解析依赖**。

## 装完没生效

- 确认模组支持的 MC 版本和加载器与当前版本一致；
- 确认装到了正确的 `mods`（版本隔离后不是根目录那个）；
- 缺前置的话，先补前置；
- 还不行就看[游戏崩溃](./mc-game.mdx)里的日志排查顺序。
