---
title: 登录：正版与离线
description: GPCL 的微软正版登录与离线登录，区别、流程和切换方式。
---

GPCL 支持两种登录方式，随时可以切换。离线登录不需要联网，但不能进入开启正版验证的服务器。

## 离线登录

在启动页输入一个玩家名就能启动，不需要密码。最近用过的 5 个名字会留在下拉里，也可以逐条删掉。

- 适合单人游戏、局域网联机，以及没有正版验证的服务器。
- 不需要联网验证，断网也能启动。
- 不能进入开启正版验证的服务器，进去会被踢。
- 不要用别人的正版 ID：服务器和玩家都可能认错人。

## Microsoft 正版登录

1. 在启动页点「正版登录」。
2. GPCL 会打开默认浏览器，跳到 Microsoft 登录页。
3. 登录并同意授权，浏览器会提示可以回到启动器。
4. GPCL 自动收到结果，玩家名由账号决定。

登录最多等 2 分钟。如果一直没反应，先确认浏览器里已经完成登录和授权，再检查网络。

启动器会保存登录状态，下次打开不用重新登录。点「启动游戏前优化内存」也不会清掉登录状态。

## 两种模式怎么选

| 场景 | 用哪种 |
| --- | --- |
| 单人游戏、自己玩 | 离线或正版都行 |
| 正版验证服务器 | 必须正版 |
| 没有正版验证的服务器 | 离线或正版都行 |
| 没有网络 | 离线 |

## 切换账号

正版登录状态下，再点一次正版按钮可以登出，然后就能改用离线名字。离线状态下点正版登录会直接进入微软登录流程。

## 服务器提示 Invalid session

多半是登录状态过期，或者这个账号没有该版本的授权：

1. 退出账号后重新做一次正版登录；
2. 确认账号确实拥有这个 Minecraft 版本；
3. 换一个正版服务器试，排除是单个服务器的问题。
