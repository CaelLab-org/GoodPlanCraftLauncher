在下载页选版本时可以直接选加载器。GPCL 会先装原版，再把加载器装到单独的版本目录里，不会覆盖原版。

## 怎么装

1. 打开下载页，选一个 Minecraft 版本。
2. 在加载器选项里选 Forge、Fabric 或 OptiFine，再选对应的加载器版本。
3. 点下载，等原版和加载器都装完。
4. 回到启动页，选带加载器名字的版本启动。

下载任务会进队列，可以连续点几个版本排队；正在下载的任务可以取消，取消后队列会继续。

## 三种加载器怎么选

| 加载器 | 适合 | 注意 |
| --- | --- | --- |
| Forge | 大型整合包、老牌模组 | 启动比 Fabric 慢，版本选择多 |
| Fabric | 轻量模组、新版本 | 需要按游戏版本选对 Fabric Loader |
| OptiFine | 光影、性能优化 | 和其他加载器混装可能需要兼容模组 |

### Forge

安装时 GPCL 只跑 `--installClient`，不会去试 GUI 或服务端参数。安装器的输出会转成进度显示，比如「正在安装 Forge：Downloading library…」。

安装前会检查 Java 大版本，低于 Forge 要求时直接报错，不会再拿低版本 Java 硬跑。整个过程最多等 15 分钟；取消下载会结束安装器进程。

### Fabric

GPCL 直接取 Fabric 的版本 profile 和库文件，不依赖安装器。

「同时安装 Fabric API」默认勾选，装完 Fabric 后会把匹配版本的 Fabric API 放进该版本的 `mods`。取消勾选就不装；Fabric API 装失败只提示，不影响 Fabric 本体。

### OptiFine

OptiFine 走静默安装，不会弹出它自己的图形安装器。安装结果会落回当前游戏目录，自定义游戏目录也能正确处理。

## 模组放哪

新下载的版本默认启用**版本隔离**：游戏目录指向 `versions/<版本名>`，模组、存档和游戏设置都跟着这个版本走。

| 版本情况 | 模组目录 |
| --- | --- |
| 新下载、已隔离 | `versions/<版本名>/mods` |
| 以前就有、版本文件夹里也没有 `mods` / `saves` | 游戏根目录下的 `mods` |

在启动页打开版本的「版本设置」，文件夹入口是按实际隔离结果算的：

- 「版本文件夹」一直有；
- 检测到 Forge / Fabric / NeoForge / Quilt 时出现「Mod 文件夹」；
- 检测到 OptiFine 时出现「光影文件夹」。

想直接往任意目录装模组，可以在模组下载的安装目标里选「选择文件夹」，它会找到那个目录下的 `mods`。

## 装完崩了

1. 先把 `mods` 里的模组全部移走，裸启动一次。
2. 能进就每次放回一半，找出问题模组。
3. 确认模组同时匹配 Minecraft 版本和加载器版本 —— Forge 模组不能直接丢进 Fabric，反过来也一样。
4. 缺前置也会在启动时崩，先去[模组下载](./mods.mdx)看它列出的前置。

OptiFine 和 Forge / Fabric 混装时通常需要额外的兼容模组。没有对应兼容模组就不要硬装。

更多排查步骤见[游戏崩溃](./mc-game.mdx)。
