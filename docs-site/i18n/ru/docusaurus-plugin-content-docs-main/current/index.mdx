## Как спрашивать о проблеме

Напишите на [gamets@caellab.com](mailto:gamets@caellab.com). С этими данными обычно удаётся найти причину:

- версия лаунчера, версия Minecraft, какие моды стоят;
- что вы делали перед сбоем (только что поставили моды? меняли Java? трогали память?);
- **отчёт об ошибке, выгруженный из GPCL** («Экспорт отчёта об ошибке» в окне сбоя).

Одного скриншота окна сбоя обычно недостаточно.
