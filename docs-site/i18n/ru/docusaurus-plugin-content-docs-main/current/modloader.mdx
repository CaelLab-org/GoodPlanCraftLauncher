При выборе версии на странице загрузки можно сразу указать загрузчик. GPCL сначала ставит ванильную версию, а затем загрузчик в отдельный каталог версии, не перезаписывая ваниль.

## Как установить

1. Откройте страницу загрузки и выберите версию Minecraft.
2. В параметрах загрузчика выберите Forge, Fabric или OptiFine, затем нужную версию загрузчика.
3. Нажмите загрузку и дождитесь, пока установятся и ваниль, и загрузчик.
4. Вернитесь на страницу запуска и запустите версию с именем загрузчика.

Задачи загрузки попадают в очередь, можно поставить в неё несколько версий подряд; текущую задачу можно отменить, после чего очередь продолжит работу.

## Какой загрузчик выбрать

| Загрузчик | Для чего | Что учесть |
| --- | --- | --- |
| Forge | Крупные модпаки, старые моды | Запускается медленнее Fabric, очень много версий |
| Fabric | Лёгкие моды, новые версии | Нужно подобрать Fabric Loader под версию игры |
| OptiFine | Шейдеры, оптимизация производительности | Вместе с другими загрузчиками часто нужны моды совместимости |

### Forge

При установке GPCL запускает только `--installClient` и не пробует параметры GUI или сервера. Вывод установщика превращается в ход выполнения, например «Установка Forge: Downloading library…».

Перед этим проверяется мажорная версия Java: если она ниже требуемой Forge, лаунчер сразу сообщает об ошибке, а не пробует со старой Java. Весь процесс длится не дольше 15 минут; отмена загрузки завершает процесс установщика.

### Fabric

GPCL берёт профиль версии и библиотеки Fabric напрямую и не зависит от установщика.

«Установить также Fabric API» отмечено по умолчанию; после Fabric подходящая Fabric API кладётся в `mods` этой версии. Если снять галочку, она не ставится; ошибка установки Fabric API только показывается сообщением и на сам Fabric не влияет.

### OptiFine

OptiFine ставится тихо, собственный графический установщик не появляется. Результат попадает в текущий каталог игры, пользовательский каталог тоже обрабатывается правильно.

## Куда класть моды

У новых загруженных версий по умолчанию включена **изоляция версий**: каталог игры указывает на `versions/<version-name>`, моды, сохранения и настройки игры относятся к этой версии.

| Ситуация с версией | Папка модов |
| --- | --- |
| Новая, изолированная | `versions/<version-name>/mods` |
| Старая, без `mods` / `saves` в папке версии | `mods` в корне игры |

На странице запуска откройте «Настройки версии»: пункты с папками зависят от фактической изоляции:

- «Папка версии» есть всегда;
- «Папка модов» появляется при обнаружении Forge / Fabric / NeoForge / Quilt;
- «Папка шейдеров» появляется при обнаружении OptiFine.

Чтобы ставить моды в произвольный каталог, в цели установки при загрузке модов выберите «Выбрать папку» — лаунчер возьмёт `mods` внутри неё.

## Вылет после установки

1. Уберите все моды из `mods` и один раз запустите без них.
2. Если запускается, возвращайте половину за раз и найдите проблемный мод.
3. Проверьте, что мод подходит и к версии Minecraft, и к версии загрузчика: мод Forge нельзя просто положить в Fabric и наоборот.
4. Отсутствующая зависимость тоже даёт вылет при запуске; посмотрите зависимости в разделе [Загрузка модов](./mods.mdx).

OptiFine вместе с Forge / Fabric обычно требует дополнительных модов совместимости. Без подходящего мода не ставьте силой.

Дальнейшие шаги — в разделе [Сбои игры](./mc-game.mdx).
