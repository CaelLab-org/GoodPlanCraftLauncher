Медленная загрузка обычно не связана с лаунчером. Сначала смените источник, потом смотрите на число потоков и ограничение скорости.

## Задачи загрузки встают в очередь

После нажатия «Загрузить» задача попадает в очередь и не блокирует интерфейс: ожидающие задачи убираются крестиком, текущую можно отменить, после чего очередь продолжит работу.

Страница загрузки показывает состояние каждой задачи: в ожидании, загружается, готово, ошибка.

## Источник файлов и источник списков версий

В **Настройки → Загрузки → Источник загрузки** два независимых списка:

- **Источник файлов**: клиентский jar, ресурсы, библиотеки;
- **Источник списков версий**: манифест версий, JSON версии, индекс ресурсов.

У обоих одинаковые четыре варианта:

| Вариант | Поведение |
| --- | --- |
| Сначала официальный, при медленной работе зеркало | По умолчанию. Сначала официальный, через несколько секунд без ответа — BMCLAPI |
| Предпочитать зеркало | В китайских сетях сразу зеркало |
| Предпочитать официальный | Сначала официальный, при ошибке обратно к зеркалу |
| Только официальный | Только официальный, при недоступности — ошибка |

## Своё зеркало файлов

В **Настройки → Загрузки → Своё зеркало файлов** можно указать корневой адрес зеркала (по умолчанию BMCLAPI, например `https://bmclapi2.bangbang93.com`). После этого манифест версий, клиент, библиотеки и ресурсы сначала идут через него, а при недоступности используется прежний порядок источников.

Пустое поле означает BMCLAPI по умолчанию.

## Каталог игры

**Настройки → Загрузки → Каталог игры** позволяет положить версии, библиотеки, ресурсы и моды в любую папку; пустое поле возвращает к `%APPDATA%\gpcl\.minecraft`.

При смене каталога существующие файлы **не переносятся**. Версии из старого каталога остаются на месте; при необходимости скопируйте их сами. Конфигурация и журналы по-прежнему в `%APPDATA%\gpcl`.

## Максимум потоков

По умолчанию 64, диапазон 1–128. При большом числе мелких файлов параллельность помогает, но слишком высокое значение может упираться в сетевое оборудование или зеркала. При нестабильной сети уменьшайте.

## Ограничение скорости

0 означает без ограничения; заданное значение — **общий предел для всех задач загрузки** в МБ/с, он действует со следующей загрузки. В сетях с несколькими пользователями имеет смысл понизить.

Ограничение действует только на загрузку ресурсов игры. Java-среда качается через отдельное зеркало и на неё это не влияет.

## Зеркала Java

В **Настройки → Загрузки → Загрузка Java** можно выбрать Университет Цинхуа, Нанкинский университет, Huawei Cloud или свой адрес. Если выбранный источник недоступен, лаунчер сам пробует следующий, в конце остаётся официальный Adoptium.

Свой адрес поддерживает две переменные:

- `{v}`: мажорная версия Java, например `8`, `17`, `21`;
- `{version}`: полная версия из апстрима, например `17.0.20.1_1`, меняется с релизами.

Пример:

```text
https://cdn.example.com/java/{v}/OpenJDK{v}U-jre_x64_windows_hotspot_{v}.zip
```

## Что делать при ошибке загрузки

1. Смените источник загрузки.
2. Уменьшите число потоков до 32 или 16 и повторите.
3. Проверьте системное время — большой перекос ломает проверку сертификата HTTPS.
4. Если не помогло, напишите письмо и приложите свежий журнал из `%APPDATA%\gpcl\gpcl\log`.
