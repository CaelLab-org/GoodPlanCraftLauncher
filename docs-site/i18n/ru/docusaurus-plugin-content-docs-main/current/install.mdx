GPCL поддерживает только **Windows 10 / 11 64 бит**. Java в установочный пакет не входит — лаунчер добавит её под версию игры.

## Загрузка

Установочный пакет берётся в [разделе загрузки на сайте](https://gamets.caellab.com/gpcl/#download) или в [GitHub Releases](https://github.com/CaelLab-org/GoodPlanCraftLauncher/releases); имя файла — `GPCL-<version>-Setup.exe`.

Не берите пакет из облачных дисков, чатов и сторонних сайтов: такие файлы могли подменить, а лаунчер не может проверить их происхождение.

## Установка

1. Дважды щёлкните по пакету и выберите каталог установки.
2. После установки запустите GPCL с рабочего стола или из меню «Пуск».
3. При первом запуске создаются конфигурация, журналы и каталог игры по умолчанию.

Перед обновлением со старой версии удалять её не нужно: установщик перехватывает существующую установку (включая старые пакеты NSIS), ярлык на рабочем столе и данные сохраняются.

## Где лежат игра и настройки

Всё в `%APPDATA%\gpcl`, а не в каталоге установки:

| Путь | Содержимое |
| --- | --- |
| `%APPDATA%\gpcl\.minecraft` | Версии игры, библиотеки, ресурсы, моды и сохранения |
| `%APPDATA%\gpcl\gpcl\config\setting.ini` | Настройки лаунчера |
| `%APPDATA%\gpcl\gpcl\log` | Журналы лаунчера |
| `%APPDATA%\gpcl\gpcl\updata` | Скачанные пакеты обновлений и записи о ходе установки |

Если каталог игры менялся, версии и ресурсы окажутся на новом месте, но конфигурация и журналы останутся в `%APPDATA%\gpcl`.

### Автоматическая установка языка игры

**Настройки → Игра → Автоматически задавать язык игры** включено по умолчанию, выбранный язык — упрощённый китайский. Перед каждым запуском GPCL записывает выбранное значение в `lang:` файла `options.txt`, который реально использует текущая версия; остальные строки не меняются.

Для изолированной версии запись идёт в `versions/<version-name>/options.txt`, для неизолированной — в `options.txt` в корне игры. Если выключить эту опцию, лаунчер вообще не трогает настройки игры.

## Обновления

По умолчанию включены две опции:

- **Автоматически проверять обновления**: проверка при запуске; если есть новая версия, справа сверху появляется значок.
- **Автоматически устанавливать обновления**: тихая загрузка в фоне, она не занимает страницу загрузки и не меняет строку состояния. После успешной проверки установка произойдёт, когда вы **закроете лаунчер**.

Круглый значок справа сверху показывает ход загрузки; по нажатию видны номер версии и изменения. Там же можно выбрать «Скачать сейчас» — после установки лаунчер откроется сам.

В **Настройки → О программе** можно отключить автопроверку или автоустановку, а также нажать «Проверить обновления» вручную.

Перед установкой пакет проверяется по SHA1; при несовпадении установка не начнётся. Если установка прервалась, следующий запуск сообщит «Предыдущее обновление не завершено» и предложит повторить; после трёх неудач лаунчер предложит заново скачать пакет с сайта.

:::warning Обновление с 1.5.2 или раньше
Старые версии ещё не знают параметров тихой установки, поэтому при этом обновлении один раз появится прежний мастер установки. Начиная с 1.6.0 всё проходит тихо.
:::

Если после обновления лаунчер не открывается, сначала посмотрите свежий журнал в `%APPDATA%\gpcl\gpcl\log` и приложите его к письму.

## Импорт локальной версии

В панели «Выбор версии» на странице запуска нажмите «Импортировать локальную версию», чтобы импортировать:

- папку версии (в ней должен быть `<version-name>.json`);
- архив zip или jar; лаунчер распакует его и рекурсивно найдёт каталог с `<version-name>.json`;

Модпаки (`manifest.json` с разделом `minecraft`) пока не импортируются: лаунчер сразу откажет и не оставит недоделанную установку.

## Удаление

Удалите GPCL через «Приложения и возможности» Windows. Деинсталлятор **не** удаляет `%APPDATA%\gpcl` — после переустановки игра и настройки на месте.

Если лаунчер больше не нужен, папку `%APPDATA%\gpcl` можно удалить вручную. Сначала сделайте резервную копию сохранений.
