В заголовке окна игры можно писать подстановки, которые GPCL заменяет на реальные значения при запуске.

Настройка находится в **Настройки → Игра → Заголовок окна игры**. Пустой заголовок означает, что заголовок окна не меняется.

## Пример

Заголовок:

```text
{time} · {mc_version} · {gpcl_version}
```

После запуска может отображаться:

```text
20:09:58 · Minecraft 1.21.3 · 1.6.0
```

## Доступные подстановки

| Подстановка | Во что превращается |
| --- | --- |
| `{mc_version}` | Отображаемое имя версии, например Minecraft 1.21.3 или имя с загрузчиком |
| `{mc_id}` | Имя папки версии, например 1.21.3-Fabric |
| `{username}` | Имя игрока, использованное в этом запуске |
| `{gpcl_version}` | Версия GPCL, например 1.6.0 |
| `{date}` | Дата запуска, формат 2026/10/20 |
| `{time}` | Текущее время, формат 20:09:58 |
| `{datetime}` | Дата и время через пробел |
| `{java}` | Имя каталога текущей среды Java |
| `{memory}` | Максимальный выделенный объём памяти в этом запуске, например 4096MB |

Регистр должен совпадать. Ошибочно написанная подстановка остаётся как есть, чтобы было видно, какую исправлять.

## Будет ли заголовок держаться

Ниже есть переключатель «По возможности сохранять это имя», по умолчанию выключен.

- **Выключен**: после появления окна GPCL поправляет заголовок 20 секунд. Если потом игра или мод меняют заголовок, лаунчер уже не вмешивается. Заголовок с `{time}` останется на том моменте.
- **Включён**: заданный заголовок держится всю игру, при входе в мир его не перекрывает « - Singleplayer».

Некоторые модпаки и моды тоже меняют заголовок окна; то, что они перекрывают друг друга, нормально.

:::note
Пока магические слова работают только в заголовке окна игры, в других настройках они не действуют.
:::
