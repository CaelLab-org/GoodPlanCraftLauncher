---
title: Java и память
description: Какая версия Java нужна какой версии игры, как GPCL распределяет память и как её поправить, если не хватает.
---

GPCL сам выбирает Java под версию игры и распределяет память по объёму ОЗУ компьютера. В большинстве случаев вручную ничего менять не нужно.

## Соответствие версий Java

| Версия Minecraft | Нужна Java |
| --- | --- |
| 1.16.5 и раньше | Java 8 |
| 1.17 – 1.20.4 | Java 17 |
| 1.20.5 и позже | Java 21 |

Если при запуске нужной Java нет, GPCL скачает и установит её сам. Если загрузка не удалась, выберите другое зеркало в **Настройки → Загрузки → Загрузка Java** и повторите.

Java устанавливается в собственный каталог GPCL, не влияет на другие Java в системе и не меняет `JAVA_HOME`.

## Память: автоматически

По умолчанию — «Автоматически». Распределение идёт в два шага:

1. сначала берётся **30 %** физической памяти, округление вниз до целых ГБ и ограничение **2 – 8 ГБ**;
2. затем учитывается доступная память: системе остаётся минимум 1 ГБ, расчёт идёт от 2 ГБ, результат округляется вниз до 512 МБ; выбирается меньшее из двух значений.

Несколько реальных результатов:

| Физическая память | Доступно сейчас | Автоматически выделяется |
| --- | --- | --- |
| 16 ГБ | 8 ГБ | 4 ГБ |
| 16 ГБ | 3,9 ГБ | 2,5 ГБ |
| 8 ГБ | 4 ГБ | 2 ГБ |

На странице настроек видно занятую / общую память системы и текущее доступное значение. Когда доступной памяти мало, автоматическое распределение снижается и предлагает закрыть часть программ.

`-Xmx` — это верхняя граница, а не занятая с запуска память. Поэтому распределение по доступной памяти устойчивее очень большого фиксированного значения.

## Память: вручную

Если модпаку или крупному набору модов не хватает, переключитесь на «Вручную» и передвиньте ползунок. Оставьте место системе и другим программам, не отдавайте игре всю физическую память.

`OutOfMemoryError` означает нехватку памяти:

1. увеличьте выделение на одну ступень и повторите;
2. если не помогло, уменьшите число модов;
3. заодно закройте программы, которые едят память, например браузер.

## Настройка G1GC

В **Настройки → Дополнительно → Управление памятью** есть настройка G1GC, по умолчанию выключена. Включать её стоит только при заметных скачках FPS и подвисаниях из-за GC; после включения добавляется набор обычных параметров G1GC.

Свои параметры JVM задаются там же. Ошибка в параметрах не даст игре запуститься — не меняйте их, если не уверены.

## Оптимизация памяти перед запуском

Если включено, GPCL перед запуском игры освобождает часть своей памяти. Это касается только процесса лаунчера, запущенный Minecraft не затрагивается, состояние входа тоже.

На механических жёстких дисках шаг может дать короткое подвисание — это нормально.
