---

GPCL поддерживает два способа входа, переключаться можно в любой момент. Офлайн-вход не требует интернета, но не пускает на серверы с проверкой лицензии.

## Офлайн-вход

На странице запуска достаточно ввести имя игрока, пароль не нужен. Последние 5 имён остаются в выпадающем списке и удаляются по одному.

- Подходит для одиночной игры, локальной сети и серверов без проверки лицензии.
- Не требует проверки по сети, запуск работает и без интернета.
- На серверы с проверкой лицензии не пустит.
- Не используйте чужой лицензионный ID: сервер и другие игроки могут обознаться.

## Вход через Microsoft с лицензией

1. На странице запуска нажмите «Вход с лицензией».
2. GPCL откроет браузер по умолчанию и перейдёт на страницу входа Microsoft.
3. Войдите и подтвердите авторизацию; браузер сообщит, что можно вернуться в лаунчер.
4. GPCL сам получит результат, имя игрока определяется аккаунтом.

GPCL ждёт не более 2 минут. Если ничего не происходит, сначала проверьте, завершены ли вход и авторизация в браузере, затем сеть.

Лаунчер сохраняет состояние входа, при следующем открытии входить заново не нужно. «Оптимизация памяти перед запуском» состояние входа не сбрасывает.

## Какой способ выбрать

| Ситуация | Способ |
| --- | --- |
| Одиночная игра, играете сами | Офлайн или лицензия |
| Сервер с проверкой лицензии | Только лицензия |
| Сервер без проверки лицензии | Офлайн или лицензия |
| Нет сети | Офлайн |

## Смена аккаунта

Если выполнен вход с лицензией, повторное нажатие лицензионной кнопки выполняет выход, после чего можно использовать офлайн-имя. В офлайн-режиме «Вход с лицензией» сразу запускает вход через Microsoft.

## Сервер пишет Invalid session

Чаще всего сеанс истёк или у аккаунта нет лицензии на эту версию:

1. выйдите из аккаунта и повторите вход с лицензией;
2. убедитесь, что аккаунт действительно владеет этой версией Minecraft;
3. попробуйте другой лицензионный сервер, чтобы исключить проблему одного сервера.
