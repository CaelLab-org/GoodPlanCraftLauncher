Раздел «Моды» на странице загрузки позволяет искать моды, выбирать файл и ставить его в нужную версию без браузера и ручного копирования файлов.

## Поиск

Источников два: **Modrinth** и **CurseForge**. По умолчанию поиск идёт в обоих, в результатах указан источник.

Запрос можно писать по-китайски. Если в запросе есть китайские символы, GPCL сначала обращается к публичному поиску MCMOD, берёт английское имя из скобок в заголовке (из «雾中人 (The Man From The Fog)» получается `The Man From The Fog`) и ищет это имя на Modrinth. Если английского имени нет, используется исходный запрос.

## Фильтры

По умолчанию фильтров по версии и загрузчику **нет**, как в PCL: сначала ищется всё, чтобы новые моды не скрывались условиями. Сужать стоит вручную:

- версия Minecraft;
- загрузчик (Forge / Fabric / NeoForge / Quilt);
- сортировка.

Список файлов ставит версию MC текущего запускаемого профиля вперёд, чтобы реже ставить не то.

## Установка

Выбор цели появляется только после нажатия «Установить» в строке файла:

- список установленных версий с модами, выберите одну;
- «Выбрать папку» — установка в `mods` любого каталога.

Файл попадает в `mods`, который реально использует целевая версия: у изолированной это `versions/<version-name>/mods`, иначе `mods` в корне игры.

У неизолированной версии первый установленный мод включает изоляцию версий; в окне выбора цели это написано, отдельного подтверждения нет.

### Зависимости

Строки файлов Modrinth показывают «N зависимостей». При установке рекурсивно ставятся зависимости, необходимые для загрузки, а сообщение об успехе указывает их число.

Режим ссылки CurseForge ставит только выбранный файл и **не устанавливает зависимости**; в интерфейсе это указано.

## CurseForge без API-ключа

Для обычного поиска CurseForge нужен API-ключ (**Настройки → Загрузки → API-ключ CurseForge**, необязательно) или доступное публичное зеркало. Без ключа и зеркала остаётся обходной путь:

вставьте в строку поиска адрес проекта или напишите `cf:<short-name>`:

```text
https://www.curseforge.com/minecraft/mc-mods/sodium
cf:sodium
```

GPCL запросит проект и файлы через `api.cfwidget.com` и скачает по прямой ссылке ForgeCDN. Этот путь **ставит только выбранный файл и не разбирает зависимости**.

## Мод установлен, но не работает

- проверьте, что поддерживаемые модом версия MC и загрузчик совпадают с текущей версией;
- проверьте, что установка попала в нужный `mods` (при изоляции это не папка в корне);
- если не хватает зависимости, сначала поставьте её;
- если не помогло, смотрите порядок разбора журналов в разделе [Сбои игры](./mc-game.mdx).
