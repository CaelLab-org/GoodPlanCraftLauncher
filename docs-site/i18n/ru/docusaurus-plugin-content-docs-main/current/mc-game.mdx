Окно сбоя само по себе обычно не говорит причину. GPCL сначала читает журналы и даёт подсказки, дальше идите по этому порядку.

:::tip Сначала одно действие
Нажмите в окне сбоя «Экспорт отчёта об ошибке» и сохраните zip. В начале отчёта — результаты анализа GPCL, дальше список модов, Java, параметры запуска и все журналы; поиск причины почти всегда опирается на него.
:::

## 1. Сначала посмотрите анализ GPCL

В окне показываются 1–2 подсказки, найденные в журналах, например «Не хватает памяти» или «Не пройдена проверка зависимостей или совместимости модов». По кнопке «Показать подробности» видны все подсказки, соответствующие строки журнала и сведения о сбое.

Эти выводы получены по совпадению ключевых слов и задают только направление. Если в журнале есть более точные данные (какой зависимости не хватает), они приводятся в доказательствах.

## 2. Выгрузите отчёт об ошибке

Кнопка находится в окне сбоя. Выберите место, и GPCL соберёт:

- `error-report.txt`: результаты анализа, краткое описание ошибки, система / видеокарта / Java, список модов, наборы ресурсов и шейдеры, параметры запуска, вывод игры, строки ошибок из журналов;
- `crash-reports/`: отчёты о сбое, созданные при этом вылете;
- `logs/`: `latest.log` и `debug.log` (если слишком большие — только конец);
- `jvm-crash/`: созданные самой JVM `hs_err_pid*.log` (при падении JVM, например из-за драйвера видеокарты);
- `launcher-log.txt`: журналы лаунчера;
- `game-output.txt`: стандартный вывод и вывод ошибок процесса игры за этот запуск.

`--accessToken` и имя пользователя системы в отчёте уже замаскированы, его можно отправлять как есть. Не присылайте только скриншот окна сбоя.

## 3. Посмотрите журналы сами

«Показать журналы» открывает вывод процесса игры. Смотрите прежде всего конец и ищите эти слова:

| Слово | Обычно означает |
| --- | --- |
| `Exception`, `Caused by` | Настоящее исключение обычно после первого `Caused by` |
| `OutOfMemoryError` | Выделенной памяти не хватает |
| `UnsupportedClassVersionError` | Версия Java не соответствует версии игры |
| `NoSuchMethodError`, `ClassNotFoundException` | Мод не совпадает с версией игры или загрузчика, либо нет зависимости |
| `GLFW error` | Проблема драйвера видеокарты или поддержки OpenGL |

## 4. Частые причины

| Симптом | Частая причина | Что делать |
| --- | --- | --- |
| Выходит сразу при запуске, в журнале `UnsupportedClassVersionError` | Не та версия Java | Дать GPCL доустановить Java; или сменить зеркало в настройках и переустановить |
| Зависает или закрывается на середине загрузки, в журнале `OutOfMemoryError` | Мало памяти или слишком много модов | Настройки → Игра → Выделение памяти, увеличить; не выше физической памяти |
| Вылет при загрузке модов, в журнале имя мода | Не та версия мода, нет зависимости, конфликт двух модов | Сначала попробуйте только этот мод; проверьте поддерживаемые версии MC и загрузчика |
| Закрывается до появления окна, `GLFW error` | Старый драйвер видеокарты или нет поддержки OpenGL | Обновите драйвер; на ноутбуке проверьте, что игра идёт на дискретной видеокарте |
| Выкидывает с сервера, `Invalid session` | Сеанс лицензии истёк или у аккаунта нет прав на эту версию | Войдите с лицензией заново; убедитесь, что аккаунт владеет версией |
| Вылет при входе в мир или загрузке наборов ресурсов | Повреждён мир, набор ресурсов или шейдерпак | Сначала создайте новый мир; сохраните копию мира перед разбором |
| Вылет при запуске Fabric, нет `fabric-api` | Не установлен Fabric API | При переустановке Fabric отметьте «Установить также Fabric API» или поставьте его вручную |

## 5. Сначала исключите три вещи

1. **Отключите все моды, наборы ресурсов и шейдеры** и запустите один раз без них. Если запускается — дело в модах.
2. **Запустите ванильную версию**. Если запускается — дело в текущей версии или её наборе модов.
3. **Создайте новый мир**. Если запускается — старый мир повреждён.

## 6. Всё равно не работает

Напишите на [gamets@caellab.com](mailto:gamets@caellab.com), приложите выгруженный отчёт об ошибке и укажите:

- версию лаунчера, версию Minecraft, версию загрузчика;
- какие моды стоят (лучше с номерами версий);
- что вы делали перед сбоем.

Описание «вылетает сразу при запуске» мало что даёт; ключ — журналы в отчёте.
