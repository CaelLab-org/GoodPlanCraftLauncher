在下載頁選版本時可以直接選載入器。GPCL 會先裝原版，再把載入器裝到單獨的版本目錄裡，不會覆蓋原版。

## 怎麼裝

1. 開啟下載頁，選一個 Minecraft 版本。
2. 在載入器選項裡選 Forge、Fabric 或 OptiFine，再選對應的載入器版本。
3. 點下載，等原版和載入器都裝完。
4. 回到啟動頁，選帶載入器名稱的版本啟動。

下載任務會進佇列，可以連續點幾個版本排隊；正在下載的任務可以取消，取消後佇列會繼續。

## 三種載入器怎麼選

| 載入器 | 適合 | 注意 |
| --- | --- | --- |
| Forge | 大型整合包、老牌模組 | 啟動比 Fabric 慢，版本選擇多 |
| Fabric | 輕量模組、新版本 | 需要按遊戲版本選對 Fabric Loader |
| OptiFine | 光影、效能最佳化 | 和其他載入器混裝可能需要相容模組 |

### Forge

安裝時 GPCL 只跑 `--installClient`，不會去試 GUI 或伺服器端參數。安裝器的輸出會轉成進度顯示，比如「正在安裝 Forge：Downloading library…」。

安裝前會檢查 Java 大版本，低於 Forge 要求時直接報錯，不會再拿低版本 Java 硬跑。整個過程最多等 15 分鐘；取消下載會結束安裝器處理程序。

### Fabric

GPCL 直接取 Fabric 的版本 profile 和庫檔案，不依賴安裝器。

「同時安裝 Fabric API」預設勾選，裝完 Fabric 後會把匹配版本的 Fabric API 放進該版本的 `mods`。取消勾選就不裝；Fabric API 裝失敗只提示，不影響 Fabric 本體。

### OptiFine

OptiFine 走靜默安裝，不會彈出它自己的圖形安裝器。安裝結果會落回目前遊戲目錄，自訂遊戲目錄也能正確處理。

## 模組放哪

新下載的版本預設啟用**版本隔離**：遊戲目錄指向 `versions/<version-name>`，模組、存檔和遊戲設定都跟著這個版本走。

| 版本情況 | 模組目錄 |
| --- | --- |
| 新下載、已隔離 | `versions/<version-name>/mods` |
| 以前就有、版本資料夾裡也沒有 `mods` / `saves` | 遊戲根目錄下的 `mods` |

在啟動頁開啟版本的「版本設定」，資料夾入口是按實際隔離結果算的：

- 「版本資料夾」一直有；
- 偵測到 Forge / Fabric / NeoForge / Quilt 時出現「Mod 資料夾」；
- 偵測到 OptiFine 時出現「光影資料夾」。

想直接往任意目錄裝模組，可以在模組下載的安裝目標裡選「選擇資料夾」，它會找到那個目錄下的 `mods`。

## 裝完崩了

1. 先把 `mods` 裡的模組全部移走，裸啟動一次。
2. 能進就每次放回一半，找出問題模組。
3. 確認模組同時匹配 Minecraft 版本和載入器版本 —— Forge 模組不能直接丟進 Fabric，反過來也一樣。
4. 缺前置也會在啟動時崩，先去[模組下載](./mods.mdx)看它列出的前置。

OptiFine 和 Forge / Fabric 混裝時通常需要額外的相容模組。沒有對應相容模組就不要硬裝。

更多排查步驟見[遊戲崩潰](./mc-game.mdx)。
