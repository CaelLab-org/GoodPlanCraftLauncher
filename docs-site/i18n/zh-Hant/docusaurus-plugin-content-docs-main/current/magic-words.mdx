遊戲視窗標題裡可以寫預留位置，啟動時 GPCL 會把它換成真實的值。

位置在 **設定 → 遊戲 → 遊戲視窗標題**。標題留空表示不修改遊戲視窗標題。

## 舉個例子

標題寫成：

```text
{time} · {mc_version} · {gpcl_version}
```

啟動後可能顯示為：

```text
20:09:58 · Minecraft 1.21.3 · 1.6.0
```

## 能用的預留位置

| 預留位置 | 會變成什麼 |
| --- | --- |
| `{mc_version}` | 版本顯示名稱，例如 Minecraft 1.21.3，或帶載入器的名字 |
| `{mc_id}` | 版本資料夾名稱，例如 1.21.3-Fabric |
| `{username}` | 這次啟動使用的玩家名稱 |
| `{gpcl_version}` | GPCL 版本號，例如 1.6.0 |
| `{date}` | 啟動日期，格式 2026/10/20 |
| `{time}` | 目前時間，格式 20:09:58 |
| `{datetime}` | 日期和時間，中間用空格分開 |
| `{java}` | 目前 Java 執行環境目錄名稱 |
| `{memory}` | 這次分配的最大記憶體，例如 4096MB |

大小寫要一致。寫錯的預留位置會原樣顯示，方便你看出是哪一個寫錯了。

## 標題會一直保持嗎

下面有一個「盡量保持該名稱」開關，預設關閉。

- **關閉**：遊戲視窗出現後，GPCL 會持續校正 20 秒。之後如果遊戲或模組改了標題，就不再管了。含 `{time}` 的標題也會停在那個時候。
- **開啟**：整局遊戲期間一直保持你設定的標題，進入世界也不會被「 - Singleplayer」蓋掉。

有些整合包或模組也會改視窗標題，兩邊互相覆蓋屬於正常現象。

:::note
目前只有遊戲視窗標題支援魔術字，其他設定裡不生效。
:::
