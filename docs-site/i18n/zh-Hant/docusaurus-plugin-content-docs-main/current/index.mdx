GoodPlanCraftLauncher（以下稱 GPCL）是 Windows 上的 Minecraft 啟動器。這套文件只講**裝好之後怎麼用、壞了怎麼查**：不寫更新日誌，也不介紹專案歷史。

| 想做的事 | 看哪裡 |
| --- | --- |
| 裝好、升級、解除安裝 | [安裝與更新](./install.mdx) |
| 正版登入還是離線名字 | [登入](./login.mdx) |
| 遊戲卡、記憶體不夠、Java 報錯 | [Java 與記憶體](./java-memory.mdx) |
| 裝 Forge / Fabric / OptiFine | [模組載入器](./modloader.mdx) |
| 在啟動器裡搜模組、裝模組 | [模組下載](./mods.mdx) |
| 下載慢、鏡像來源怎麼選 | [下載與鏡像來源](./download.mdx) |
| 遊戲崩了 | [遊戲崩潰](./mc-game.mdx) |
| 改遊戲視窗標題 | [視窗標題魔術字](./magic-words.mdx) |

:::tip 先確認版本
這些頁面按 1.9.3 寫。目前版本在 **設定 → 關於** 裡能看到；版本差得多時，個別選項的位置可能不一樣。
:::

## 出了問題怎麼問

寄信到 [gamets@caellab.com](mailto:gamets@caellab.com)。寫清楚這幾樣，基本就能定位：

- 啟動器版本、Minecraft 版本、裝了哪些模組；
- 崩潰前做了什麼（剛裝完模組？換過 Java？改過記憶體？）；
- **GPCL 匯出的錯誤報告**（崩潰對話框上的「匯出錯誤報告」）。

只寄一張崩潰視窗的截圖，資訊量通常不夠。
