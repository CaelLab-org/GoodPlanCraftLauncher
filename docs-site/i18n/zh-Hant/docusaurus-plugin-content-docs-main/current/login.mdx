---
title: 登入：正版與離線
description: GPCL 的 Microsoft 正版登入與離線登入，區別、流程和切換方式。
---

GPCL 支援兩種登入方式，隨時可以切換。離線登入不需要連線，但不能進入開啟正版驗證的伺服器。

## 離線登入

在啟動頁輸入一個玩家名稱就能啟動，不需要密碼。最近用過的 5 個名字會留在下拉式選單裡，也可以逐條刪掉。

- 適合單人遊戲、區域網路連線，以及沒有正版驗證的伺服器。
- 不需要連線驗證，斷網也能啟動。
- 不能進入開啟正版驗證的伺服器，進去會被踢。
- 不要用別人的正版 ID：伺服器和玩家都可能認錯人。

## Microsoft 正版登入

1. 在啟動頁點「正版登入」。
2. GPCL 會開啟預設瀏覽器，跳到 Microsoft 登入頁。
3. 登入並同意授權，瀏覽器會提示可以回到啟動器。
4. GPCL 自動收到結果，玩家名稱由帳號決定。

登入最多等 2 分鐘。如果一直沒反應，先確認瀏覽器裡已經完成登入和授權，再檢查網路。

啟動器會儲存登入狀態，下次開啟不用重新登入。點「啟動遊戲前最佳化記憶體」也不會清掉登入狀態。

## 兩種模式怎麼選

| 場景 | 用哪種 |
| --- | --- |
| 單人遊戲、自己玩 | 離線或正版都行 |
| 正版驗證伺服器 | 必須正版 |
| 沒有正版驗證的伺服器 | 離線或正版都行 |
| 沒有網路 | 離線 |

## 切換帳號

正版登入狀態下，再點一次正版按鈕可以登出，然後就能改用離線名字。離線狀態下點正版登入會直接進入 Microsoft 登入流程。

## 伺服器提示 Invalid session

多半是登入狀態過期，或者這個帳號沒有該版本的授權：

1. 登出帳號後重新做一次正版登入；
2. 確認帳號確實擁有這個 Minecraft 版本；
3. 換一個正版伺服器試，排除是單一伺服器的問題。
