---
title: 安裝與更新
description: 下載、安裝、升級和解除安裝 GPCL；遊戲與設定存在 %APPDATA%\gpcl。
---

GPCL 只支援 **Windows 10 / 11 64 位元**。安裝包裡不帶 Java，啟動器會按遊戲版本自己補。

## 下載

從[官網下載區](https://gamets.caellab.com/gpcl/#download)或 [GitHub Releases](https://github.com/CaelLab-org/GoodPlanCraftLauncher/releases) 取得安裝包，檔名是 `GPCL-<version>-Setup.exe`。

別從網路硬碟、群組檔案或第三方下載站取得安裝包：那類檔案可能被替換過，啟動器也無法驗證來源。

## 安裝

1. 雙擊安裝包，選擇安裝目錄。
2. 裝完從桌面或開始功能表啟動 GPCL。
3. 第一次啟動會建立設定、日誌和預設遊戲目錄。

從舊版升級不用先解除安裝。安裝程式會就地接管原本的安裝（包括更早的 NSIS 安裝包），桌面捷徑和資料都保留。

## 遊戲和設定存在哪

都在 `%APPDATA%\gpcl`，不在安裝目錄裡：

| 路徑 | 內容 |
| --- | --- |
| `%APPDATA%\gpcl\.minecraft` | 遊戲版本、庫、資源、模組和存檔 |
| `%APPDATA%\gpcl\gpcl\config\setting.ini` | 啟動器設定 |
| `%APPDATA%\gpcl\gpcl\log` | 啟動器日誌 |
| `%APPDATA%\gpcl\gpcl\updata` | 自動更新下載的安裝包和進度記錄 |

如果改過遊戲目錄，版本和資源會放到新位置，但設定和日誌仍然留在 `%APPDATA%\gpcl`。

### 自動設定遊戲語言

**設定 → 遊戲 → 自動設定遊戲語言** 預設開啟，選中的語言預設是簡體中文。每次啟動前，GPCL 會把目前版本實際使用的 `options.txt` 裡的 `lang:` 改成選定的值，其餘行原樣保留。

隔離版本寫進 `versions/<version-name>/options.txt`，未隔離的寫進遊戲根目錄的 `options.txt`。關掉這個開關就完全不碰遊戲裡的設定。

## 更新

預設開啟兩項：

- **自動檢查更新**：啟動時檢查，有新版本會在右上角顯示提示。
- **自動安裝更新**：背景靜默下載，不佔用下載頁，也不改狀態列。驗證通過後，等你**結束啟動器**時再靜默安裝。

右上角的圓形徽章會顯示下載進度；點開能看到版本號和這一版的更新內容。也可以在裡面點「立即下載」，裝完會自動重新開啟啟動器。

在 **設定 → 關於** 裡可以關掉自動檢查或自動安裝，也可以手動點「檢查更新」。

更新包會先驗證 SHA1 再安裝，驗證失敗不會裝。如果裝到一半中斷，下次啟動會提示「上次更新未完成」，可以重試；連續失敗三次會引導你去官網重新下載安裝包。

:::warning 從 1.5.2 或更早升級
舊版本還不認識靜默安裝的參數，所以這一次升級仍會彈出一次舊的安裝精靈。從 1.6.0 往後才是全程靜默。
:::

更新後啟動器打不開，先看 `%APPDATA%\gpcl\gpcl\log` 裡最新的日誌，再帶著日誌寄信。

## 匯入本機版本

在啟動頁的「版本選擇」面板裡點「匯入本機版本」，可以匯入：

- 一個版本資料夾（裡面要有 `<version-name>.json`）；
- 一個 zip 或 jar 壓縮包，啟動器會解開並遞迴找 `<version-name>.json` 所在的目錄；

整合包（`manifest.json` 裡帶 `minecraft` 段的那種）目前不能匯入，啟動器會直接拒絕，不會裝一半。

## 解除安裝

在 Windows 的「應用程式與功能」裡解除安裝 GPCL。解除安裝程式**不會**刪除 `%APPDATA%\gpcl`，重裝之後遊戲和設定還在。

確定不再使用，可以手動刪掉整個 `%APPDATA%\gpcl`。刪之前先把存檔備份出來。
