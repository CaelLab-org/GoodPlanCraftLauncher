## Cómo preguntar cuando hay un problema

Escribe a [gamets@caellab.com](mailto:gamets@caellab.com). Con estos datos casi siempre se puede localizar el problema:

- versión del lanzador, versión de Minecraft y mods instalados;
- qué hiciste antes del fallo (¿acababas de instalar mods? ¿cambiaste Java? ¿tocaste la memoria?);
- **el informe de errores exportado por GPCL** («Exportar informe de errores» en la ventana de fallo).

Una captura de la ventana de fallo por sí sola normalmente no basta.
