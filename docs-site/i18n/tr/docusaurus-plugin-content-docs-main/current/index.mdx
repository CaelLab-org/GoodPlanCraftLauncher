:::tip Önce sürümü doğrulayın
Bu sayfalar 1.8.0 için yazıldı. Geçerli sürüm **Ayarlar → Hakkında** bölümünde görünür; sürüm çok farklıysa bazı seçeneklerin yeri değişebilir.
:::

## Bir sorun olduğunda nasıl yazmalı

[gamets@caellab.com](mailto:gamets@caellab.com) adresine e-posta gönderin. Şunları yazarsanız sorun genellikle yerini bulur:

- başlatıcı sürümü, Minecraft sürümü, kurulu modlar;
- çökmeden önce ne yaptığınız (yeni mod mu kurdunuz? Java'yı mı değiştirdiniz? belleği mi değiştirdiniz?);
- **GPCL'nin dışa aktardığı hata raporu** (çökme penceresindeki «Hata raporunu dışa aktar»).

Yalnızca çökme penceresinin ekran görüntüsünü göndermek genellikle yeterli bilgi vermez.
