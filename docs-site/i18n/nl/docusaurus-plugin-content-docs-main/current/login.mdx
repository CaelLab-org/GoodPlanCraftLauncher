GPCL kent twee manieren van inloggen, en je kunt altijd wisselen. Offline inloggen werkt zonder internet, maar je kunt er geen servers mee binnen die officiële accountverificatie vereisen.

## Offline inloggen

Vul op de startpagina een spelersnaam in en start; een wachtwoord is niet nodig. De laatste 5 gebruikte namen blijven in de keuzelijst staan en kun je één voor één verwijderen.

- Geschikt voor singleplayer, LAN en servers zonder officiële accountverificatie.
- Geen online controle nodig; werkt ook zonder verbinding.
- Je kunt servers met officiële accountverificatie niet binnen; je wordt eruit gezet.
- Gebruik niet iemands officiële ID: servers en spelers kunnen je voor iemand anders aanzien.

## Inloggen met een Microsoft-account

1. Klik op de startpagina op ‘Met officieel account inloggen’.
2. GPCL opent je standaardbrowser op de Microsoft-inlogpagina.
3. Log in en geef toestemming; de browser meldt dat je terug kunt naar de launcher.
4. GPCL ontvangt het resultaat automatisch en je spelersnaam wordt die van het account.

Inloggen wacht maximaal 2 minuten. Gebeurt er niets, controleer dan eerst of het inloggen en de toestemming in de browser zijn afgerond en daarna je netwerk.

De launcher bewaart de inlogstatus, dus bij de volgende start hoef je niet opnieuw in te loggen. ‘Geheugen optimaliseren voor het starten’ wist de inlogstatus ook niet.

## Welke manier kiezen

| Situatie | Wat je gebruikt |
| --- | --- |
| Singleplayer, voor jezelf | Offline of officieel account, maakt niet uit |
| Server met officiële accountverificatie | Officieel account verplicht |
| Server zonder officiële accountverificatie | Offline of officieel account, maakt niet uit |
| Geen internet | Offline |

## Van account wisselen

Met een officieel account ingelogd log je uit door nog eens op de knop voor het officiële account te klikken; daarna kun je een offlinenaam gebruiken. Offline start een klik op inloggen met officieel account meteen de Microsoft-procedure.

## De server meldt Invalid session

Meestal is de inlogstatus verlopen of heeft het account geen recht op die versie:

1. log uit en doe opnieuw een officiële login;
2. controleer of het account die Minecraft-versie echt bezit;
3. probeer een andere server met officiële verificatie om een probleem met één server uit te sluiten.
