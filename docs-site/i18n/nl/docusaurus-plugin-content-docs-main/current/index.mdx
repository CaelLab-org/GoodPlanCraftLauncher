## Hulp vragen als er iets misgaat

Mail naar [gamets@caellab.com](mailto:gamets@caellab.com). Met deze punten beschreven is het probleem meestal te vinden:

- launcherversie, Minecraft-versie en geïnstalleerde mods;
- wat je deed vlak voor de crash (net mods geïnstalleerd? Java gewijzigd? geheugen aangepast?);
- **het foutrapport dat GPCL exporteert** (knop ‘Foutrapport exporteren’ in het crashvenster).

Alleen een schermafbeelding van het crashvenster levert meestal te weinig informatie op.
