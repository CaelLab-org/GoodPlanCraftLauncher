بطء التنزيل ليس مشكلة المشغّل عادةً. غيّر مصدر التنزيل أولًا، ثم فكّر في عدد الخيوط وتحديد السرعة.

## مهام التنزيل تدخل قائمة انتظار

بعد النقر على «تنزيل» تدخل المهمة قائمة انتظار ولا تجمّد الواجهة: يمكن إزالة المهمة المنتظرة بالنقر على ×، ويمكن إلغاء المهمة الجاري تنزيلها، وبعد الإلغاء تستمر قائمة الانتظار.

تعرض صفحة التنزيل حالة كل مهمة: في الانتظار، جارٍ التنزيل، مكتمل، فاشل.

## مصدر الملفات ومصدر قائمة الإصدارات

في **الإعدادات ← التنزيل ← مصدر التنزيل** قائمتان منسدلتان مستقلتان:

- **مصدر تنزيل الملفات**: ملف jar للعميل، وملفات المواد، ومكتبات التبعيات؛
- **مصدر قائمة الإصدارات**: بيان الإصدارات، وملفات JSON للإصدارات، وفهارس المواد.

لكل منهما الخيارات الأربعة نفسها:

| الخيار | السلوك |
| --- | --- |
| الرسمي أولًا والتحويل إلى المرآة عند البطء | افتراضي. الاتصال أولًا بالمصدر الرسمي، وإن لم يصل رد في بضع ثوانٍ يُنتقل إلى BMCLAPI |
| تفضيل مصادر المرايا | استخدام المرآة مباشرة في الشبكات داخل الصين |
| تفضيل المصدر الرسمي | الرسمي أولًا، والعودة إلى المرآة عند الفشل |
| استخدام المصدر الرسمي فقط | الرسمي فقط، ويفشل التنزيل إذا تعذّر الاتصال به |

## مرآة ملفات مخصّصة

يمكن في **الإعدادات ← التنزيل ← مرآة ملفات مخصّصة** إدخال عنوان جذر مرآة (BMCLAPI افتراضيًا، مثل `https://bmclapi2.bangbang93.com`). بعد إدخاله تُجلب بيانات الإصدارات والعميل والمكتبات والمواد منه أولًا، وإن تعذّر ذلك يُستخدم ترتيب المصادر الأصلي كبديل.

تركه فارغًا يعني BMCLAPI الافتراضية.

## مجلد اللعبة

يتيح **الإعدادات ← التنزيل ← مجلد اللعبة** وضع الإصدارات والمكتبات والمواد والمودات في أي مجلد؛ وتركه فارغًا يعيد `%APPDATA%\gpcl\.minecraft`.

تغيير المجلد **لا ينقل** الملفات الموجودة تلقائيًا. الإصدارات في المجلد القديم لن تنتقل معك؛ انسخها يدويًا إن لزم. وتبقى الإعدادات والسجلات في `%APPDATA%\gpcl`.

## الحد الأقصى لعدد الخيوط

القيمة الافتراضية 64، والنطاق 1–128. عند كثرة الملفات الصغيرة يسرّع رفع التزامن قليلًا، لكن القيم العالية جدًا قد تصطدم بحدود أجهزة الشبكة أو المرآة. أنزله إذا كانت الشبكة غير مستقرة.

## تحديد السرعة

0 يعني بلا حد؛ وبعد إدخال قيمة **تتشارك كل مهام التنزيل هذا الحد الإجمالي**، بوحدة MB/s، ويُطبَّق بدءًا من التنزيل التالي.

يخصّ هذا الحد تنزيل مواد اللعبة فقط. أما Java فيُنزَّل من مرآة منفصلة ولا يتأثر به.

## مصادر مرآة Java

في **الإعدادات ← التنزيل ← تنزيل Java** يمكن اختيار جامعة تسينغهوا أو جامعة نانجينغ أو Huawei Cloud أو مصدر مخصّص. وإذا فشل المصدر المختار يُنتقل تلقائيًا إلى التالي، وفي النهاية يبقى Adoptium الرسمي كبديل.

يدعم العنوان المخصّص متغيرين:

- `{v}`: الإصدار الرئيسي لـ Java، مثل `8` و`17` و`21`؛
- `{version}`: رقم الإصدار الكامل من المصدر الأعلى، مثل `17.0.20.1_1`، ويتغيّر مع إصدارات المصدر.

مثال:

```text
https://cdn.example.com/java/{v}/OpenJDK{v}U-jre_x64_windows_hotspot_{v}.zip
```

## ماذا تفعل أولًا عند فشل التنزيل

1. غيّر مصدر التنزيل.
2. أنزل عدد الخيوط إلى 32 أو 16 وأعد المحاولة.
3. تأكد من صحة وقت النظام — الانحراف الكبير يسبب فشل التحقق من شهادات HTTPS.
4. إذا لم ينفع، أرسل بريدًا مع أحدث سجل في `%APPDATA%\gpcl\gpcl\log`.
