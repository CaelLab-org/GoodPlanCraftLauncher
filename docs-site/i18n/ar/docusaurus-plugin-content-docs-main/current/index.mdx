## كيف تسأل عند حدوث مشكلة

أرسل بريدًا إلى [gamets@caellab.com](mailto:gamets@caellab.com). اذكر ما يلي وستتمكن غالبًا من تحديد المشكلة:

- إصدار المشغّل، وإصدار Minecraft، والمودات المثبّتة؛
- ما فعلته قبل الانهيار (هل ثبّت مودًا للتو؟ هل غيّرت Java؟ هل عدّلت الذاكرة؟)؛
- **تقرير الخطأ الذي يصدّره GPCL** («تصدير تقرير الخطأ» في نافذة الانهيار).

إرسال لقطة شاشة لنافذة الانهيار وحدها لا يوفّر معلومات كافية عادةً.
