---
title: Java والذاكرة
description: كيف تتوافق إصدارات Java، وكيف يوزّع GPCL الذاكرة، وما تفعله عند نقص الذاكرة.
---

يختار GPCL إصدار Java تلقائيًا بحسب إصدار اللعبة، ويوزّع الذاكرة تلقائيًا بحسب ذاكرة الحاسوب. لا تحتاج في معظم الحالات إلى تعديل يدوي.

## توافق إصدارات Java

| إصدار Minecraft | Java المطلوبة |
| --- | --- |
| 1.16.5 وأقدم | Java 8 |
| 1.17 – 1.20.4 | Java 17 |
| 1.20.5 وأحدث | Java 21 |

إذا لم تكن Java المطلوبة موجودة عند التشغيل، ينزّلها GPCL ويثبّتها تلقائيًا. وإذا فشل التنزيل، انتقل إلى **الإعدادات ← التنزيل ← تنزيل Java** وجرّب مصدر مرآة آخر.

تُثبَّت Java في مجلد GPCL الخاص، ولا تؤثر على نسخ Java الأخرى في النظام ولا تغيّر متغير النظام `JAVA_HOME`.

## الذاكرة: تلقائي

الإعداد الافتراضي هو «تلقائي». تعتمد آلية التوزيع على خطوتين:

1. أولًا يُقدَّر **30%** من الذاكرة الفيزيائية، ويُقرَّب نزولًا إلى GB كاملة، ويُقيَّد بين **2 و8 GB**؛
2. ثم تُؤخذ الذاكرة المتاحة الحالية بعين الاعتبار: يُترك للنظام 1 GB على الأقل، ويُحسب 2 GB كحد أدنى، وتُقرَّب النتيجة نزولًا إلى 512 MB، ويُؤخذ الأصغر من القيمتين.

بعض النتائج الفعلية:

| الذاكرة الفيزيائية | المتاحة حاليًا | التوزيع التلقائي |
| --- | --- | --- |
| 16 GB | 8 GB | 4 GB |
| 16 GB | 3.9 GB | 2.5 GB |
| 8 GB | 4 GB | 2 GB |

تعرض صفحة الإعدادات المستخدم من ذاكرة النظام وإجماليها والقيمة المتاحة حاليًا. وعندما تقل الذاكرة المتاحة ينخفض التوزيع التلقائي وينبّهك إلى إغلاق بعض البرامج أولًا.

`-Xmx` حدّ أقصى وليس حجزًا كاملًا منذ التشغيل. لذلك يكون التوزيع بحسب الذاكرة المتاحة في تلك اللحظة أكثر استقرارًا من إعطاء قيمة كبيرة ثابتة.

## الذاكرة: مخصّص

إذا لم تكفِ الذاكرة لحزمة مودات أو مجموعة مودات كبيرة، فانتقل إلى «مخصّص» واسحب شريط التمرير. اترك مساحة للنظام وللبرامج الأخرى، ولا تمنح اللعبة كل الذاكرة الفيزيائية.

ظهور `OutOfMemoryError` يعني أن الذاكرة لا تكفي:

1. ارفع التوزيع درجة واحدة ثم أعد المحاولة؛
2. إذا لم ينفع، فقلّل المودات؛
3. أغلق في الوقت نفسه البرامج المستهلكة للذاكرة مثل المتصفح.

## ضبط G1GC

يوجد في **الإعدادات ← متقدّم ← إدارة الذاكرة** ضبط G1GC، وهو معطّل افتراضيًا. يُنصح بتفعيله فقط عند تقلّب معدل الإطارات أو ظهور توقفات GC واضحة؛ وعند تفعيله تُضاف مجموعة شائعة من معاملات G1GC.

معاملات JVM المخصّصة في الموضع نفسه. المعاملات الخاطئة تمنع اللعبة من الإقلاع، فلا تعدّلها إن لم تكن متأكدًا.

## تحسين الذاكرة قبل التشغيل

عند تفعيله يستعيد GPCL جزءًا من الذاكرة التي يشغلها قبل بدء اللعبة. ينظّف عملية المشغّل وحدها، ولا يمسّ Minecraft قيد التشغيل ولا يمسح حالة تسجيل الدخول.

قد يظهر تقطّع قصير في هذه الخطوة على الأقراص الميكانيكية، وهذا أمر طبيعي.
