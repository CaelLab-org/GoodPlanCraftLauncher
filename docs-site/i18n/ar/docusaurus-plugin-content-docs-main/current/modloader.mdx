في صفحة التنزيل يمكنك اختيار المُحمّل مع الإصدار. يثبّت GPCL أولًا النسخة الأصلية، ثم يثبّت المُحمّل في مجلد إصدار منفصل دون استبدال النسخة الأصلية.

## كيف تُثبّت

1. افتح صفحة التنزيل واختر إصدار Minecraft.
2. في خيارات المُحمّل اختر Forge أو Fabric أو OptiFine، ثم الإصدار المناسب للمُحمّل.
3. انقر على «تنزيل» وانتظر حتى يكتمل تثبيت النسخة الأصلية والمُحمّل.
4. عُد إلى صفحة التشغيل وشغّل الإصدار الذي يحمل اسم المُحمّل.

تذهب مهام التنزيل إلى قائمة انتظار، ويمكن إضافة عدة إصدارات على التوالي؛ ويمكن إلغاء المهمة الجاري تنزيلها، وبعد الإلغاء تستمر قائمة الانتظار.

## أي مُحمّل تختار

| المُحمّل | المناسب لـ | ملاحظات |
| --- | --- | --- |
| Forge | حزم المودات الكبيرة والمودات القديمة | يبدأ أبطأ من Fabric، وخيارات الإصدارات أكثر |
| Fabric | المودات الخفيفة والإصدارات الجديدة | يلزم اختيار Fabric Loader المناسب لإصدار اللعبة |
| OptiFine | الشيدر وتحسين الأداء | قد يحتاج إلى مودات توافق عند استخدامه مع مُحمّلات أخرى |

### Forge

أثناء التثبيت يشغّل GPCL الخيار `--installClient` فقط، ولا يجرّب واجهة رسومية أو معاملات خادم. يُحوَّل ناتج برنامج التثبيت إلى تقدّم، مثل «جارٍ تثبيت Forge: Downloading library…».

يُفحص الإصدار الرئيسي لـ Java قبل التثبيت؛ فإذا كان أقل من متطلبات Forge يظهر خطأ مباشرة ولا يُشغَّل برنامج التثبيت على Java أقدم. تُنتظر العملية كلها مدة أقصاها 15 دقيقة؛ وإلغاء التنزيل يُنهي عملية برنامج التثبيت.

### Fabric

يأخذ GPCL ملف تعريف إصدار Fabric وملفات المكتبات مباشرة، دون الاعتماد على برنامج التثبيت.

خيار «تثبيت Fabric API أيضًا» محدّد افتراضيًا؛ فبعد تثبيت Fabric يُوضع الإصدار المطابق من Fabric API في `mods` لذلك الإصدار. وإلغاء التحديد يمنع تثبيته؛ وفشل تثبيت Fabric API يعرض تنبيهًا فقط ولا يؤثر على Fabric نفسه.

### OptiFine

يُثبَّت OptiFine بصمت، ولا يفتح برنامج التثبيت الرسومي الخاص به. تذهب نتيجة التثبيت إلى مجلد اللعبة الحالي، ويُعالَج مجلد اللعبة المخصّص بشكل صحيح أيضًا.

## أين توضع المودات

الإصدارات المنزّلة حديثًا تُفعّل **عزل الإصدار** افتراضيًا: يشير مجلد اللعبة إلى `versions/<version-name>`، وتتبع المودات وملفات الحفظ وإعدادات اللعبة هذا الإصدار.

| حالة الإصدار | مجلد المودات |
| --- | --- |
| منزّل حديثًا ومعزول | `versions/<version-name>/mods` |
| موجود مسبقًا ولا يحتوي مجلد الإصدار على `mods` / `saves` | `mods` في جذر مجلد اللعبة |

في صفحة التشغيل افتح «إعدادات الإصدار»؛ وتُحسب مداخل المجلدات بحسب نتيجة العزل الفعلية:

- «مجلد الإصدار» موجود دائمًا؛
- يظهر «مجلد المودات» عند اكتشاف Forge / Fabric / NeoForge / Quilt؛
- يظهر «مجلد الشيدر» عند اكتشاف OptiFine.

لتثبيت المودات في أي مجلد مباشرة، اختر «اختيار مجلد» في هدف تثبيت المودات؛ وسيجد `mods` داخل ذلك المجلد.

## انهيار بعد التثبيت

1. انقل كل المودات من `mods` جانبًا وشغّل اللعبة نظيفة مرة واحدة.
2. إذا أقلعت، فأعد نصف المودات في كل مرة حتى تجد المود المشكلة.
3. تأكد من أن المود يطابق إصدار Minecraft وإصدار المُحمّل معًا — لا يمكن وضع مود Forge في Fabric والعكس.
4. نقص المتطلبات يؤدي أيضًا إلى الانهيار عند التشغيل؛ فاطّلع أولًا على المتطلبات المذكورة في [تنزيل المودات](./mods.mdx).

استخدام OptiFine مع Forge / Fabric يحتاج عادةً إلى مودات توافق إضافية. لا تفرض التثبيت إن لم يتوفر مود التوافق المناسب.

لمزيد من خطوات التشخيص راجع [انهيار اللعبة](./mc-game.mdx).
