يمكن كتابة عناصر نائبة في عنوان نافذة اللعبة، ويستبدلها GPCL بالقيم الحقيقية عند التشغيل.

الموضع في **الإعدادات ← اللعبة ← عنوان نافذة اللعبة**. ترك العنوان فارغًا يعني عدم تغيير عنوان نافذة اللعبة.

## مثال

إذا كتبت العنوان هكذا:

```text
{time} · {mc_version} · {gpcl_version}
```

فقد يظهر بعد التشغيل هكذا:

```text
20:09:58 · Minecraft 1.21.3 · 1.6.0
```

## العناصر النائبة المتاحة

| العنصر النائب | القيمة التي يتحول إليها |
| --- | --- |
| `{mc_version}` | الاسم المعروض للإصدار، مثل Minecraft 1.21.3 أو الاسم مع المُحمّل |
| `{mc_id}` | اسم مجلد الإصدار، مثل 1.21.3-Fabric |
| `{username}` | اسم اللاعب المستخدم في هذا التشغيل |
| `{gpcl_version}` | رقم إصدار GPCL، مثل 1.6.0 |
| `{date}` | تاريخ التشغيل بصيغة 2026/10/20 |
| `{time}` | الوقت الحالي بصيغة 20:09:58 |
| `{datetime}` | التاريخ والوقت مفصولين بمسافة |
| `{java}` | اسم مجلد بيئة تشغيل Java الحالية |
| `{memory}` | أقصى ذاكرة مخصّصة لهذا التشغيل، مثل 4096MB |

يجب مطابقة حالة الأحرف. يظهر العنصر النائب الخاطئ كما هو، لتتمكن من معرفة أيّها كتبته خطأً.

## هل يبقى العنوان دائمًا

يوجد أسفله مفتاح «محاولة الحفاظ على الاسم»، وهو معطّل افتراضيًا.

- **معطّل**: بعد ظهور نافذة اللعبة يضبط GPCL العنوان لمدة 20 ثانية. وبعد ذلك، إذا غيّرت اللعبة أو إحدى المودات العنوان، لا يتدخل مجددًا. والعنوان الذي يحتوي `{time}` يتوقف عند تلك اللحظة أيضًا.
- **مفعّل**: يبقى العنوان الذي حددته طوال الجلسة، ولا يُستبدل بـ « - Singleplayer» عند دخول العالم.

بعض حزم المودات أو المودات تغيّر عنوان النافذة أيضًا، وتبادل الكتابة بينهما أمر طبيعي.

:::note
العناصر النائبة مدعومة حاليًا في عنوان نافذة اللعبة فقط، ولا تعمل في الإعدادات الأخرى.
:::
