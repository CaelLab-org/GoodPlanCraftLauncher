---
title: 'Login: premium dan offline'
description: Login Microsoft premium dan login offline di GPCL — perbedaannya, alurnya, dan cara berganti.
---

GPCL mendukung dua cara login dan bisa diganti kapan saja. Login offline tidak perlu internet, tetapi tidak bisa masuk ke server yang mengaktifkan verifikasi premium.

## Login offline

Di halaman peluncuran cukup masukkan nama pemain untuk menjalankan game, tanpa kata sandi. Lima nama terakhir tetap ada di dropdown dan bisa dihapus satu per satu.

- Cocok untuk singleplayer, LAN, dan server tanpa verifikasi premium.
- Tidak perlu verifikasi online, tetap bisa dijalankan tanpa internet.
- Tidak bisa masuk ke server yang mengaktifkan verifikasi premium; akan ditendang.
- Jangan memakai ID premium orang lain: server maupun pemain lain bisa salah mengenali.

## Login premium Microsoft

1. Di halaman peluncuran, klik "Login premium".
2. GPCL membuka browser bawaan dan membuka halaman login Microsoft.
3. Login dan setujui otorisasinya; browser akan memberi tahu bahwa Anda bisa kembali ke launcher.
4. GPCL menerima hasilnya otomatis, dan nama pemain ditentukan oleh akun.

Login menunggu paling lama 2 menit. Kalau tidak ada respons, pastikan dulu login dan otorisasi di browser sudah selesai, baru periksa jaringan.

Launcher menyimpan status login, jadi tidak perlu login lagi saat dibuka berikutnya. "Optimalkan memori sebelum menjalankan game" juga tidak menghapus status login.

## Memilih di antara kedua mode

| Situasi | Yang dipakai |
| --- | --- |
| Singleplayer, main sendiri | Offline atau premium, keduanya bisa |
| Server dengan verifikasi premium | Harus premium |
| Server tanpa verifikasi premium | Offline atau premium, keduanya bisa |
| Tanpa internet | Offline |

## Berganti akun

Saat login premium, klik lagi tombol premium untuk logout, lalu nama offline bisa dipakai. Saat offline, klik login premium akan langsung masuk ke alur login Microsoft.

## Server menampilkan Invalid session

Biasanya status login sudah kedaluwarsa, atau akun ini tidak punya lisensi untuk versi tersebut:

1. Logout lalu lakukan login premium sekali lagi;
2. Pastikan akun memang memiliki versi Minecraft ini;
3. Coba server premium lain, untuk memastikan bukan masalah satu server.
