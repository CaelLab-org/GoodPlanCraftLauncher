:::tip Periksa versinya dulu
Halaman ini ditulis untuk 1.9.2. Versi saat ini terlihat di **Pengaturan → Tentang**; kalau versinya jauh berbeda, posisi sebagian opsi bisa berubah.

## Cara bertanya saat ada masalah

Kirim email ke [gamets@caellab.com](mailto:gamets@caellab.com). Tuliskan hal-hal ini dengan jelas, biasanya sudah cukup untuk melacak masalahnya:

- versi launcher, versi Minecraft, mod apa saja yang terpasang;
- apa yang dilakukan sebelum crash (baru memasang mod? mengganti Java? mengubah memori?);
- **laporan kesalahan hasil ekspor GPCL** (tombol "Ekspor laporan kesalahan" di dialog crash).

Hanya mengirim tangkapan layar jendela crash biasanya tidak cukup.
