GoodPlanCraftLauncher (ต่อไปนี้เรียก GPCL) เป็นตัวเปิดเกม Minecraft บน Windows เอกสารชุดนี้อธิบายเฉพาะ **วิธีใช้หลังติดตั้งและวิธีตรวจสอบเมื่อเกิดปัญหา**: ไม่มีบันทึกการเปลี่ยนแปลง และไม่แนะนำประวัติของโปรเจกต์

| อยากทำอะไร | ดูที่ไหน |
| --- | --- |
| ติดตั้ง อัปเกรด ถอนการติดตั้ง | [การติดตั้งและอัปเดต](./install.mdx) |
| เข้าสู่ระบบอย่างเป็นทางการหรือชื่อออฟไลน์ | [การเข้าสู่ระบบ](./login.mdx) |
| เกมกระตุก หน่วยความจำไม่พอ Java แจ้งข้อผิดพลาด | [Java และหน่วยความจำ](./java-memory.mdx) |
| ติดตั้ง Forge / Fabric / OptiFine | [ตัวโหลดมอด](./modloader.mdx) |
| ค้นหาและติดตั้งมอดในตัวเปิดเกม | [ดาวน์โหลดมอด](./mods.mdx) |
| ดาวน์โหลดช้า จะเลือกแหล่งมิเรอร์อย่างไร | [ดาวน์โหลดและแหล่งมิเรอร์](./download.mdx) |
| เกมแครช | [เกมแครช](./mc-game.mdx) |
| เปลี่ยนชื่อหน้าต่างเกม | [คำวิเศษของชื่อหน้าต่าง](./magic-words.mdx) |

:::tip ตรวจสอบเวอร์ชันก่อน
หน้าเหล่านี้เขียนอ้างอิง 1.9.0 เวอร์ชันปัจจุบันดูได้ที่ **การตั้งค่า → เกี่ยวกับ**; หากเวอร์ชันต่างกันมาก ตำแหน่งของบางตัวเลือกอาจไม่เหมือนกัน
:::

## มีปัญหาแล้วถามอย่างไร

ส่งอีเมลถึง [gamets@caellab.com](mailto:gamets@caellab.com) ระบุสิ่งต่อไปนี้ก็มักจะระบุสาเหตุได้:

- เวอร์ชันตัวเปิดเกม เวอร์ชัน Minecraft มอดที่ติดตั้งไว้;
- ทำอะไรก่อนเกิดแครช (เพิ่งติดตั้งมอด? เปลี่ยน Java? เปลี่ยนหน่วยความจำ?);
- **รายงานข้อผิดพลาดที่ GPCL ส่งออก** (ปุ่ม "ส่งออกรายงานข้อผิดพลาด" บนหน้าต่างแจ้งเตือนแครช)

ส่งแค่ภาพหน้าจอของหน้าต่างแครชมักมีข้อมูลไม่พอ
