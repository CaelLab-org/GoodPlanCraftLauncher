description: การจับคู่เวอร์ชัน Java, GPCL จัดสรรหน่วยความจำอัตโนมัติอย่างไร, และวิธีปรับเมื่อหน่วยความจำไม่พอ
---

GPCL เลือก Java ตามเวอร์ชันเกมโดยอัตโนมัติ และจัดสรรตามหน่วยความจำของคอมพิวเตอร์ ส่วนใหญ่ไม่ต้องปรับด้วยตนเอง

## ความสัมพันธ์ของเวอร์ชัน Java

| เวอร์ชัน Minecraft | Java ที่ต้องใช้ |
| --- | --- |
| 1.16.5 และเก่ากว่า | Java 8 |
| 1.17 – 1.20.4 | Java 17 |
| 1.20.5 ขึ้นไป | Java 21 |

เมื่อเปิดเกมแล้วพบว่าไม่มี Java ที่ตรงกัน GPCL จะดาวน์โหลดและติดตั้งให้อัตโนมัติ หากดาวน์โหลดล้มเหลว ให้ไปที่ **การตั้งค่า → ดาวน์โหลด → ดาวน์โหลด Java** เปลี่ยนแหล่งมิเรอร์แล้วลองใหม่

Java ติดตั้งอยู่ในโฟลเดอร์ของ GPCL เอง ไม่กระทบ Java อื่นในระบบ และไม่เปลี่ยน `JAVA_HOME` ของระบบ

## หน่วยความจำ: อัตโนมัติ

ค่าเริ่มต้นคือ "อัตโนมัติ" ตรรกะการจัดสรรมีสองขั้น:

1. ประเมินจาก **30%** ของหน่วยความจำกายภาพก่อน ปัดลงเป็นจำนวนเต็ม GB และจำกัดในช่วง **2 – 8 GB**;
2. จากนั้นดูหน่วยความจำที่ใช้ได้ในขณะนั้น: เหลือให้ระบบอย่างน้อย 1 GB คิดขั้นต่ำ 2 GB ปัดผลลัพธ์ลงเป็นทวีคูณของ 512 MB แล้วเลือกค่าที่น้อยกว่าระหว่างสองค่า

ผลลัพธ์จริงบางกรณี:

| หน่วยความจำกายภาพ | ใช้ได้ในขณะนั้น | จัดสรรอัตโนมัติ |
| --- | --- | --- |
| 16 GB | 8 GB | 4 GB |
| 16 GB | 3.9 GB | 2.5 GB |
| 8 GB | 4 GB | 2 GB |

หน้าตั้งค่าจะแสดงหน่วยความจำระบบที่ใช้ไป / ทั้งหมด และค่าที่ใช้ได้ในขณะนั้น เมื่อหน่วยความจำที่ใช้ได้ตึง การจัดสรรอัตโนมัติจะลดลงตาม และแนะนำให้ปิดโปรแกรมบางตัวก่อน

`-Xmx` เป็นเพดาน ไม่ได้ใช้เต็มทันทีที่เปิดเกม ดังนั้นการจัดสรรตามหน่วยความจำที่ใช้ได้ในขณะนั้นจึงเสถียรกว่าการกำหนดค่ามาก ๆ แบบตายตัว

## หน่วยความจำ: กำหนดเอง

เมื่อมอดแพ็กหรือชุดมอดขนาดใหญ่ใช้ไม่พอ ให้เปลี่ยนเป็น "กำหนดเอง" แล้วลากแถบเลื่อน เหลือที่ให้ระบบและโปรแกรมอื่น อย่าให้หน่วยความจำกายภาพทั้งหมดกับเกม

ถ้าเจอ `OutOfMemoryError` แสดงว่าหน่วยความจำไม่พอ:

1. เพิ่มการจัดสรรขึ้นหนึ่งระดับแล้วลองใหม่;
2. ยังไม่พอให้ลดมอด;
3. ปิดเบราว์เซอร์และโปรแกรมที่กินหน่วยความจำพร้อมกัน

## การปรับแต่ง G1GC

**การตั้งค่า → ขั้นสูง → การจัดการหน่วยความจำ** มีการปรับแต่ง G1GC ปิดเป็นค่าเริ่มต้น แนะนำให้เปิดเฉพาะเมื่อเฟรมเรตแกว่งหรือ GC กระตุกชัดเจน เมื่อเปิดแล้วจะเพิ่มชุดพารามิเตอร์ G1GC ที่ใช้บ่อย

พารามิเตอร์ JVM กำหนดเองอยู่ในส่วนเดียวกัน หากเขียนพารามิเตอร์ผิดเกมจะเปิดไม่ขึ้น ไม่แน่ใจอย่าแก้

## เพิ่มประสิทธิภาพหน่วยความจำก่อนเปิดเกม

เมื่อเปิดใช้ GPCL จะคืนหน่วยความจำส่วนหนึ่งที่ตัวเองใช้ก่อนเปิดเกม มันเก็บกวาดเฉพาะโปรเซสของตัวเปิดเกมเอง ไม่แตะ Minecraft ที่กำลังทำงาน และไม่ล้างสถานะการเข้าสู่ระบบ

บนฮาร์ดดิสก์แบบจานหมุน ขั้นตอนนี้อาจกระตุกสั้น ๆ เป็นเรื่องปกติ
