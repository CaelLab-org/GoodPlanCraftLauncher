ดาวน์โหลดช้ามักไม่ใช่ปัญหาของตัวเปิดเกม เปลี่ยนแหล่งดาวน์โหลดก่อน แล้วค่อยพิจารณาจำนวนเธรดและจำกัดความเร็ว

## งานดาวน์โหลดจะเข้าคิว

หลังกด "ดาวน์โหลด" งานจะเข้าคิว ไม่ทำให้หน้าจอทั้งหมดค้าง: งานที่รออยู่กด × เพื่อลบได้ งานที่กำลังดาวน์โหลดยกเลิกได้ เมื่อยกเลิกแล้วคิวจะทำงานต่อ

หน้าดาวน์โหลดจะแสดงสถานะของแต่ละงาน: รออยู่ กำลังดาวน์โหลด เสร็จสิ้น ล้มเหลว

## แหล่งดาวน์โหลดไฟล์ vs แหล่งรายการเวอร์ชัน

**การตั้งค่า → ดาวน์โหลด → แหล่งดาวน์โหลด** มีสองรายการแบบเลื่อนลง แยกกัน:

- **แหล่งดาวน์โหลดไฟล์**: jar ฝั่งไคลเอนต์ ไฟล์ทรัพยากร ไลบรารีที่พึ่งพา;
- **แหล่งรายการเวอร์ชัน**: รายการเวอร์ชัน JSON เวอร์ชัน ดัชนีทรัพยากร

ทั้งสองมีสี่ตัวเลือกเหมือนกัน:

| ตัวเลือก | พฤติกรรม |
| --- | --- |
| อย่างเป็นทางการก่อน ช้าแล้วเปลี่ยนมิเรอร์ | ค่าเริ่มต้น เชื่อมต่อทางการก่อน หากไม่ตอบสนองภายในไม่กี่วินาทีเปลี่ยนเป็น BMCLAPI |
| ใช้แหล่งมิเรอร์ให้มากที่สุด | เครือข่ายในประเทศจีนใช้มิเรอร์โดยตรง |
| ให้ความสำคัญกับแหล่งทางการ | ทางการก่อน ล้มเหลวแล้วกลับไปมิเรอร์ |
| ใช้แหล่งทางการให้มากที่สุด | ใช้เฉพาะทางการ เชื่อมต่อไม่ได้ก็ล้มเหลว |

## มิเรอร์ไฟล์กำหนดเอง

**การตั้งค่า → ดาวน์โหลด → มิเรอร์ไฟล์กำหนดเอง** กรอกที่อยู่รากของมิเรอร์ได้ (ค่าเริ่มต้น BMCLAPI เช่น `https://bmclapi2.bangbang93.com`) เมื่อกรอกแล้ว รายการเวอร์ชัน ไคลเอนต์ ไลบรารี และทรัพยากรจะใช้มันก่อน หากดึงไม่ได้จึงสำรองตามลำดับแหล่งเดิม

เว้นว่างคือ BMCLAPI เริ่มต้น

## โฟลเดอร์เกม

**การตั้งค่า → ดาวน์โหลด → โฟลเดอร์เกม** วางเวอร์ชัน ไลบรารี ทรัพยากร และมอดไว้ในโฟลเดอร์ใดก็ได้; เว้นว่างกลับไปที่ `%APPDATA%\gpcl\.minecraft`

การเปลี่ยนโฟลเดอร์**จะไม่ย้าย**ไฟล์ที่มีอยู่ให้อัตโนมัติ เวอร์ชันในโฟลเดอร์เก่าจะไม่ตามไปด้วย หากต้องการให้คัดลอกเอง การตั้งค่าและบันทึกยังอยู่ใน `%APPDATA%\gpcl`

## จำนวนเธรดสูงสุด

ค่าเริ่มต้น 64 ช่วง 1–128 เมื่อมีไฟล์เล็ก ๆ เยอะ การเพิ่มการทำงานพร้อมกันจะเร็วขึ้น แต่หากสูงเกินไปอาจถูกอุปกรณ์เครือข่ายหรือมิเรอร์จำกัด เครือข่ายไม่เสถียรให้ลดลง

## จำกัดความเร็ว

0 หมายถึงไม่จำกัดความเร็ว; เมื่อกรอกค่าแล้ว **งานดาวน์โหลดทั้งหมดใช้เพดานรวมนี้ร่วมกัน** หน่วย MB/s มีผลเมื่อเริ่มดาวน์โหลดครั้งถัดไป หลายคนใช้เครือข่ายร่วมกันสามารถลดลงได้

ข้อจำกัดนี้ใช้กับดาวน์โหลดทรัพยากรเกมเท่านั้น Java runtime ใช้มิเรอร์ดาวน์โหลดแยก ไม่ได้รับผลกระทบ

## แหล่งมิเรอร์ Java

ใน **การตั้งค่า → ดาวน์โหลด → ดาวน์โหลด Java** เลือกมหาวิทยาลัยชิงหวา มหาวิทยาลัยหนานจิง Huawei Cloud หรือกำหนดเองได้ เมื่อแหล่งที่เลือก ล้มเหลวจะเปลี่ยนไปแหล่งถัดไปโดยอัตโนมัติ สุดท้ายยังมี Adoptium ทางการเป็นตัวสำรอง

ที่อยู่กำหนดเองรองรับสองตัวแปร:

- `{v}`: Major version ของ Java เช่น `8`, `17`, `21`;
- `{version}`: หมายเลขเวอร์ชันเต็มจากต้นทาง เช่น `17.0.20.1_1` จะเปลี่ยนตามการอัปเดตต้นทาง

ตัวอย่าง:

```text
https://cdn.example.com/java/{v}/OpenJDK{v}U-jre_x64_windows_hotspot_{v}.zip
```

## ดาวน์โหลดล้มเหลวทำอะไรก่อน

1. เปลี่ยนแหล่งดาวน์โหลด
2. ลดจำนวนเธรดลงเป็น 32 หรือ 16 แล้วลองใหม่
3. ยืนยันเวลาในระบบถูกต้อง — เวลาเบี่ยงเบนมากจะทำให้การตรวจสอบใบรับรอง HTTPS ล้มเหลว
4. ยังไม่ได้ให้ส่งอีเมลพร้อมบันทึกล่าสุดใน `%APPDATA%\gpcl\gpcl\log`
