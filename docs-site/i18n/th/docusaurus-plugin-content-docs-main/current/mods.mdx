ส่วน "มอด" ในหน้าดาวน์โหลดค้นหามอด เลือกไฟล์ และติดตั้งลงเวอร์ชันที่กำหนดได้เลย ไม่ต้องดาวน์โหลดจากเว็บแล้วลากเข้าโฟลเดอร์เอง

## การค้นหา

มีสองแหล่ง: **Modrinth** และ **CurseForge** ค่าเริ่มต้นค้นทั้งสองพร้อมกัน รายการผลลัพธ์จะระบุแหล่งที่มา

ช่องค้นหาพิมพ์ภาษาจีนได้ก่อน เมื่อคำค้นมีภาษาจีน GPCL จะค้นผลการค้นหาสาธารณะของ MCMOD ก่อน ดึงชื่อภาษาอังกฤษจากวงเล็บในชื่อเรื่อง (เช่น "雾中人 (The Man From The Fog)" ดึง `The Man From The Fog` ออกมา) แล้วใช้ชื่อภาษาอังกฤษค้น Modrinth หากดึงชื่อภาษาอังกฤษไม่ได้จะค้นตามคำค้นเดิม

## การกรอง

ค่าเริ่มต้น**ไม่ใส่**การกรองเวอร์ชันและตัวโหลด เหมือน PCL ค้นทั้งหมดก่อน เพื่อไม่ให้มอดใหม่ถูกซ่อนเพราะเงื่อนไขกรอง เมื่อต้องจำกัดขอบเขตค่อยเลือกเอง:

- เวอร์ชัน Minecraft;
- ตัวโหลด (Forge / Fabric / NeoForge / Quilt);
- วิธีเรียงลำดับ

รายการไฟล์จะจัดเวอร์ชัน MC ของเวอร์ชันที่เปิดเกมอยู่ขึ้นก่อน ลดโอกาสติดตั้งผิดเวอร์ชัน

## การติดตั้ง

กด "ติดตั้ง" ที่แถวไฟล์แล้วจึงจะแสดงการเลือกเป้าหมาย:

- รายการเวอร์ชัน Mod ที่ติดตั้งแล้ว เลือกหนึ่งเพื่อติดตั้งตรง ๆ;
- "เลือกโฟลเดอร์" ติดตั้งลง `mods` ของโฟลเดอร์ใดก็ได้

ไฟล์จะลงใน `mods` ที่เวอร์ชันเป้าหมายใช้จริง: เวอร์ชันที่แยกคือ `versions/<version-name>/mods` มิฉะนั้นคือ `mods` ในโฟลเดอร์หลักของเกม

เวอร์ชันที่ยังไม่แยก เมื่อติดตั้งมอดครั้งแรกจะเปิดการแยกเวอร์ชัน กล่องเป้าหมายจะระบุไว้ และไม่เด้งยืนยันเพิ่ม

### สิ่งที่ต้องมีก่อน

แถวไฟล์ของ Modrinth จะแสดง "สิ่งที่ต้องมีก่อน N รายการ" ตอนติดตั้งจะติดตั้งการพึ่งพาที่จำเป็นแบบเรียกซ้ำ ข้อความสำเร็จก็จะระบุว่ามีอะไรบ้าง

โหมดลิงก์ของ CurseForge ติดตั้งเฉพาะไฟล์เดียวที่เลือก **ไม่ติดตั้งสิ่งที่ต้องมีก่อนอัตโนมัติ** หน้าจอก็ระบุไว้

## CurseForge ไม่มี API Key

การค้นหา CurseForge ปกติต้องใช้ API Key (**การตั้งค่า → ดาวน์โหลด → CurseForge API Key**, ไม่บังคับ) หรือรอให้มิเรอร์สาธารณะใช้ได้ หากไม่มี Key และมิเรอร์ก็ใช้ไม่ได้ ยังมีทางสำรอง:

วางที่อยู่โปรเจกต์ในช่องค้นหา หรือเขียน `cf:<short-name>`:

```text
https://www.curseforge.com/minecraft/mc-mods/sodium
cf:sodium
```

GPCL จะค้นโปรเจกต์และไฟล์ผ่าน `api.cfwidget.com` แล้วดาวน์โหลดด้วยลิงก์ตรง ForgeCDN เส้นทางนี้**ติดตั้งเฉพาะไฟล์เดียวที่เลือก ไม่แก้ไขการพึ่งพา**

## ติดตั้งแล้วไม่ทำงาน

- ยืนยันว่าเวอร์ชัน MC และตัวโหลดที่มอดรองรับตรงกับเวอร์ชันปัจจุบัน;
- ยืนยันว่าติดตั้งลง `mods` ที่ถูกต้อง (หลังแยกเวอร์ชันไม่ใช่ตัวในโฟลเดอร์หลัก);
- หากขาดสิ่งที่ต้องมีก่อน ให้ติดตั้งสิ่งนั้นก่อน;
- ยังไม่ได้ให้ดูลำดับการตรวจสอบบันทึกใน[เกมแครช](./mc-game.mdx)
