GPCL รองรับเฉพาะ **Windows 10 / 11 64 บิต** ไฟล์ติดตั้งไม่มี Java มาด้วย ตัวเปิดเกมจะติดตั้งให้ตามเวอร์ชันเกม

## ดาวน์โหลด

ดาวน์โหลดไฟล์ติดตั้งจาก[ส่วนดาวน์โหลดของเว็บไซต์](https://gamets.caellab.com/gpcl/#download) หรือ [GitHub Releases](https://github.com/CaelLab-org/GoodPlanCraftLauncher/releases) ชื่อไฟล์คือ `GPCL-<version>-Setup.exe`

อย่ารับไฟล์ติดตั้งจากคลาวด์ดิสก์ ไฟล์ในกลุ่ม หรือเว็บดาวน์โหลดของบุคคลที่สาม: ไฟล์ประเภทนั้นอาจถูกแทนที่ และตัวเปิดเกมไม่สามารถตรวจสอบแหล่งที่มาได้

## การติดตั้ง

1. ดับเบิลคลิกไฟล์ติดตั้ง แล้วเลือกโฟลเดอร์ติดตั้ง
2. เมื่อติดตั้งเสร็จ เปิด GPCL จากเดสก์ท็อปหรือเมนู Start
3. การเปิดครั้งแรกจะสร้างการตั้งค่า บันทึก และโฟลเดอร์เกมเริ่มต้น

อัปเกรดจากเวอร์ชันเก่าไม่ต้องถอนการติดตั้งก่อน ตัวติดตั้งจะรับช่วงการติดตั้งเดิมในที่เดิม (รวมถึงไฟล์ติดตั้ง NSIS ที่เก่ากว่า) ทางลัดบนเดสก์ท็อปและข้อมูลยังคงอยู่

## เกมและการตั้งค่าเก็บไว้ที่ไหน

ทั้งหมดอยู่ใน `%APPDATA%\gpcl` ไม่ได้อยู่ในโฟลเดอร์ติดตั้ง:

| พาธ | เนื้อหา |
| --- | --- |
| `%APPDATA%\gpcl\.minecraft` | เวอร์ชันเกม ไลบรารี ทรัพยากร มอด และเซฟ |
| `%APPDATA%\gpcl\gpcl\config\setting.ini` | การตั้งค่าตัวเปิดเกม |
| `%APPDATA%\gpcl\gpcl\log` | บันทึกของตัวเปิดเกม |
| `%APPDATA%\gpcl\gpcl\updata` | ไฟล์ติดตั้งที่ดาวน์โหลดเพื่ออัปเดตอัตโนมัติและบันทึกความคืบหน้า |

หากเปลี่ยนโฟลเดอร์เกม เวอร์ชันและทรัพยากรจะไปอยู่ที่ตำแหน่งใหม่ แต่การตั้งค่าและบันทึกยังอยู่ใน `%APPDATA%\gpcl`

### ตั้งค่าภาษาเกมอัตโนมัติ

**การตั้งค่า → เกม → ตั้งค่าภาษาเกมอัตโนมัติ** เปิดเป็นค่าเริ่มต้น ภาษาที่เลือกเป็นค่าเริ่มต้นคือจีนตัวย่อ ก่อนเปิดเกมทุกครั้ง GPCL จะเปลี่ยน `lang:` ใน `options.txt` ที่เวอร์ชันปัจจุบันใช้จริงเป็นค่าที่เลือก โดยคงบรรทัดอื่นไว้ตามเดิม

เวอร์ชันที่แยกโฟลเดอร์จะเขียนลง `versions/<version-name>/options.txt` เวอร์ชันที่ไม่ได้แยกจะเขียนลง `options.txt` ในโฟลเดอร์หลักของเกม ปิดสวิตช์นี้แล้วจะไม่แตะการตั้งค่าในเกมเลย

## การอัปเดต

เปิดใช้สองอย่างเป็นค่าเริ่มต้น:

- **ตรวจหาการอัปเดตอัตโนมัติ**: ตรวจเมื่อเปิดโปรแกรม หากมีเวอร์ชันใหม่จะแสดงข้อความที่มุมขวาบน
- **ติดตั้งการอัปเดตอัตโนมัติ**: ดาวน์โหลดเงียบ ๆ เบื้องหลัง ไม่ใช้หน้าดาวน์โหลด และไม่เปลี่ยนแถบสถานะ เมื่อตรวจสอบผ่านแล้ว จะติดตั้งเงียบ ๆ ตอนที่คุณ**ออกจากตัวเปิดเกม**

ป้ายวงกลมที่มุมขวาบนแสดงความคืบหน้าการดาวน์โหลด คลิกเพื่อดูหมายเลขเวอร์ชันและเนื้อหาการอัปเดตของเวอร์ชันนี้ ในนั้นยังกด "ดาวน์โหลดทันที" ได้ เมื่อติดตั้งเสร็จจะเปิดตัวเปิดเกมขึ้นมาใหม่โดยอัตโนมัติ

ใน **การตั้งค่า → เกี่ยวกับ** สามารถปิดการตรวจสอบอัตโนมัติหรือการติดตั้งอัตโนมัติได้ และกด "ตรวจหาการอัปเดต" ด้วยตนเองได้

ไฟล์อัปเดตจะตรวจสอบ SHA1 ก่อนติดตั้ง หากตรวจสอบไม่ผ่านจะไม่ติดตั้ง หากติดตั้งค้างกลางทาง การเปิดครั้งถัดไปจะแจ้ง "การอัปเดตครั้งก่อนยังไม่เสร็จ" และลองใหม่ได้ หากล้มเหลวติดกันสามครั้งจะแนะนำให้ไปดาวน์โหลดไฟล์ติดตั้งใหม่จากเว็บไซต์

:::warning อัปเกรดจาก 1.5.2 หรือเก่ากว่า
เวอร์ชันเก่ายังไม่รู้จักพารามิเตอร์การติดตั้งเงียบ ดังนั้นการอัปเกรดครั้งนี้จะยังแสดงตัวช่วยติดตั้งแบบเก่าหนึ่งครั้ง ตั้งแต่ 1.6.0 เป็นต้นไปจึงจะเงียบตลอดกระบวนการ
:::

หากหลังอัปเดตแล้วตัวเปิดเกมเปิดไม่ได้ ให้ดูบันทึกล่าสุดใน `%APPDATA%\gpcl\gpcl\log` ก่อน แล้วส่งอีเมลพร้อมบันทึก

## นำเข้าเวอร์ชันในเครื่อง

ในแผง "เลือกเวอร์ชัน" ที่หน้าเปิดเกม กด "นำเข้าเวอร์ชันในเครื่อง" สามารถนำเข้า:

- โฟลเดอร์เวอร์ชันหนึ่ง (ข้างในต้องมี `<version-name>.json`);
- ไฟล์บีบอัด zip หรือ jar ตัวเปิดเกมจะแตกไฟล์และค้นหาโฟลเดอร์ที่มี `<version-name>.json` แบบเรียกซ้ำ;

มอดแพ็ก (แบบที่มีส่วน `minecraft` ใน `manifest.json`) ยังนำเข้าไม่ได้ในตอนนี้ ตัวเปิดเกมจะปฏิเสธทันที ไม่ติดตั้งค้างไว้ครึ่งทาง

## ถอนการติดตั้ง

ถอนการติดตั้ง GPCL ใน "แอปและฟีเจอร์" ของ Windows ตัวถอนการติดตั้ง**จะไม่**ลบ `%APPDATA%\gpcl` หลังติดตั้งใหม่ เกมและการตั้งค่ายังอยู่

หากแน่ใจว่าไม่ใช้แล้ว สามารถลบ `%APPDATA%\gpcl` ทั้งโฟลเดอร์ด้วยตนเองได้ ก่อนลบให้สำรองเซฟออกมาก่อน
