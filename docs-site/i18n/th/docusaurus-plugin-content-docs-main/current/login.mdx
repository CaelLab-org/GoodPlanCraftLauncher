---

GPCL รองรับการเข้าสู่ระบบสองแบบ สลับได้ตลอดเวลา การเข้าสู่ระบบแบบออฟไลน์ไม่ต้องใช้อินเทอร์เน็ต แต่เข้าเซิร์ฟเวอร์ที่เปิดการตรวจสอบอย่างเป็นทางการไม่ได้

## การเข้าสู่ระบบแบบออฟไลน์

ที่หน้าเปิดเกม พิมพ์ชื่อผู้เล่นก็เปิดเกมได้ ไม่ต้องใช้รหัสผ่าน 5 ชื่อที่ใช้ล่าสุดจะอยู่ในรายการแบบเลื่อนลง และลบทีละรายการได้

- เหมาะกับเกมคนเดียว เล่น LAN และเซิร์ฟเวอร์ที่ไม่เปิดการตรวจสอบอย่างเป็นทางการ
- ไม่ต้องตรวจสอบผ่านเครือข่าย ตัดเน็ตก็เปิดเกมได้
- เข้าเซิร์ฟเวอร์ที่เปิดการตรวจสอบอย่างเป็นทางการไม่ได้ เข้าไปจะถูกเตะ
- อย่าใช้ ID อย่างเป็นทางการของคนอื่น: ทั้งเซิร์ฟเวอร์และผู้เล่นอื่นอาจจำคนผิด

## การเข้าสู่ระบบ Microsoft อย่างเป็นทางการ

1. ที่หน้าเปิดเกม กด "เข้าสู่ระบบอย่างเป็นทางการ"
2. GPCL จะเปิดเบราว์เซอร์เริ่มต้นและไปที่หน้าเข้าสู่ระบบ Microsoft
3. เข้าสู่ระบบและยอมรับการอนุญาต เบราว์เซอร์จะแจ้งว่ากลับไปที่ตัวเปิดเกมได้
4. GPCL จะได้รับผลลัพธ์โดยอัตโนมัติ ชื่อผู้เล่นถูกกำหนดโดยบัญชี

การเข้าสู่ระบบรอได้สูงสุด 2 นาที หากไม่มีการตอบสนอง ให้ตรวจสอบในเบราว์เซอร์ว่าทำการเข้าสู่ระบบและอนุญาตเสร็จแล้วก่อน แล้วจึงตรวจสอบเครือข่าย

ตัวเปิดเกมจะบันทึกสถานะการเข้าสู่ระบบ ครั้งถัดไปไม่ต้องเข้าสู่ระบบใหม่ กด "เพิ่มประสิทธิภาพหน่วยความจำก่อนเปิดเกม" ก็ไม่ล้างสถานะการเข้าสู่ระบบ

## เลือกโหมดไหนดี

| สถานการณ์ | ใช้แบบไหน |
| --- | --- |
| เล่นคนเดียว เล่นเอง | ออฟไลน์หรืออย่างเป็นทางการก็ได้ |
| เซิร์ฟเวอร์ที่ตรวจสอบอย่างเป็นทางการ | ต้องเป็นทางการเท่านั้น |
| เซิร์ฟเวอร์ที่ไม่ตรวจสอบอย่างเป็นทางการ | ออฟไลน์หรืออย่างเป็นทางการก็ได้ |
| ไม่มีอินเทอร์เน็ต | ออฟไลน์ |

## สลับบัญชี

เมื่อเข้าสู่ระบบอย่างเป็นทางการอยู่ กดปุ่มอย่างเป็นทางการอีกครั้งเพื่อออกจากระบบ จากนั้นจึงใช้ชื่อออฟไลน์ได้ เมื่ออยู่ในสถานะออฟไลน์ การกดเข้าสู่ระบบอย่างเป็นทางการจะเข้าสู่ขั้นตอนการเข้าสู่ระบบ Microsoft ทันที

## เซิร์ฟเวอร์แจ้ง Invalid session

ส่วนใหญ่คือสถานะการเข้าสู่ระบบหมดอายุ หรือบัญชีนี้ไม่มีสิทธิ์สำหรับเวอร์ชันนั้น:

1. ออกจากระบบบัญชีแล้วเข้าสู่ระบบอย่างเป็นทางการอีกครั้ง;
2. ยืนยันว่าบัญชีเป็นเจ้าของเวอร์ชัน Minecraft นี้จริง;
3. ลองเซิร์ฟเวอร์อย่างเป็นทางการอื่น เพื่อตัดปัญหาที่เกิดจากเซิร์ฟเวอร์เดียว
