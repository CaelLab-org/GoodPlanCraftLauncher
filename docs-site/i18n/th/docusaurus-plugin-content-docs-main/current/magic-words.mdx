ในชื่อหน้าต่างเกมเขียนตัวแทนได้ เมื่อเปิดเกม GPCL จะแทนที่ด้วยค่าจริง

ตำแหน่งอยู่ที่ **การตั้งค่า → เกม → ชื่อหน้าต่างเกม** ชื่อหน้าต่างเว้นว่างหมายถึงไม่แก้ไขชื่อหน้าต่างเกม

## ตัวอย่าง

เขียนชื่อหน้าต่างเป็น:

```text
{time} · {mc_version} · {gpcl_version}
```

หลังเปิดเกมอาจแสดงเป็น:

```text
20:09:58 · Minecraft 1.21.3 · 1.6.0
```

## ตัวแทนที่ใช้ได้

| ตัวแทน | จะกลายเป็น |
| --- | --- |
| `{mc_version}` | ชื่อที่แสดงของเวอร์ชัน เช่น Minecraft 1.21.3 หรือชื่อที่มีตัวโหลด |
| `{mc_id}` | ชื่อโฟลเดอร์เวอร์ชัน เช่น 1.21.3-Fabric |
| `{username}` | ชื่อผู้เล่นที่ใช้เปิดเกมครั้งนี้ |
| `{gpcl_version}` | หมายเลขเวอร์ชัน GPCL เช่น 1.6.0 |
| `{date}` | วันที่เปิดเกม รูปแบบ 2026/10/20 |
| `{time}` | เวลาปัจจุบัน รูปแบบ 20:09:58 |
| `{datetime}` | วันที่และเวลา คั่นด้วยช่องว่าง |
| `{java}` | ชื่อโฟลเดอร์ Java runtime ปัจจุบัน |
| `{memory}` | หน่วยความจำสูงสุดที่จัดสรรครั้งนี้ เช่น 4096MB |

ตัวพิมพ์เล็กพิมพ์ใหญ่ต้องตรงกัน ตัวแทนที่เขียนผิดจะแสดงตามเดิม เพื่อให้เห็นว่าตัวไหนผิด

## ชื่อหน้าต่างจะคงอยู่ตลอดไหม

ด้านล่างมีสวิตช์ "พยายามคงชื่อนี้ไว้" ปิดเป็นค่าเริ่มต้น

- **ปิด**: หลังหน้าต่างเกมปรากฏ GPCL จะแก้ไขต่อเนื่อง 20 วินาที หลังจากนั้นหากเกมหรือมอดเปลี่ยนชื่อจะไม่สนใจอีก ชื่อที่มี `{time}` ก็จะหยุดอยู่ที่เวลานั้น
- **เปิด**: คงชื่อที่คุณตั้งไว้ตลอดการเล่น เข้าดาวก็ไม่ถูก " - Singleplayer" ทับ

มอดแพ็กหรือมอดบางตัวก็เปลี่ยนชื่อหน้าต่างเช่นกัน การทับกันไปมาระหว่างสองฝ่ายเป็นเรื่องปกติ

:::note
ตอนนี้มีเฉพาะชื่อหน้าต่างเกมที่รองรับคำวิเศษ การตั้งค่าอื่นไม่มีผล
:::
