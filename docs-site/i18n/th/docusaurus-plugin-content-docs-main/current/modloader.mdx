ที่หน้าดาวน์โหลดสามารถเลือกตัวโหลดได้เลย GPCL จะติดตั้งเวอร์ชันต้นฉบับก่อน แล้วติดตั้งตัวโหลดลงโฟลเดอร์เวอร์ชันแยก ไม่ทับเวอร์ชันต้นฉบับ

## วิธีติดตั้ง

1. เปิดหน้าดาวน์โหลด เลือกเวอร์ชัน Minecraft
2. ในตัวเลือกตัวโหลด เลือก Forge, Fabric หรือ OptiFine แล้วเลือกเวอร์ชันตัวโหลดที่ตรงกัน
3. กดดาวน์โหลด รอให้ทั้งเวอร์ชันต้นฉบับและตัวโหลดติดตั้งเสร็จ
4. กลับไปที่หน้าเปิดเกม เลือกเวอร์ชันที่มีชื่อตัวโหลดเพื่อเปิดเกม

งานดาวน์โหลดจะเข้าคิว กดหลายเวอร์ชันต่อเนื่องเพื่อต่อคิวได้ งานที่กำลังดาวน์โหลดยกเลิกได้ เมื่อยกเลิกแล้วคิวจะทำงานต่อ

## เลือกตัวโหลดแบบไหน

| ตัวโหลด | เหมาะกับ | ข้อควรระวัง |
| --- | --- | --- |
| Forge | มอดแพ็กขนาดใหญ่ มอดรุ่นเก่า | เปิดช้ากว่า Fabric ตัวเลือกเวอร์ชันเยอะ |
| Fabric | มอดเบา ๆ เวอร์ชันใหม่ | ต้องเลือก Fabric Loader ให้ตรงกับเวอร์ชันเกม |
| OptiFine | เชดเดอร์ ปรับประสิทธิภาพ | ติดตั้งร่วมกับตัวโหลดอื่นอาจต้องใช้มอดที่เข้ากันได้ |

### Forge

ตอนติดตั้ง GPCL รันแค่ `--installClient` ไม่ลอง GUI หรือพารามิเตอร์ฝั่งเซิร์ฟเวอร์ เอาต์พุตของตัวติดตั้งจะแปลงเป็นความคืบหน้า เช่น "กำลังติดตั้ง Forge: Downloading library…"

ก่อนติดตั้งจะตรวจสอบ Major version ของ Java หากต่ำกว่าที่ Forge ต้องการจะแจ้งข้อผิดพลาดทันที ไม่เอา Java เวอร์ชันต่ำมาฝืนรัน กระบวนการทั้งหมดรอได้สูงสุด 15 นาที การยกเลิกดาวน์โหลดจะสิ้นสุดโปรเซสตัวติดตั้ง

### Fabric

GPCL ดึงโปรไฟล์เวอร์ชันและไฟล์ไลบรารีของ Fabric โดยตรง ไม่พึ่งตัวติดตั้ง

"ติดตั้ง Fabric API ด้วย" ติ๊กเป็นค่าเริ่มต้น เมื่อติดตั้ง Fabric เสร็จจะวาง Fabric API เวอร์ชันที่ตรงกันลง `mods` ของเวอร์ชันนั้น หากเอาติ๊กออกจะไม่ติดตั้ง ติดตั้ง Fabric API ล้มเหลวเพียงแจ้งเตือน ไม่กระทบตัว Fabric เอง

### OptiFine

OptiFine ติดตั้งแบบเงียบ ไม่เด้งตัวติดตั้งแบบกราฟิกของมันเอง ผลการติดตั้งจะลงในโฟลเดอร์เกมปัจจุบัน โฟลเดอร์เกมที่กำหนดเองก็จัดการได้ถูกต้อง

## วางมอดไว้ที่ไหน

เวอร์ชันที่ดาวน์โหลดใหม่จะเปิด **การแยกเวอร์ชัน** เป็นค่าเริ่มต้น: โฟลเดอร์เกมชี้ไปที่ `versions/<version-name>` มอด เซฟ และการตั้งค่าเกมจะตามเวอร์ชันนี้

| สภาพเวอร์ชัน | โฟลเดอร์มอด |
| --- | --- |
| ดาวน์โหลดใหม่ แยกแล้ว | `versions/<version-name>/mods` |
| มีอยู่ก่อนแล้ว และในโฟลเดอร์เวอร์ชันไม่มี `mods` / `saves` | `mods` ในโฟลเดอร์หลักของเกม |

ที่หน้าเปิดเกม เปิด "การตั้งค่าเวอร์ชัน" ของเวอร์ชันนั้น ทางเข้าโฟลเดอร์คำนวณจากผลการแยกจริง:

- "โฟลเดอร์เวอร์ชัน" มีเสมอ;
- "โฟลเดอร์ Mod" จะปรากฏเมื่อตรวจพบ Forge / Fabric / NeoForge / Quilt;
- "โฟลเดอร์เชดเดอร์" จะปรากฏเมื่อตรวจพบ OptiFine

หากอยากติดตั้งมอดลงโฟลเดอร์ใดก็ได้ ในเป้าหมายการติดตั้งของดาวน์โหลดมอดให้เลือก "เลือกโฟลเดอร์" มันจะหา `mods` ในโฟลเดอร์นั้น

## ติดตั้งแล้วแครช

1. ย้ายมอดทั้งหมดออกจาก `mods` ก่อน เปิดเกมเปล่าหนึ่งครั้ง
2. เข้าได้ก็ใส่คืนทีละครึ่ง เพื่อหามอดที่มีปัญหา
3. ยืนยันว่ามอดตรงกับทั้งเวอร์ชัน Minecraft และเวอร์ชันตัวโหลด — มอด Forge ใส่ลง Fabric ตรง ๆ ไม่ได้ และกลับกันก็เช่นกัน
4. ขาดสิ่งที่ต้องมีก่อนก็แครชตอนเปิดเกมได้ เข้าไปดูรายการที่ต้องมีก่อนใน[ดาวน์โหลดมอด](./mods.mdx)

การติดตั้ง OptiFine ร่วมกับ Forge / Fabric มักต้องใช้มอดที่เข้ากันได้เพิ่มเติม หากไม่มีมอดที่เข้ากันได้อย่าฝืนติดตั้ง
