הורדה איטית בדרך כלל לא בעיה של המשגר. קודם מחליפים מקור הורדה, ורק אחר כך נוגעים במספר התהליכונים ובהגבלת המהירות.

## משימות ההורדה נכנסות לתור

אחרי לחיצה על "הורדה" המשימה נכנסת לתור ולא תוקעת את כל הממשק: משימה ממתינה אפשר להסיר בלחיצה על ×, משימה שרצה אפשר לבטל, ואחרי הביטול התור ממשיך.

דף ההורדות מציג את מצב כל משימה: ממתין, מוריד, הושלם, נכשל.

## מקור הורדת קבצים מול מקור רשימת גרסאות

ב**הגדרות → הורדות → מקור הורדה** יש שתי רשימות נפתחות, כל אחת עצמאית:

- **מקור הורדת קבצים**: קובץ ה-jar של הלקוח, קבצי נכסים, ספריות תלויות;
- **מקור רשימת גרסאות**: מניפסט הגרסאות, קובצי JSON של גרסאות, אינדקס הנכסים.

לשתיהן ארבע אותן אפשרויות:

| אפשרות | התנהגות |
| --- | --- |
| עדיפות לרשמי, החלפה למירור כשהאיט | ברירת מחדל. קודם מתחברים לרשמי, ואם אין תגובה בכמה שניות עוברים ל-BMCLAPI |
| להשתמש במקור מירור ככל האפשר | ברשתות בסין משתמשים ישירות במירור |
| עדיפות למקור הרשמי | קודם רשמי, ורק אם נכשל חוזרים למירור |
| להשתמש במקור הרשמי ככל האפשר | רק רשמי; אם אין חיבור — כשל |

## מירור מותאם לקבצים

ב**הגדרות → הורדות → מירור קבצים מותאם** אפשר למלא כתובת שורש של מירור (ברירת מחדל BMCLAPI, למשל `https://bmclapi2.bangbang93.com`). אחרי שממלאים, מניפסט הגרסאות, הלקוח, הספריות והנכסים עוברים דרכה קודם, ורק אם לא נמשך — חוזרים לסדר המקורות הרגיל.

השארה ריקה = BMCLAPI כברירת מחדל.

## תיקיית המשחק

ב**הגדרות → הורדות → תיקיית משחק** אפשר לשים גרסאות, ספריות, נכסים ומודים בכל תיקייה; ריק מחזיר ל-`%APPDATA%\gpcl\.minecraft`.

החלפת התיקייה **לא מעבירה** קבצים קיימים. גרסאות בתיקייה הישנה לא עוברות אוטומטית — העתיקו בעצמכם אם צריך; ההגדרות והלוגים נשארים ב-`%APPDATA%\gpcl`.

## מספר תהליכונים מקסימלי

ברירת מחדל 64, טווח 1–128. כשיש הרבה קבצים קטנים, הגדלת המקביליות מאיצה, אבל יותר מדי עלול להיתקל בהגבלת ציוד הרשת או המירור. ברשת לא יציבה — להקטין.

## הגבלת מהירות

0 משמעותו בלי הגבלה; אחרי שמזינים מספר, **כל משימות ההורדה חולקות את אותה תקרה**, ב-MB/s, וההגבלה נכנסת לתוקף בהורדה הבאה. ברשת משותפת אפשר להוריד את הערך.

ההגבלה חלה רק על הורדת נכסי המשחק. סביבת ה-Java מורדת ממירור נפרד ולא מושפעת מכאן.

## מקורות מירור ל-Java

ב**הגדרות → הורדות → הורדת Java** אפשר לבחור אוניברסיטת Tsinghua, אוניברסיטת נאנג'ינג, Huawei Cloud או מקור מותאם. אם המקור הנבחר נכשל, GPCL עובר אוטומטית לבא אחריו, ובסוף יש את Adoptium הרשמי כגיבוי.

כתובת מותאמת תומכת בשני משתנים:

- `{v}`: גרסת ה-Java הראשית, למשל `8`, `17`, `21`;
- `{version}`: מספר הגרסה המלא במעלה הזרם, למשל `17.0.20.1_1` — משתנה עם שחרורי הגרסה.

דוגמה:

```text
https://cdn.example.com/java/{v}/OpenJDK{v}U-jre_x64_windows_hotspot_{v}.zip
```

## מה לעשות כשההורדה נכשלת

1. החליפו מקור הורדה.
2. הורידו את מספר התהליכונים ל-32 או 16 ונסו שוב.
3. ודאו שזמן המערכת נכון — סטייה גדולה מדי מכשילה את אימות תעודת ה-HTTPS.
4. אם עדיין לא — שלחו דוא"ל עם הלוג העדכני מתוך `%APPDATA%\gpcl\gpcl\log`.
