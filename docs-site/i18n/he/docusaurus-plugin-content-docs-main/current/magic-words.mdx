בכותרת חלון המשחק אפשר לכתוב מצייני מקום, ובהפעלה GPCL מחליף אותם בערכים אמיתיים.

המיקום: **הגדרות → משחק → כותרת חלון המשחק**. כותרת ריקה משמעה לא לשנות את כותרת חלון המשחק.

## דוגמה

כותרת כזו:

```text
{time} · {mc_version} · {gpcl_version}
```

לאחר ההפעלה היא עשויה להיראות כך:

```text
20:09:58 · Minecraft 1.21.3 · 1.6.0
```

## מצייני המקום הזמינים

| מציין מקום | למה הוא הופך |
| --- | --- |
| `{mc_version}` | שם התצוגה של הגרסה, למשל Minecraft 1.21.3, או שם עם הלואדר |
| `{mc_id}` | שם תיקיית הגרסה, למשל 1.21.3-Fabric |
| `{username}` | שם השחקן ששימש בהפעלה הזו |
| `{gpcl_version}` | מספר הגרסה של GPCL, למשל 1.6.0 |
| `{date}` | תאריך ההפעלה, בפורמט 2026/10/20 |
| `{time}` | השעה הנוכחית, בפורמט 20:09:58 |
| `{datetime}` | תאריך ושעה, מופרדים ברווח |
| `{java}` | שם תיקיית סביבת ה-Java הנוכחית |
| `{memory}` | הזיכרון המקסימלי שהוקצה הפעם, למשל 4096MB |

חשוב לשמור על אותו רישיות (אותיות גדולות/קטנות). מציין מקום שגוי מוצג כמו שהוא, כדי שיהיה קל לראות מה טעות.

## האם הכותרת נשארת כל הזמן

מתחת יש מתג "לשמור על השם ככל האפשר", כבוי כברירת מחדל.

- **כבוי**: אחרי שחלון המשחק מופיע, GPCL מתקן את הכותרת במשך 20 שניות. אחר כך, אם המשחק או מוד משנים את הכותרת, הוא כבר לא נוגע בה. כותרת עם `{time}` תיעצר על השעה ההיא.
- **דלוק**: הכותרת שקבעתם נשמרת לאורך כל המשחק, וגם בכניסה לעולם היא לא נדרסת על ידי " - Singleplayer".

יש חבילות מודים ומודים שמשנים גם הם את כותרת החלון; דריסה הדדית היא תופעה תקינה.

:::note
כרגע רק כותרת חלון המשחק תומכת במילות קסם; בשאר ההגדרות זה לא עובד.
:::
