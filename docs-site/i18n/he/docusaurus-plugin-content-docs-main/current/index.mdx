GoodPlanCraftLauncher (להלן GPCL) הוא משגר Minecraft ל-Windows. המסמכים האלה עוסקים רק ב**איך להשתמש אחרי ההתקנה ואיך לבדוק כשמשהו נשבר**: אין כאן יומן שינויים, וגם לא היסטוריית פרויקט.

| מה רוצים לעשות | איפה לקרוא |
| --- | --- |
| להתקין, לשדרג, להסיר | [התקנה ועדכונים](./install.mdx) |
| התחברות פרימיום או שם לא מקוון | [התחברות](./login.mdx) |
| המשחק נתקע, אין מספיק זיכרון, שגיאות Java | [Java וזיכרון](./java-memory.mdx) |
| להתקין Forge / Fabric / OptiFine | [מוד לואדרים](./modloader.mdx) |
| לחפש מודים ולהתקין אותם מהמשגר | [הורדת מודים](./mods.mdx) |
| ההורדה איטית, איך לבחור מקור מירור | [הורדות ומקורות מירור](./download.mdx) |
| המשחק קרס | [קריסת משחק](./mc-game.mdx) |
| לשנות את כותרת חלון המשחק | [מילות קסם לכותרת החלון](./magic-words.mdx) |

:::tip קודם כל לבדוק את הגרסה
הדפים האלה נכתבו לגרסה 1.8.0. את הגרסה הנוכחית רואים ב**הגדרות → אודות**; אם הגרסה שונה בהרבה, ייתכן שמיקום חלק מהאפשרויות אחר.
:::

## איך לשאול כשמשהו לא עובד

שלחו דוא"ל ל-[gamets@caellab.com](mailto:gamets@caellab.com). עם הפרטים האלה בדרך כלל אפשר לאתר את הבעיה:

- גרסת המשגר, גרסת Minecraft ואילו מודים מותקנים;
- מה עשיתם לפני הקריסה (הרגע התקנתם מודים? החלפתם Java? שיניתם את הזיכרון?);
- **דוח השגיאה ש-GPCL מייצא** (הכפתור "ייצוא דוח שגיאה" בחלון הקריסה).

צילום מסך של חלון הקריסה בלבד בדרך כלל לא מספיק.
