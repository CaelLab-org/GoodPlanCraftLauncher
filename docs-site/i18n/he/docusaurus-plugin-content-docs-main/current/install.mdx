GPCL תומך רק ב-**Windows 10 / 11 64-bit**. חבילת ההתקנה לא כוללת Java — המשגר מתקין את הגרסה המתאימה לפי גרסת המשחק.

## הורדה

מורידים את חבילת ההתקנה מ[אזור ההורדות באתר הרשמי](https://gamets.caellab.com/gpcl/#download) או מ-[GitHub Releases](https://github.com/CaelLab-org/GoodPlanCraftLauncher/releases). שם הקובץ הוא `GPCL-<version>-Setup.exe`.

אל תורידו את חבילת ההתקנה מדיסקים מקוונים, מקבוצות צ'אט או מאתרי הורדות של צד שלישי: קבצים כאלה עלולים להיות מוחלפים, וגם המשגר לא יכול לאמת את מקורם.

## התקנה

1. לחצו פעמיים על חבילת ההתקנה ובחרו תיקיית התקנה.
2. אחרי ההתקנה הפעילו את GPCL משולחן העבודה או מתפריט התחל.
3. בהפעלה הראשונה נוצרים קובץ הגדרות, לוגים ותיקיית משחק ברירת מחדל.

אין צורך להסיר גרסה ישנה לפני שדרוג. המתקין משתלט על ההתקנה הקיימת במקומה (כולל התקנות NSIS ישנות יותר), וקיצורי הדרך והנתונים נשמרים.

## איפה נשמרים המשחק וההגדרות

הכול ב-`%APPDATA%\gpcl`, לא בתיקיית ההתקנה:

| נתיב | תוכן |
| --- | --- |
| `%APPDATA%\gpcl\.minecraft` | גרסאות משחק, ספריות, נכסים, מודים ועולמות שמורים |
| `%APPDATA%\gpcl\gpcl\config\setting.ini` | הגדרות המשגר |
| `%APPDATA%\gpcl\gpcl\log` | לוגים של המשגר |
| `%APPDATA%\gpcl\gpcl\updata` | חבילות ההתקנה שהורדו בעדכון אוטומטי ורשומות ההתקדמות |

אם שיניתם את תיקיית המשחק, הגרסאות והנכסים עוברים למיקום החדש, אבל ההגדרות והלוגים נשארים ב-`%APPDATA%\gpcl`.

### הגדרת שפת המשחק אוטומטית

**הגדרות → משחק → הגדרת שפת משחק אוטומטית** פעיל כברירת מחדל, והשפה הנבחרת היא סינית מפושטת. לפני כל הפעלה GPCL משנה את `lang:` בקובץ `options.txt` שהגרסה הנוכחית באמת משתמשת בו לערך הנבחר, ושאר השורות נשארות כפי שהן.

בגרסה מבודדת הערך נכתב ל-`versions/<version-name>/options.txt`, ובגרסה לא מבודדת ל-`options.txt` שבתיקיית השורש של המשחק. כיבוי המתג הזה משאיר את הגדרות המשחק לגמרי בלי שינוי.

## עדכון

שתי האפשרויות פעילות כברירת מחדל:

- **בדיקת עדכונים אוטומטית**: בדיקה בהפעלה; אם יש גרסה חדשה, מופיעה התראה בפינה הימנית העליונה.
- **התקנת עדכונים אוטומטית**: ההורדה מתבצעת בשקט ברקע, בלי לתפוס את דף ההורדות ובלי לשנות את שורת המצב. אחרי שהאימות עובר, ההתקנה מתבצעת בשקט כש**יוצאים מהמשגר**.

תג עגול בפינה הימנית העליונה מציג את התקדמות ההורדה; לחיצה עליו מציגה את מספר הגרסה ואת תוכן העדכון. שם אפשר גם ללחוץ על "הורדה עכשיו" — בסיום ההתקנה המשגר ייפתח מחדש אוטומטית.

ב**הגדרות → אודות** אפשר לכבות את הבדיקה או את ההתקנה האוטומטית, וגם ללחוץ ידנית על "בדיקת עדכונים".

חבילת העדכון נבדקת ב-SHA1 לפני ההתקנה, ואם הבדיקה נכשלת היא לא תותקן. אם ההתקנה נקטעת באמצע, בהפעלה הבאה תופיע הודעה "העדכון הקודם לא הושלם" עם אפשרות לנסות שוב; אחרי שלושה כשלונות ברצף תופנו להוריד מחדש את חבילת ההתקנה מהאתר.

:::warning שדרוג מ-1.5.2 או מוקדם יותר
גרסאות ישנות עדיין לא מכירות את הפרמטרים של התקנה שקטה, ולכן השדרוג הזה עדיין יציג פעם אחת את אשף ההתקנה הישן. מ-1.6.0 והלאה הכול שקט.
:::

אם אחרי העדכון המשגר לא נפתח, בדקו קודם את הלוג העדכני ב-`%APPDATA%\gpcl\gpcl\log`, ואז שלחו דוא"ל עם הלוג.

## ייבוא גרסה מקומית

בלוח "בחירת גרסה" בדף הפתיחה לוחצים על "ייבוא גרסה מקומית". אפשר לייבא:

- תיקיית גרסה (חייבת להכיל `<version-name>.json`);
- ארכיון zip או jar — המשגר יחלץ אותו ויחפש רקורסיבית את התיקייה שמכילה `<version-name>.json`;

חבילות מודים (כאלה שיש בהן מקטע `minecraft` ב-`manifest.json`) עדיין לא ניתנות לייבוא; המשגר דוחה אותן מיד ולא משאיר התקנה חלקית.

## הסרה

מסירים את GPCL דרך "אפליקציות ותכונות" ב-Windows. תוכנית ההסרה **לא** מוחקת את `%APPDATA%\gpcl`, כך שאחרי התקנה מחדש המשחק וההגדרות עדיין שם.

אם לא מתכננים להשתמש יותר, אפשר למחוק ידנית את כל `%APPDATA%\gpcl`. לפני המחיקה גיבו את העולמות השמורים.
