בעת בחירת גרסה בדף ההורדות אפשר לבחור גם את הלואדר. GPCL מתקין קודם את הווניל, ואז מתקין את הלואדר בתיקיית גרסה נפרדת — הווניל לא נדרס.

## איך מתקינים

1. פותחים את דף ההורדות ובוחרים גרסת Minecraft.
2. באפשרויות הלואדר בוחרים Forge, Fabric או OptiFine, ואז את גרסת הלואדר המתאימה.
3. לוחצים על הורדה וממתינים ששתי ההתקנות יסתיימו — הווניל והלואדר.
4. חוזרים לדף הפתיחה ומפעילים את הגרסה ששמה כולל את שם הלואדר.

משימות ההורדה נכנסות לתור, ואפשר ללחוץ על כמה גרסאות ברצף; משימה שרצה אפשר לבטל, והתור ממשיך אחריה.

## איזה לואדר לבחור

| לואדר | מתאים ל | שים לב |
| --- | --- | --- |
| Forge | חבילות מודים גדולות, מודים ותיקים | עולה לאט יותר מ-Fabric, ומגוון הגרסאות גדול |
| Fabric | מודים קלים, גרסאות חדשות | צריך לבחור את גרסת Fabric Loader המתאימה לגרסת המשחק |
| OptiFine | שיידרים ושיפור ביצועים | בשילוב עם לואדרים אחרים ייתכן צורך במודים לתאימות |

### Forge

בהתקנה GPCL מריץ רק `--installClient`, ולא מנסה פרמטרים של GUI או של צד השרת. הפלט של המתקין מוצג כהתקדמות, למשל "מתקין Forge: Downloading library…".

לפני ההתקנה נבדקת גרסת ה-Java הראשית, ואם היא מתחת לדרישה של Forge מוצגת שגיאה — לא מריצים את המתקין עם גרסת Java נמוכה מדי. התהליך ממתין עד 15 דקות; ביטול ההורדה מסיים את תהליך המתקין.

### Fabric

GPCL לוקח ישירות את פרופיל הגרסה ואת קבצי הספרייה של Fabric, בלי תלות במתקין.

"התקנת Fabric API יחד עם Fabric" מסומן כברירת מחדל; בסיום ההתקנה GPCL מכניס את גרסת ה-Fabric API המתאימה לתיקיית ה-`mods` של אותה גרסה. אם מסירים את הסימון, הוא לא יותקן; כשל בהתקנת Fabric API רק מציג הודעה ולא פוגע ב-Fabric עצמו.

### OptiFine

OptiFine מותקן בשקט, בלי לפתוח את מתקין ה-GUI שלו. תוצאת ההתקנה נכנסת לתיקיית המשחק הנוכחית, וגם תיקיית משחק מותאמת אישית מטופלת נכון.

## איפה נמצאים המודים

גרסאות שהורדו חדשות מפעילות כברירת מחדל **בידוד גרסאות**: תיקיית המשחק מצביעה ל-`versions/<version-name>`, והמודים, העולמות השמורים והגדרות המשחק הולכים אחרי אותה גרסה.

| מצב הגרסה | תיקיית מודים |
| --- | --- |
| הורדה חדשה, מבודדת | `versions/<version-name>/mods` |
| גרסה קיימת, ובלי `mods` / `saves` בתיקיית הגרסה | `mods` בתיקיית השורש של המשחק |

בדף הפתיחה פותחים את "הגדרות גרסה" של הגרסה; כניסות התיקיות מחושבות לפי תוצאת הבידוד בפועל:

- "תיקיית הגרסה" קיימת תמיד;
- כשה-Loader הוא Forge / Fabric / NeoForge / Quilt מופיע "תיקיית Mod";
- כשה-Loader הוא OptiFine מופיע "תיקיית שיידרים".

רוצים להתקין מודים ישירות לכל תיקייה? בחרו "בחירת תיקייה" ביעד ההתקנה בהורדת מודים — המשגר ימצא את תיקיית ה-`mods` ששם.

## קרס אחרי ההתקנה

1. הוציאו את כל המודים מתוך `mods` והפעילו פעם אחת בלי מודים.
2. אם עולה — החזירו חצי בכל פעם וכך אתרו את המוד הבעייתי.
3. ודאו שהמוד מתאים גם לגרסת ה-Minecraft וגם לגרסת הלואדר — מוד של Forge לא הולך ל-Fabric, וגם לא להפך.
4. חוסר בתלות חובה גם מפיל את המשחק בהפעלה; בדקו ב[הורדת מודים](./mods.mdx) אילו תלויות נדרשות.

שילוב OptiFine עם Forge / Fabric בדרך כלל דורש מודים נוספים לתאימות. בלי מוד תאימות מתאים — עדיף לא לכפות את השילוב.

שלבי בדיקה נוספים ב[קריסת משחק](./mc-game.mdx).
