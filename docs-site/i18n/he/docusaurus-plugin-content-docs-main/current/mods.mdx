באזור "מודים" בדף ההורדות אפשר לחפש מודים, לבחור קובץ ולהתקין לגרסה מסוימת — בלי להוריד מהאתר ולגרור לתיקייה בעצמכם.

## חיפוש

שני המקורות: **Modrinth** ו-**CurseForge**. כברירת מחדל החיפוש מתבצע בשניהם, והתוצאות מסמנות את המקור.

אפשר להקליד קודם בסינית. כשהשאילתה מכילה סינית, GPCL בודק קודם את תוצאות החיפוש הפומביות של MCMOD, מוציא את השם האנגלי מהסוגריים בכותרת (למשל "雾中人 (The Man From The Fog)" → `The Man From The Fog`), ואז מחפש את השם האנגלי ב-Modrinth. אם לא נמצא שם אנגלי, החיפוש מתבצע עם השאילתה המקורית.

## סינון

כברירת מחדל החיפוש **ללא** סינון לפי גרסה ולואדר — כמו ב-PCL, קודם מחפשים הכול, כדי שמודים חדשים לא יוסתרו בגלל הסינון. מצמצמים ידנית כשצריך:

- גרסת Minecraft;
- לואדר (Forge / Fabric / NeoForge / Quilt);
- סדר מיון.

רשימת הקבצים מציגה קודם את גרסאות ה-MC של הגרסה הפעילה, כדי לצמצם התקנה של גרסה לא מתאימה.

## התקנה

רק לחיצה על "התקנה" בשורת הקובץ פותחת את בחירת היעד:

- רשימת גרסאות ה-Mod המותקנות — בוחרים אחת ומתקינים ישירות;
- "בחירת תיקייה" — התקנה לתיקיית `mods` בכל נתיב.

הקובץ נכנס ל-`mods` שהגרסה ביעד באמת משתמשת בו: בגרסה מבודדת `versions/<version-name>/mods`, אחרת `mods` בתיקיית השורש של המשחק.

בגרסה לא מבודדת, התקנת המוד הראשון מפעילה בידוד גרסאות; חלון היעד מציין זאת ולא מבקש אישור נוסף.

### תלויות חובה

שורות הקבצים ב-Modrinth מציגות "N תלויות". בהתקנה מותקנות רקורסיבית גם התלויות הנדרשות להורדה, והודעת ההצלחה מפרטת כמה תלויות נוספו.

מצב הקישור של CurseForge מתקין רק את הקובץ הנבחר, **בלי להתקין תלויות אוטומטית**, וגם זה כתוב בממשק.

## כשאין API Key ל-CurseForge

חיפוש רגיל ב-CurseForge דורש API Key (**הגדרות → הורדות → CurseForge API Key**, אופציונלי), או המתנה ששרת המירור הציבורי יחזור לפעול. בלי Key והמירור לא זמין — יש עדיין מוצא אחרון:

מדביקים בשדה החיפוש את כתובת הפרויקט, או כותבים `cf:<short-name>`:

```text
https://www.curseforge.com/minecraft/mc-mods/sodium
cf:sodium
```

GPCL שולף את הפרויקט והקבצים דרך `api.cfwidget.com`, ומוריד בקישור ישיר מ-ForgeCDN. המסלול הזה **מתקין רק את הקובץ הנבחר ואינו פותר תלויות**.

## הותקן אבל לא עובד

- ודאו שגרסת ה-MC והלואדר שהמוד תומך בהם תואמים לגרסה הנוכחית;
- ודאו שההתקנה נכנסה ל-`mods` הנכון (אחרי בידוד גרסאות זה לא זה שבשורש);
- אם חסרה תלות חובה, התקינו אותה קודם;
- אם עדיין לא — ראו את סדר הבדיקה ב[קריסת משחק](./mc-game.mdx).
