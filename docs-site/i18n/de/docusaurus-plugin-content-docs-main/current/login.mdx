---
title: Premium- und Offline-Anmeldung
description: Microsoft-Premium-Anmeldung und Offline-Anmeldung in GPCL — Unterschiede, Ablauf und Wechsel.
---

GPCL unterstützt zwei Anmeldearten, zwischen denen du jederzeit wechseln kannst. Die Offline-Anmeldung braucht kein Internet, kommt aber nicht auf Server mit Premium-Prüfung.

## Offline-Anmeldung

Auf der Startseite genügt ein Spielername, ein Passwort ist nicht nötig. Die letzten 5 Namen bleiben im Dropdown und lassen sich einzeln löschen.

- Geeignet für Einzelspieler, LAN-Partien und Server ohne Premium-Prüfung.
- Keine Online-Prüfung, der Start funktioniert auch ohne Internet.
- Server mit Premium-Prüfung lehnen dich ab.
- Verwende keine fremde Premium-ID: Server und andere Spieler können die Person verwechseln.

## Microsoft-Premium-Anmeldung

1. Klicke auf der Startseite auf „Premium-Anmeldung“.
2. GPCL öffnet den Standardbrowser und springt zur Microsoft-Anmeldeseite.
3. Melde dich an und bestätige die Freigabe; der Browser weist darauf hin, dass du zum Launcher zurückkehren kannst.
4. GPCL übernimmt das Ergebnis automatisch, der Spielername kommt aus dem Konto.

GPCL wartet höchstens 2 Minuten. Reagiert nichts, prüfe zuerst, ob Anmeldung und Freigabe im Browser abgeschlossen sind, und dann die Netzwerkverbindung.

Der Launcher speichert den Anmeldestatus, beim nächsten Start ist keine erneute Anmeldung nötig. „Arbeitsspeicher vor dem Start optimieren“ löscht den Anmeldestatus nicht.

## Welche Anmeldeart wählen

| Situation | Anmeldeart |
| --- | --- |
| Einzelspieler, nur für dich | Offline oder Premium |
| Server mit Premium-Prüfung | Nur Premium |
| Server ohne Premium-Prüfung | Offline oder Premium |
| Kein Internet | Offline |

## Konto wechseln

Bist du mit einem Premium-Konto angemeldet, meldet ein weiterer Klick auf die Premium-Schaltfläche dich ab; danach kannst du einen Offline-Namen verwenden. Im Offline-Modus startet „Premium-Anmeldung“ direkt den Microsoft-Anmeldeablauf.

## Server meldet Invalid session

Meist ist die Anmeldung abgelaufen oder das Konto besitzt keine Lizenz für diese Version:

1. Abmelden und die Premium-Anmeldung erneut durchführen;
2. prüfen, ob das Konto diese Minecraft-Version wirklich besitzt;
3. einen anderen Premium-Server testen, um ein Problem des einzelnen Servers auszuschließen.
