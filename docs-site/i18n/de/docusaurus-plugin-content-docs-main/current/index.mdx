GoodPlanCraftLauncher (kurz GPCL) ist ein Minecraft-Launcher für Windows. Diese Dokumentation beschreibt nur, **wie man ihn nach der Installation benutzt und wie man Fehler eingrenzt**: keine Changelogs, keine Projektgeschichte.

| Vorhaben | Wo nachsehen |
| --- | --- |
| Installieren, aktualisieren, deinstallieren | [Installation und Updates](./install.mdx) |
| Premium-Anmeldung oder Offline-Name | [Anmeldung](./login.mdx) |
| Spiel ruckelt, Speicher reicht nicht, Java-Fehler | [Java und Arbeitsspeicher](./java-memory.mdx) |
| Forge / Fabric / OptiFine installieren | [Mod-Loader](./modloader.mdx) |
| Mods im Launcher suchen und installieren | [Mods herunterladen](./mods.mdx) |
| Langsame Downloads, Wahl des Mirrors | [Downloads und Mirrors](./download.mdx) |
| Das Spiel ist abgestürzt | [Spielabsturz](./mc-game.mdx) |
| Fenstertitel des Spiels ändern | [Magische Wörter im Fenstertitel](./magic-words.mdx) |

:::tip Erst die Version prüfen
Diese Seiten beziehen sich auf Version 1.9.3. Die installierte Version steht unter **Einstellungen → Über**; weicht sie deutlich ab, können einzelne Optionen woanders liegen.
:::

## Wie man bei Problemen fragt

Schreibe eine E-Mail an [gamets@caellab.com](mailto:gamets@caellab.com). Mit diesen Angaben lässt sich fast alles eingrenzen:

- Launcher-Version, Minecraft-Version, installierte Mods;
- was vor dem Absturz passiert ist (gerade Mods installiert? Java gewechselt? Arbeitsspeicher geändert?);
- **den von GPCL exportierten Fehlerbericht** („Fehlerbericht exportieren“ im Absturzfenster).

Ein Screenshot des Absturzfensters allein reicht meistens nicht.
