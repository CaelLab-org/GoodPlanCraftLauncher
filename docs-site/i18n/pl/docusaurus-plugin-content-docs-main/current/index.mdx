Te strony opisują wersję 1.9.2. Aktualną wersję widać w **Ustawienia → Informacje**; przy dużej różnicy położenie niektórych opcji może się różnić.

## Jak poprosić o pomoc

Napisz na [gamets@caellab.com](mailto:gamets@caellab.com). Opisując te punkty, w większości przypadków można zlokalizować problem:

- wersja launcha, wersja Minecrafta, zainstalowane mody;
- co robiłeś przed awarią (właśnie zainstalowałeś mody? zmieniłeś Javę? zmieniłeś pamięć?);
- **raport błędu wyeksportowany przez GPCL** (przycisk „Eksportuj raport błędu” w oknie awarii).

Sam zrzut ekranu okna awarii zwykle nie wystarcza.
