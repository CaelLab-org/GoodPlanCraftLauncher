---
title: Login com conta oficial ou offline
description: Login com conta Microsoft e login offline no GPCL — diferenças, fluxo e como alternar entre os dois.
---

O GPCL oferece dois modos de login, alternáveis a qualquer momento. O login offline não precisa de internet, mas não permite entrar em servidores com verificação de conta oficial.

## Login offline

Basta digitar um nome de jogador na página inicial para iniciar; não há senha. Os 5 nomes usados por último ficam na lista suspensa e podem ser removidos um a um.

- Indicado para jogo solo, LAN e servidores sem verificação de conta oficial.
- Não exige validação online; funciona mesmo sem conexão.
- Não é possível entrar em servidores com verificação de conta oficial: você será expulso.
- Não use o ID oficial de outra pessoa: servidores e jogadores podem confundir sua identidade.

## Login com conta Microsoft

1. Na página inicial, clique em “Entrar com conta oficial”.
2. O GPCL abre o navegador padrão na página de login da Microsoft.
3. Faça login e autorize o acesso; o navegador avisa que você pode voltar ao launcher.
4. O GPCL recebe o resultado automaticamente, e o nome do jogador passa a ser o da conta.

O login espera no máximo 2 minutos. Se não houver resposta, confirme primeiro se o login e a autorização foram concluídos no navegador e depois verifique a conexão.

O launcher guarda o estado de login, então não é preciso entrar de novo na próxima vez. Clicar em “Otimizar memória antes de iniciar o jogo” também não apaga o login.

## Qual modo usar

| Cenário | Use |
| --- | --- |
| Jogo solo, para você mesmo | Offline ou conta oficial, tanto faz |
| Servidor com verificação de conta oficial | Conta oficial obrigatória |
| Servidor sem verificação de conta oficial | Offline ou conta oficial, tanto faz |
| Sem internet | Offline |

## Alternar de conta

Com uma conta oficial conectada, clicar novamente no botão de conta oficial desconecta; depois é possível usar um nome offline. No modo offline, clicar em login com conta oficial inicia diretamente o fluxo da Microsoft.

## O servidor mostra Invalid session

Na maioria dos casos, o login expirou ou a conta não tem direito a essa versão:

1. saia da conta e faça o login com conta Microsoft novamente;
2. confirme se a conta realmente possui essa versão do Minecraft;
3. teste em outro servidor com verificação de conta oficial para descartar um problema isolado do servidor.
