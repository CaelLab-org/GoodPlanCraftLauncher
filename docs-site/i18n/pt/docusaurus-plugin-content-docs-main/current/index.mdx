## Como pedir ajuda quando algo dá errado

Envie um e-mail para [gamets@caellab.com](mailto:gamets@caellab.com). Com estes pontos descritos, na maioria dos casos é possível localizar o problema:

- versão do launcher, versão do Minecraft e mods instalados;
- o que foi feito antes do travamento (acabou de instalar mods? trocou o Java? alterou a memória?);
- **o relatório de erro exportado pelo GPCL** (botão “Exportar relatório de erro” na janela de travamento).

Apenas uma captura de tela da janela de travamento quase nunca traz informação suficiente.
