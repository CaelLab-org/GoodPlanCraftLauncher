GPCL은 두 가지 로그인 방식을 지원하며 언제든 전환할 수 있습니다. 오프라인 로그인은 네트워크가 필요 없지만, 정품 인증이 켜진 서버에는 들어갈 수 없습니다.

## 오프라인 로그인

실행 페이지에서 플레이어 이름을 입력하면 바로 실행할 수 있습니다. 비밀번호는 필요 없습니다. 최근 사용한 이름 5개가 드롭다운에 남고, 하나씩 삭제할 수 있습니다.

- 싱글 플레이, LAN 플레이, 정품 인증이 없는 서버에 적합합니다.
- 네트워크 인증이 없어 오프라인에서도 실행됩니다.
- 정품 인증이 켜진 서버에는 들어갈 수 없고, 들어가도 추방됩니다.
- 다른 사람의 정품 ID를 쓰지 마세요. 서버와 다른 플레이어 모두 혼동할 수 있습니다.

## Microsoft 정품 로그인

1. 실행 페이지에서 "정품 로그인"을 누릅니다.
2. GPCL이 기본 브라우저를 열고 Microsoft 로그인 페이지로 이동합니다.
3. 로그인하고 권한 부여에 동의하면, 브라우저에 런처로 돌아가도 된다는 안내가 표시됩니다.
4. GPCL이 결과를 자동으로 받고, 플레이어 이름은 계정에 따라 정해집니다.

로그인은 최대 2분까지 기다립니다. 반응이 없으면 먼저 브라우저에서 로그인과 권한 부여가 끝났는지 확인하고, 그다음 네트워크를 확인하세요.

런처는 로그인 상태를 저장하므로 다음에 열 때 다시 로그인할 필요가 없습니다. "게임 실행 전 메모리 최적화"를 눌러도 로그인 상태는 지워지지 않습니다.

## 두 방식 중 무엇을 쓸까

| 상황 | 선택 |
| --- | --- |
| 싱글 플레이, 혼자 할 때 | 오프라인과 정품 모두 가능 |
| 정품 인증 서버 | 반드시 정품 |
| 정품 인증이 없는 서버 | 오프라인과 정품 모두 가능 |
| 네트워크 없음 | 오프라인 |

## 계정 전환

정품 로그인 상태에서 정품 버튼을 다시 누르면 로그아웃되고, 그다음 오프라인 이름으로 바꿀 수 있습니다. 오프라인 상태에서 정품 로그인을 누르면 곧바로 Microsoft 로그인 절차로 들어갑니다.

## 서버에서 Invalid session이 표시될 때

대개 로그인 상태가 만료되었거나, 이 계정에 해당 버전의 권한이 없는 경우입니다.

1. 로그아웃한 뒤 정품 로그인을 다시 합니다.
2. 계정이 실제로 이 Minecraft 버전을 보유하고 있는지 확인합니다.
3. 다른 정품 서버에서 시도해 특정 서버의 문제인지 확인합니다.
