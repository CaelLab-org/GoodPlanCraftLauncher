GoodPlanCraftLauncher(이하 GPCL)는 Windows용 Minecraft 런처입니다. 이 문서는 **설치한 뒤 어떻게 쓰는지, 문제가 생겼을 때 어디를 확인하는지**만 다룹니다. 업데이트 내역이나 프로젝트 연혁은 넣지 않았습니다.

이 문서는 1.9.3을 기준으로 작성했습니다. 현재 버전은 **설정 → 정보**에서 확인할 수 있으며, 버전 차이가 크면 일부 옵션의 위치가 다를 수 있습니다.

## 문제를 문의하는 방법

[gamets@caellab.com](mailto:gamets@caellab.com)으로 메일을 보내세요. 다음 내용을 적어 주면 대부분 원인을 좁힐 수 있습니다.

- 런처 버전, Minecraft 버전, 설치한 모드
- 충돌 직전에 한 일(모드를 막 설치했는지, Java를 바꿨는지, 메모리를 바꿨는지)
- **GPCL에서 내보낸 오류 보고서**(충돌 창의 "오류 보고서 내보내기")

충돌 창 스크린샷 한 장만으로는 정보가 부족한 경우가 많습니다.
