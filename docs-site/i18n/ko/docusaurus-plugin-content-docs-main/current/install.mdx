GPCL은 **Windows 10 / 11 64비트**만 지원합니다. 설치 파일에 Java가 포함되어 있지 않으며, 런처가 게임 버전에 맞춰 직접 설치합니다.

## 다운로드

[공식 사이트 다운로드 페이지](https://gamets.caellab.com/gpcl/#download) 또는 [GitHub Releases](https://github.com/CaelLab-org/GoodPlanCraftLauncher/releases)에서 설치 파일을 받으세요. 파일 이름은 `GPCL-<version>-Setup.exe`입니다.

클라우드 드라이브, 단체 채팅방 파일, 제3자 다운로드 사이트에서 받지 마세요. 그런 파일은 변조되었을 수 있고, 런처도 출처를 검증할 수 없습니다.

## 설치

1. 설치 파일을 두 번 클릭하고 설치 폴더를 고릅니다.
2. 설치가 끝나면 바탕 화면이나 시작 메뉴에서 GPCL을 실행합니다.
3. 처음 실행하면 설정, 로그, 기본 게임 폴더가 만들어집니다.

이전 버전에서 업그레이드할 때 먼저 제거할 필요는 없습니다. 설치 프로그램이 기존 설치를 그대로 인계하며(이전 NSIS 패키지 포함), 바탕 화면 바로 가기와 데이터도 유지됩니다.

## 게임과 설정의 저장 위치

모두 설치 폴더가 아니라 `%APPDATA%\gpcl`에 있습니다.

| 경로 | 내용 |
| --- | --- |
| `%APPDATA%\gpcl\.minecraft` | 게임 버전, 라이브러리, 에셋, 모드, 월드 |
| `%APPDATA%\gpcl\gpcl\config\setting.ini` | 런처 설정 |
| `%APPDATA%\gpcl\gpcl\log` | 런처 로그 |
| `%APPDATA%\gpcl\gpcl\updata` | 자동 업데이트로 받은 설치 파일과 진행 기록 |

게임 폴더를 바꿨다면 버전과 에셋은 새 위치에 저장되지만, 설정과 로그는 여전히 `%APPDATA%\gpcl`에 남습니다.

### 게임 언어 자동 설정

**설정 → 게임 → 게임 언어 자동 설정**은 기본으로 켜져 있고, 선택된 언어의 기본값은 중국어 간체입니다. 실행할 때마다 GPCL은 현재 버전이 실제로 사용하는 `options.txt`의 `lang:` 값을 선택한 값으로 바꾸고, 나머지 줄은 그대로 둡니다.

격리된 버전은 `versions/<version-name>/options.txt`에, 격리되지 않은 버전은 게임 루트의 `options.txt`에 기록합니다. 이 스위치를 끄면 게임 설정은 전혀 건드리지 않습니다.

## 업데이트

두 항목이 기본으로 켜져 있습니다.

- **업데이트 자동 확인**: 실행할 때 확인하고, 새 버전이 있으면 오른쪽 위에 알림을 표시합니다.
- **업데이트 자동 설치**: 백그라운드에서 조용히 다운로드하며, 다운로드 페이지를 쓰지 않고 상태 표시줄도 바꾸지 않습니다. 검증을 통과하면 **런처를 종료할 때** 조용히 설치합니다.

오른쪽 위의 원형 배지에 다운로드 진행률이 표시됩니다. 열면 버전 번호와 해당 버전의 변경 내용을 볼 수 있습니다. 여기서 "지금 다운로드"를 눌러도 되고, 설치가 끝나면 런처가 자동으로 다시 열립니다.

**설정 → 정보**에서 자동 확인이나 자동 설치를 끌 수 있고, "업데이트 확인"을 직접 누를 수도 있습니다.

업데이트 패키지는 SHA1을 검증한 뒤 설치하며, 검증에 실패하면 설치하지 않습니다. 설치 도중 중단되면 다음 실행 때 "지난 업데이트가 완료되지 않았습니다"라고 안내하고 다시 시도할 수 있습니다. 3회 연속 실패하면 공식 사이트에서 설치 파일을 다시 받도록 안내합니다.

:::warning 1.5.2 이하에서 업그레이드하는 경우
이전 버전은 자동 설치 인수를 인식하지 못하므로, 이번 한 번은 예전 설치 마법사가 뜹니다. 1.6.0부터는 전 과정이 조용히 진행됩니다.
:::

업데이트 후 런처가 열리지 않으면 먼저 `%APPDATA%\gpcl\gpcl\log`의 최신 로그를 확인하고, 로그와 함께 메일을 보내세요.

## 로컬 버전 가져오기

실행 페이지의 "버전 선택" 패널에서 "로컬 버전 가져오기"를 누르면 다음을 가져올 수 있습니다.

- 버전 폴더(`<version-name>.json`이 있어야 함)
- zip 또는 jar 압축 파일. 런처가 압축을 풀고 `<version-name>.json`이 있는 폴더를 재귀적으로 찾습니다

모드팩(`manifest.json`에 `minecraft` 섹션이 있는 형식)은 아직 가져올 수 없습니다. 런처는 일부만 설치하지 않고 바로 거부합니다.

## 제거

Windows의 "앱 및 기능"에서 GPCL을 제거합니다. 제거 프로그램은 `%APPDATA%\gpcl`을 **삭제하지 않으므로** 재설치 후에도 게임과 설정이 그대로 남습니다.

더 이상 쓰지 않겠다면 `%APPDATA%\gpcl` 폴더 전체를 직접 삭제하면 됩니다. 삭제 전에 월드를 백업하세요.
