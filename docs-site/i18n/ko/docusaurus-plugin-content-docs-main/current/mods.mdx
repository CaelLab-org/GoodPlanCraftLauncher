다운로드 페이지의 "모드" 탭에서 모드를 검색하고 파일을 골라 지정한 버전에 설치할 수 있습니다. 웹사이트에서 직접 받아 폴더에 넣을 필요가 없습니다.

## 검색

출처는 **Modrinth**와 **CurseForge** 두 곳입니다. 기본으로 둘 다 검색하며 결과 목록에 출처가 표시됩니다.

검색창에 중국어를 입력할 수도 있습니다. 쿼리에 중국어가 들어 있으면 GPCL은 먼저 MCMOD의 공개 검색 결과를 조회하고, 제목 괄호에서 영어 이름을 뽑아(예: "雾中人 (The Man From The Fog)"에서 `The Man From The Fog`) 그 영어 이름으로 Modrinth를 검색합니다. 영어 이름을 못 찾으면 원래 쿼리로 검색합니다.

## 필터

기본적으로 버전과 로더 필터를 **적용하지 않습니다**. PCL과 마찬가지로 일단 전체를 검색해 새 모드가 조건에 걸려 숨지 않게 합니다. 좁혀야 할 때만 직접 고릅니다.

- Minecraft 버전
- 로더(Forge / Fabric / NeoForge / Quilt)
- 정렬 방식

파일 목록은 현재 실행 버전의 MC 버전에 맞는 파일을 앞에 배치해 버전을 잘못 고를 확률을 줄입니다.

## 설치

파일 행의 "설치"를 눌러야 대상 선택 창이 뜹니다.

- 설치된 Mod 버전 목록에서 골라 바로 설치
- "폴더 선택"으로 임의 폴더의 `mods`에 설치

파일은 대상 버전이 실제로 쓰는 `mods`에 들어갑니다. 격리된 버전은 `versions/<version-name>/mods`, 아니면 게임 루트의 `mods`입니다.

격리되지 않은 버전에 처음 모드를 설치하면 버전 격리가 켜지며, 대상 창에 그 사실이 적혀 있고 별도 확인은 뜨지 않습니다.

### 선행 모드

Modrinth 파일 행에는 "선행 N개"가 표시됩니다. 설치할 때 다운로드에 필요한 의존성을 재귀적으로 함께 설치하며, 성공 알림에도 선행 모드를 몇 개 포함했는지 나옵니다.

CurseForge 링크 모드는 선택한 파일 하나만 설치하고 **선행 모드를 자동으로 설치하지 않으며**, 화면에도 그렇게 적혀 있습니다.

## CurseForge API 키가 없을 때

일반적인 CurseForge 검색에는 API 키(**설정 → 다운로드 → CurseForge API 키**, 선택 사항)가 필요하거나 공개 미러가 살아나기를 기다려야 합니다. 키도 없고 미러도 안 될 때를 위한 대비책이 있습니다.

검색창에 프로젝트 주소를 붙여넣거나 `cf:<short-name>`를 입력합니다.

```text
https://www.curseforge.com/minecraft/mc-mods/sodium
cf:sodium
```

GPCL은 `api.cfwidget.com`으로 프로젝트와 파일을 조회하고 ForgeCDN 직링크로 내려받습니다. 이 경로는 **선택한 파일 하나만 설치하고 의존성을 해석하지 않습니다**.

## 설치했는데 적용되지 않을 때

- 모드가 지원하는 MC 버전과 로더가 현재 버전과 맞는지 확인하세요.
- 올바른 `mods`에 들어갔는지 확인하세요(버전 격리 후에는 루트의 것이 아닙니다).
- 선행 모드가 빠졌다면 먼저 채우세요.
- 그래도 안 되면 [게임 충돌](./mc-game.mdx)의 로그 확인 순서를 보세요.
