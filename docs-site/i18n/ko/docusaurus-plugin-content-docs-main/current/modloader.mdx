다운로드 페이지에서 버전을 고를 때 로더도 함께 고를 수 있습니다. GPCL은 먼저 바닐라를 설치한 뒤 로더를 별도의 버전 폴더에 설치하며, 바닐라를 덮어쓰지 않습니다.

## 설치 방법

1. 다운로드 페이지를 열고 Minecraft 버전을 고릅니다.
2. 로더 옵션에서 Forge, Fabric, OptiFine 중 하나를 고르고 해당 로더 버전을 선택합니다.
3. 다운로드를 누르고 바닐라와 로더가 모두 끝날 때까지 기다립니다.
4. 실행 페이지로 돌아가 로더 이름이 붙은 버전을 선택해 실행합니다.

다운로드 작업은 대기열에 들어가므로 여러 버전을 연달아 예약할 수 있습니다. 진행 중인 작업은 취소할 수 있고, 취소해도 대기열은 계속 진행됩니다.

## 세 로더 중 무엇을 고를까

| 로더 | 적합한 용도 | 주의 |
| --- | --- | --- |
| Forge | 대형 모드팩, 오래된 모드 | Fabric보다 시작이 느리고 선택할 수 있는 버전이 많음 |
| Fabric | 가벼운 모드, 새 버전 | 게임 버전에 맞는 Fabric Loader를 골라야 함 |
| OptiFine | 셰이더, 성능 최적화 | 다른 로더와 섞으면 호환 모드가 필요할 수 있음 |

### Forge

설치할 때 GPCL은 `--installClient`만 실행하며 GUI나 서버 인수를 시도하지 않습니다. 설치 프로그램의 출력은 진행률로 바뀌어 표시됩니다(예: "Forge 설치 중: Downloading library...").

설치 전에 Java 주 버전을 확인하고, Forge 요구 사항보다 낮으면 바로 오류를 냅니다. 낮은 Java로 억지로 돌리지 않습니다. 전체 과정은 최대 15분 기다리며, 다운로드를 취소하면 설치 프로그램 프로세스도 종료됩니다.

### Fabric

GPCL은 Fabric의 버전 프로필과 라이브러리를 직접 가져오며 설치 프로그램에 의존하지 않습니다.

"Fabric API도 함께 설치"가 기본으로 켜져 있습니다. Fabric 설치 후 일치하는 버전의 Fabric API를 해당 버전의 `mods`에 넣습니다. 끄면 설치하지 않으며, Fabric API 설치에 실패해도 알림만 하고 Fabric 본체에는 영향이 없습니다.

### OptiFine

OptiFine은 자동 설치로 진행되며 OptiFine 자체의 그래픽 설치 프로그램이 뜨지 않습니다. 결과는 현재 게임 폴더에 반영되고, 사용자 지정 게임 폴더도 올바르게 처리합니다.

## 모드 위치

새로 받은 버전은 **버전 격리**가 기본으로 켜집니다. 게임 폴더가 `versions/<version-name>`을 가리키며, 모드, 월드, 게임 설정이 모두 해당 버전을 따릅니다.

| 버전 상태 | 모드 폴더 |
| --- | --- |
| 새로 받았고 격리됨 | `versions/<version-name>/mods` |
| 예전부터 있었고 버전 폴더에 `mods` / `saves`가 없음 | 게임 루트의 `mods` |

실행 페이지에서 버전의 "버전 설정"을 열면 폴더 항목은 실제 격리 결과로 정해집니다.

- "버전 폴더"는 항상 있습니다.
- Forge / Fabric / NeoForge / Quilt가 감지되면 "모드 폴더"가 나타납니다.
- OptiFine이 감지되면 "셰이더 폴더"가 나타납니다.

임의의 폴더에 모드를 설치하려면 모드 다운로드의 설치 대상에서 "폴더 선택"을 고르면 그 폴더의 `mods`를 찾습니다.

## 설치 후 충돌할 때

1. `mods`의 모드를 모두 옮기고 아무것도 없는 상태로 한 번 실행합니다.
2. 실행되면 절반씩 되돌려 문제 모드를 찾습니다.
3. 모드가 Minecraft 버전과 로더 버전 모두에 맞는지 확인합니다. Forge 모드를 Fabric에 그대로 넣을 수 없고 반대도 마찬가지입니다.
4. 선행 모드가 없어도 실행 중 충돌합니다. [모드 다운로드](./mods.mdx)에 나온 선행 모드를 먼저 확인하세요.

OptiFine과 Forge / Fabric을 함께 쓸 때는 보통 추가 호환 모드가 필요합니다. 맞는 호환 모드가 없으면 억지로 설치하지 마세요.

자세한 확인 순서는 [게임 충돌](./mc-game.mdx)에 있습니다.
