게임 창 제목에는 자리표시자를 넣을 수 있고, 실행할 때 GPCL이 실제 값으로 바꿉니다.

위치는 **설정 → 게임 → 게임 창 제목**입니다. 제목을 비우면 게임 창 제목을 바꾸지 않습니다.

## 예시

제목을 다음과 같이 쓰면:

```text
{time} · {mc_version} · {gpcl_version}
```

실행 후 이렇게 표시될 수 있습니다:

```text
20:09:58 · Minecraft 1.21.3 · 1.6.0
```

## 사용할 수 있는 자리표시자

| 자리표시자 | 바뀌는 값 |
| --- | --- |
| `{mc_version}` | 버전 표시 이름(예: Minecraft 1.21.3, 또는 로더 이름이 붙은 이름) |
| `{mc_id}` | 버전 폴더 이름(예: 1.21.3-Fabric) |
| `{username}` | 이번 실행에 쓰는 플레이어 이름 |
| `{gpcl_version}` | GPCL 버전 번호(예: 1.6.0) |
| `{date}` | 실행 날짜, 형식 2026/10/20 |
| `{time}` | 현재 시각, 형식 20:09:58 |
| `{datetime}` | 날짜와 시각, 사이는 공백으로 구분 |
| `{java}` | 현재 Java 런타임 디렉터리 이름 |
| `{memory}` | 이번에 할당한 최대 메모리(예: 4096MB) |

대소문자를 구분합니다. 잘못 쓴 자리표시자는 그대로 표시되므로 어느 것을 틀렸는지 바로 알 수 있습니다.

## 제목이 계속 유지되나요

아래에 "가능하면 이 이름 유지" 스위치가 있고 기본값은 꺼짐입니다.

- **끔**: 게임 창이 나타난 뒤 GPCL이 20초 동안 계속 제목을 교정합니다. 그 뒤 게임이나 모드가 제목을 바꾸면 더 이상 손대지 않습니다. `{time}`이 들어간 제목도 그 시점에 멈춥니다.
- **켬**: 게임을 끝낼 때까지 설정한 제목을 유지하며, 월드에 들어가도 " - Singleplayer"로 덮어쓰이지 않습니다.

일부 모드팩이나 모드도 창 제목을 바꾸기 때문에 서로 덮어쓰는 것은 정상입니다.

:::note
현재 매직 워드는 게임 창 제목에서만 동작하며 다른 설정에서는 효과가 없습니다.
:::
