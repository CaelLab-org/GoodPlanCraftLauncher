ゲームウィンドウのタイトルにはプレースホルダーを書けます。起動時に GPCL が実際の値に置き換えます。

場所は **設定 → ゲーム → ゲームウィンドウのタイトル** です。タイトルを空にすると、ゲームウィンドウのタイトルは変更されません。

## 例

タイトルを次のように書くと：

```text
{time} · {mc_version} · {gpcl_version}
```

起動後はこのように表示されます：

```text
20:09:58 · Minecraft 1.21.3 · 1.6.0
```

## 使えるプレースホルダー

| プレースホルダー | 置き換わる内容 |
| --- | --- |
| `{mc_version}` | バージョンの表示名（例：Minecraft 1.21.3、またはローダー名を含む名前） |
| `{mc_id}` | バージョンフォルダー名（例：1.21.3-Fabric） |
| `{username}` | 今回の起動で使うプレイヤー名 |
| `{gpcl_version}` | GPCL のバージョン番号（例：1.6.0） |
| `{date}` | 起動日（形式 2026/10/20） |
| `{time}` | 現在時刻（形式 20:09:58） |
| `{datetime}` | 日付と時刻。間はスペースで区切る |
| `{java}` | 現在の Java ランタイムのディレクトリ名 |
| `{memory}` | 今回割り当てた最大メモリ（例：4096MB） |

大文字と小文字は区別されます。間違えたプレースホルダーはそのまま表示されるので、どれを書き間違えたか分かります。

## タイトルは保持される？

下に「できるだけこの名前を保つ」スイッチがあり、既定ではオフです。

- **オフ**：ゲームウィンドウが表示された後、GPCL は 20 秒間タイトルを補正し続けます。その後ゲームや Mod がタイトルを変えても、関与しません。`{time}` を含むタイトルもその時点で止まります。
- **オン**：ゲームを終えるまで設定したタイトルを保ち、ワールドに入っても「 - Singleplayer」で上書きされません。

Mod パックや Mod がウィンドウタイトルを変えることもあり、互いに上書きし合うのは正常な動作です。

:::note
現在マジックワードに対応しているのはゲームウィンドウのタイトルだけで、ほかの設定では効果がありません。
:::
