GPCL は **Windows 10 / 11 64 ビット**のみに対応しています。インストーラーに Java は含まれておらず、ランチャーがゲームのバージョンに合わせて導入します。

## ダウンロード

[公式サイトのダウンロード欄](https://gamets.caellab.com/gpcl/#download)または [GitHub Releases](https://github.com/CaelLab-org/GoodPlanCraftLauncher/releases) からインストーラーを入手してください。ファイル名は `GPCL-<version>-Setup.exe` です。

クラウドストレージ、グループのファイル共有、第三者のダウンロードサイトから入手しないでください。そうしたファイルは差し替えられている可能性があり、ランチャー側でも入手元を検証できません。

## インストール

1. インストーラーをダブルクリックし、インストール先を選びます。
2. 完了後、デスクトップまたはスタートメニューから GPCL を起動します。
3. 初回起動時に設定、ログ、既定のゲームディレクトリが作成されます。

旧バージョンからのアップグレードにアンインストールは不要です。インストーラーは既存のインストールをそのまま引き継ぎます（以前の NSIS パッケージも含みます）。デスクトップのショートカットとデータは保持されます。

## ゲームと設定の保存先

いずれもインストール先ではなく `%APPDATA%\gpcl` にあります。

| パス | 内容 |
| --- | --- |
| `%APPDATA%\gpcl\.minecraft` | ゲームのバージョン、ライブラリ、アセット、Mod、ワールド |
| `%APPDATA%\gpcl\gpcl\config\setting.ini` | ランチャーの設定 |
| `%APPDATA%\gpcl\gpcl\log` | ランチャーのログ |
| `%APPDATA%\gpcl\gpcl\updata` | 自動更新でダウンロードしたインストーラーと進行状況の記録 |

ゲームディレクトリを変更している場合、バージョンとアセットは新しい場所に置かれますが、設定とログは引き続き `%APPDATA%\gpcl` に残ります。

### ゲーム言語の自動設定

**設定 → ゲーム → ゲーム言語を自動設定** は既定でオンで、選択言語の既定値は簡体字中国語です。起動のたびに、GPCL は現在のバージョンが実際に使う `options.txt` の `lang:` を選択した値に書き換えます。ほかの行はそのまま残します。

分離バージョンでは `versions/<version-name>/options.txt`、分離していないバージョンではゲームのルートにある `options.txt` に書き込みます。このスイッチをオフにすると、ゲーム内の設定には一切触れません。

## 更新

次の 2 項目が既定でオンです。

- **アップデートを自動で確認**：起動時に確認し、新しいバージョンがあれば右上に通知を表示します。
- **アップデートを自動でインストール**：バックグラウンドで静かにダウンロードし、ダウンロードページもステータスバーも使いません。検証に通ると、**ランチャーを終了する**タイミングで静かにインストールします。

右上の丸いバッジにダウンロードの進行状況が表示されます。クリックするとバージョン番号とその版の更新内容が見られます。そこで「今すぐダウンロード」を押すこともでき、インストール完了後にランチャーが自動で開き直ります。

**設定 → バージョン情報** で自動確認・自動インストールをオフにでき、「アップデートを確認」を手動で押すこともできます。

更新パッケージは SHA1 を検証してからインストールし、検証に失敗した場合はインストールしません。途中で中断した場合は、次回起動時に「前回の更新が完了していません」と表示され、再試行できます。3 回連続で失敗すると、公式サイトからインストーラーを再ダウンロードするよう案内します。

:::warning 1.5.2 以前からのアップグレード
旧バージョンはサイレントインストールの引数を認識しないため、この 1 回だけ従来のインストーラー画面が表示されます。1.6.0 以降はすべてサイレントで行われます。
:::

更新後にランチャーが起動しない場合は、まず `%APPDATA%\gpcl\gpcl\log` の最新ログを確認し、ログを添えてメールしてください。

## ローカルバージョンのインポート

起動ページの「バージョン選択」パネルで「ローカルバージョンをインポート」を押すと、次のものをインポートできます。

- バージョンフォルダー（中に `<version-name>.json` が必要）
- zip または jar アーカイブ。ランチャーが展開し、`<version-name>.json` のあるフォルダーを再帰的に探します

Mod パック（`manifest.json` に `minecraft` セクションがあるもの）は現在インポートできません。ランチャーは途中まで入れてしまわず、はっきり拒否します。

## アンインストール

Windows の「アプリと機能」から GPCL をアンインストールします。アンインストーラーは `%APPDATA%\gpcl` を**削除しません**。再インストール後もゲームと設定はそのまま残ります。

もう使わないと決めた場合は、`%APPDATA%\gpcl` フォルダーごと手動で削除できます。削除する前にワールドをバックアップしてください。
