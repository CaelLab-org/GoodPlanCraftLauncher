:::tip まずバージョンを確認
このページは 1.9.2 を基準に書いています。現在のバージョンは **設定 → バージョン情報** で確認できます。大きく異なる場合、一部の項目の位置が違うことがあります。
:::

## 問題を報告するには

[gamets@caellab.com](mailto:gamets@caellab.com) までメールしてください。次の内容があれば、たいてい原因を絞り込めます。

- ランチャーのバージョン、Minecraft のバージョン、導入している Mod
- クラッシュ前に何をしたか（Mod を入れた直後か、Java を変えたか、メモリを変えたか）
- **GPCL で書き出したエラーレポート**（クラッシュダイアログの「エラーレポートを書き出す」）

クラッシュ画面のスクリーンショットだけでは、情報量が足りないことがほとんどです。
