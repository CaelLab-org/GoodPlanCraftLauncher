---
title: ログイン：正規アカウントとオフライン
description: GPCL の Microsoft 正規アカウントログインとオフラインログインの違い、流れ、切り替え方。
---

GPCL は 2 種類のログインに対応しており、いつでも切り替えられます。オフラインログインはネットワーク不要ですが、正規アカウント認証が有効なサーバーには入れません。

## オフラインログイン

起動ページでプレイヤー名を入力するだけで起動できます。パスワードは不要です。最近使った 5 件の名前がドロップダウンに残り、1 件ずつ削除できます。

- シングルプレイ、LAN プレイ、正規アカウント認証のないサーバーに向いています。
- ネットワーク認証がないため、オフラインでも起動できます。
- 正規アカウント認証が有効なサーバーには入れず、入ってもキックされます。
- 他人の正規 ID を使わないでください。サーバー側でもプレイヤー側でも別人と誤認されます。

## Microsoft 正規アカウントログイン

1. 起動ページで「正規アカウントでログイン」を押します。
2. GPCL が既定のブラウザーを開き、Microsoft のログインページへ移動します。
3. ログインして認可に同意すると、ブラウザーにランチャーへ戻れる旨が表示されます。
4. GPCL が結果を自動で受け取り、プレイヤー名はアカウントのものになります。

ログインは最大 2 分待ちます。反応がない場合は、まずブラウザーでログインと認可が完了しているか確認し、そのうえでネットワークを確認してください。

ランチャーはログイン状態を保存するため、次回起動時の再ログインは不要です。「起動前にメモリを最適化」を押してもログイン状態は消えません。

## 2 つのモードの使い分け

| 状況 | 使うモード |
| --- | --- |
| シングルプレイ、ひとりで遊ぶ | オフラインでも正規アカウントでも可 |
| 正規アカウント認証のあるサーバー | 正規アカウントが必須 |
| 正規アカウント認証のないサーバー | オフラインでも正規アカウントでも可 |
| ネットワークがない | オフライン |

## アカウントの切り替え

正規アカウントでログイン中に正規アカウントのボタンをもう一度押すとログアウトし、その後オフラインの名前に切り替えられます。オフライン状態で正規アカウントのログインを押すと、そのまま Microsoft のログイン手順に入ります。

## サーバーで Invalid session と表示される

多くの場合、ログイン状態の失効か、そのアカウントにこのバージョンの権利がないことが原因です。

1. ログアウトして、正規アカウントでログインし直す
2. そのアカウントが本当にこの Minecraft のバージョンを所有しているか確認する
3. 別の正規アカウント用サーバーで試し、1 つのサーバーの問題か切り分ける
