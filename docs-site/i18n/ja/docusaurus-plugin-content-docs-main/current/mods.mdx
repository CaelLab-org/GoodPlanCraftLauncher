ダウンロードページの「Mod」セクションでは、Web サイトから落としてフォルダーに放り込む手間なく、Mod の検索、ファイルの選択、指定バージョンへの導入までをランチャー内で行えます。

## 検索

ソースは **Modrinth** と **CurseForge** の 2 つです。既定では両方を検索し、結果一覧にソースが表示されます。

検索ボックスには中国語も入力できます。クエリに中国語が含まれる場合、GPCL はまず MCMOD の公開検索結果を引き、タイトルの括弧から英語名を取り出して（例：「雾中人 (The Man From The Fog)」から `The Man From The Fog`）、その英語名で Modrinth を検索します。英語名が取れない場合は元のクエリで検索します。

## 絞り込み

既定ではバージョンもローダーも**絞り込みません**。PCL と同じくまず全体を検索し、新しい Mod が条件で隠れないようにします。絞りたいときだけ手動で選びます。

- Minecraft のバージョン
- ローダー（Forge / Fabric / NeoForge / Quilt）
- 並び順

ファイル一覧では、現在の起動バージョンの MC バージョンに合うものが先頭に来ます。バージョンを間違えて入れる確率を下げるためです。

## インストール

ファイル行の「インストール」を押すと、インストール先の選択が表示されます。

- インストール済みの Mod バージョンの一覧から選んでそのまま導入
- 「フォルダーを選択」で任意のフォルダーの `mods` に導入

ファイルは対象バージョンが実際に使う `mods` に入ります。分離バージョンなら `versions/<version-name>/mods`、そうでなければゲームのルートの `mods` です。

分離していないバージョンに初めて Mod を入れるとバージョン分離が有効になります。その旨は選択ダイアログに書かれ、追加の確認は表示されません。

### 前提 Mod

Modrinth のファイル行には「前提 N 件」と表示されます。インストール時にはダウンロードに必要な依存関係も再帰的に導入され、完了通知にも前提をいくつ含めたかが書かれます。

CurseForge のリンクモードは選択した 1 ファイルだけを導入し、**前提 Mod は自動で入れません**。画面にもその旨が表示されます。

## CurseForge に API キーがない場合

通常の CurseForge 検索には API キー（**設定 → ダウンロード → CurseForge API キー**、任意）が必要か、公開ミラーが使えるようになるのを待つ必要があります。キーがなくミラーも使えない場合の代替手段があります。

検索ボックスにプロジェクトの URL を貼るか、`cf:<short-name>` と書きます。

```text
https://www.curseforge.com/minecraft/mc-mods/sodium
cf:sodium
```

GPCL は `api.cfwidget.com` でプロジェクトとファイルを引き、ForgeCDN の直リンクからダウンロードします。この経路では**選択した 1 ファイルだけを導入し、依存関係は解決しません**。

## 導入したのに反映されない

- Mod が対応する MC バージョンとローダーが現在のバージョンと一致しているか確認する
- 正しい `mods` に入っているか確認する（バージョン分離後はルートのものではない）
- 前提 Mod が足りない場合は先に補う
- それでもだめなら[ゲームのクラッシュ](./mc-game.mdx)のログ確認手順へ
