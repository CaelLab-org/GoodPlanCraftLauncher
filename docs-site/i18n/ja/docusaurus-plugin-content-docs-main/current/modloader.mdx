title: Forge / Fabric / OptiFine
description: GPCL で Mod ローダーを導入し、バージョンを選び、Mod フォルダーを開く方法。
---

ダウンロードページでバージョンを選ぶときに、ローダーも同時に選べます。GPCL はまずバニラを導入し、そのうえでローダーを独立したバージョンフォルダーに導入します。バニラを上書きすることはありません。

## 導入手順

1. ダウンロードページを開き、Minecraft のバージョンを選びます。
2. ローダーの選択肢から Forge、Fabric、OptiFine のいずれかを選び、対応するローダーのバージョンを選びます。
3. ダウンロードを押し、バニラとローダーの両方が完了するまで待ちます。
4. 起動ページに戻り、ローダー名が付いたバージョンを選んで起動します。

ダウンロードはキューに入るため、複数のバージョンを続けて予約できます。実行中のタスクはキャンセルでき、キャンセル後もキューは続行します。

## 3 種類のローダーの選び方

| ローダー | 向いている用途 | 注意点 |
| --- | --- | --- |
| Forge | 大型 Mod パック、定番の Mod | Fabric より起動が遅く、選べるバージョンが多い |
| Fabric | 軽量な Mod、新しいバージョン | ゲームのバージョンに合った Fabric Loader を選ぶ必要がある |
| OptiFine | シェーダー、パフォーマンス改善 | 他のローダーと併用する場合は互換 Mod が必要なことがある |

### Forge

インストール時、GPCL は `--installClient` だけを実行し、GUI やサーバー向けの引数は試しません。インストーラーの出力は進捗表示に変換されます（例：「Forge をインストール中：Downloading library…」）。

インストール前に Java のメジャーバージョンを確認し、Forge の要件を下回る場合はその場でエラーにします。古い Java で無理に走らせることはありません。処理は最大 15 分待ち、ダウンロードをキャンセルするとインストーラーのプロセスも終了します。

### Fabric

GPCL は Fabric のバージョンプロファイルとライブラリを直接取得し、インストーラーに依存しません。

「Fabric API も同時にインストール」は既定でオンです。Fabric の導入後、対応するバージョンの Fabric API をそのバージョンの `mods` に入れます。オフにすれば導入しません。Fabric API の導入に失敗しても通知だけで、Fabric 本体には影響しません。

### OptiFine

OptiFine はサイレントインストールで、OptiFine 自身の GUI インストーラーは表示されません。結果は現在のゲームディレクトリに反映され、カスタムのゲームディレクトリでも正しく処理されます。

## Mod の置き場所

新しくダウンロードしたバージョンは**バージョン分離**が既定で有効です。ゲームディレクトリが `versions/<version-name>` を指し、Mod、ワールド、ゲーム設定がそのバージョンに従います。

| バージョンの状態 | Mod フォルダー |
| --- | --- |
| 新規ダウンロードで分離済み | `versions/<version-name>/mods` |
| 以前からあり、バージョンフォルダーに `mods` / `saves` がない | ゲームのルートにある `mods` |

起動ページでバージョンの「バージョン設定」を開くと、フォルダーの項目は実際の分離結果から決まります。

- 「バージョンフォルダー」は常にあります。
- Forge / Fabric / NeoForge / Quilt を検出すると「Mod フォルダー」が現れます。
- OptiFine を検出すると「シェーダーフォルダー」が現れます。

任意のフォルダーに Mod を入れたい場合は、Mod ダウンロードのインストール先で「フォルダーを選択」を選ぶと、そのフォルダー内の `mods` を見つけます。

## 導入後にクラッシュする

1. `mods` 内の Mod をすべて退避し、素の状態で一度起動します。
2. 起動できるなら半分ずつ戻して、問題の Mod を絞ります。
3. Mod が Minecraft のバージョンとローダーのバージョンの両方に合っているか確認します。Forge 用の Mod を Fabric に入れることはできず、逆も同じです。
4. 前提 Mod の不足でも起動時にクラッシュします。[Mod のダウンロード](./mods.mdx)に載っている前提 Mod を確認してください。

OptiFine と Forge / Fabric を併用する場合は、通常は追加の互換 Mod が必要です。対応する互換 Mod がない場合は無理に入れないでください。

詳しい切り分けは[ゲームのクラッシュ](./mc-game.mdx)にあります。
