## How to ask for help

Email [gamets@caellab.com](mailto:gamets@caellab.com). Include the following and the cause can usually be narrowed down:

- launcher version, Minecraft version, and which mods are installed;
- what you did before the crash (just installed a mod? changed Java? changed the memory setting?);
- **the error report exported from GPCL** ("Export error report" in the crash dialog).

A screenshot of the crash window alone rarely carries enough information.
