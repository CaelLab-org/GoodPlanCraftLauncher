در صفحهٔ دانلود، هنگام انتخاب نسخه می‌توانید لودر را هم انتخاب کنید. GPCL اول نسخهٔ اصلی را نصب می‌کند و بعد لودر را در پوشهٔ نسخهٔ جداگانه نصب می‌کند و نسخهٔ اصلی را بازنویسی نمی‌کند.

## نحوهٔ نصب

1. صفحهٔ دانلود را باز کنید و یک نسخهٔ Minecraft انتخاب کنید.
2. در گزینه‌های لودر، Forge یا Fabric یا OptiFine و بعد نسخهٔ متناظر لودر را انتخاب کنید.
3. «دانلود» را بزنید و صبر کنید تا هم نسخهٔ اصلی و هم لودر نصب شوند.
4. به صفحهٔ اجرا برگردید و نسخه‌ای را که نام لودر دارد اجرا کنید.

وظیفه‌های دانلود در صف قرار می‌گیرند و می‌توانید چند نسخه را پشت‌سرهم در صف بگذارید؛ وظیفهٔ در حال دانلود قابل لغو است و پس از لغو، صف ادامه پیدا می‌کند.

## کدام لودر را انتخاب کنیم

| لودر | مناسب برای | نکته |
| --- | --- | --- |
| Forge | مدپک‌های بزرگ، مودهای قدیمی | از Fabric کندتر بالا می‌آید، گزینه‌های نسخه بیشتر |
| Fabric | مودهای سبک، نسخه‌های جدید | باید Fabric Loader را متناسب با نسخهٔ بازی انتخاب کنید |
| OptiFine | شیدر، بهینه‌سازی کارایی | در ترکیب با لودرهای دیگر ممکن است مود سازگاری لازم شود |

### Forge

هنگام نصب، GPCL فقط `--installClient` را اجرا می‌کند و سراغ GUI یا پارامترهای سرور نمی‌رود. خروجی نصب‌کننده به پیشرفت تبدیل می‌شود، مثلاً «در حال نصب Forge: Downloading library…».

پیش از نصب، نسخهٔ اصلی Java بررسی می‌شود؛ اگر پایین‌تر از نیاز Forge باشد مستقیم خطا می‌دهد و نصب‌کننده را با Java قدیمی‌تر اجرا نمی‌کند. کل فرایند حداکثر ۱۵ دقیقه منتظر می‌ماند؛ لغو دانلود فرایند نصب‌کننده را پایان می‌دهد.

### Fabric

GPCL پروفایل نسخهٔ Fabric و فایل‌های کتابخانه را مستقیم می‌گیرد و به نصب‌کننده وابسته نیست.

گزینهٔ «نصب Fabric API هم» پیش‌فرض تیک خورده است و پس از نصب Fabric، نسخهٔ متناظر Fabric API در `mods` همان نسخه گذاشته می‌شود. با برداشتن تیک نصب نمی‌شود؛ شکست در نصب Fabric API فقط اعلان می‌دهد و به خود Fabric کاری ندارد.

### OptiFine

OptiFine بی‌صدا نصب می‌شود و پنجرهٔ گرافیکی خودش باز نمی‌شود. نتیجهٔ نصب در پوشهٔ فعلی بازی می‌نشیند و پوشهٔ بازی سفارشی هم درست پردازش می‌شود.

## مودها کجا می‌روند

نسخه‌های تازه دانلودشده به‌طور پیش‌فرض **جداسازی نسخه** را فعال می‌کنند: پوشهٔ بازی به `versions/<version-name>` اشاره می‌کند و مودها، ذخیره‌ها و تنظیمات بازی با همان نسخه می‌مانند.

| وضعیت نسخه | پوشهٔ مودها |
| --- | --- |
| تازه دانلودشده و جداسازی‌شده | `versions/<version-name>/mods` |
| از قبل بوده و پوشهٔ نسخه `mods` / `saves` ندارد | `mods` در ریشهٔ پوشهٔ بازی |

در صفحهٔ اجرا «تنظیمات نسخه» را باز کنید؛ ورودی‌های پوشه بر اساس نتیجهٔ واقعی جداسازی محاسبه می‌شوند:

- «پوشهٔ نسخه» همیشه هست؛
- با شناسایی Forge / Fabric / NeoForge / Quilt «پوشهٔ مودها» ظاهر می‌شود؛
- با شناسایی OptiFine «پوشهٔ شیدر» ظاهر می‌شود.

برای نصب مود در هر پوشه‌ای، در هدف نصب مود «انتخاب پوشه» را بزنید؛ لانچر `mods` داخل آن پوشه را پیدا می‌کند.

## بعد از نصب کرش می‌کند

1. اول همهٔ مودها را از `mods` بیرون ببرید و یک بار تمیز اجرا کنید.
2. اگر بالا آمد، هر بار نصف مودها را برگردانید تا مود مشکل‌دار پیدا شود.
3. مطمئن شوید مود هم با نسخهٔ Minecraft و هم با نسخهٔ لودر می‌خواند — مود Forge را نمی‌شود در Fabric انداخت و برعکس.
4. نبودن پیش‌نیاز هم هنگام اجرا کرش می‌دهد؛ اول پیش‌نیازهای فهرست‌شده در [دانلود مود](./mods.mdx) را ببینید.

ترکیب OptiFine با Forge / Fabric معمولاً به مود سازگاری اضافه نیاز دارد. اگر مود سازگار موجود نیست، به زور نصبش نکنید.
