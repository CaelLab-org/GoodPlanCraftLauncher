GoodPlanCraftLauncher (از این پس GPCL) لانچر Minecraft روی Windows است. این مستندات فقط دربارهٔ **نحوهٔ استفاده پس از نصب و چگونگی بررسی مشکل** است: تغییرات نسخه‌ها و تاریخچهٔ پروژه در اینجا نیست.

| کاری که می‌خواهید | کجا را ببینید |
| --- | --- |
| نصب، ارتقا و حذف | [نصب و به‌روزرسانی](./install.mdx) |
| ورود با حساب رسمی یا نام آفلاین | [ورود](./login.mdx) |
| کندی بازی، کمبود حافظه، خطای Java | [Java و حافظه](./java-memory.mdx) |
| نصب Forge / Fabric / OptiFine | [لودرهای مود](./modloader.mdx) |
| جست‌وجو و نصب مود داخل لانچر | [دانلود مود](./mods.mdx) |
| کندی دانلود، انتخاب منبع آینه | [دانلود و منابع آینه](./download.mdx) |
| کرش بازی | [کرش بازی](./mc-game.mdx) |
| تغییر عنوان پنجرهٔ بازی | [کلمات جادویی عنوان](./magic-words.mdx) |

:::tip اول نسخه را بررسی کنید
این صفحه‌ها برای 1.9.2 نوشته شده‌اند. نسخهٔ فعلی در **تنظیمات ← درباره** دیده می‌شود؛ اگر نسخه خیلی متفاوت باشد، جای بعضی گزینه‌ها ممکن است فرق کند.
:::

## در صورت بروز مشکل چگونه بپرسیم

به [gamets@caellab.com](mailto:gamets@caellab.com) ایمیل بزنید. با نوشتن این موارد معمولاً می‌توان مشکل را پیدا کرد:

- نسخهٔ لانچر، نسخهٔ Minecraft، و مودهای نصب‌شده؛
- کاری که پیش از کرش انجام داده‌اید (مود تازه‌ای نصب کردید؟ Java را عوض کردید؟ حافظه را تغییر دادید؟)؛
- **گزارش خطایی که GPCL می‌سازد** («خروجی گرفتن از گزارش خطا» در پنجرهٔ کرش).

فرستادن فقط یک تصویر از پنجرهٔ کرش معمولاً اطلاعات کافی نمی‌دهد.
