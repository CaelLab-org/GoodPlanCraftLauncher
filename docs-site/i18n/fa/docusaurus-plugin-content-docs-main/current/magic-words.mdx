در عنوان پنجرهٔ بازی می‌توانید متغیر بنویسید و GPCL هنگام اجرا آن را با مقدار واقعی عوض می‌کند.

جایش در **تنظیمات ← بازی ← عنوان پنجرهٔ بازی** است. خالی گذاشتن عنوان یعنی عنوان پنجرهٔ بازی تغییر نمی‌کند.

## برای نمونه

عنوان را این‌طور بنویسید:

```text
{time} · {mc_version} · {gpcl_version}
```

پس از اجرا ممکن است این‌طور دیده شود:

```text
20:09:58 · Minecraft 1.21.3 · 1.6.0
```

## متغیرهای قابل استفاده

| متغیر | چه می‌شود |
| --- | --- |
| `{mc_version}` | نام نمایشی نسخه، مثلاً Minecraft 1.21.3 یا نام همراه لودر |
| `{mc_id}` | نام پوشهٔ نسخه، مثلاً 1.21.3-Fabric |
| `{username}` | نام بازیکن استفاده‌شده در این اجرا |
| `{gpcl_version}` | شمارهٔ نسخهٔ GPCL، مثلاً 1.6.0 |
| `{date}` | تاریخ اجرا، قالب 2026/10/20 |
| `{time}` | ساعت فعلی، قالب 20:09:58 |
| `{datetime}` | تاریخ و ساعت، جدا‌شده با فاصله |
| `{java}` | نام پوشهٔ محیط اجرای Java فعلی |
| `{memory}` | بیشترین حافظهٔ تخصیص‌یافته در این اجرا، مثلاً 4096MB |

بزرگی و کوچکی حروف باید یکی باشد. متغیر اشتباه همان‌طور که نوشته شده نمایش داده می‌شود تا بفهمید کدام را غلط نوشته‌اید.

## آیا عنوان همیشه می‌ماند

پایین آن کلید «تلاش برای نگه داشتن نام» هست و پیش‌فرض خاموش است.

- **خاموش**: بعد از آمدن پنجرهٔ بازی، GPCL تا ۲۰ ثانیه عنوان را اصلاح می‌کند. بعد از آن اگر بازی یا مودی عنوان را عوض کند دیگر کاری نمی‌کند. عنوانی که `{time}` دارد هم در همان لحظه متوقف می‌شود.
- **روشن**: عنوانی که گذاشته‌اید در کل بازی می‌ماند و با ورود به دنیا با « - Singleplayer» پوشانده نمی‌شود.

بعضی مدپک‌ها یا مودها هم عنوان پنجره را عوض می‌کنند؛ نوشتن روی هم در این حالت طبیعی است.

:::note
فعلاً کلمات جادویی فقط در عنوان پنجرهٔ بازی پشتیبانی می‌شوند و در تنظیمات دیگر اثر ندارند.
:::
