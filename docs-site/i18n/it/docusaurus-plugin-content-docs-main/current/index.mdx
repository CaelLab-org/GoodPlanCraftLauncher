Queste pagine sono scritte per la versione 1.9.0. La versione attuale si vede in **Impostazioni → Informazioni**; se la differenza è grande, la posizione di alcune opzioni può cambiare.

## Come chiedere aiuto

Scrivi a [gamets@caellab.com](mailto:gamets@caellab.com). Descrivendo questi elementi, nella maggior parte dei casi il problema si individua:

- versione del launcher, versione di Minecraft, mod installate;
- cosa hai fatto prima del crash (hai appena installato mod? hai cambiato Java? hai modificato la memoria?);
- **il report di errore esportato da GPCL** (pulsante «Esporta report di errore» nella finestra di crash).

Una sola schermata della finestra di crash di solito non basta per capire cosa è successo.
