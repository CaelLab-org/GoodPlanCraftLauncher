---
title: Accesso con account ufficiale o offline
description: Accesso con account Microsoft e accesso offline in GPCL — differenze, procedura e come passare da uno all'altro.
---

GPCL supporta due modalità di accesso, intercambiabili in qualsiasi momento. L'accesso offline non richiede internet, ma non permette di entrare nei server con verifica dell'account ufficiale.

## Accesso offline

Basta inserire un nome giocatore nella schermata iniziale per avviare, senza password. Gli ultimi 5 nomi usati restano nell'elenco a discesa e si possono eliminare uno per uno.

- Adatto al gioco in singolo, alla LAN e ai server senza verifica dell'account ufficiale.
- Non richiede convalida online: funziona anche senza connessione.
- Non permette di entrare nei server con verifica dell'account ufficiale: verresti espulso.
- Non usare l'ID ufficiale di un'altra persona: server e giocatori potrebbero confondere le identità.

## Accesso con account Microsoft

1. Nella schermata iniziale fai clic su «Accedi con account ufficiale».
2. GPCL apre il browser predefinito sulla pagina di accesso Microsoft.
3. Accedi e autorizza l'accesso: il browser indica che puoi tornare al launcher.
4. GPCL riceve il risultato automaticamente e il nome giocatore diventa quello dell'account.

L'accesso attende al massimo 2 minuti. Se non succede nulla, verifica prima che accesso e autorizzazione siano stati completati nel browser, poi controlla la connessione.

Il launcher salva lo stato di accesso, quindi al prossimo avvio non serve rifare l'accesso. Anche «Ottimizza la memoria prima di avviare il gioco» non cancella lo stato di accesso.

## Quale modalità scegliere

| Scenario | Cosa usare |
| --- | --- |
| Gioco in singolo, per te | Offline o account ufficiale, indifferente |
| Server con verifica dell'account ufficiale | Account ufficiale obbligatorio |
| Server senza verifica dell'account ufficiale | Offline o account ufficiale, indifferente |
| Nessuna connessione | Offline |

## Cambiare account

Con un account ufficiale connesso, un secondo clic sul pulsante dell'account ufficiale disconnette; poi puoi usare un nome offline. In modalità offline, il clic sull'accesso con account ufficiale avvia direttamente la procedura Microsoft.

## Il server risponde Invalid session

Nella maggior parte dei casi l'accesso è scaduto oppure l'account non ha diritto a quella versione:

1. esci dall'account e ripeti l'accesso con account Microsoft;
2. verifica che l'account possieda davvero quella versione di Minecraft;
3. prova su un altro server con verifica dell'account ufficiale per escludere un problema del singolo server.
