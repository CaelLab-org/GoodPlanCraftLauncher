## Comment poser une question en cas de problème

Écrivez à [gamets@caellab.com](mailto:gamets@caellab.com). Avec ces éléments, on peut presque toujours cerner le problème :

- version du lanceur, version de Minecraft, mods installés ;
- ce que vous avez fait avant le plantage (mods tout juste installés ? Java changé ? mémoire modifiée ?) ;
- **le rapport d'erreur exporté par GPCL** (« Exporter le rapport d'erreur » dans la fenêtre de plantage).

Une simple capture d'écran de la fenêtre de plantage ne suffit généralement pas.
