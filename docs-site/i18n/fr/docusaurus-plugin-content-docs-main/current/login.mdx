---
title: Connexion premium et hors ligne
description: Connexion Microsoft premium et connexion hors ligne dans GPCL — différences, déroulement et bascule.
---

GPCL propose deux modes de connexion, permutables à tout moment. La connexion hors ligne ne nécessite pas Internet, mais ne permet pas d'entrer sur un serveur avec vérification premium.

## Connexion hors ligne

Sur la page de démarrage, un pseudo suffit pour lancer le jeu, sans mot de passe. Les 5 derniers pseudos restent dans la liste déroulante et peuvent être supprimés un par un.

- Adapté au solo, au réseau local et aux serveurs sans vérification premium.
- Aucune vérification en ligne : le lancement fonctionne même sans connexion.
- Impossible de rejoindre un serveur avec vérification premium, vous serez expulsé.
- N'utilisez pas l'identifiant premium d'autrui : serveurs et joueurs peuvent confondre les personnes.

## Connexion Microsoft premium

1. Sur la page de démarrage, cliquez sur « Connexion premium ».
2. GPCL ouvre le navigateur par défaut et va à la page de connexion Microsoft.
3. Connectez-vous et acceptez l'autorisation ; le navigateur indique que vous pouvez revenir au lanceur.
4. GPCL reçoit le résultat automatiquement ; le pseudo vient du compte.

GPCL attend au maximum 2 minutes. Sans réaction, vérifiez d'abord que la connexion et l'autorisation sont terminées dans le navigateur, puis le réseau.

Le lanceur conserve l'état de connexion, inutile de vous reconnecter au démarrage suivant. « Optimiser la mémoire avant le lancement » ne supprime pas cet état.

## Quel mode choisir

| Situation | Mode |
| --- | --- |
| Solo, jouer seul | Hors ligne ou premium |
| Serveur avec vérification premium | Premium uniquement |
| Serveur sans vérification premium | Hors ligne ou premium |
| Pas de réseau | Hors ligne |

## Changer de compte

Connecté en premium, un nouveau clic sur le bouton premium vous déconnecte ; vous pouvez ensuite utiliser un pseudo hors ligne. En mode hors ligne, « Connexion premium » lance directement le parcours Microsoft.

## Le serveur affiche Invalid session

Le plus souvent, la session a expiré ou le compte ne possède pas de licence pour cette version :

1. Déconnectez-vous et refaites une connexion premium ;
2. vérifiez que le compte possède bien cette version de Minecraft ;
3. essayez un autre serveur premium pour écarter un problème propre à un seul serveur.
