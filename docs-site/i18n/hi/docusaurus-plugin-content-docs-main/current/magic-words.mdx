गेम विंडो के टाइटल में प्लेसहोल्डर लिखे जा सकते हैं; लॉन्च के समय GPCL उन्हें असली मान में बदल देता है।

जगह: **सेटिंग्स → गेम → गेम विंडो टाइटल**। टाइटल खाली छोड़ने का मतलब गेम विंडो का टाइटल न बदलना।

## एक उदाहरण

टाइटल इस तरह लिखें:

```text
{time} · {mc_version} · {gpcl_version}
```

लॉन्च के बाद यह कुछ ऐसा दिख सकता है:

```text
20:09:58 · Minecraft 1.21.3 · 1.6.0
```

## कौन-कौन से प्लेसहोल्डर चलते हैं

| प्लेसहोल्डर | क्या बनेगा |
| --- | --- |
| `{mc_version}` | वर्ज़न का डिस्प्ले नाम, जैसे Minecraft 1.21.3, या लोडर के साथ नाम |
| `{mc_id}` | वर्ज़न फ़ोल्डर का नाम, जैसे 1.21.3-Fabric |
| `{username}` | इस लॉन्च में इस्तेमाल हुआ प्लेयर नाम |
| `{gpcl_version}` | GPCL का वर्ज़न नंबर, जैसे 1.6.0 |
| `{date}` | लॉन्च की तारीख़, फ़ॉर्मैट 2026/10/20 |
| `{time}` | मौजूदा समय, फ़ॉर्मैट 20:09:58 |
| `{datetime}` | तारीख़ और समय, बीच में स्पेस |
| `{java}` | मौजूदा Java रनटाइम डायरेक्टरी का नाम |
| `{memory}` | इस बार आवंटित अधिकतम मेमोरी, जैसे 4096MB |

छोटे-बड़े अक्षर वैसे ही रखें। गलत प्लेसहोल्डर जैसा लिखा है वैसा ही दिखता है, ताकि पता चले कि कौन-सा गलत है।

## क्या टाइटल बना रहेगा

नीचे "नाम को ज़्यादा से ज़्यादा बनाए रखें" टॉगल है, डिफ़ॉल्ट बंद।

- **बंद**: गेम विंडो आने के बाद GPCL 20 सेकंड तक टाइटल ठीक करता रहता है। इसके बाद गेम या मॉड टाइटल बदले तो वह हाथ नहीं लगाता। `{time}` वाला टाइटल भी उसी समय पर रुक जाता है।
- **चालू**: पूरे गेम के दौरान आपका सेट किया टाइटल बना रहता है, दुनिया में जाने पर भी " - Singleplayer" उसे नहीं ढकता।

कुछ मॉडपैक और मॉड भी विंडो टाइटल बदलते हैं; दोनों का एक-दूसरे को ढकना सामान्य है।

:::note
अभी सिर्फ़ गेम विंडो टाइटल में मैजिक वर्ड चलते हैं, बाकी सेटिंग्स में नहीं।
:::
