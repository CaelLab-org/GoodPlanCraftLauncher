GoodPlanCraftLauncher (आगे GPCL) Windows के लिए Minecraft लॉन्चर है। इन दस्तावेज़ों में सिर्फ़ यह बताया गया है कि **इंस्टॉल करने के बाद कैसे इस्तेमाल करें और कुछ टूटे तो कैसे जाँचें**: यहाँ चेंजलॉग नहीं है, और प्रोजेक्ट का इतिहास भी नहीं।

| आप क्या करना चाहते हैं | कहाँ देखें |
| --- | --- |
| इंस्टॉल, अपग्रेड, अनइंस्टॉल | [इंस्टॉल और अपडेट](./install.mdx) |
| प्रीमियम लॉगिन या ऑफ़लाइन नाम | [लॉगिन](./login.mdx) |
| गेम लैग कर रहा है, मेमोरी कम है, Java में एरर | [Java और मेमोरी](./java-memory.mdx) |
| Forge / Fabric / OptiFine इंस्टॉल करना | [मॉड लोडर](./modloader.mdx) |
| लॉन्चर से मॉड खोजना और इंस्टॉल करना | [मॉड डाउनलोड](./mods.mdx) |
| डाउनलोड धीमा है, मिरर कैसे चुनें | [डाउनलोड और मिरर](./download.mdx) |
| गेम क्रैश हो गया | [गेम क्रैश](./mc-game.mdx) |
| गेम विंडो का टाइटल बदलना | [विंडो टाइटल के मैजिक वर्ड](./magic-words.mdx) |

:::tip पहले वर्ज़न जाँचें
ये पेज 1.9.2 के हिसाब से लिखे गए हैं। मौजूदा वर्ज़न **सेटिंग्स → जानकारी** में दिखता है; अगर वर्ज़न में काफ़ी फ़र्क है, तो कुछ विकल्पों की जगह अलग हो सकती है।
:::

## दिक्कत हो तो कैसे पूछें

[gamets@caellab.com](mailto:gamets@caellab.com) पर मेल भेजें। ये बातें साफ़ लिखें, तो आम तौर पर समस्या पकड़ में आ जाती है:

- लॉन्चर का वर्ज़न, Minecraft का वर्ज़न, कौन-कौन से मॉड इंस्टॉल हैं;
- क्रैश से पहले क्या किया (अभी मॉड इंस्टॉल किए? Java बदला? मेमोरी बदली?);
- **GPCL से एक्सपोर्ट की गई एरर रिपोर्ट** (क्रैश डायलॉग पर "एरर रिपोर्ट एक्सपोर्ट करें")।

सिर्फ़ क्रैश विंडो का स्क्रीनशॉट भेजना आम तौर पर काफ़ी नहीं होता।
