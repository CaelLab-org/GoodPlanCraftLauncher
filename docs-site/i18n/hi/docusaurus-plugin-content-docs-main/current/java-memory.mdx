GPCL गेम वर्ज़न के हिसाब से Java चुनता है और कंप्यूटर की मेमोरी के हिसाब से मेमोरी बाँटता है। ज़्यादातर मामलों में हाथ से बदलने की ज़रूरत नहीं।

## Java वर्ज़न का मेल

| Minecraft वर्ज़न | ज़रूरी Java |
| --- | --- |
| 1.16.5 और उससे पुराने | Java 8 |
| 1.17 – 1.20.4 | Java 17 |
| 1.20.5 और उसके बाद | Java 21 |

लॉन्च के समय सही Java न मिले तो GPCL उसे अपने आप डाउनलोड और इंस्टॉल करता है। डाउनलोड फेल हो तो **सेटिंग्स → डाउनलोड → Java डाउनलोड** में जाकर दूसरा मिरर स्रोत चुनकर दोबारा कोशिश करें।

Java GPCL की अपनी डायरेक्टरी में इंस्टॉल होता है, सिस्टम के दूसरे Java पर असर नहीं डालता और सिस्टम का `JAVA_HOME` नहीं बदलता।

## मेमोरी: अपने आप

डिफ़ॉल्ट "अपने आप" है। बाँटने का तरीका दो कदम में:

1. पहले फ़िज़िकल मेमोरी का **30%** अनुमान लगाएँ, GB में नीचे की ओर राउंड करें, और **2 – 8 GB** के बीच सीमित रखें;
2. फिर मौजूदा उपलब्ध मेमोरी देखें: सिस्टम के लिए कम से कम 1 GB छोड़ें, कम से कम 2 GB मानें, नतीजे को 512 MB में नीचे की ओर राउंड करें, और दोनों में से छोटा लें।

कुछ असली नतीजे:

| फ़िज़िकल मेमोरी | मौजूदा उपलब्ध | अपने आप आवंटित |
| --- | --- | --- |
| 16 GB | 8 GB | 4 GB |
| 16 GB | 3.9 GB | 2.5 GB |
| 8 GB | 4 GB | 2 GB |

सेटिंग्स पेज सिस्टम मेमोरी का इस्तेमाल / कुल और मौजूदा उपलब्ध दिखाता है। उपलब्ध मेमोरी कम हो तो अपने आप वाला आवंटन भी घट जाता है और कुछ प्रोग्राम बंद करने का सुझाव दिखता है।

`-Xmx` ऊपरी सीमा है, लॉन्च होते ही पूरी नहीं भर जाती। इसलिए उस वक्त की उपलब्ध मेमोरी के हिसाब से बाँटना, बहुत बड़ा मान देने से ज़्यादा स्थिर रहता है।

## मेमोरी: कस्टम

बड़े मॉडपैक या भारी मॉड सेट से कम पड़े तो "कस्टम" पर जाकर स्लाइडर खींचें। सिस्टम और दूसरे प्रोग्राम के लिए जगह छोड़ें, पूरी फ़िज़िकल मेमोरी गेम को न दें।

`OutOfMemoryError` का मतलब मेमोरी कम है:

1. आवंटन एक स्टेप बढ़ाकर दोबारा कोशिश करें;
2. फिर भी न हो तो मॉड घटाएँ;
3. साथ ही ब्राउज़र जैसे मेमोरी लेने वाले प्रोग्राम बंद करें।

## G1GC ट्यूनिंग

**सेटिंग्स → एडवांस्ड → मेमोरी मैनेजमेंट** में G1GC ट्यूनिंग है, डिफ़ॉल्ट बंद। सिर्फ़ तब चालू करने की सलाह है जब FPS में उतार-चढ़ाव या GC में साफ़ रुकावट महसूस हो; चालू करने पर G1GC के आम पैरामीटर जोड़ दिए जाते हैं।

कस्टम JVM पैरामीटर भी इसी जगह हैं। गलत पैरामीटर से गेम सीधे नहीं उठेगा, पक्का न हो तो न बदलें।

## लॉन्च से पहले मेमोरी ऑप्टिमाइज़ करना

चालू होने पर GPCL गेम लॉन्च करने से पहले अपने प्रोसेस की कुछ मेमोरी वापस छोड़ देता है। यह सिर्फ़ लॉन्चर का प्रोसेस साफ़ करता है, चल रहे Minecraft को नहीं छूता और लॉगिन स्टेटस नहीं मिटाता।

हार्ड डिस्क (HDD) पर इस कदम में थोड़ी देर रुकावट आ सकती है, यह सामान्य है।
