Το παράθυρο κατάρρευσης συνήθως δεν δείχνει την αιτία. Το GPCL διαβάζει πρώτα τα αρχεία καταγραφής για ενδείξεις και μετά ελέγχετε με την παρακάτω σειρά.

:::tip Κάντε πρώτα ένα πράγμα
Πατήστε «Εξαγωγή αναφοράς σφάλματος» στο παράθυρο κατάρρευσης και αποθηκεύστε το zip. Στην αρχή της αναφοράς είναι το αποτέλεσμα ανάλυσης του GPCL και μετά ακολουθούν λίστα Mod, Java, παράμετροι εκκίνησης και όλα τα αρχεία καταγραφής· ο έλεγχος βασίζεται κυρίως σε αυτό.
:::

## 1. Δείτε πρώτα την ανάλυση του GPCL

Το παράθυρο δείχνει 1–2 ενδείξεις που βρήκε το GPCL στα αρχεία καταγραφής, π.χ. «ανεπαρκής μνήμη» ή «ο έλεγχος εξαρτήσεων ή συμβατότητας Mod δεν πέρασε». Με «Προβολή λεπτομερειών» βλέπετε όλες τις ενδείξεις, τα αντίστοιχα αποσπάσματα καταγραφής και τις πληροφορίες κατάρρευσης.

Αυτά τα συμπεράσματα προκύπτουν από αντιστοίχιση λέξεων-κλειδιών και είναι μόνο κατεύθυνση ελέγχου. Όταν τα αρχεία καταγραφής έχουν πιο συγκεκριμένες πληροφορίες (π.χ. ποιο προαπαιτούμενο λείπει), αναφέρονται μαζί στα στοιχεία.

## 2. Εξαγωγή αναφοράς σφάλματος

Το κουμπί βρίσκεται στο παράθυρο κατάρρευσης. Διαλέξτε θέση αποθήκευσης· το GPCL πακετάρει:

- `error-report.txt`: αποτέλεσμα ανάλυσης, σύνοψη σφάλματος, σύστημα / κάρτα γραφικών / Java, λίστα Mod, πακέτα πόρων και shader, παράμετροι εκκίνησης, έξοδος παιχνιδιού, γραμμές σφάλματος από τα αρχεία καταγραφής.
- `crash-reports/`: η αναφορά κατάρρευσης αυτής της φοράς.
- `logs/`: `latest.log` και `debug.log` (αν είναι πολύ μεγάλα, μόνο το τέλος).
- `jvm-crash/`: `hs_err_pid*.log` που γράφει η ίδια η JVM (αν πρόβλημα όπως πρόγραμμα οδήγησης κάρτας γραφικών προκαλέσει κατάρρευση της JVM).
- `launcher-log.txt`: αρχείο καταγραφής εκκινητή.
- `game-output.txt`: τυπική έξοδος και έξοδος σφάλματος της διεργασίας παιχνιδιού αυτής της εκτέλεσης.

Το `--accessToken` και το όνομα χρήστη συστήματος στην αναφορά είναι καλυμμένα, οπότε μπορείτε να τη στείλετε. Μην στέλνετε μόνο στιγμιότυπο οθόνης του παραθύρου κατάρρευσης.

## 3. Δείτε μόνοι τα αρχεία καταγραφής

Το «Προβολή καταγραφής» ανοίγει την έξοδο της διεργασίας παιχνιδιού. Κοιτάξτε το κάτω μέρος και αναζητήστε αυτές τις λέξεις:

| Λέξη-κλειδί | Συνήθως σημαίνει |
| --- | --- |
| `Exception`, `Caused by` | Η πραγματική εξαίρεση είναι συνήθως μετά το πρώτο `Caused by` |
| `OutOfMemoryError` | Η εκχωρημένη μνήμη δεν φτάνει |
| `UnsupportedClassVersionError` | Η έκδοση Java δεν ταιριάζει με την έκδοση παιχνιδιού |
| `NoSuchMethodError`, `ClassNotFoundException` | Το mod δεν ταιριάζει με έκδοση παιχνιδιού ή φορτωτή, ή λείπει προαπαιτούμενο |
| `GLFW error` | Πρόβλημα με πρόγραμμα οδήγησης κάρτας γραφικών ή υποστήριξη OpenGL |

## 4. Συνήθεις αιτίες

| Σύμπτωμα | Συνήθης αιτία | Τι να κάνετε |
| --- | --- | --- |
| Κλείνει αμέσως με την εκκίνηση, στο log υπάρχει `UnsupportedClassVersionError` | Λάθος έκδοση Java | Αφήστε το GPCL να προσθέσει Java αυτόματα· ή αλλάξτε πηγή mirror στις ρυθμίσεις και εγκαταστήστε ξανά |
| Κολλάει ή κλείνει στα μισά της φόρτωσης, στο log υπάρχει `OutOfMemoryError` | Λίγη μνήμη ή πολλά mod | Αυξήστε στο Ρυθμίσεις → Παιχνίδι → Εκχώρηση μνήμης· μην ξεπερνάτε τη φυσική μνήμη |
| Κατάρρευση κατά τη φόρτωση mod, στο log εμφανίζεται όνομα mod | Λάθος έκδοση mod, λείπει προαπαιτούμενο, δύο mod συγκρούονται | Δοκιμάστε πρώτα μόνο αυτό το mod· επιβεβαιώστε την έκδοση MC και φορτωτή που υποστηρίζει |
| Κλείνει πριν εμφανιστεί το παράθυρο, υπάρχει `GLFW error` | Πολύ παλιό πρόγραμμα οδήγησης κάρτας γραφικών ή μη υποστηριζόμενο OpenGL | Ενημερώστε το πρόγραμμα οδήγησης· σε φορητό βεβαιωθείτε ότι το παιχνίδι χρησιμοποιεί την ξεχωριστή GPU |
| Σας διώχνουν από διακομιστή, εμφανίζεται `Invalid session` | Η επίσημη σύνδεση έληξε ή ο λογαριασμός δεν έχει άδεια για αυτή την έκδοση | Συνδεθείτε ξανά επίσημα· βεβαιωθείτε ότι ο λογαριασμός κατέχει την έκδοση |
| Κατάρρευση κατά την είσοδο σε κόσμο ή φόρτωση πακέτου πόρων | Κατεστραμμένο αποθηκευμένο παιχνίδι, πακέτο πόρων ή πακέτο shader | Δημιουργήστε πρώτα νέο κόσμο· κρατήστε αντίγραφο ασφαλείας πριν την επισκευή |
| Κατάρρευση με Fabric, λείπει `fabric-api` | Δεν έχει εγκατασταθεί Fabric API | Κατά την επανεγκατάσταση Fabric τσεκάρετε «Εγκατάσταση και Fabric API» ή εγκαταστήστε το χειροκίνητα |

## 5. Αποκλείστε πρώτα αυτά τα τρία

1. **Απενεργοποιήστε όλα τα mod, πακέτα πόρων και shader** και ξεκινήστε μία φορά χωρίς τίποτα. Αν μπαίνει, το πρόβλημα είναι στα mod.
2. **Δοκιμάστε μια αυθεντική έκδοση**. Αν μπαίνει, το πρόβλημα είναι η τρέχουσα έκδοση ή ο συνδυασμός mod της.
3. **Δημιουργήστε νέο κόσμο**. Αν μπαίνει, το παλιό αποθηκευμένο παιχνίδι είναι κατεστραμμένο.

## 6. Αν ακόμα δεν λυθεί

Στείλτε email στο [gamets@caellab.com](mailto:gamets@caellab.com), επισυνάψτε την εξαγόμενη αναφορά σφάλματος και γράψτε καθαρά:

- έκδοση εκκινητή, έκδοση Minecraft, έκδοση φορτωτή.
- ποια mod είναι εγκατεστημένα (με αριθμούς έκδοσης αν γίνεται).
- τι κάνατε πριν την κατάρρευση.

Η περιγραφή «καταρρέει μόλις ξεκινήσει» δύσκολα εντοπίζεται· τα αρχεία καταγραφής στην αναφορά είναι το κλειδί.
