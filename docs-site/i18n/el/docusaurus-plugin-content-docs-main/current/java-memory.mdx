---
title: Java και μνήμη
description: Αντιστοίχιση εκδόσεων Java, πώς το GPCL εκχωρεί μνήμη αυτόματα και πώς να ρυθμίσετε όταν δεν φτάνει.
---

Το GPCL επιλέγει Java ανάλογα με την έκδοση του παιχνιδιού και εκχωρεί μνήμη με βάση τη μνήμη του υπολογιστή. Στις περισσότερες περιπτώσεις δεν χρειάζεται χειροκίνητη ρύθμιση.

## Αντιστοίχιση εκδόσεων Java

| Έκδοση Minecraft | Απαιτούμενη Java |
| --- | --- |
| 1.16.5 και παλαιότερα | Java 8 |
| 1.17 – 1.20.4 | Java 17 |
| 1.20.5 και μετά | Java 21 |

Αν κατά την εκκίνηση λείπει η κατάλληλη Java, το GPCL την κατεβάζει και την εγκαθιστά αυτόματα. Αν η λήψη αποτύχει, πηγαίνετε στο **Ρυθμίσεις → Λήψη → Λήψη Java**, αλλάξτε πηγή mirror και δοκιμάστε ξανά.

Η Java εγκαθίσταται στον δικό του φάκελο του GPCL· δεν επηρεάζει άλλες Java του συστήματος και δεν αλλάζει το `JAVA_HOME` του συστήματος.

## Μνήμη: αυτόματα

Η προεπιλογή είναι «Αυτόματα». Η λογική εκχώρησης έχει δύο βήματα:

1. Αρχικά υπολογίζεται το **30%** της φυσικής μνήμης, στρογγυλοποιείται προς τα κάτω σε GB και περιορίζεται στα **2 – 8 GB**.
2. Έπειτα εξετάζεται η διαθέσιμη μνήμη εκείνης της στιγμής: κρατάμε τουλάχιστον 1 GB για το σύστημα, με ελάχιστο 2 GB, στρογγυλοποιούμε προς τα κάτω σε 512 MB και παίρνουμε τη μικρότερη από τις δύο τιμές.

Μερικά πραγματικά αποτελέσματα:

| Φυσική μνήμη | Διαθέσιμη εκείνη τη στιγμή | Αυτόματη εκχώρηση |
| --- | --- | --- |
| 16 GB | 8 GB | 4 GB |
| 16 GB | 3.9 GB | 2.5 GB |
| 8 GB | 4 GB | 2 GB |

Η σελίδα ρυθμίσεων δείχνει τη μνήμη συστήματος σε χρήση / σύνολο και τη διαθέσιμη τιμή. Όταν η διαθέσιμη μνήμη είναι περιορισμένη, η αυτόματη εκχώρηση μειώνεται και σας προτείνει να κλείσετε μερικά προγράμματα.

Το `-Xmx` είναι ανώτατο όριο, δεν δεσμεύεται όλο με την εκκίνηση. Γι' αυτό η εκχώρηση με βάση τη διαθέσιμη μνήμη εκείνης της στιγμής είναι πιο σταθερή από ένα σταθερά μεγάλο νούμερο.

## Μνήμη: προσαρμοσμένη

Όταν ένα modpack ή μεγάλο πακέτο mod δεν φτάνει, αλλάξτε σε «Προσαρμοσμένη» και σύρετε το ρυθμιστικό. Αφήστε χώρο για το σύστημα και άλλα προγράμματα· μην δίνετε όλη τη φυσική μνήμη στο παιχνίδι.

Αν εμφανιστεί `OutOfMemoryError`, η μνήμη δεν φτάνει:

1. Ανεβάστε την εκχώρηση ένα επίπεδο και δοκιμάστε ξανά.
2. Αν συνεχίζει, μειώστε τα mod.
3. Κλείστε παράλληλα προγράμματα που τρώνε μνήμη, όπως τον περιηγητή.

## Ρύθμιση G1GC

Στις **Ρυθμίσεις → Για προχωρημένους → Διαχείριση μνήμης** υπάρχει ρύθμιση G1GC, απενεργοποιημένη από προεπιλογή. Συνιστάται μόνο όταν υπάρχουν διακυμάνσεις FPS ή αισθητό κόλλημα από GC· όταν ενεργοποιηθεί, προστίθεται ένα σύνολο συνηθισμένων παραμέτρων G1GC.

Οι προσαρμοσμένες παράμετροι JVM βρίσκονται στο ίδιο σημείο. Λάθος παράμετροι εμποδίζουν την εκκίνηση του παιχνιδιού· αν δεν είστε σίγουροι, μην τις αλλάξετε.

## Βελτιστοποίηση μνήμης πριν την εκκίνηση

Όταν είναι ενεργή, το GPCL απελευθερώνει μέρος της μνήμης που καταλαμβάνει πριν ξεκινήσει το παιχνίδι. Καθαρίζει μόνο τη διεργασία του ίδιου του εκκινητή, δεν αγγίζει το Minecraft που τρέχει και δεν διαγράφει την κατάσταση σύνδεσης.

Σε σκληρό δίσκο με περιστρεφόμενους δίσκους αυτό το βήμα μπορεί να προκαλέσει σύντομο κόλλημα· είναι φυσιολογικό.
