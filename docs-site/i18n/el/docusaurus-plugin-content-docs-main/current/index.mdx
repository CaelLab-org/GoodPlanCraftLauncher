Το GoodPlanCraftLauncher (εφεξής GPCL) είναι εκκινητής Minecraft για Windows. Αυτή η τεκμηρίωση καλύπτει μόνο **πώς να το χρησιμοποιήσετε μετά την εγκατάσταση και πώς να ελέγξετε τι πήγε στραβά**: δεν περιέχει ιστορικό αλλαγών ούτε ιστορία του έργου.

| --- | --- |
| Εγκατάσταση, αναβάθμιση, απεγκατάσταση | [Εγκατάσταση και ενημερώσεις](./install.mdx) |
| Επίσημη σύνδεση ή όνομα offline | [Σύνδεση](./login.mdx) |
| Το παιχνίδι κολλάει, λίγη μνήμη, σφάλμα Java | [Java και μνήμη](./java-memory.mdx) |

| Αναζήτηση και εγκατάσταση mod στον εκκινητή | [Λήψη mod](./mods.mdx) |
| Αργή λήψη, πώς να επιλέξετε πηγή mirror | [Λήψεις και πηγές mirror](./download.mdx) |

## Πώς να ρωτήσετε όταν υπάρχει πρόβλημα

Στείλτε email στο [gamets@caellab.com](mailto:gamets@caellab.com). Αν γράψετε τα παρακάτω, συνήθως εντοπίζεται το πρόβλημα:

- έκδοση εκκινητή, έκδοση Minecraft, ποια mod είναι εγκατεστημένα;
- τι κάνατε πριν την κατάρρευση (μόλις εγκαταστήσατε mod; αλλάξατε Java; αλλάξατε μνήμη;);
- **την αναφορά σφάλματος που εξάγει το GPCL** (κουμπί «Εξαγωγή αναφοράς σφάλματος» στο παράθυρο κατάρρευσης).

Ένα στιγμιότυπο οθόνης του παραθύρου κατάρρευσης συνήθως δεν αρκεί.
