Η αργή λήψη συνήθως δεν είναι πρόβλημα του εκκινητή. Αλλάξτε πρώτα πηγή λήψης και μετά εξετάστε αριθμό νημάτων και όριο ταχύτητας.

## Οι λήψεις μπαίνουν σε ουρά

Μετά το κλικ στο «Λήψη» η εργασία μπαίνει σε ουρά και δεν κολλάει όλη τη διεπαφή: οι εργασίες σε αναμονή αφαιρούνται με ×, η τρέχουσα λήψη ακυρώνεται και μετά η ουρά συνεχίζει.

Η σελίδα λήψης δείχνει την κατάσταση κάθε εργασίας: σε αναμονή, σε λήψη, ολοκληρώθηκε, απέτυχε.

## Πηγή λήψης αρχείων vs πηγή λίστας εκδόσεων

Στις **Ρυθμίσεις → Λήψη → Πηγές λήψης** υπάρχουν δύο ανεξάρτητες αναπτυσσόμενες λίστες:

- **Πηγή λήψης αρχείων**: jar πελάτη, αρχεία πόρων, βιβλιοθήκες εξαρτήσεων.
- **Πηγή λίστας εκδόσεων**: manifest εκδόσεων, JSON έκδοσης, ευρετήριο πόρων.

Και οι δύο έχουν τις ίδιες τέσσερις επιλογές:

| Επιλογή | Συμπεριφορά |
| --- | --- |
| Επίσημη πρώτα, αλλαγή mirror όταν αργεί | Προεπιλογή. Σύνδεση πρώτα στην επίσημη· αν δεν αποκριθεί σε λίγα δευτερόλεπτα, αλλαγή σε BMCLAPI |
| Χρήση πηγών mirror όσο γίνεται | Τα δίκτυα στην Κίνα χρησιμοποιούν απευθείας mirror |
| Επίσημη πηγή κατά προτεραιότητα | Επίσημη πρώτα· αν αποτύχει, επιστροφή σε mirror |
| Χρήση επίσημης πηγής όσο γίνεται | Μόνο επίσημη· αν δεν συνδεθεί, αποτυγχάνει |

## Προσαρμοσμένο mirror αρχείων

Στις **Ρυθμίσεις → Λήψη → Προσαρμοσμένο mirror αρχείων** μπορείτε να βάλετε διεύθυνση ρίζας mirror (προεπιλογή BMCLAPI, π.χ. `https://bmclapi2.bangbang93.com`). Όταν συμπληρωθεί, το manifest εκδόσεων, ο πελάτης, οι βιβλιοθήκες και οι πόροι περνούν πρώτα από εκεί· αν δεν κατέβουν, χρησιμοποιείται η αρχική σειρά πηγών ως εφεδρεία.

Κενό σημαίνει προεπιλογή BMCLAPI.

## Φάκελος παιχνιδιού

Στις **Ρυθμίσεις → Λήψη → Φάκελος παιχνιδιού** μπορείτε να βάλετε εκδόσεις, βιβλιοθήκες, πόρους και mod σε οποιονδήποτε φάκελο· κενό επιστρέφει στο `%APPDATA%\gpcl\.minecraft`.

Η αλλαγή φακέλου **δεν μεταφέρει αυτόματα** τα υπάρχοντα αρχεία. Οι εκδόσεις στον παλιό φάκελο δεν ακολουθούν· αν τις χρειάζεστε, αντιγράψτε τις. Οι ρυθμίσεις και τα αρχεία καταγραφής παραμένουν στο `%APPDATA%\gpcl`.

## Μέγιστος αριθμός νημάτων

Προεπιλογή 64, εύρος 1–128. Με πολλά μικρά αρχεία η αύξηση του παραλληλισμού βοηθά, αλλά πολύ υψηλή τιμή μπορεί να περιοριστεί από δικτυακές συσκευές ή mirror. Αν το δίκτυο δεν είναι σταθερό, μειώστε το.

## Όριο ταχύτητας

Το 0 σημαίνει χωρίς όριο· με τιμή, **όλες οι λήψεις μοιράζονται αυτό το συνολικό όριο**, σε MB/s, και ισχύει από την επόμενη λήψη. Αν πολλοί μοιράζονται το δίκτυο, μπορείτε να το μειώσετε.

Το όριο ισχύει μόνο για λήψεις πόρων παιχνιδιού. Το Java runtime χρησιμοποιεί ξεχωριστό mirror λήψης και δεν επηρεάζεται.

## Πηγή mirror Java

Στις **Ρυθμίσεις → Λήψη → Λήψη Java** μπορείτε να επιλέξετε Πανεπιστήμιο Tsinghua, Πανεπιστήμιο Nanjing, Huawei Cloud ή προσαρμοσμένη. Αν η επιλεγμένη αποτύχει, περνά αυτόματα στην επόμενη και στο τέλος υπάρχει η επίσημη εφεδρεία Adoptium.

Η προσαρμοσμένη διεύθυνση υποστηρίζει δύο μεταβλητές:

- `{v}`: κύρια έκδοση Java, π.χ. `8`, `17`, `21`.
- `{version}`: πλήρης αριθμός έκδοσης ανάντη, π.χ. `17.0.20.1_1`, αλλάζει με τις εκδόσεις ανάντη.

Παράδειγμα:

```text
https://cdn.example.com/java/{v}/OpenJDK{v}U-jre_x64_windows_hotspot_{v}.zip
```

## Τι να κάνετε πρώτα όταν αποτύχει η λήψη

1. Αλλάξτε πηγή λήψης.
2. Μειώστε τα νήματα σε 32 ή 16 και δοκιμάστε ξανά.
3. Βεβαιωθείτε ότι η ώρα του συστήματος είναι σωστή — μεγάλη απόκλιση προκαλεί αποτυχία επαλήθευσης πιστοποιητικού HTTPS.
4. Αν συνεχίζει, στείλτε email με το πιο πρόσφατο αρχείο καταγραφής από `%APPDATA%\gpcl\gpcl\log`.
