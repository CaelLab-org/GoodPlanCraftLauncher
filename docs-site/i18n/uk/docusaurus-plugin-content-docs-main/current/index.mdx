GoodPlanCraftLauncher (далі GPCL) — це лаунчер Minecraft для Windows. Ця документація розповідає лише про те, **як користуватися вже встановленим лаунчером і як шукати причину несправності**: тут немає списку змін і історії проєкту.

| --- | --- |
| Встановити, оновити, видалити | [Встановлення та оновлення](./install.mdx) |
| Ліцензійний вхід чи офлайн-ім'я | [Вхід](./login.mdx) |
| Гра гальмує, не вистачає пам'яті, помилки Java | [Java і пам'ять](./java-memory.mdx) |
| Встановити Forge / Fabric / OptiFine | [Завантажувачі модів](./modloader.mdx) |

| Повільне завантаження, вибір дзеркала | [Завантаження та дзеркала](./download.mdx) |
| Гра вилітає | [Збої гри](./mc-game.mdx) |
| Змінити заголовок вікна гри | [Магічні слова в заголовку](./magic-words.mdx) |

:::tip Спершу перевірте версію
Ці сторінки написані для 1.8.0. Поточну версію видно в **Налаштування → Про програму**; якщо версія значно інша, деякі опції можуть розташовуватися інакше.
:::

## Як поставити запитання, якщо щось зламалося

Напишіть на [gamets@caellab.com](mailto:gamets@caellab.com). Достатньо вказати таке, і проблему зазвичай вдається локалізувати:

- версія лаунчера, версія Minecraft, які моди встановлені;
- що робили перед збоєм (щойно поставили мод? змінили Java? змінили пам'ять?);
- **звіт про помилку, експортований з GPCL** («Експортувати звіт про помилку» у вікні збою).

Скріншот вікна збою зазвичай дає замало інформації.
