Повільне завантаження зазвичай не є проблемою лаунчера. Спершу змініть джерело завантаження, а потім думайте про кількість потоків і обмеження швидкості.

## Завдання завантаження стають у чергу

Після натискання «Завантажити» завдання потрапляє в чергу й не блокує інтерфейс: завдання в очікуванні можна прибрати хрестиком, поточне — скасувати, і черга продовжиться.

Сторінка завантажень показує стан кожного завдання: в очікуванні, завантажується, завершено, помилка.

## Джерело файлів і джерело списку версій

У **Налаштування → Завантаження → Джерело завантаження** є два незалежні списки:

- **Джерело файлів**: клієнтський jar, файли ресурсів, бібліотеки залежностей;
- **Джерело списку версій**: маніфест версій, JSON версій, індекси ресурсів.

В обох однакові чотири варіанти:

| Варіант | Поведінка |
| --- | --- |
| Спершу офіційне, за повільної роботи — дзеркало | За замовчуванням. Спершу офіційний сервер, якщо кілька секунд немає відповіді — BMCLAPI |
| Переважно дзеркала | Для мереж у Китаї одразу дзеркало |
| Спершу офіційне джерело | Спершу офіційне, у разі помилки — дзеркало |
| Переважно офіційне джерело | Лише офіційне; якщо не підключається — помилка |

## Власне дзеркало файлів

У **Налаштування → Завантаження → Власне дзеркало файлів** можна вказати кореневу адресу дзеркала (за замовчуванням BMCLAPI, наприклад `https://bmclapi2.bangbang93.com`). Після цього маніфест версій, клієнт, бібліотеки й ресурси спершу йдуть через нього, а якщо не виходить — за звичайним порядком джерел.

Порожнє поле означає типовий BMCLAPI.

## Тека гри

**Налаштування → Завантаження → Тека гри** дозволяє розмістити версії, бібліотеки, ресурси й моди в будь-якій теці; порожнє поле повертає до `%APPDATA%\gpcl\.minecraft`.

Зміна теки **не переносить** наявні файли автоматично. Версії зі старої теки не переїдуть — за потреби скопіюйте їх вручну; конфігурація й журнали залишаться в `%APPDATA%\gpcl`.

## Максимальна кількість потоків

За замовчуванням 64, діапазон 1–128. Коли багато дрібних файлів, вища паралельність трохи прискорює роботу, але завелике значення може впертися в обмеження мережевого обладнання чи дзеркала. За нестабільної мережі зменшуйте.

## Обмеження швидкості

0 означає без обмеження; після введення числа **всі завдання завантаження ділять цю загальну межу**, одиниця — MB/s, діє з наступного завантаження.

Обмеження стосується лише завантаження ресурсів гри. Java завантажується з окремого дзеркала й на нього це не впливає.

## Дзеркала Java

У **Налаштування → Завантаження → Завантаження Java** можна вибрати Університет Цінхуа, Нанкінський університет, Huawei Cloud або власне дзеркало. Якщо вибране джерело не працює, лаунчер автоматично переходить до наступного, а в кінці є офіційний Adoptium.

Власна адреса підтримує дві змінні:

- `{v}`: мажорна версія Java, наприклад `8`, `17`, `21`;
- `{version}`: повний номер версії з upstream, наприклад `17.0.20.1_1`; він змінюється разом із релізами upstream.

Приклад:

```text
https://cdn.example.com/java/{v}/OpenJDK{v}U-jre_x64_windows_hotspot_{v}.zip
```

## Що робити, якщо завантаження не вдалося

1. Змініть джерело завантаження.
2. Зменште кількість потоків до 32 або 16 і спробуйте знову.
3. Перевірте, чи правильний системний час — велике відхилення ламає перевірку сертифікатів HTTPS.
4. Якщо не допомогло, напишіть лист і додайте найсвіжіший журнал із `%APPDATA%\gpcl\gpcl\log`.
