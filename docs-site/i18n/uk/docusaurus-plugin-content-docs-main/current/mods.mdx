---
title: Завантаження модів
description: Пошук і встановлення модів із Modrinth і CurseForge у GPCL, залежності та пошук китайською.
---

Розділ «Моди» на сторінці завантажень дозволяє шукати моди, вибирати файл і ставити його в потрібну версію — не потрібно качати з сайту й тягнути в теку вручну.

## Пошук

Джерел два: **Modrinth** і **CurseForge**. За замовчуванням пошук іде в обох, джерело позначене в списку результатів.

Пошук можна вести китайською. Якщо в запиті є китайські символи, GPCL спершу переглядає публічні результати пошуку MCMOD і витягує англійську назву з дужок у заголовку (наприклад, з «雾中人 (The Man From The Fog)» виходить `The Man From The Fog`), а далі шукає за цією назвою в Modrinth. Якщо англійської назви немає, пошук іде за початковим запитом.

## Фільтри

За замовчуванням фільтрів за версією та завантажувачем **немає** — як і в PCL, спершу шукаються всі результати, щоб нові моди не ховалися через умови фільтра. Звузьте вибір вручну, коли потрібно:

- версія Minecraft;
- завантажувач (Forge / Fabric / NeoForge / Quilt);
- порядок сортування.

У списку файлів першими йдуть файли для версії MC поточного запуску — менше шансів поставити не ту версію.

## Встановлення

Ціль вибирається після натискання «Встановити» в рядку файлу:

- список встановлених версій Mod — виберіть одну й ставте;
- «Вибрати теку» — встановлення в `mods` будь-якої теки.

Файл потрапляє в `mods`, яку фактично використовує цільова версія: для ізольованих це `versions/<version-name>/mods`, інакше — `mods` у корені теки гри.

Для неізольованої версії перше встановлення мода вмикає ізоляцію версій; у вікні вибору цілі це написано, окремого підтвердження не буде.

### Залежності

У рядку файлу Modrinth показується «N залежностей». Під час встановлення потрібні для завантаження залежності ставляться рекурсивно, і повідомлення про успіх теж згадує, скільки залежностей додано.

Режим посилань CurseForge встановлює лише вибраний файл і **не ставить залежності автоматично**; в інтерфейсі це теж написано.

## CurseForge без API Key

Для звичайного пошуку в CurseForge потрібен API Key (**Налаштування → Завантаження → CurseForge API Key**, необов'язково) або робоче публічне дзеркало. Якщо ключа немає, а дзеркало недоступне, є ще один варіант:

Вставте в поле пошуку адресу проєкту або `cf:<short-name>`:

```text
https://www.curseforge.com/minecraft/mc-mods/sodium
cf:sodium
```

GPCL запитає проєкт і файли через `api.cfwidget.com`, а потім завантажить за прямим посиланням ForgeCDN. Цей шлях **ставить лише вибраний файл і не розв'язує залежності**.

## Встановили, а не працює

- переконайтеся, що підтримувані модом версії MC і завантажувач збігаються з поточною версією;
- перевірте, що мод потрапив у правильну `mods` (після ізоляції це не тека в корені);
- якщо бракує залежностей, спершу встановіть їх;
- якщо не допомогло, дивіться порядок діагностики за журналами в [Збоях гри](./mc-game.mdx).
