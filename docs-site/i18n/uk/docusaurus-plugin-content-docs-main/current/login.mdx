GPCL підтримує два способи входу, перемикатися можна будь-коли. Офлайн-вхід не потребує інтернету, але з ним не можна зайти на сервери з перевіркою ліцензії.

## Офлайн-вхід

На сторінці запуску достатньо ввести ім'я гравця — пароль не потрібен. Останні 5 імен залишаються у випадаючому списку, кожне можна видалити окремо.

- Підходить для одиночної гри, LAN-ігор і серверів без перевірки ліцензії.
- Не потребує перевірки через інтернет, запуск працює навіть без мережі.
- Не пускає на сервери з перевіркою ліцензії — вас викине.
- Не використовуйте чужі ліцензійні ніки: і сервер, і гравці можуть помилитися щодо того, хто ви.

## Вхід через Microsoft

1. На сторінці запуску натисніть «Ліцензійний вхід».
2. GPCL відкриє типовий браузер і перейде на сторінку входу Microsoft.
3. Увійдіть і дозвольте доступ; браузер повідомить, що можна повернутися в лаунчер.
4. GPCL автоматично отримає результат, а ім'я гравця визначить акаунт.

Вхід очікується щонайбільше 2 хвилини. Якщо нічого не відбувається, спершу переконайтеся, що в браузері ви завершили вхід і надали дозвіл, а потім перевірте мережу.

Лаунчер зберігає стан входу, тому наступного разу входити не потрібно. Опція «Оптимізувати пам'ять перед запуском гри» не скидає стан входу.

## Який режим вибрати

| Ситуація | Що використовувати |
| --- | --- |
| Одиночна гра, граєте самі | Офлайн або ліцензійний — будь-що |
| Сервер із перевіркою ліцензії | Тільки ліцензійний |
| Сервер без перевірки ліцензії | Офлайн або ліцензійний — будь-що |
| Немає мережі | Офлайн |

## Перемикання акаунтів

У стані ліцензійного входу повторне натискання кнопки виконує вихід, після чого можна перейти на офлайн-ім'я. В офлайн-стані натискання «Ліцензійний вхід» одразу відкриває процес входу Microsoft.

## Сервер пише Invalid session

Найчастіше це прострочений стан входу або в акаунта немає прав на цю версію:

1. Вийдіть з акаунта й повторіть ліцензійний вхід;
2. Переконайтеся, що акаунт справді володіє цією версією Minecraft;
3. Спробуйте інший ліцензійний сервер, щоб виключити проблему конкретного сервера.
