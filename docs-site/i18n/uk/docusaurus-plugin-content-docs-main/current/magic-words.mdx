У заголовку вікна гри можна писати плейсхолдери — під час запуску GPCL замінить їх реальними значеннями.

Налаштування в **Налаштування → Гра → Заголовок вікна гри**. Порожній заголовок означає, що заголовок вікна гри не змінюється.

## Приклад

Заголовок:

```text
{time} · {mc_version} · {gpcl_version}
```

Після запуску може виглядати так:

```text
20:09:58 · Minecraft 1.21.3 · 1.6.0
```

## Доступні плейсхолдери

| Плейсхолдер | На що замінюється |
| --- | --- |
| `{mc_version}` | Відображувана назва версії, наприклад Minecraft 1.21.3 або назва із завантажувачем |
| `{mc_id}` | Назва теки версії, наприклад 1.21.3-Fabric |
| `{username}` | Ім'я гравця, використане цього запуску |
| `{gpcl_version}` | Номер версії GPCL, наприклад 1.6.0 |
| `{date}` | Дата запуску у форматі 2026/10/20 |
| `{time}` | Поточний час у форматі 20:09:58 |
| `{datetime}` | Дата й час, розділені пробілом |
| `{java}` | Назва теки поточного середовища виконання Java |
| `{memory}` | Максимальна пам'ять цього запуску, наприклад 4096MB |

Регістр має значення. Неправильний плейсхолдер показується як є — так видно, який саме написано з помилкою.

## Чи заголовок зберігається весь час

Нижче є перемикач «Намагатися зберегти назву», за замовчуванням вимкнений.

- **Вимкнено**: після появи вікна гри GPCL коригує заголовок протягом 20 секунд. Далі, якщо гра чи мод змінять заголовок, лаунчер уже не втручається. Заголовок із `{time}` теж застигне на тому моменті.
- **Увімкнено**: заголовок, який ви задали, тримається всю гру, і вхід у світ не перекриває його на « - Singleplayer».

Деякі модпаки чи моди теж змінюють заголовок вікна — взаємне перезаписування є нормальним.

:::note
Наразі магічні слова підтримує лише заголовок вікна гри; в інших налаштуваннях вони не працюють.
:::
