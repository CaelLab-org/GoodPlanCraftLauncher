---
title: Java і пам'ять
description: Як версії Java відповідають версіям гри, як GPCL розподіляє пам'ять і що робити, коли її не вистачає.
---

GPCL сам вибирає Java відповідно до версії гри й автоматично розподіляє пам'ять залежно від обсягу пам'яті комп'ютера. У більшості випадків нічого змінювати вручну не потрібно.

## Відповідність версій Java

| Версія Minecraft | Потрібна Java |
| --- | --- |
| 1.16.5 і старіші | Java 8 |
| 1.17 – 1.20.4 | Java 17 |
| 1.20.5 і новіші | Java 21 |

Якщо під час запуску потрібної Java немає, GPCL завантажить і встановить її сам. Якщо завантаження не вдалося, перейдіть у **Налаштування → Завантаження → Завантаження Java** і спробуйте інше дзеркало.

Java встановлюється у власну теку GPCL, не впливає на інші версії Java в системі й не змінює системну змінну `JAVA_HOME`.

## Пам'ять: автоматично

За замовчуванням — «Автоматично». Логіка розподілу має два кроки:

1. Спершу береться **30%** фізичної пам'яті, округлення вниз до цілих GB, обмеження **2–8 GB**;
2. Потім враховується поточна вільна пам'ять: системі залишається щонайменше 1 GB, мінімум — 2 GB, результат округлюється вниз до 512 MB, і береться менше з двох значень.

Кілька реальних результатів:

| Фізична пам'ять | Поточна вільна | Автоматично |
| --- | --- | --- |
| 16 GB | 8 GB | 4 GB |
| 16 GB | 3.9 GB | 2.5 GB |
| 8 GB | 4 GB | 2 GB |

Сторінка налаштувань показує використану / загальну пам'ять системи й поточний обсяг вільної. Коли вільної пам'яті мало, автоматичний розподіл зменшується й лаунчер радить спершу закрити кілька програм.

`-Xmx` — це верхня межа, а не резервування з моменту запуску. Тому розподіл за поточною вільною пам'яттю стабільніший, ніж жорстко задане велике значення.

## Пам'ять: вручну

Якщо модпаку чи великому набору модів не вистачає пам'яті, перемкніться на «Вручну» й посуньте повзунок. Залиште місце системі та іншим програмам — не віддавайте грі всю фізичну пам'ять.

Поява `OutOfMemoryError` означає, що пам'яті не вистачає:

1. Збільште виділений обсяг на один крок і спробуйте знову;
2. Якщо не допомогло — зменште кількість модів;
3. Одночасно закрийте браузер та інші програми, що споживають пам'ять.

## Налаштування G1GC

У **Налаштування → Додатково → Керування пам'яттю** є налаштування G1GC, за замовчуванням вимкнене. Вмикати його варто лише тоді, коли помітні коливання FPS і паузи GC; після ввімкнення додається набір типових параметрів G1GC.

Власні параметри JVM також у цьому блоці. Помилка в параметрах не дасть грі запуститися — якщо не впевнені, не змінюйте.

## Оптимізація пам'яті перед запуском

Коли опцію ввімкнено, GPCL перед запуском гри звільняє частину власної пам'яті. Він прибирає лише процес лаунчера, не торкається запущеного Minecraft і не скидає стан входу.

На механічних дисках цей крок може дати коротке підгальмовування — це нормально.
