На сторінці завантажень завантажувач вибирається разом із версією. GPCL спершу встановлює оригінальну версію, а потім ставить завантажувач в окрему теку версії, не перезаписуючи оригінал.

## Як встановити

1. Відкрийте сторінку завантажень і виберіть версію Minecraft.
2. У параметрах завантажувача виберіть Forge, Fabric або OptiFine, потім відповідну версію завантажувача.
3. Натисніть «Завантажити» й дочекайтеся, поки встановляться і оригінал, і завантажувач.
4. Поверніться на сторінку запуску й запустіть версію, у назві якої є завантажувач.

Завдання завантаження потрапляють у чергу, тож можна поставити в чергу кілька версій підряд; поточне завдання можна скасувати — після скасування черга продовжиться.

## Який завантажувач вибрати

| Завантажувач | Для чого | Зауваження |
| --- | --- | --- |
| Forge | Великі модпаки, старі моди | Запускається повільніше за Fabric, більше варіантів версій |
| Fabric | Легкі моди, нові версії | Треба правильно підібрати Fabric Loader під версію гри |
| OptiFine | Шейдери, оптимізація | У поєднанні з іншими завантажувачами можуть знадобитися моди сумісності |

### Forge

Під час встановлення GPCL запускає лише `--installClient` і не пробує GUI чи серверні параметри. Вивід інсталятора перетворюється на прогрес, наприклад «Встановлення Forge: Downloading library…».

Перед встановленням перевіряється мажорна версія Java; якщо вона нижча за вимоги Forge, лаунчер одразу видасть помилку й не запускатиме інсталятор на слабшій Java. Увесь процес очікується щонайбільше 15 хвилин; скасування завантаження завершує процес інсталятора.

### Fabric

GPCL бере профіль версії Fabric і файли бібліотек напряму, без інсталятора.

«Також встановити Fabric API» позначено за замовчуванням: після встановлення Fabric відповідна версія Fabric API потрапить у `mods` цієї версії. Якщо зняти позначку, Fabric API не встановлюватиметься; невдача з Fabric API лише покаже повідомлення й не вплине на сам Fabric.

### OptiFine

OptiFine встановлюється тихо, його власний графічний інсталятор не відкривається. Результат встановлення потрапляє в поточну теку гри; нестандартна тека гри також обробляється правильно.

## Куди класти моди

Для щойно завантажених версій за замовчуванням увімкнено **ізоляцію версій**: тека гри вказує на `versions/<version-name>`, і моди, збереження та налаштування гри живуть разом із цією версією.

| Стан версії | Тека модів |
| --- | --- |
| Щойно завантажена, ізольована | `versions/<version-name>/mods` |
| Уже існувала, і в теці версії немає `mods` / `saves` | `mods` у корені теки гри |

На сторінці запуску відкрийте «Налаштування версії» — ярлики тек рахуються за фактичним результатом ізоляції:

- «Тека версії» є завжди;
- «Тека модів» з'являється, якщо виявлено Forge / Fabric / NeoForge / Quilt;
- «Тека шейдерів» з'являється, якщо виявлено OptiFine.

Якщо хочете ставити моди в довільну теку, у виборі цілі встановлення модів натисніть «Вибрати теку» — лаунчер знайде `mods` усередині неї.

## Після встановлення гра падає

1. Приберіть усі моди з `mods` і запустіть гру начисто.
2. Якщо запускається — повертайте моди половинами, доки не знайдете проблемний.
3. Переконайтеся, що мод підходить і до версії Minecraft, і до версії завантажувача — мод для Forge не можна кинути у Fabric, і навпаки.
4. Відсутність залежностей теж валить запуск — спершу подивіться, які залежності перелічені в [Завантаженні модів](./mods.mdx).

Поєднання OptiFine з Forge / Fabric зазвичай потребує додаткових модів сумісності. Якщо такого мода немає, не ставте їх силою.

Більше кроків діагностики — у [Збоях гри](./mc-game.mdx).
