গেম উইন্ডোর টাইটেলে প্লেসহোল্ডার লেখা যায়, চালুর সময় GPCL সেগুলো আসল মানে বদলে দেয়।

জায়গা: **সেটিংস → গেম → গেম উইন্ডো টাইটেল**। টাইটেল খালি রাখলে গেম উইন্ডোর টাইটেল বদলানো হয় না।

## একটি উদাহরণ

টাইটেল এভাবে লিখুন:

```text
{time} · {mc_version} · {gpcl_version}
```

চালুর পরে দেখাতে পারে:

```text
20:09:58 · Minecraft 1.21.3 · 1.6.0
```

## কোন প্লেসহোল্ডার চলে

| প্লেসহোল্ডার | কী হবে |
| --- | --- |
| `{mc_version}` | ভার্সনের প্রদর্শন নাম, যেমন Minecraft 1.21.3, বা লোডারসহ নাম |
| `{mc_id}` | ভার্সন ফোল্ডারের নাম, যেমন 1.21.3-Fabric |
| `{username}` | এই চালুতে ব্যবহৃত প্লেয়ার নাম |
| `{gpcl_version}` | GPCL-এর ভার্সন নম্বর, যেমন 1.6.0 |
| `{date}` | চালুর তারিখ, ফরম্যাট 2026/10/20 |
| `{time}` | চলমান সময়, ফরম্যাট 20:09:58 |
| `{datetime}` | তারিখ ও সময়, মাঝে স্পেস |
| `{java}` | চলমান Java রানটাইম ফোল্ডারের নাম |
| `{memory}` | এবার বরাদ্দ করা সর্বোচ্চ মেমরি, যেমন 4096MB |

বড়-ছোট হাতের অক্ষর একই রাখুন। ভুল প্লেসহোল্ডার যেমন লেখা তেমনই দেখায়, যাতে বোঝা যায় কোনটি ভুল।

## টাইটেল কি থাকবে

নিচে "নামটি যতটা সম্ভব ধরে রাখুন" টগল আছে, ডিফল্টে বন্ধ।

- **বন্ধ**: গেম উইন্ডো আসার পরে GPCL 20 সেকেন্ড টাইটেল ঠিক করতে থাকে। এরপর গেম বা মড টাইটেল বদলালে আর হাত দেয় না। `{time}` থাকা টাইটেলও সেই সময়েই থেমে যায়।
- **চালু**: পুরো গেম চলাকালীন আপনার দেওয়া টাইটেল থাকে, দুনিয়ায় ঢুকলেও " - Singleplayer" তা ঢেকে দেয় না।

কিছু মডপ্যাক ও মডও উইন্ডো টাইটেল বদলায়; দুটোর একে অন্যকে ঢেকে দেওয়া স্বাভাবিক।

:::note
এখন শুধু গেম উইন্ডো টাইটেলে ম্যাজিক ওয়ার্ড চলে, অন্য সেটিংসে কাজ করে না।
:::
