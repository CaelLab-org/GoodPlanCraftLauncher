ক্র্যাশ উইন্ডো থেকে সাধারণত কারণ বোঝা যায় না। GPCL আগে লগ পড়ে সূত্র দেয়, তারপর নিচের ক্রমে দেখুন।

:::tip আগে একটি কাজ
ক্র্যাশ ডায়ালগের "এরর রিপোর্ট এক্সপোর্ট করুন"-এ ক্লিক করে তৈরি zip সংরক্ষণ করুন। রিপোর্টের শুরুতে GPCL-এর বিশ্লেষণ থাকে, পরে Mod তালিকা, Java, চালুর প্যারামিটার আর সব লগ — যাচাই মূলত এটির উপরই নির্ভর করে।
:::

## 1. আগে GPCL-এর বিশ্লেষণ দেখুন

ডায়ালগ GPCL লগে পাওয়া 1–2টি সূত্র দেখায়, যেমন "মেমরি কম" বা "Mod-এর ডিপেন্ডেন্সি বা কম্প্যাটিবিলিটি যাচাই পাস হয়নি"। "বিস্তারিত দেখুন"-এ ক্লিক করলে সব সূত্র, সংশ্লিষ্ট লগের লাইন আর ক্র্যাশের তথ্য দেখা যায়।

এই সিদ্ধান্তগুলো কীওয়ার্ড মিলিয়ে বের করা, তাই শুধু যাচাইয়ের দিক হিসেবে ধরুন। লগে আরও নির্দিষ্ট তথ্য থাকলে (যেমন কোন ডিপেন্ডেন্সি নেই) তা প্রমাণের সঙ্গে দেখানো হয়।

## 2. এরর রিপোর্ট এক্সপোর্ট

বোতামটি ক্র্যাশ ডায়ালগেই আছে। জায়গা বেছে সংরক্ষণ করুন, GPCL প্যাক করে:

- `error-report.txt`: বিশ্লেষণের ফল, এরর সারসংক্ষেপ, সিস্টেম / GPU / Java, Mod তালিকা, রিসোর্স প্যাক ও শেডার, চালুর প্যারামিটার, গেমের আউটপুট, লগের এরর লাইন;
- `crash-reports/`: এই ক্র্যাশে তৈরি ক্র্যাশ রিপোর্ট;
- `logs/`: `latest.log` ও `debug.log` (খুব বড় হলে শুধু শেষ অংশ);
- `jvm-crash/`: JVM-এর নিজে লেখা `hs_err_pid*.log` (GPU ড্রাইভার জাতীয় সমস্যায় JVM ক্র্যাশ হলে);
- `launcher-log.txt`: লঞ্চারের লগ;
- `game-output.txt`: এই রানে গেম প্রসেসের স্ট্যান্ডার্ড আউটপুট ও এরর আউটপুট।

রিপোর্টে `--accessToken` ও সিস্টেম ইউজারনেম আগেই মাস্ক করা, সরাসরি পাঠানো যায়। শুধু ক্র্যাশ উইন্ডোর স্ক্রিনশট পাঠাবেন না।

## 3. নিজে লগ দেখুন

ডায়ালগের "লগ দেখুন" গেম প্রসেসের আউটপুট খোলে। একেবারে নিচে আর এই শব্দগুলোতে নজর দিন:

| কীওয়ার্ড | সাধারণত মানে |
| --- | --- |
| `Exception`, `Caused by` | আসল এক্সসেপশন সাধারণত প্রথম `Caused by`-এর পরে থাকে |
| `OutOfMemoryError` | বরাদ্দ করা মেমরি যথেষ্ট নয় |
| `UnsupportedClassVersionError` | Java ভার্সন ও গেম ভার্সন মেলে না |
| `NoSuchMethodError`, `ClassNotFoundException` | মড গেম ভার্সন বা লোডার ভার্সনের সঙ্গে মেলে না, বা ডিপেন্ডেন্সি নেই |
| `GLFW error` | GPU ড্রাইভার বা OpenGL সমর্থনে সমস্যা |

## 4. সাধারণ কারণ

| লক্ষণ | সাধারণ কারণ | কী করবেন |
| --- | --- | --- |
| চালু হওয়ামাত্র বন্ধ, লগে `UnsupportedClassVersionError` | Java ভার্সন ভুল | GPCL-কে Java নিজে ইনস্টল করতে দিন; বা সেটিংসে মিরর বদলে আবার ইনস্টল করুন |
| লোড হওয়ার মাঝে আটকে যায় বা বন্ধ হয়ে যায়, লগে `OutOfMemoryError` | মেমরি কম, বা মড বেশি | সেটিংস → গেম → মেমরি বরাদ্দে বাড়ান; ফিজিক্যাল মেমরির বেশি দেবেন না |
| মড লোড করার সময় ক্র্যাশ, লগে মডের নাম | মড ভার্সন ভুল, ডিপেন্ডেন্সি নেই, দুই মডের সংঘর্ষ | আগে শুধু এই মডটি ইনস্টল করে দেখুন; এটি কোন MC ও লোডার ভার্সন সমর্থন করে দেখে নিন |
| উইন্ডো আসার আগেই বন্ধ, `GLFW error` | GPU ড্রাইভার পুরোনো, বা OpenGL সমর্থন নেই | GPU ড্রাইভার আপডেট করুন; ল্যাপটপে নিশ্চিত করুন গেম ডেডিকেটেড GPU-তে চলছে |
| সার্ভার থেকে কিক, `Invalid session` | প্রিমিয়াম লগইনের মেয়াদ শেষ, বা অ্যাকাউন্টে এই ভার্সনের লাইসেন্স নেই | আবার প্রিমিয়াম লগইন করুন; অ্যাকাউন্টে সত্যিই এই ভার্সন আছে দেখে নিন |
| দুনিয়ায় ঢোকার সময় বা রিসোর্স প্যাক লোডে ক্র্যাশ | সেভ, রিসোর্স প্যাক বা শেডার প্যাক নষ্ট | আগে নতুন দুনিয়া বানিয়ে দেখুন; সেভের ব্যাকআপ নিয়ে তারপর সামলান |
| Fabric দিয়ে চালু করলেই ক্র্যাশ, `fabric-api` নেই বলে বার্তা | Fabric API ইনস্টল নেই | Fabric আবার ইনস্টল করার সময় "সঙ্গে Fabric API ইনস্টল করুন" টিক দিন, বা হাতে ইনস্টল করুন |

## 5. আগে এই তিনটি জিনিস আলাদা করুন

1. **সব মড, রিসোর্স প্যাক ও শেডার বন্ধ করুন** এবং একবার কিছু ছাড়া চালান। চললে সমস্যা মডের দিকে।
2. **অন্য একটি ভ্যানিলা ভার্সন চালান**। চললে চলমান ভার্সন বা তার মড-সমাহারে সমস্যা।
3. **নতুন একটি দুনিয়া বানান**। চললে পুরোনো সেভ নষ্ট।
