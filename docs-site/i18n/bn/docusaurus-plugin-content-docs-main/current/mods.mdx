ডাউনলোড পেজের "মড" অংশে সরাসরি মড খোঁজা, ফাইল বাছাই এবং নির্দিষ্ট ভার্সনে ইনস্টল করা যায় — সাইট থেকে ডাউনলোড করে ফোল্ডারে টেনে আনার দরকার নেই।

## খোঁজা

সোর্স দুটি: **Modrinth** ও **CurseForge**। ডিফল্টে দুটোতেই একসঙ্গে খোঁজা হয়, আর ফলাফল তালিকায় সোর্স লেখা থাকে।

সার্চ বক্সে আগে চীনা ভাষায়ও লেখা যায়। কোয়েরিতে চীনা থাকলে GPCL আগে MCMOD-এর প্রকাশ্য সার্চ ফলাফল দেখে, টাইটেলের বন্ধনী থেকে ইংরেজি নাম বের করে (যেমন "雾中人 (The Man From The Fog)" থেকে `The Man From The Fog`), তারপর সেই ইংরেজি নাম দিয়ে Modrinth-এ খোঁজে। ইংরেজি নাম না পেলে মূল কোয়েরি দিয়েই খোঁজে।

## ফিল্টার

ডিফল্টে ভার্সন ও লোডারের ফিল্টার **লাগে না** — PCL-এর মতো আগে সব খোঁজা হয়, যাতে নতুন মড ফিল্টারের কারণে লুকিয়ে না যায়। দরকার হলে হাতে বাছুন:

- Minecraft ভার্সন;
- লোডার (Forge / Fabric / NeoForge / Quilt);
- সাজানোর ধরন।

ফাইল তালিকায় চলমান চালুর ভার্সনের MC ভার্সন আগে দেখায়, যাতে ভুল ভার্সন ইনস্টলের সম্ভাবনা কমে।

## ইনস্টল

ফাইল সারির "ইনস্টল"-এ ক্লিক করলেই লক্ষ্য বাছাইয়ের ডায়ালগ খোলে:

- ইনস্টল করা Mod ভার্সনের তালিকা — একটি বেছে সরাসরি ইনস্টল;
- "ফোল্ডার বাছুন" — যেকোনো ফোল্ডারের `mods`-এ ইনস্টল।

ফাইল লক্ষ্য ভার্সন যে `mods` আসলে ব্যবহার করে সেখানেই পড়ে: আইসোলেটেড ভার্সনে `versions/<version-name>/mods`, নাহলে গেম রুটের `mods`।

আইসোলেটেড না হওয়া ভার্সনে প্রথম মড ইনস্টল করলে ভার্সন আইসোলেশন চালু হয়; লক্ষ্য ডায়ালগে এটি লেখা থাকে, আলাদা করে অনুমতি চাওয়া হয় না।

### প্রয়োজনীয় ডিপেন্ডেন্সি

Modrinth-এর ফাইল সারিতে "N ডিপেন্ডেন্সি" দেখায়। ইনস্টলের সময় ডাউনলোডের জন্য প্রয়োজনীয় ডিপেন্ডেন্সিও রিকার্সিভভাবে ইনস্টল হয়, আর সফলতার বার্তায় কয়টি ডিপেন্ডেন্সি এসেছে তা বলে দেয়।

CurseForge-এর লিংক মোড শুধু নির্বাচিত এক ফাইল ইনস্টল করে, **ডিপেন্ডেন্সি নিজে থেকে ইনস্টল করে না**, ইন্টারফেসেও তা লেখা থাকে।

## CurseForge-এ API Key নেই

CurseForge-এ সাধারণ সার্চের জন্য API Key দরকার (**সেটিংস → ডাউনলোড → CurseForge API Key**, ঐচ্ছিক), অথবা প্রকাশ্য মিরর ফিরে আসার অপেক্ষা। Key না থাকলে আর মিররও না চললে একটা শেষ উপায় আছে:

সার্চ বক্সে প্রজেক্টের ঠিকানা পেস্ট করুন, বা `cf:<short-name>` লিখুন:

```text
https://www.curseforge.com/minecraft/mc-mods/sodium
cf:sodium
```

GPCL `api.cfwidget.com` দিয়ে প্রজেক্ট ও ফাইল দেখে, তারপর ForgeCDN-এর সরাসরি লিংক দিয়ে ডাউনলোড করে। এই পথে **শুধু নির্বাচিত এক ফাইল ইনস্টল হয়, ডিপেন্ডেন্সি মেটানো হয় না**।

## ইনস্টল হয়েছে কিন্তু কাজ করছে না

- নিশ্চিত করুন মড যে MC ভার্সন ও লোডার সমর্থন করে তা চলমান ভার্সনের সঙ্গে মেলে;
- নিশ্চিত করুন সঠিক `mods`-এ ইনস্টল হয়েছে (ভার্সন আইসোলেশনের পরে রুটেরটা নয়);
- প্রয়োজনীয় ডিপেন্ডেন্সি না থাকলে আগে সেটি ইনস্টল করুন;
- তাতেও না হলে [গেম ক্র্যাশ](./mc-game.mdx)-এ লগ যাচাইয়ের ক্রম দেখুন।
