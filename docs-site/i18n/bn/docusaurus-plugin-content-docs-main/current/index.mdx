GoodPlanCraftLauncher (এরপর GPCL) Windows-এর জন্য Minecraft লঞ্চার। এই ডকুমেন্টগুলো শুধু বলে **ইনস্টল করার পরে কীভাবে ব্যবহার করবেন আর কিছু নষ্ট হলে কীভাবে খুঁজবেন**: এখানে চেঞ্জলগ নেই, প্রজেক্টের ইতিহাসও নেই।

| যা করতে চান | কোথায় দেখবেন |
| --- | --- |
| ইনস্টল, আপগ্রেড, আনইনস্টল | [ইনস্টল ও আপডেট](./install.mdx) |
| প্রিমিয়াম লগইন নাকি অফলাইন নাম | [লগইন](./login.mdx) |
| গেম ল্যাগ করছে, মেমরি কম, Java-তে এরর | [Java ও মেমরি](./java-memory.mdx) |
| Forge / Fabric / OptiFine ইনস্টল | [মড লোডার](./modloader.mdx) |
| লঞ্চার থেকে মড খোঁজা ও ইনস্টল করা | [মড ডাউনলোড](./mods.mdx) |
| ডাউনলোড ধীর, কোন মিরর বেছে নেবেন | [ডাউনলোড ও মিরর](./download.mdx) |
| গেম ক্র্যাশ করেছে | [গেম ক্র্যাশ](./mc-game.mdx) |
| গেম উইন্ডোর টাইটেল বদলানো | [উইন্ডো টাইটেলের ম্যাজিক ওয়ার্ড](./magic-words.mdx) |

:::tip আগে ভার্সন দেখে নিন
এই পেজগুলো 1.9.2 ধরে লেখা। চলমান ভার্সন **সেটিংস → সম্পর্কে**-তে দেখা যায়; ভার্সনের ফারাক বেশি হলে কিছু অপশনের জায়গা আলাদা হতে পারে।
:::

## কিছু সমস্যা হলে কীভাবে জিজ্ঞাসা করবেন

[gamets@caellab.com](mailto:gamets@caellab.com)-এ মেইল করুন। এই তথ্যগুলো পরিষ্কারভাবে লিখলে সাধারণত সমস্যা ধরা পড়ে:

- লঞ্চারের ভার্সন, Minecraft-এর ভার্সন, কোন কোন মড ইনস্টল আছে;
- ক্র্যাশের আগে কী করেছেন (এখনই মড ইনস্টল করেছেন? Java বদলেছেন? মেমরি বদলেছেন?);
- **GPCL থেকে এক্সপোর্ট করা এরর রিপোর্ট** (ক্র্যাশ ডায়ালগের "এরর রিপোর্ট এক্সপোর্ট করুন")।

শুধু ক্র্যাশ উইন্ডোর স্ক্রিনশট পাঠালে সাধারণত যথেষ্ট তথ্য পাওয়া যায় না।
