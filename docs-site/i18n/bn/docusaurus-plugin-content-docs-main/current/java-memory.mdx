GPCL গেম ভার্সন অনুযায়ী Java বেছে নেয়, আর কম্পিউটারের মেমরি অনুযায়ী মেমরি বাঁটে। বেশিরভাগ ক্ষেত্রে হাতে বদলানোর দরকার নেই।

## Java ভার্সনের মিল

| Minecraft ভার্সন | প্রয়োজনীয় Java |
| --- | --- |
| 1.16.5 ও তার আগে | Java 8 |
| 1.17 – 1.20.4 | Java 17 |
| 1.20.5 ও তার পরে | Java 21 |

চালু করার সময় সঠিক Java না থাকলে GPCL নিজেই ডাউনলোড করে ইনস্টল করে। ডাউনলোড ব্যর্থ হলে **সেটিংস → ডাউনলোড → Java ডাউনলোড**-এ গিয়ে অন্য মিরর সোর্স বেছে আবার চেষ্টা করুন।

Java GPCL-এর নিজের ফোল্ডারে ইনস্টল হয়, সিস্টেমের অন্য Java-তে প্রভাব ফেলে না এবং সিস্টেমের `JAVA_HOME` বদলায় না।

## মেমরি: স্বয়ংক্রিয়

ডিফল্ট "স্বয়ংক্রিয়"। বণ্টনের নিয়ম দুই ধাপে:

1. আগে ফিজিক্যাল মেমরির **30%** হিসাব, GB-তে নিচের দিকে রাউন্ড, এবং **2 – 8 GB**-এর মধ্যে সীমাবদ্ধ;
2. তারপর চলমান খালি মেমরি দেখে: সিস্টেমের জন্য অন্তত 1 GB রাখুন, কমপক্ষে 2 GB ধরুন, ফলাফল 512 MB-তে নিচের দিকে রাউন্ড করুন, আর দুটোর মধ্যে ছোটটি নিন।

কয়েকটি বাস্তব ফলাফল:

| ফিজিক্যাল মেমরি | চলমান খালি | স্বয়ংক্রিয় বরাদ্দ |
| --- | --- | --- |
| 16 GB | 8 GB | 4 GB |
| 16 GB | 3.9 GB | 2.5 GB |
| 8 GB | 4 GB | 2 GB |

সেটিংস পেজে সিস্টেম মেমরির ব্যবহৃত / মোট এবং চলমান খালি মান দেখায়। খালি মেমরি টান হলে স্বয়ংক্রিয় বরাদ্দও কমে যায়, আর কিছু প্রোগ্রাম বন্ধ করার পরামর্শ দেয়।

`-Xmx` হলো ঊর্ধ্বসীমা, চালু হওয়ামাত্র পুরোটা দখল করে না। তাই ওই মুহূর্তের খালি মেমরি অনুযায়ী বরাদ্দ করা, হাতে খুব বড় মান দেওয়ার চেয়ে বেশি স্থিতিশীল।

## মেমরি: কাস্টম

বড় মডপ্যাক বা ভারী মড সেটে কম পড়লে "কাস্টম"-এ গিয়ে স্লাইডার টানুন। সিস্টেম ও অন্য প্রোগ্রামের জন্য জায়গা রাখুন, পুরো ফিজিক্যাল মেমরি গেমকে দেবেন না।

`OutOfMemoryError` মানে মেমরি কম:

1. বরাদ্দ এক ধাপ বাড়িয়ে আবার চেষ্টা করুন;
2. তাতেও না হলে মড কমান;
3. একইসঙ্গে ব্রাউজারের মতো মেমরি-খেকো প্রোগ্রাম বন্ধ করুন।

## G1GC টিউনিং

**সেটিংস → অ্যাডভান্সড → মেমরি ম্যানেজমেন্ট**-এ G1GC টিউনিং আছে, ডিফল্টে বন্ধ। শুধু FPS ওঠানামা বা GC-তে স্পষ্ট আটকে যাওয়া টের পেলে চালু করার পরামর্শ; চালু করলে G1GC-র প্রচলিত কিছু প্যারামিটার যোগ হয়।

কাস্টম JVM প্যারামিটারও একই জায়গায়। ভুল প্যারামিটারে গেম সরাসরি চালু হবে না, নিশ্চিত না হলে বদলাবেন না।

## চালুর আগে মেমরি অপ্টিমাইজ

চালু থাকলে GPCL গেম চালু করার আগে নিজের প্রসেসের কিছু মেমরি ছেড়ে দেয়। এটি শুধু লঞ্চারের নিজের প্রসেস পরিষ্কার করে, চলমান Minecraft-এ হাত দেয় না, লগইন অবস্থাও মুছিয়ে দেয় না।

হার্ড ডিস্কে (HDD) এই ধাপে সামান্য আটকে যাওয়া স্বাভাবিক।
