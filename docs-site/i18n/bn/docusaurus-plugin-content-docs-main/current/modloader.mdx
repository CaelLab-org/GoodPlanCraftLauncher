ডাউনলোড পেজে ভার্সন বাছাইয়ের সময় সরাসরি লোডারও বেছে নেওয়া যায়। GPCL আগে ভ্যানিলা ইনস্টল করে, তারপর লোডার আলাদা ভার্সন ফোল্ডারে ইনস্টল করে — ভ্যানিলার উপর লেখা হয় না।

## কীভাবে ইনস্টল

1. ডাউনলোড পেজ খুলে একটি Minecraft ভার্সন বাছুন।
2. লোডার অপশনে Forge, Fabric বা OptiFine বাছুন, তারপর সংশ্লিষ্ট লোডার ভার্সন।
3. ডাউনলোডে ক্লিক করে ভ্যানিলা ও লোডার দুটোরই ইনস্টল শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
4. লঞ্চ পেজে ফিরে লোডারের নাম থাকা ভার্সন বেছে চালান।

ডাউনলোড টাস্ক কিউতে যায়, পরপর কয়েকটি ভার্সন ক্লিক করা যায়; চলমান টাস্ক বাতিলও করা যায়, বাতিলের পরে কিউ এগোতে থাকে।

## তিন লোডারের মধ্যে কোনটি

| লোডার | উপযুক্ত | খেয়াল রাখুন |
| --- | --- | --- |
| Forge | বড় মডপ্যাক, পুরোনো মড | Fabric-এর চেয়ে ধীরে চালু হয়, ভার্সন অনেক |
| Fabric | হালকা মড, নতুন ভার্সন | গেম ভার্সন অনুযায়ী সঠিক Fabric Loader বাছতে হয় |
| OptiFine | শেডার, পারফরম্যান্স উন্নতি | অন্য লোডারের সঙ্গে মেশালে কম্প্যাটিবিলিটি মড লাগতে পারে |

### Forge

ইনস্টলের সময় GPCL শুধু `--installClient` চালায়, GUI বা সার্ভার প্যারামিটার চেষ্টা করে না। ইনস্টলারের আউটপুট অগ্রগতিতে দেখায়, যেমন "Forge ইনস্টল হচ্ছে: Downloading library…"।

ইনস্টলের আগে Java-র বড় ভার্সন যাচাই হয়; Forge-র প্রয়োজনের চেয়ে কম হলে সরাসরি এরর দেখায়, কম ভার্সনের Java দিয়ে জোর করে চালায় না। পুরো প্রক্রিয়া সর্বোচ্চ 15 মিনিট অপেক্ষা করে; ডাউনলোড বাতিল করলে ইনস্টলার প্রসেস শেষ হয়।

### Fabric

GPCL সরাসরি Fabric-এর ভার্সন প্রোফাইল ও লাইব্রেরি ফাইল নেয়, ইনস্টলারের উপর নির্ভর করে না।

"সঙ্গে Fabric API ইনস্টল করুন" ডিফল্টে টিক দেওয়া; Fabric ইনস্টলের পরে মিলে যাওয়া ভার্সনের Fabric API ওই ভার্সনের `mods`-এ রাখা হয়। টিক তুলে নিলে ইনস্টল হবে না; Fabric API ব্যর্থ হলে শুধু বার্তা দেখায়, Fabric-এ ক্ষতি হয় না।

### OptiFine

OptiFine সাইলেন্টভাবে ইনস্টল হয়, তার নিজের GUI ইনস্টলার খোলে না। ফলাফল চলমান গেম ফোল্ডারেই পড়ে, কাস্টম গেম ফোল্ডারও ঠিকভাবে সামলানো হয়।

## মড কোথায় রাখবেন

নতুন ডাউনলোড করা ভার্সনে ডিফল্টে **ভার্সন আইসোলেশন** চালু: গেম ফোল্ডার `versions/<version-name>`-এর দিকে যায়, মড, সেভ ও গেম সেটিংস ওই ভার্সনের সঙ্গেই চলে।

| ভার্সনের অবস্থা | মড ফোল্ডার |
| --- | --- |
| নতুন ডাউনলোড, আইসোলেটেড | `versions/<version-name>/mods` |
| আগে থেকেই আছে, আর ভার্সন ফোল্ডারে `mods` / `saves` নেই | গেম রুটের নিচে `mods` |

লঞ্চ পেজে ভার্সনের "ভার্সন সেটিংস" খুলুন; ফোল্ডারের এন্ট্রি আসল আইসোলেশনের ফলাফল অনুযায়ী তৈরি হয়:

- "ভার্সন ফোল্ডার" সবসময় থাকে;
- Forge / Fabric / NeoForge / Quilt পাওয়া গেলে "Mod ফোল্ডার" দেখায়;
- OptiFine পাওয়া গেলে "শেডার ফোল্ডার" দেখায়।

যেকোনো ফোল্ডারে সরাসরি মড ইনস্টল করতে চাইলে মড ডাউনলোডের ইনস্টল লক্ষ্যে "ফোল্ডার বাছুন" বেছে নিন — এটি সেই ফোল্ডারের ভিতরের `mods` খুঁজে নেয়।

## ইনস্টলের পরে ক্র্যাশ

1. আগে `mods`-এর সব মড সরিয়ে একবার মড ছাড়া চালান।
2. চলে গেলে প্রতিবার অর্ধেক মড ফিরিয়ে দিয়ে সমস্যার মড খুঁজুন।
3. নিশ্চিত করুন মড Minecraft ভার্সন ও লোডার ভার্সন দুটোর সঙ্গেই মেলে — Forge-এর মড Fabric-এ সরাসরি ফেলা যায় না, উল্টোটাও একই।
4. প্রয়োজনীয় ডিপেন্ডেন্সি না থাকলেও চালুর সময় ক্র্যাশ হয়; আগে [মড ডাউনলোড](./mods.mdx)-এ দেখুন কী কী ডিপেন্ডেন্সি দরকার বলা আছে।

OptiFine-কে Forge / Fabric-এর সঙ্গে মেশালে সাধারণত আলাদা কম্প্যাটিবিলিটি মড লাগে। উপযুক্ত কম্প্যাটিবিলিটি মড ছাড়া জোর করে ইনস্টল করবেন না।

আরও যাচাইয়ের ধাপ [গেম ক্র্যাশ](./mc-game.mdx)-এ আছে।
