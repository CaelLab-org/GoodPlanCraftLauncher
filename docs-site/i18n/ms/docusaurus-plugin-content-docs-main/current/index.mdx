GoodPlanCraftLauncher (selepas ini GPCL) ialah pelancar Minecraft untuk Windows. Dokumentasi ini hanya menerangkan **cara menggunakan selepas dipasang dan cara menyiasat apabila berlaku masalah**: tiada log perubahan, dan tiada sejarah projek.

| Permainan tersekat, memori tidak cukup, ralat Java | [Java dan memori](./java-memory.mdx) |
| Pasang Forge / Fabric / OptiFine | [Pemuat mod](./modloader.mdx) |

| Tukar tajuk tetingkap permainan | [Kata ajaib tajuk tetingkap](./magic-words.mdx) |

:::tip Sahkan versi dahulu
Halaman ini ditulis untuk 1.9.0. Versi semasa boleh dilihat dalam **Tetapan → Perihal**; jika versi jauh berbeza, kedudukan sesetengah pilihan mungkin berlainan.
:::

## Apa yang perlu dihantar jika ada masalah

Hantar e-mel ke [gamets@caellab.com](mailto:gamets@caellab.com). Sertakan perkara berikut dan biasanya masalah boleh dikenal pasti:

- versi pelancar, versi Minecraft dan mod yang dipasang;
- apa yang dilakukan sebelum ranap (baru pasang mod? tukar Java? ubah memori?);
- **laporan ralat yang dieksport oleh GPCL** (butang "Eksport laporan ralat" pada tetingkap ranap).

Hanya menghantar tangkapan skrin tetingkap ranap biasanya tidak cukup maklumat.
