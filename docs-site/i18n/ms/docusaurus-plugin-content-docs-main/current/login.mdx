GPCL menyokong dua kaedah log masuk dan boleh bertukar pada bila-bila masa. Log masuk luar talian tidak memerlukan rangkaian, tetapi tidak boleh menyertai pelayan yang mengaktifkan pengesahan rasmi.

## Log masuk luar talian

Di halaman pelancaran, masukkan nama pemain untuk melancarkan; kata laluan tidak diperlukan. 5 nama yang terakhir digunakan akan kekal dalam senarai juntai bawah, dan boleh dipadam satu demi satu.

- Sesuai untuk permainan pemain tunggal, LAN, dan pelayan tanpa pengesahan rasmi.
- Tidak memerlukan pengesahan rangkaian; boleh dilancarkan walaupun tanpa Internet.
- Tidak boleh menyertai pelayan yang mengaktifkan pengesahan rasmi; anda akan ditendang keluar.
- Jangan gunakan ID rasmi orang lain: pelayan dan pemain lain mungkin menyalah anggap identiti anda.

## Log masuk rasmi Microsoft

1. Di halaman pelancaran, klik "Log masuk rasmi".
2. GPCL akan membuka pelayar lalai dan menuju ke halaman log masuk Microsoft.
3. Log masuk dan setujui kebenaran; pelayar akan memberitahu bahawa anda boleh kembali ke pelancar.
4. GPCL menerima keputusan secara automatik; nama pemain ditentukan oleh akaun.

Log masuk menunggu paling lama 2 minit. Jika tiada tindak balas, pastikan log masuk dan kebenaran telah selesai dalam pelayar dahulu, kemudian semak rangkaian.

Pelancar akan menyimpan status log masuk; anda tidak perlu log masuk semula pada pembukaan seterusnya. Mengklik "Optimumkan memori sebelum melancarkan permainan" juga tidak akan menghapuskan status log masuk.

## Cara memilih antara dua mod

| Senario | Kaedah |
| --- | --- |
| Permainan pemain tunggal, bermain sendiri | Luar talian atau rasmi, kedua-duanya boleh |
| Pelayan dengan pengesahan rasmi | Mesti rasmi |
| Pelayan tanpa pengesahan rasmi | Luar talian atau rasmi, kedua-duanya boleh |
| Tiada rangkaian | Luar talian |

## Bertukar akaun

Dalam keadaan log masuk rasmi, klik butang rasmi sekali lagi untuk log keluar, kemudian anda boleh menggunakan nama luar talian. Dalam keadaan luar talian, mengklik log masuk rasmi akan terus memasuki aliran log masuk Microsoft.

## Pelayan memaparkan Invalid session

Selalunya status log masuk telah tamat tempoh, atau akaun ini tidak mempunyai kebenaran untuk versi tersebut:

1. Log keluar dari akaun dan lakukan log masuk rasmi sekali lagi;
2. Pastikan akaun memang memiliki versi Minecraft ini;
3. Cuba pelayan rasmi yang lain untuk mengecualikan masalah pelayan tunggal.
